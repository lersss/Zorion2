## Границы на всю сессию

- Работай в пределах одного пакета Go или одной папки JS. Не разливайся по проекту.
- Нужен файл — открывай его по имени, а не ищи по всему дереву.
- Комментарии в коде не добавляй без просьбы.
- **Git — по правилу 44a** (идея — в `docs/gamedesign/ideas/_archive/`): не трогай до полной приёмки создателем; после
  приёмки код своей зоны коммитит @developer, артефакты (идеи/спеки) — @manager,
  явными путями без `git add -A`; горячие доки — только через @dispatcher.
- Перед каждой правкой перечитывай файл — над проектом работают параллельно.

**Готово** только когда прошёл DoD из `AGENTS.md` §2 (быстрый цикл с детектором
гонок; тяжёлый генераторный прогон — если тронут генератор).

Не отчитывайся об успехе без его прогона. В конце: что изменил (`файл:строка`),
