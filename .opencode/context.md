## Принятые решения создателя (свежие)

- 2026-09-16: сетка из 7 векторов (Генерация, Новые механики, Поселения, Агенты, Визуал, Баги, Игрок) утверждена, подсказка `docs/VECTORS.md`; открыта развязка «Поселения» ↔ «Новые механики» (Вариант 1/2).
- 2026-09-15: коммит-ответственность на команды — команды коммитят код в свои зоны сами (менеджер — спеки/идеи, developer — код, по гейтам); горячие доки только дельтами на @dispatcher (идея 44a).
- 2026-09-14: «События» в карточке поселения — это **лог** (результат, не происшествие); отдельная таблица `settlement_log`; расширяемость под много типов; общую систему событий вселенной не строим.
- 2026-09-14: Бэкфилл отменён — «Если не было события, то и записи о нем никакой нет. Вообще не надо старых обслуживать».
- 2026-09-14: Причина «Вымерло» при равенстве вкладов — температура → гравитация → радиация.
- 2026-09-14: перекалибровка температуры (14b) — модульная «формула изменения населения» (R_total = R_ест + R_темп + λ) вместо жёсткого нуля/экспоненты; жёсткий ноль-обнуление отменён (эталон «порог-переключатель запрещён»); возрастной потолок 120 лет.
- 2026-09-13: подход «близнецы» для проверки гипотез (параметрический генератор с планами осей заброшен как переусложнённый); по одной звезде на группу, варьируется ровно одна ось.
- 2026-09-13: тир при генерации не задаётся (колонка `settlements.level` удалена); население — стратегия модели (fixed/random).
- 2026-09-13: заводы будут создаваться отдельно — удалить старую логику генерации заводов из `GenerateSettlements` (прототипное наслоение).
- 2026-09-13: гипотезы `requiem`/`only_green` урезаны до `math.MaxInt32` (B22), верхняя граница населения в валидации.
- 2026-09-12: CI (в т.ч. `-race`) и бэкапы БД отложены до версии 1.0; локальный DoD = `go build` + `go vet` + `go test ./...`.
