## 2026-09-15 — NPC-агенты, смертность населения, гипотезы-близнецы, модель поселения, лог «Вымерло»

**Реализовано:**
- Модель поселения целиком (`13_tiers.md`): население — объём труда, тир — качество труда; тир растёт от подушевого излишка; два потолка населения (подножный корм — не хранится, привозная еда); нагрузка — вектор товаров, покрытие рваное; прогресс тира в товарах; природный потолок тира; естественный запас «сливки»; деньги — три потока (`14_money.md` §14.3.0); словарь `docs/GLOSSARY.md` (~130 терминов, расхождения P1–P5); дыра «у робота нет квалификации» закрыта снабжением деталями (`13_tiers.md` §13.9.6).
- NPC-агенты v1 (`20a`): автономные наблюдатели (рандом в радиусе 1000), метят мир посещённым, пуш `npc_arrivals_batch`, ромбы на карте; архитектура под сотни тысяч (batch 2000/тик, сетка 1000, `PositionCache`); таблица `npc_agents` (`000026`), `/admin/npc*` + `/api/npc/positions`, вкладка «NPC». FAQ NPC: 9/9 закрыты.
- Минимальная модель смерти населения (`18a_population_death.md`): `TwoSidedSeverity`/`OneSidedSeverity`, формула `p0·exp(−λ·Δt)`, миграция `000021` (`settlements.population_exact`), экстраполяция на фронте, `GET /admin/mortality-preview`.
- Вкладка «Проверка гипотез» (близнецы): канонический шаблон клонируется N раз, одна варьируемая ось (`twin.go`), джоб `hypothesis`, `/admin/hypothesis/run`, тег `_experiment.{id,group}`, вкладка «🔬 Гипотезы».
- Калибровка температурной смертности (`99.2.12`): квадратичная тяжесть, `SatHot=200`/`SatCold=350`, жёсткий ноль T ≥ 700 K, `MaxRatePerHour` 0.01 → 0.1/час (500 K → t50% ≈ 12 ч).
- Перекалибровка температуры (`14b`): модульная формула `R_total = R_ест + R_темп(T) + λ-факторы`, `R_ест ≈ 6.34·10⁻¹⁰/сек` (2%/год), двухрежимная сшивка по контрольным точкам, возрастной потолок 120 лет.
- Лог поселения «Вымерло» (`16a`): таблица `settlement_log` (`000024`), запись той же транзакцией синка, дата — пересечение порога `NDead` по R-модели, причина — доминирующая компонента среды, UI «💀 Вымерло · дата · причина», до 3 записей.
- Плавное движение NPC-агентов между сэмплами (`25a`): клиентская линейная интерполяция позиций летящих между опросами 5с (лаг в один опрос — в сэмпле нет временных меток сервера), лёгкий rAF-цикл только при летящем агенте в вьюпорте, клик и поворот спрайта от интерполированной позиции. Реализация спеки 20a.1 §7 («при полёте иконка движется между сэмплами»).
- Массовая генерация NPC-агентов (26a): слоговый генератор имён «Имя Фамилия» (~7 млн пар, уникальность между пачками), POST /admin/npc/generate (фоновый джоб, COPY-вставка, без лимита, стартовые миры случайные), пагинация списка (keyset, миграция 000029), поиск агента на карте (имя/UUID, центрирование, подсветка), глобальный рубильник пушей (по умолчанию выкл), метрики (очередь на тик, лаги, время генерации), POST /admin/npc/clear «удалить всех агентов», тултип агента по наведению, имена агентов убраны с карты.

**Исправлено:**
- B27 (кнопка «Найти меня» молчала) — `clearUniverseTx` обнулял `current_world_id`; хелпер `assignCurrentWorldsTx` назначает ближайший к центру мир роли `skycomposer`.
- B28 (браузерный WS-тост NPC не работал) — `AuthMiddleware` читает JWT из query `?token=` только для пути `/ws`; реконнект ≤5 попыток.
- B29 (вкладка «Корабли» в админке пустая) — `tab-ships` был вложен в `tab-users` (незакрытый `</div>`), контент скрыт родителем `display:none`; фикс — закрывающий тег (25b).

**Дополнительно:**
- FPS-счётчик в нижнем левом углу карты для ролей admin/skycomposer (инструмент создателя) (28a).
- AGENTS.md §1/§5 устарели — админка на JWT-ролях (admin/skycomposer), а не X-Admin-Password; `zorion-server.exe` добавлен в `.gitignore` (26a).

## Ранняя сессия (без даты) — описания планет, кластеризация карты, безопасность

**Реализовано:**

- Миграция `000010` (`assignments.type/reward`); JWT-секрет из env (`JWT_SECRET`, ≥ 32 байта, `log.Fatal` при пустом).

**Исправлено:**
- `concurrent map writes` в `PlanetGenerator` (паника сервера) — `sync.Mutex` на кэш/`rand`; concurrent write в `WebSocketHub` — per-connection мьютекс; race в `TravelManager`/`StatusManager` (`TryStart`); паника от `r.(string)` в `recover`.
- Классификатор планет: ледяная требует `ShareOf(Glaciers) >= 30` (было 28% перекоса), органик — биосфера ≥ 25% вместо доминанты (тип был почти недостижим), стекло/металл — пороги 15 → 10.
- `ClearUniverse` падала с `upstream request timeout` — `clearUniverseTx`: `TRUNCATE` без CASCADE + явный список таблиц + временное снятие FK у `users`.
- `GetWorld` 500 при несуществующих locations/assignments (→ 404); `column "type" does not exist` → миграция `000010`; `superfluous WriteHeader`.
- `.env` удалён из индекса (был локальный дев-конфиг, не прод-секреты), добавлен в `.gitignore`.

**Дополнительно:**
- Удалены: `docs/CONTEXT.md` (→ `STATUS.md` + `docs/ARCHITECTURE.md`), `docs/readme.gamedev`, `faq_gamedesign.md`, `docs/PROMPT.md` (→ корень); `planet_data_description.go` восстановлен (нужная `clamp`, `generateDescription` — мёртвый код).
