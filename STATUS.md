## 3. Что дальше

Порядок по соотношению «риск / стоимость»:

1. **Бэкапы БД** — `pg_dump` по расписанию. Таблица `users` с паролями уже терялась однажды (см. `AGENTS.md` §8). До любого роста нагрузки.
2. **CI** (`.github/workflows/ci.yml`): `go build` + `go vet`. Сейчас CI нет вообще. `go test -race ./...` из DoD локально не запускается — нужен cgo, gcc в PATH нет. Тесты уже есть (`mapcache`, `generator/planet`, `generator/galaxy`, `repository`, `handlers`, `auth`); `-race` на них гоняется только на CI, которого нет. См. §4.
3. **`VACUUM (ANALYZE)` на проде** — после массовой перегенерации галактики карта видимости холодная (ловушка `AGENTS.md` §8): фильтры по `planets.data` деградируют с 63 до 306 мс. Делать руками, миграцией нельзя (не работает внутри транзакции).
4. **Нагрузочный тест** — 100 синтетических клиентов на `/ws`, `/travel`, `/api/contracts`. Рекорд по реальным игрокам — 7, почти наверняка не одновременно. Пока теста нет, «многопользовательская игра» ничем не проверена. Карта теперь снабжена снапшотом — `/api/worlds/filter` из узкого места вышел.
5. **Убрать перемещение из дашборда** — убрать блок/кнопку перемещения с дашборда.
6. **Попап звезды** — при открытии сейчас сразу показывается список планет. Перенести его в инфо по звезде (компактно, можно второй колонкой рядом с информацией о звезде); если планета не выбрана — показывать инфо по звезде (в т.ч. по клику в пустое пространство).
7. **Градации цвета звёзд на карте** — оттенки по светимости с небольшим разбегом, чтобы визуально различать звёзды одного спектрального класса.
8. **Плотность звёзд к краям карты** — чем ближе к краям, тем плотность должна снижаться (сейчас края не разрежены).
9. **Генератор веществ** — блокер снят, перевывод номенклатуры выполнен. Порядок работ: универсальный слой → генератор полей → месторождения (`99_roadmap.md` §99.2.5). Дизайн: `09_resources.md`, `05_economy.md` §5.2.1.
10. **Прототип поселения** — таблица `settlements` пишется, но не читается: `stability` не используется нигде, вкладка «Поселения» в модалке — заглушка. Первый вертикальный срез от `13_settlements.md`: потребности → стабильность → карточка.

Долгосрочный бэклог — `docs/gamedesign/99_roadmap.md`.

- **`-race` в definition of done.** `AGENTS.md` §2 называет его основным инструментом против риска из §0, но локально он не запускается — нужен cgo, gcc в PATH нет. Тесты при этом есть в 11 пакетах и проходят. Ставить mingw локально или оставить `-race` только в CI?

Аргумент: вселенная уже готова (100k миров), а контракты существуют как `/api/contracts/complete-test`.
- **`.env` в истории git** (`5253b8c` → `44e3cfc`). Чистить историю или просто ротировать креды? Практично второе, и это совпадает с B6.
- **Блок «корабли/полёты»** — фиксировать в GDD или оставить как есть?
