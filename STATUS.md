### 2.6. Инцидент и фикс: очистка вселенной ⚠️→✅

**Что было:** кнопка «Очистка вселенной» в админке падала с `upstream request timeout`
на 100k миров. Причина: `DELETE FROM worlds` — долго, Amvera-прокси рвал соединение.

**Первая попытка фикса:** `TRUNCATE worlds CASCADE`. Оказалось **опасно**:
`TRUNCATE CASCADE` работает на уровне **таблиц**, а не строк, и не учитывает
`ON DELETE SET NULL`. Таблица `users` (у неё FK на `worlds`) была снесена целиком
вместе с паролями.

**Итоговый фикс:** `TRUNCATE` **без** CASCADE + явный список зависимых таблиц
+ временное снятие FK у `users`. Всё в одной транзакции. Работает мгновенно,
`users` не трогает.

**Файл:** `internal/handlers/admin_universe.go`, функция `clearUniverseTx`.

**Урок (зафиксирован в `docs/ARCHITECTURE.md`, раздел 4):**
`TRUNCATE ... CASCADE` **не безопасен** там, где есть таблицы, которые нельзя терять,
но они формально ссылаются на очищаемую. Использовать `TRUNCATE` без CASCADE
+ явный список + временное снятие FK.

### 2.7. Спутники — формы поверхности ✅

- Спутниковые формы: `реголит`, `ледяная_кора`, `криовулканы`, `тектонические_разломы`,
  `гейзерные_поля` (`composition_forms.go`, `AllSatelliteSurfaceForms`).
- ~1.5% спутников — «планетарные» с обычными планетными формами.
- Диспетчер `generateSatelliteSurface` + ветви `generateTypicalSatelliteSurface` /
  `generateSatellitePlanetarySurface`; недра коррелируют с водой/льдом;
  `satelliteDescription` переписана. Файл: `planet_data_satellites_physics.go`.
- Иконки и цвета форм — `web/static/js/modal/tabs.js`.
- Юнит-тесты (временные): доля планетарных 1.520% — пройдены.

### 2.8. Фикс: пустые системы (planets null) ✅

- Для миров без планет (12 963 шт.) `GetPlanetsByWorld` отдавал `"planets": null` →
  `planets.forEach is not a function` в модалке (B-фикс в этой сессии).
- Исправлено: хендлер всегда отдаёт `[]` (`planet_handler.go`), фронт защищён
  `Array.isArray` (`index.js`).

### 2.9. Перегенерация вселенной ✅

- 100k миров, `mapSize=1 400 000` (координаты до ±700k — как прежняя карта),
  `minDist=150`, кластеры 20 (радиус 1200), спейсинг 200, выбросы 30%.
- Итог: миров 100 000, планет 319 573.
- **Статистика классификатора (факт, 256 251 не-гигант):** ледяная 36.5%,
  газовый гигант 19.8%, пустынная 14.0%, землеподобная 11.0%, вулканическая 10.5%,
  скалистая 6.6%, океаническая 6.0%, органик 1.5%, радиоактивная 1.3%,
  стеклянная/металлическая 0%. **Решение: баланс не корректировать.**
- **Спутники (412 965):** доминанта преимущественно `ледяная_кора` (~94.5%),
  планетные формы ~1.8% (ветка планетарных спутников), имена `Звезда-XXXX`,
  fallback «Спутник-» = 0.
