# Внешний участник Zorion — первый вход и правила

> Для тех, кто работает над Zorion по приглашению. Как поднять проект локально —
> не дублируется здесь: смотри `AGENTS.md` §1 и `docs/DEPLOY.md` §2.

**Репозиторий:** `https://github.com/lersss/Zorion2` (главная ветка — `master`)

---

## 1. Разверни локально

- Скопируй `.env.example` в `.env` и заполни доступы.
- Подними локальные сервера — `start-all.cmd` в корне проекта.
- Проверь, что отвечает `/health`.

Подробности — `AGENTS.md` §1 и `docs/DEPLOY.md` §2.

## 2. Работай с ролью `contributor`

- В opencode выбери роль **contributor** — это твоя приёмная: она поможет довести
  идею до готового предложения.
- Чтобы сессия стартовала сразу с неё, укажи её личной главной ролью. Файл
  `~/.config/opencode/opencode.json` (на Windows —
  `%USERPROFILE%\.config\opencode\opencode.json`):

  ```json
  { "$schema": "https://opencode.ai/config.json", "default_agent": "contributor" }
  ```

  Это твой личный выбор — на других он не влияет. Не хочешь настраивать — просто
  выбери роль из списка при старте.
- После правки настроек **перезапусти opencode** — роли и настройки читаются один
  раз при старте.

## 3. Как идёт работа

- **Перед задачей** обнови `master` из общего репозитория.
- Работай в отдельной **короткой** ветке (часы, максимум день-два).
- Готово — пришли ветку в общий репозиторий и открой предложение влить в `master`.
- **В `master` не пишет никто, кроме создателя** — он и вливает.
- **Одна задача за раз:** файлы общие, за одно и то же вдвоём не берёмся.

## 4. Чего не делать

- Не писать в `master`.
- Не править горячие сводные документы (`STATUS.md`, `docs/INDEX.md`,
  `CHANGELOG.md`, `99_roadmap.md`, `faq_counter.md`, `.opencode/context.md`) — их
  пишет только `@dispatcher`. Нужна правка — скажи создателю.

## 5. Что приложить к предложению

Сводку для создателя (её соберёт роль `contributor`):

- **Что сделано** — простым языком, 2–4 строки.
- **Что затронуто** — какие связанные механики могут отреагировать.
- **Сомнения и конфликты** — что оставляешь на решение создателя.
- **Как проверено** — что прогнал `@tester`, что зелёное.
