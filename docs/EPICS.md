> Доска прогресса по эпик-идеям. Владелец — `@manager`. Одна строка на эпик:
> **идея → текущий чекпоинт → что дальше**. Сами чекпоинты и детали живут в идее
> (`docs/gamedesign/ideas/`), здесь — только сводка. Состояние проекта целиком —
> `STATUS.md`; долгосрочный план — `docs/gamedesign/99_roadmap.md`.

## Как ведётся

- Эпик-идея держит **внутри себя** список чекпоинтов (✅ пройден / 🔄 идём / ⬜ ждёт) и раздел «Дальше».
- Здесь обновляется **одна строка на эпик** — при прохождении чекпоинта (`@manager`).
- Роадмап держит только «блок в работе / сделан», без чекпоинтов.
