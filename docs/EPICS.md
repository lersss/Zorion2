## Как ведётся

- Эпик-идея держит **внутри себя** список чекпоинтов (✅ пройден / 🔄 идём / ⬜ ждёт) и раздел «Дальше».
- Здесь обновляется **одна строка на эпик** — при прохождении чекпоинта (`@manager`).
- Роадмап держит только «блок в работе / сделан», без чекпоинтов.
