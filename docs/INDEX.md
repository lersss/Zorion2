# docs/INDEX.md — карта документации Zorion

> Зачем: агент должен найти нужный док, не читая всё подряд. **Один факт — одно
> место**: описания здесь не дублируют содержимое доков, а только указывают, где
> какое. Точка входа остаётся в `AGENTS.md` (+ `STATUS.md`) — этот файл сам по
> себе не читается, он читается по ссылке из `AGENTS.md` §7.
> Если задача о конкретном пакете Go — открой его `doc.go` (в каждом пакете).

## Точки входа

| Файл | Что это | Когда |
|---|---|---|
| `AGENTS.md` | стек, команды, структура, правила работы, API | всегда (подгружается автоматически) |
| `STATUS.md` | текущее состояние: фокус, баги, что дальше | всегда вместе с `AGENTS.md` |
| `docs/AGENT_RULES.md` | как писать код (минимум, хирургия, критерий успеха) | подгружается автоматически, открывать не нужно |
| `docs/GLOSSARY.md` | ~130 терминов, §1 разбирает многозначные слова | встретил незнакомый термин |

## Как читать пакеты Go

У каждого пакета в `internal/` и `pkg/` есть `doc.go` — 1–3 строки о назначении.
Открывай его первым делом, затем — файлы по имени. Поиск по коду —
`grep`/`rg` по `file_path:line`, точные пути в архитектуре `ARCHITECTURE.md` §2.
