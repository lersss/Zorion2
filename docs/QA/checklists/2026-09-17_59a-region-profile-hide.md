# QA-прогон: скрытие типа профиля региона у игроков (59a, отображение по роли)

**Дата:** 2026-09-17
**Тестировщик:** @tester
**Вектор:** Игрок (карта/фронт)

## Контекст

Правка `web/static/js/map/map_render.js`: вторая строка под названием региона
(тип профиля, отладочный вывод 59a) теперь рисуется только для ролей
`admin`/`skycomposer` (новая константа `REGION_PROFILE_ROLES`), у обычных игроков —
только название региона. Сервер не менялся, `/api/regions` по-прежнему отдаёт
`profile` всем — отображение режет клиент (решение, как у FPS-счётчика).

## Прогнал

- `node --check web/static/js/map/map_render.js` — OK (exit 0)
- Статический анализ ролей, `state.userRole`, полноты скрытия `profile` по
  `web/static/js/map/` (grep), регресса соседней отрисовки.

## Вердикт

**ПРОЙДЕНО.** Логика ролей корректна (`player` не входит в `REGION_PROFILE_ROLES`),
скрытие полное (единственный гейт `hasProfile`), регресса соседней отрисовки нет,
синтаксис валиден. Правку можно принимать.
