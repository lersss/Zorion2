## Найденное

- Багов 83a не найдено.
- Замечание (не баг, поведение валидатора): при запуске hook'а через sh **без** PATH Git (`sh .githooks/post-commit` из чистого PowerShell) `dirname` не находится (`dirname: command not found`) → путь к скрипту ломается. Git for Windows при исполнении hook'ов сам добавляет свои каталоги в PATH, поэтому штатный прогон после коммита работает (проверено с PATH Git: валидатор отработал). Это не баг реализации, но hook зависит от окружения git — если когда-нибудь hook будет исполняться вне git (ручной запуск), он упадёт. Решение за @manager: можно заменить `dirname "$0"` на фиксированный относительный путь или `cd "$(dirname "$0")/.."` — не критично.
