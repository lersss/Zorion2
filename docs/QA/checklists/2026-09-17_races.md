## Найденное

### Блокер: кнопка «Сгенерировать поселения рас» не работает (ReferenceError)

- `web/admin.html:434` — `onclick="generateRaceSettlements()"`.
- `web/static/js/admin/main.js:5-12` — импорт из `generation.js` НЕ включает `generateRaceSettlements`; в блоке `window.*` (строки 26-73) функция НЕ вывешена на window.
- `web/static/js/admin/generation.js:633` — функция экспортируется как ES-модуль, но в глобальную область не попадает.
- Итог: клик по кнопке → `ReferenceError: generateRaceSettlements is not defined`. Карточка админки (пункт 5 фичи) через UI не работает. Серверный хендлер при этом исправен (тесты проходят).

### Минор: отчёт по незаселившимся расам не показывается в UI

- `web/static/js/admin/poll.js:30-60` — для job `generate_race_settlements` нет ветки отображения `data.report` (хендлер его формирует, `admin_race_settlements.go:102-105`, и `GenerateStatus` отдаёт в `report`). Вместо отчёта — generic `✅ Готово! (N объектов)`, где N = число планет (total из TryStart), а не число поселений.
