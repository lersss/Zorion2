## Найденное

Блокеров нет. Замечания (не баги, UX-мелочи):

1. **`resources.js:171-183` — имя расы в колонке «Раса» при активном фильтре оси.**
   Имя выводится по `idx === 0` (первая ось в массиве расы), а не по первой
   *видимой* строке. При выборе оси в фильтре (например ОРГ) у рас, чья первая
   ось — не ОРГ, колонка «Раса» пустая (данные строки видны: ось/вес/ресурсы/статус).
   Не потеря данных — имя расы есть в селекте фильтра. Косметика.

- **Живой браузер (UX вкладки):** фильтры, тултипы, пустые состояния, «Обновить» —
  проверены статически по коду + node --check; окружение без браузера. Создателю:
  открыть админку → вкладка «📦 Ресурсы» → поиграть фильтрами (категория/тип/поиск,
  раса/ось), навести на «Ключевые оси» (тултип полного профиля), нажать «Обновить».
- **Соседние вкладки в живом браузере:** import-граф проверен статически
  (main.js/tabs.js) и node --check; реальное переключение вкладок — только в браузере.
- **Экстремальные входы хендлера:** «каталог рас не загружен → 500» — на живом
  сервере каталог всегда загружен (main.go грузит до старта HTTP); покрыто тестом
  `TestAdminResourcesNoRaceCatalog` (200 или 500, без паники).
- **Доли 5–9 (мостовые) и < 5 (микронутриенты):** критерий §8.1 проверяет только
