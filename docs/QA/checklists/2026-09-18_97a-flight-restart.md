Замечание окружения (не баг фичи): `Start-Process` с `-RedirectStandardOutput` в PowerShell
обрывает команду тестера ("ChildProcess.kill") — сервер при этом стартует, но команда не
возвращает вывод. Для рестартов в прогоне использован `Start-Process` без редиректа — работает
стабильно. Это ограничение окружения, не кода.
