## Найденные проблемы

1. **[некритично, операционная] Сервер был поднят со старым бинарником** (`C:\Users\admin\AppData\Local\Temp\opencode\zorion-server.exe`, старт 18.09 21:33 — до правок фичи): `GET /api/encyclopedia/races` отдавал только старые поля лора (`character/how_live/why/coexistence/origin`), новых полей не было. После перезапуска `go run ./cmd/server` (пакетом, не файлом — иначе `undefined: bootstrapSkycomposer`) все новые поля на месте. Это не баг кода фичи, а напоминание AGENTS.md §4.13 (перезапуск после правок рантайма). Код фичи корректен.
2. **[некритично, тест-артефакт] Ложное срабатывание первого e2e-варианта:** проверка «нет слова „Рой“» по всей карточке людей падала из-за подстроки «рой» в слове «которой» в лоре людей. Спека требует отсутствие size_group именно в блоке «Вид · Ниша · Размер» — проверка переписана на блок (точная проверка §2 п.5). Не баг фичи.
3. **[ограничение прогона] Скриншоты не просмотрены визуально** — модель @tester не поддерживает чтение изображений. Содержимое карточек подтверждено DOM-проверками e2e (слова, блоки, лор); скриншоты сохранены в `tools/e2e/artifacts/` для создателя.

## Не проверено (чеклист непроверяемого)

- **Визуальный UX карточки глазами игрока** (вёрстка, читаемость, эстетика) — модель не видит скриншоты; нужно создателю/игроку открыть дашборд → Энциклопедия → Расы.
- **Открытие расы «настоящей встречей»** (модалка системы с поселением → журнал) — в e2e раса добавлена в журнал напрямую (презентационный слой, 86a §7.3); полный флоу «модалка → журнал → карточка» не гонялся (не входит в чек-лист фичи, хук журнала — зона 86a).
- **Ступени-резервы шкал** (завоеватели/переговорщики/хрупкие/почти неразрушимые) — пусты в текущих 60 расах, недостижимы штатно; покрыты юнит-тестами границ (`TestScaleBoundaries`).
