## Не проверено (граница покрытия)

- **Живой ИИ «заполнить комплектующие»** (вставка карточек по одной на слот): POST fill → 202
  проверен, но результат генерации зависит от запущенного opencode на 127.0.0.1:3456 — в прогоне
  opencode не проверялся (контракт эндпоинта и промпт по вычисленному тиру покрыты юнит-тестами
  `handlers`/`ai`). Нужно: запущенный opencode + живой прогон fill на товаре с оверрайдом (промпт
  должен получить вычисленный тир, не оверрайд).
- **DAG-артефакт раскладки** (родитель-родитель в подграфе): в текущих данных такого подграфа нет —
  визуальная проверка невозможна штатно.
- **Визуально-UX** (перетаскивание попапа за заголовок, подсветка выбранного, приглушение забаненных
  в подграфе): проверено функционально (селекторы/состояния), эстетика — глазами создателя.
- **localStorage `gs_spravBanned`/`gs_fullTree`** персист: проверен `gs_fullTree` (шаг 14), полный
  цикл reload для `gs_spravBanned` не гонял (галка работает, localStorage-запись в коде есть).
