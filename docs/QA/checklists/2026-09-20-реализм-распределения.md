## Найденные проблемы

1. **[баг, minor] Сверхгиганты («прочая экзотика») могут получить газового гиганта — нарушение спеки §4.2 и 99.2.4 §5.3.** `internal/generator/planet/planet_data.go:263-266` — гейт `rollGiantOrbit` исключает только `isExoticObject(w.StarType)` (ЧД/НЗ/WD/протозвезда) и `isCircumbinary`. Сверхгиганты в продакшене — `StarType: "star"` + `Phase: "I"` (`galaxy.go:553-569`), поэтому `isExoticObject("star")` = false → `rollGiantOrbit` вызывается, и при n ≥ 1 (lbv/wr: mean 0.1 → P(1)=10%; без подтипа: класс-mean O/B 0.3 / A 1) гигант роллится по классу (O/B 0.5%, A 2%) и попадает на орбиту 1 фолбэком «горячий по необходимости». Старый триггер `orbitIndex >= 3` при n ≤ 1 никогда не давал гиганта сверхгигантам — поведение изменилось вопреки «без изменений» в спеке §4.2. Подтверждено временным тестом (удалён): 1 гигант на 1895 сверхгигантов с планетами (lbv/wr); без подтипа (80% популяции, A: n≡1) — чаще. Масштаб ≈ 9–10 гигантов на 20 000 миров (~1% всех гигантов). Аудит не ловит: `exotic_system: true` пишется только в `exotic.go:125` (ветка ЧД/НЗ/WD), сверхгиганты идут общим путём без флага. **Фикс:** в гейт `planet_data.go:264` добавить исключение сверхгигантов (`w.Mods != nil && w.Mods.Phase == "I"` или `IsSupergiantExotic()`).

   **→ ЗАКРЫТ 2026-09-21.** Фикс разработчика: `planet_data.go:269` — гейт `rollGiantOrbit` дополнен `!isSupergiantExotic(w)` (хелпер `isSupergiantExotic` `planet_data.go:319`, `w.Mods.IsSupergiantExotic()` = фаза I + lbv/wr); легаси `GeneratePlanetsForWorld` помечен комментарием (вызовов нет). Подтверждено: (1) регрессионный тест `TestSupergiantNoGasGiant` (`giant_distribution_test.go:301`, мировой поток `generateWorldWithCountIntoBuffer`, count=1, O/B/A × lbv/wr, 1000 итераций, assert «не гигант» + «планеты есть») — PASS; (2) сценарий A-подтверждения (временный тест, естественный поток `generateWorldIntoBuffer`, 20 000 сверхгигантов): 1935 с планетами, **0 гигантов** (до фикса 1/1895); (3) DoD `go test -race ./internal/generator/planet/ -run "TestSupergiantNoGasGiant|TestSmoke20000Worlds"` — PASS (8.75 s / 17.65 s), окна §11 не изменились (G/K/F 9.04%, M 2.87%, O/B 0.21%, A 1.96%, горячие 0.66%, max 7/7, обитаемая 2.47%, планет 75 991); полный пакет planet — зелёный.

## Замечания

1. **[З1] Смоук не применяет металличность.** `giant_smoke_test.go:95` — `stellarParamsFromClass(cls, 0, g.rng)` даёт `Metallicity: 0` (множитель ×1.0), тогда как в продакшене `stellarParamsFromWorld` читает `w.Mods.Metallicity` (роллится galaxy). Фактические доли смоука (G/K/F 9.04%, M 2.87%) — без ×1.045; с металличностью были бы ≈10.45%/3.1%. Окна §11 держатся в обоих случаях, путь металличности покрыт `TestGiantRateByClass`/`TestGiantMetallicityCorrelation` (через `testMetallicity`). Не баг, но смоук не воспроизводит продакшн-путь металличности.
2. **[З2] Смоук моделирует exotic-системы как 0 планет.** `giant_smoke_test.go:68` — `planetCountFor(WorldInfo{StarType: "exotic"})` → 0 (в `planetCountFor` нет ветки "exotic"), в продакшене exotic → сверхгигант (`StarType: "star"`, mean 0.1/класс-mean). Это скрывает П1 и слегка занижает число планет смоука (~430 на 20k). Рекомендация: моделировать exotic как сверхгиганта (StarType "star" + Phase I) — тогда смоук поймал бы П1.
3. **[З3] `TestCascadeSmoke1000` лог-цель «~3–4%» vs факт 1.9%.** `cascade_test.go:253-256` — лог без assert; выборка равномерная по классам и без гигантов (`generatePlanet` напрямую, `giantOrbit` = 0), не галактическое распределение. Фактическая мера §11 — смоук 20k (2.47% ✓). Комментарий может вводить в заблуждение, но не баг.
4. **[З4] `TestDiskCacheBig` флапает в полном прогоне `./internal/handlers/`** (1 из 2 прогонов FAIL «Received unexpected error», в изоляции и на повторе PASS). Файл не относится к фиче (последний коммит f579edf, не в диффе). Зафиксировано для менеджера — возможный флаки-тест окружения (temp-dir/порядок тестов).

## Не проверено (чеклист непроверяемого)

- **Смоук с профилями регионов «как продакшн»** — `TestSmoke20000Worlds` идёт без профилей (`g.profile` = nil). Влияние `gas_giant_shift`/`planet_count_mult` на окна §11 проверено только юнит-тестами (`TestProfileGasGiantShiftClamped`, `TestProfilePlanetCountMult`), не интегрально на 20k. Для закрытия: прогнать смоук с профилями (или принять, что рескейл §4.5 покрыт юнитами).
- **Металличность в смоуке** (З1) — смоук без множителя; закрыто юнитами.
- **Сверхгиганты в смоуке** (З2/П1) — смоук не моделирует; П1 закрыт отдельным регрессионным тестом `TestSupergiantNoGasGiant` + подтверждающим прогоном (см. П1). З2 (смоук моделирует exotic как 0 планет) остаётся открытым замечанием.
- **Живой прогон генерации в БД** (админка «Генерация планет» на реальной вселенной) — не гонялся: требует живого сервера + массовой перегенерации (пишет в БД, ~2× времени по §8). Для закрытия: прогон создателем/менеджером на dev-вселенной + `VACUUM (ANALYZE) planets;` (DEPLOY.md §5).
- **Визуал гигантов/горячих юпитеров на карте** — вне скоупа (серверная генерация; картинка гиганта — тот же тип, правок не требует по §9).
