## Найденные проблемы

1. **[баг, minor] Read-only для skycomposer нарушен: поле «Отображаемое имя» биома редактируемо.** `web/static/js/admin/biomeCatalog.js:410` — `textInput(row1, 'Отображаемое имя', b.name, ..., { width: '160px' })` без `disabled: !admin` (в отличие от всех остальных полей редактора). Аналогично `:581` — «Имя» типа недр. Подтверждено живым браузером под skycomposer: поле активно, правка ставит «⚠️ изменено», сохранить нельзя (кнопка скрыта + `saveBiomeCatalog` проверяет роль → тост «Недостаточно прав»). Нарушает UI-спеку §8 («поля disabled») и §6.1. Сохранение невозможно — ущерб только UX/консистентность, не данные.
