## Найденные проблемы

1. **[операционка, не баг фичи] Dev-сервер крутил старую версию кода.** Запуск сервера 19:17:58, правки фичи 22:32–22:35 (mtime `planet_image_handler.go` 22:35, `main.go` 22:32). До перезапуска `/api/planet-image` без JWT отвечал 200 (старый публичный контракт) — это регрессия B-DB-5 («развёрнутый код = исходники»), не дефект фичи. Перезапустил сервер на актуальном коде (22:57) — после этого без JWT → 401, режимы работают по спеке. Рекомендация: перед приёмкой фичи убедиться, что dev-сервер перезапущен после последних правок.

## Чеклист непроверяемого

- **Админский режим картинки живьём** (admin/skycomposer → честная всегда): нет админского токена (bootstrap-учётки `SKYCOMPOSER_BOOTSTRAP_*` в `.env` нет). Проверено по коду `resolveMode` + тесты `TestPlanetImageHonestForOwn`. Закрыть: дать тестеру админский токен (или bootstrap-учётку) — проверить big-картинку чужой планеты под админом.
- **«Вид с орбиты» для админа без прилёта** (`isAdmin` → orbitViewHtml, `tabs.js:149-160`): живьём не проверено (нет админского токена). По коду — показывается.
- **Экзотические планеты живьём**: в dev-БД нет экзотических типов (все планеты с biomes, кроме гигантов). Проверено по коду (`determineVisualTypeFromInput`/`postVisualType` не падают на любом type) + тесты. Закрыть: сгенерировать мир с экзотикой или вставить тестовую планету.
- **Старые миры без `biomes` живьём**: в dev-БД все планеты имеют `biomes` (кроме гигантов). Проверено по коду (`planet_image_v2.go:377-382`) + тесты. Закрыть: планета с `data` без ключа `biomes`.
- **Визуальное качество картинок (стиль А, «глазами» создателя)**: критерий приёмки §8.3 п.1 — субъективная оценка, вне моей зоны. Скриншоты приложены (`tools/e2e/artifacts/`), создатель может посмотреть.
- **Диск-кэш LRU 1000 файлов на живом сервере**: проверен тестом `TestDiskCacheLimitLRU` (PASS); живьём — запись/чтение одного файла.
