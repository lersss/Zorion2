## Найденное (блокер)

**BUG-1 (блокер, критерий §7.4 «добавить родителя» работает): «добавить родителя» в UI не заполняет слот — TypeError.**

- Файл: `web/studio.html:1223` — `const n = parent.recipe.length - 1;` в `addParent()`.
- Причина: контракт iterA §7 — `POST /studio/api/goods/{id}/slots` возвращает `{"id": id}` (`internal/handlers/studio_handlers.go:422`), а НЕ полный товар с `recipe`. Старый API студии возвращал полный товар — при переносе UI `addParent` не адаптирован.
- Воспроизведение (браузер, /studio): открыть попап ресурса → «добавить родителя» → выбрать товар-родителя в модалке → в консоли `TypeError: Cannot read properties of undefined (reading 'length') at addParent (studio.html:1223:27)`; у родителя добавляется ПУСТОЙ слот (POST прошёл), но составляющая не кладётся (PUT не выполняется), откат не срабатывает, тост не показывается. Рецепт родителя остаётся с пустым слотом.
- Затрагивает: и товары, и ресурсы (кнопка «добавить родителя» в попапе обоих). Критерий §7.4 и инвариант §8.2 («добавить родителя» разрешено — ресурс как составляющая) нарушены.
- Обход: через API `PUT /studio/api/goods/{id}/slots/{n} {good_id}` работает (проверено: 200, слот заполняется).
