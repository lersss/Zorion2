## Что НЕ проверено (граница покрытия)

- **Визуальный UX студии в браузере** (переключение вкладок, попапы производителей/предметов,
  поля объёма/веса в попапе глазами): проверял API + HTML-разметку (renderPopup/volInput/wgtInput,
  renderProdSprav/renderItemSprav), но не живой клик по UI студии в Chrome. e2e map-check покрывает
  карту, не студию. Закрыть: ручной прогон студии в браузере (создатель/игрок) или e2e-скрипт по студии.
- **«Чистый» первый старт сида с пустой БД** (маркер отсутствует): БД уже была посеяна
  разработчиком (маркер applied_at 16:32Z до моего старта); идемпотентность проверена через
  маркер + отсутствие дублей после рестарта. Закрыть: прогон на пустой БД (drop + старт).
- **Экстремальные входы** (объём/вес = 0, огромные значения, NaN): 0 и отрицательные — валидация
  есть (отрицательный → 400); NaN/Inf через JSON не передать штатно (json.Decode отклонит).
