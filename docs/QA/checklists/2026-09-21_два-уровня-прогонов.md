# Прогон: два уровня прогонов (тяжёлый генераторный смоук отдельно)

**Дата:** 2026-09-21
**Задача:** идея `docs/gamedesign/ideas/2026-09-21_два-уровня-прогонов-тяжёлый-генератор-отдельно.md`
**Проверял:** @tester (независимо)
**Что проверялось:** `testing.Short()`-пропуск в 8 тяжёлых генераторных тестах;
правила четырёх мест переведены на два уровня (быстрый цикл с детектором без
генераторных пакетов + обязательный тяжёлый генераторный прогон без детектора).

## Результаты

1. **git status --short** → в правке 7 тестовых файлов `internal/generator/`
   (`galaxy/galaxy_test.go` + `planet/accretion_mass_test.go`, `biome_test.go`,
   `giant_smoke_test.go`, `planet_data_simple_test.go`, `race_tuning_test.go`,
   `region_profile_test.go`), три агентских файла (`.opencode/agents/developer.md`,
   `tester.md`, `manager.md`), `docs/GO_DEV_PROMPT.md` и неотслеживаемая идея.
   Совпадает с ожиданием. **В дереве есть чужие изменения** (не этой задачи):
   `cmd/art-studio/*` (ships_handlers, index.html, новый `ships_edit.go`),
   `internal/models/ship_sprites*.go`, `tools/process_ship.py`,
   `.opencode/plugins/loop-guard.js`, `.gitignore`, `docs/COORDINATION.md`,
   чужая идея 2026-09-20, ~50 новых `data/planet_images/v4_*.png`, ~30 файлов
   `tools/spike_ship_*`, `web/static/sprites/race_humans_*.png`,
   `docs/specs/2026-09-21-ships-quality-rework.md`.
2. **go build ./...** → exit 0.
3. **go vet ./...** → exit 0.
4. **Быстрый цикл** `go test -race -short (go list … −generator/(planet|galaxy))`
   → **exit 1, 24.6 с**. Единственный FAIL — `TestGetPlanetByID`
   (`internal/repository/planet_repo_by_id_test.go:67`, expected `1000000`,
   actual `999999`). Это известный мигающий тест из раздела «Долг» идеи,
   к правке и к генератору отношения не имеет.
5. **go list** → всего пакетов **38**, отфильтровано **36** (исключены ровно
   `generator/planet` + `generator/galaxy`).
6. **Тяжёлый генераторный прогон** `go test ./internal/generator/planet/ ./internal/generator/galaxy/`
   → **exit 0, 55.1 с** (planet 53.6 с, galaxy 39.8 с — пакеты идут параллельно).
   Тяжёлые тесты **выполняются, не пропущены**:
   `--- PASS: TestSmoke20000Worlds (16.62s)`,
   `--- PASS: TestGenerateOutlierPositionNearCluster (32.83s)`.
7. **`go test -race -short ./internal/generator/… -v`** → **exit 0, 89 с**;
   строк `--- SKIP` — **9**, из них **8 новых** (изменённых этой правкой) и
   **1 ранее существовавшая** `TestGenerateGalaxyPerformance`
   (`planet/perf…` → `galaxy/performance_test.go:29`, не входит в диф):
   - planet (7): `TestSystemBudgetInterSystemSpread`, `TestSystemBudgetSingleRollPerSystem`,
     `TestBiomeSmokeDistribution`, `TestSmoke20000Worlds`, `TestPlanetsSimpleRare`,
     `TestSmokePiggyBankRacesGetPlanets`, `TestProfilePlanetCountPerWorld`;
   - galaxy (2): `TestGenerateOutlierPositionNearCluster` + ранее бывший
     `TestGenerateGalaxyPerformance`.
8. **Повтор быстрого цикла** → **exit 0, 4.9 с**; ни одного `FAIL` /
   `WARNING: DATA RACE` / `panic`. Итого мигание `TestGetPlanetByID` — 1 из 2
   прогонов (воспроизводится нестабильно, подтверждает диагноз «мигающий»).

## Вердикт: С ОГОВОРКАМИ

Механика правки работает: 8 тестов корректно пропускаются под `-short`
(exit 0) и выполняются в тяжёлом прогоне (exit 0), сужение быстрого цикла даёт
~25–30 с против нескольких минут, правила в четырёх местах обновлены.
Оговорка одна: **быстрый цикл (п.4) дал exit 1** из-за известного мигающего
`TestGetPlanetByID` — не связано с этой правкой и с генератором (лежит в
`internal/repository`), уже зафиксировано в «Долге» идеи. Повторный прогон
чистый (exit 0).

## Чеклист непроверяемого

- **Мигающий `TestGetPlanetByID`** — воспроизводится нестабильно (1/2 раз);
  за 2 попытки закономерность не вывел. Нужен отдельный разбор слоя
  `internal/repository` (порядок/общее состояние моков) — задача в бэклоге.
- **Долгосрочный выигрыш от двух уровней** (обычная задача 3–5 мин → 30 с,
  генераторная → ~90 с) на реальных будущих задачах — проверяется только
  накоплением статистики; здесь подтверждён лишь факт замеров (быстрый цикл
  24.6 с / 4.9 с, тяжёлый 55.1 с, полный скип-прогон 89 с).
- **Слепая зона** «одновременный доступ к общим ленивым справочникам генератора
  из джоба генерации и запроса игрока» — ни один тест не покрывает (по идее).
  Проверить нечем, теста нет; кандидат на отдельную задачу.
