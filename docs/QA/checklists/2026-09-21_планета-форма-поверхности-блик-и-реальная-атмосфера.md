## Найденное

**Баг-блокеров нет.** Находки:

1. **[среда, не код] e2e `map-check-planet.js` падает на перезаписи существующих скриншотов.** `page.screenshot({path: artifacts/planet-modal.png})` → `UNKNOWN: unknown error, open ...` когда файл уже существует (артефакты прошлого прогона разработчика 20.09). После удаления старых файлов — ALL PASS. Воспроизводится стабильно на 2 файлах (planet-modal.png, orbit-view.png). Playwright на этой системе не перезаписывает существующий PNG. Скрипт `mkdirSync` делает, но не чистит старые файлы. Рекомендация @manager: в `map-check-planet.js` перед скриншотами удалять существующие файлы (или писать с суффиксом времени). Серьёзность: низкая (среда), но ломает повторные прогоны e2e.
2. **[чек-лист, формулировка] Пункт 5 «mtime не меняется»** — диск-кэш намеренно трогает mtime при хите (LRU, `planet_image_disk_cache.go:83`, предсуществующее). Суть пункта (нет перегенерации) выполняется — проверено по CreationTime. Предложение @manager: переформулировать пункт в «повторный запрос не перегенерирует (CreationTime/содержимое стабильны; mtime может меняться LRU-touch'ем)».

## Не проверено (граница покрытия)

- **«Глазами» по PNG** — модель не поддерживает просмотр изображений; заменено программным анализом (PIL): круглость границ, палитры, полосы, кольца, блик. Для финальной визуальной приёмки нужен создатель (критерии §8.3: «просмотр картинок»).
- **Кольца на планете с кольцами из БД** — в БД нет планет с кольцами (кольца генерируются от seed, `hasRingsBySeed`); проверено на живом гиганте Odmusrim (кольца от seed, день/ночь 104/534) + `TestRingsLit`.
- **Точные значения калибровки атмосферы** (haze/limb/glow по таблице §4.3) — покрыто юнит-тестом `TestAtmosphereReal`; живьём подтверждён только качественный признак (тёплая дымка Венероподобной).
- **UX глазами игрока** (отвлекает ли блик, читаются ли доли) — вкусовое, за создателем.
