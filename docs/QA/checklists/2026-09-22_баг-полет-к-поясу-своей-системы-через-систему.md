## Не проверено (граница покрытия)

- **Чистое состояние «in_own_system + нет активного полёта + my_position пуст»**
  недостижимо на ЖИВОМ сервере: при `current_world_id == worldID` без полёта сервер
  синтезирует `my_position = orbit star` (planet_handler.go:130-135), а в межзвёздном
  полёте у клиента выставлен `interstellarFlight` → режим composite (редирект, не intra).
  Покрыто юнит-тестом и Node-тестом; живой путь до этой комбинации требует окна «/me
  ещё не ответил» (клиентский тайминг) — визуально в браузере не воспроизводил.
- **Полёт к поясу в чужой системе (композитный маршрут пояса) «от кнопки до прибытия»**
  не прогонял живьём: нужен мир с поясом за радаром и длинная межзвёздная фаза;
  проверена только выдача данных (`in_own_system=false` → композитная кнопка).
- **Границы поясов у звезды (position=orbit у пояса после прибытия)** — проверено
  живьём только для своей системы; для чужой не воспроизводил.
- **Админский путь (`visibility == nil`)** — флаг `in_own_system` там не вычисляется
  (остаётся false); админ пояса видит вне гейта, кнопки полёта игрока к нему не
  привязаны — не проверял.
