## Найденное

### D1 (пункт 17) — провалы кадров при спринте, `tools/e2e/surface-fps-check.js`
- **Шаги:** `cd tools/e2e; node surface-fps-check.js` (headless Chrome, живая мягкая планета, Shift+→ 2.5 с).
- **Факт:** `F1 FAIL — fps=59.3 frames=151 longFrames=3 maxGap=58.4ms dist=14 м`; F2/F3 PASS.
- **Оговорка:** сценарий — именно спринт со стримингом чанков (комментарий скрипта: мерить стоимость кэша чанков), headless = софтверный рендер без GPU. Причина провалов plausibly — генерация чанков/GC, **не** погода: статические прогоны пакета-1 (отчёт `2026-09-22_погода-поверхности-вид-и-физика.md` §9) дали `long=0` на всех явлениях, а вес частиц здесь не менялся. Однозначно погоде не приписываю.
- **Что сделать:** повторный замер в живом браузере создателя (GPU) и/или на простое сервера; при устойчивом повторении — замер по явлениям отдельно.

Других дефектов нет.
