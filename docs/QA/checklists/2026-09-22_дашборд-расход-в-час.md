## Найденное (баги)

- **Багов не найдено.** Все 3 пункта — PASS.

Наблюдения (не дефекты):

1. `rate.perHour` растёт в реальном времени: за ~70 с между двумя замерами API отдал `2.13 → 2.14 → 2.17`
   при независимом пересчёте `2.169 → 2.172`. Расхождение — эффект живого дрейфа суммы (`~$0.03/мин`),
   а не ошибки расчёта. **Сравнивать можно только по одному снапшоту** — по `generatedAt` ответа;
   при таком сравнении сходится с точностью 0.002.
2. Подстрока «расход в час» присутствует в `document.body.innerText` страницы, но **не как подпись
   у цифры**. Это заголовок сессии/фичи из данных API: `features[16].label = active[0].parent =
   active[7].title = "Добавить расход в час в шапку 8790"`. В `index.html`/отдаваемом HTML строки
   «расход в час» нет (проверено grep по файлу и по телу HTTP-ответа). Требование «рядом с цифрой нет
   текстовой подписи» выполнено.

## Не проверено (граница покрытия)

- **Настраиваемое окно `DASH_RATE_MIN ≠ 60` на живом сервисе.** Тест `stats.test.mjs` покрывает
  константу окна (`windowMin=60`) и фильтр свежести, но живой сервис с нестандартным окном не гонял —
  сервис на 8790 останавливать/перезапускать запрещено. Чтобы закрыть — отдельный запуск `node server.mjs`
  с `DASH_RATE_MIN=15` (создатель/@manager).
- **Вкусовое: формат `$X.XX/ч` глазами создателя** (шрифт/акцентный цвет, крупная цифра без подписи).
  Я фиксирую наличие/поведение, «нравится» — не мой вердикт.
