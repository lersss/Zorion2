## Непроверяемое (граница покрытия)

- **Игрок видит «Нет данных» на незнакомой планете в живом UI** — не удалось
  воспроизвести: текущая система сканируется при `GET /api/worlds/{id}/planets`
  (`planet_handler.go:132`, ленивый `ScanSystem` в радиусе радара), поэтому через
  UI карточка незнакомой планеты на этом аккаунте не открывается. Гейт доказан
  API-403 + кодом. Чтобы закрыть визуально: аккаунт без сканера / планета вне
  радара, либо адресный e2e-пробник — за создателем/менеджером.
- **UX глазами игрока** (верстка строк, форма публикации, тосты) — только
  headless-скриншот; вкусовая приёмка — за создателем.
- **Публикация фракцией/постройкой/агентом** (`/admin/contracts`) — вне B3
  (фронт игрока); не проверял.
- **Закрытие перелёта по прибытии / NPC-исполнитель** — этап B2b, не входит в B3;
  не проверял.
- **Прямые (`visibility='direct'`) контракты на доске** — сервером на доску не
  отдаются; отдельный кейс без данных не проверял.
- **Срок предложения (`offer_window`) на доске** — в прогоне контракт успел
  перейти в `expired` (ленивое истечение); граничное «осталось N» по живому
  времени не снимал (покрыто node-тестом `timeLeftText`).
