## Найденное

Красного по объёму задачи нет — багов не обнаружено.

1. **[инфо, не баг] `CloseTravelArrivals` вызывает `expireDueTx` для каждого кандидата; при истечении счётчик `completed` не растёт.** Ожидаемо по спеке §1.4 (просроченный — провал, залог автору). Возвращаемое число = «фактически выполненные», что совпадает с логом `✅ contracts: закрыто перелётов: N`.
2. **[инфо, не баг] Взятие перелёта не сверяет `from_world_id` с позицией берущего.** Осознанное упрощение создателя, зафиксировано комментарием `contract_handlers.go:236-240`. Не дефект.
3. **[инфо, чужое дерево] Рабочее дерево содержит крупные параллельные незакоммиченные правки** (поселения/`branch*`, surface/`planet_visibility`, `deposits.js`, `tabs.js`, tools). На сборку/прогон B2a не влияют (`build`/`vet`/`-race` зелёные), состав диффа по задаче не затронут.
