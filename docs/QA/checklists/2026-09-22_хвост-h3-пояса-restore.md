Файлы `internal/repository/contract_repository.go` (удалено поле `ContractScope.All`), `internal/handlers/admin_universe.go`, `internal/handlers/contract_handlers.go` — не входят в объём задачи H3 и менялись сторонним агентом прямо во время прогона (в первом `git status` их не было). Состояние стабилизировалось само: build/vet/tests после этого зелёные. На результат H3-проверок не влияет.
2. **[известный дефект, не регресс] Битый цель-пояс при Restore: строка удаляется, `current_position` остаётся `in_flight` — «зависший» игрок.** `internal/travel/intrasystem_manager.go:269-274` при `validTarget==false` делает `store.Delete` и `continue`, не трогая `users.current_position`; `onArrival` (единственный, кто пишет финальную позицию) не вызывается. Дефект общий для всех типов битых целей (`planet`/`satellite`/`belt`), нашим хвостом не внесён. Рекомендация (совпадает с прошлым QA-отчётом): при удалении intra-строки без `onArrival` очищать/сбрасывать `current_position` (иначе клиент рисует вечный полёт).
3. **[инфо] `system_belts` в дев-БД пуста** (0 строк): пояса есть только у миров, сгенерированных после этапа 1, бэкфилла нет (следствие этапа 1, не этапа 2/хвоста).
