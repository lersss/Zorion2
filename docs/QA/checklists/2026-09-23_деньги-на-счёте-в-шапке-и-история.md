- **Риск сдачи (порядок коммитов), не баг фичи.** `web/static/js/dashboard/money.js:18`
  импортирует `../game_date.js`, а файл `web/static/js/game_date.js` сейчас **untracked**

  (`money.js` не загрузится). Коммитить обе правки согласованно (или одним релизом).
  severity: medium (сдача). Класс: зависимость от незакоммиченного чужого файла.
- **Мелочь, не дефект.** `escapeHtml` импортируется из `./cargo.js` (`money.js:19`) —
  файл tracked, безопасно; но это неявная связанность блока «Счёт» с блоком «Трюм».

## Что НЕ проверено (границы покрытия)

- **«Чужой баланс не виден» глазами в браузере** — нужны два играющих аккаунта
  одновременно и UI-сценарий «смотрю на чужой экран». Проверено статически
  (endpoint JWT-scoped, только `owner_id` из токена; иных способов получить баланс
  в `web/` нет). Закрыть: создать/использовать второго игрока с иным балансом и
  сверить, что в UI второго виден только его счёт.
- **Состояния «Ошибка» и «Пусто по факту наличия операций»** — недостижимы на новом
  игроке: история пуста по решению создателя (стартовый сид не журналируется), а
  реальных `escrow_*`/`contract_work_earn` операций в БД без подрядов нет. Проверены
  только чистые функции (`moneyItemsHtml`/`moneyRowHtml` через Node-зонд и go-тест).
  Закрыть: карточка игрока с реальными операциями в журнале.
- **Ошибка сети (`fetch` не ок, не 401/403)** — код возвращает `❌ Не удалось загрузить
  счёт` (§5.3), но в e2e не инсценировал падение `/me/money`. Закрыть: intercept
  запроса в playwright (по аналогии с фиксом «трюм полон»).
- **Вкусовое/визуальное** — читаемость вкладки «💳 Счёт» и цвета `+ #4ade80` / `− #f87171`
  глазами игрока: только скриншоты `tools/e2e/artifacts/dashboard-account.png`,
  `map-account.png` (мой временный зонд). Если @gdesigner закрепит иные цвета — сверить.
- **Редирект 401 без токена** — статически `money.js` уходит на `/login-page` только
  при `401/403` от ответа; сценарий «нет токена вовсе» (`token()` → `null`) даёт ранний
  `return` без запроса — проверено только чтением кода, в браузере не гонял.
