## Что НЕ проверено (граница покрытия)

- **Живой пустой пул → 400** — опустошение `factions` на общей dev-БД снесло бы данные для других
  задач; проверено юнит-тестом хендлера. Чтобы закрыть живьём: отдельная тестовая БД или
  согласованный слот вайпа.
- **Живой переход «пул пуст → наполнен» после `/admin/generate-factions`** — требует очистки
  `factions` (разрушительно); проверено тестом с фиксацией порядка SQL и чтением кода.
- **Живой вайп (ClearUniverse/Пакман)** — снос всей галактики на shared dev-БД недопустим;
  проверено `TestManagerRacePoolDropsRemovedWorlds` (смена снапшота) и валидацией пула.
- **Визуал/UX глазами игрока** — П2 не трогает клиент (раса в позициях — П3); карта проверена
  `map-check.js` программно.
- **Пакет `generator/planet|galaxy`** — в рабочем дереве есть незакоммиченные правки другой фичи;
  по инструкции исключены из `-race -short`, отдельно не гонял (вне зоны П2).
