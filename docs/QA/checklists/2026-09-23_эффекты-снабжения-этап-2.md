## FAIL

### F1 (крупный): миграция `000070` не создаёт `params.effects` — пилот не активируется на существующих БД

- **Где:** `migrations/000070_supply_effects.sql:33-37` (вложенный `jsonb_set` по пути `{effects,продовольствие}`).
- **Что:** `jsonb_set(target, '{effects,продовольствие}', …, true)` **не создаёт отсутствующий промежуточный объект** `effects`. PostgreSQL 16.9: `SELECT jsonb_set('{}'::jsonb, '{a,b}', '"x"', true)` → `{}` (проверено на живой БД; создаётся только последний ключ при уже существующем родителе). До `000070` тип «обычное поселение» имеет `params` **без** ключа `effects` (сид `000067_settlement_type.sql:33` кладёт только `eat`), поэтому внутренний `jsonb_set` — no-op.
- **Доказательство (живая БД):** `producer_types.params` для `обычное поселение` = `{"eat": {"вода":…, "пища":…, "продовольствие":…}}` — ключа `effects` **нет**; `SELECT count(*) FROM producer_types WHERE params ? 'effects'` = **0**; `active_effects` = **0 строк**. Повторный прогон `migrations/000070_supply_effects.sql` (идемпотентный, exit 0) ключ `effects` **по-прежнему не создаёт**.
- **Следствие:** на любой БД, мигрировавшей через `000070` (а не через Go-сид), `EffectsByPosition` пуст → `buildBindings` не создаёт ни одной привязки → эффект «голод» **молча не работает** (нет строк `active_effects`, нет `w`/`load`). Ровно сценарий «пилот — no-op», который спека запрещает (§3.1/§7.5: привязка обязана быть в **обеих** точках — миграция и Go-сид; §3.3/finding 9). Go-сид свежей БД (`seed_producers.go:76`) корректен — расходится только путь миграции.
- **Ссылка на спеку:** §3.1 (комментарий «трогаем ТОЛЬКО нужные ключи (jsonb_set на уровне ключа)»), §7.5, §12 T1/T36.
- **Почему тесты зелёные (ложный PASS):** `internal/goodsstudio/supply_effects_consistency_test.go:64-70` (`TestSupplyEffectsMigrationPilotBindingByKey`) проверяет лишь **наличие подстрок** `jsonb_set` и `{effects,продовольствие}` в тексте SQL — семантику `jsonb_set` (создание промежуточного ключа) он не ловит. Тест нужно усилить (например, выполнять выражение на временной таблице/`jsonb`-значении или проверять итоговый `params`).
