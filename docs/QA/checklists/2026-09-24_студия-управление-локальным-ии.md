## Вердикт

**ПРОЙДЕНО (с оговоркой по п.9).** Все прямые кейсы фичи (п.1–8, 10–12) — PASS: состояние
выводится по факту (stopped/starting/running/foreign), single-flight работает, чужой процесс не
гасится (409), живой цикл запуск→работа→остановка проходит, UI-элементы и ручки на месте,
`start-all.cmd` в cp866 с корректной нумерацией. Единственный FAIL — шаг 9a e2e
(`copy-universal`) и SKIP шага E3: обе позиции **не связаны с правкой** (данные каталога / ветка
по среде `managed=true`). Багов самой фичи не найдено.

## Найденное

- **Не баг фичи, но стоит знать:** поднятый помощник отвечает `401` на `/global/health` и `/config`,
  потому что в окружении запуска задан `OPENCODE_SERVER_PASSWORD`. Из-за этого:
  - `state` определился как `running` по владельцу порта (fallback §2), а `version` пуст
    (`detail="ИИ: работает"`, без версии) — это штатное поведение спеки;
  - ИИ-клиент студии (`internal/goodsstudio/ai`, не менялся) на `fill` получил
    `Ошибка ИИ: opencode: 401 Unauthorized` (e2e шаг 8). Спека прямо выносит basic-auth за объём
    («`OPENCODE_SERVER_PASSWORD` считается не заданным»), поэтому это артефакт среды, не дефект кода.
- **9a e2e `copy-universal`** (`tools/e2e/goods-studio-server-check.js:379–395`): `uniSrc=undefined`
  — в dev-каталоге нет `producer_type` (parent_id, kind=goods, категория=good, без расы/семейства)
  с рецептами. Проверка данных, к aiserve/студийным ручкам отношения не имеет.
- **E3 e2e** (`:444`) пропускается при `managed=true`; ветка `managed=false`/`foreign` в среде
  недостижима (Windows + loopback + npx). Суть E3 (409 человеческим текстом, чужой процесс жив)
  подтверждена вручную в п.7.

## Не проверял сам

- **Go DoD (`go vet ./...`, `go test -race -short …`)** — вне 12 пунктов задания; `go build` прошёл
  (exit 0). Unit-тесты `aiserve`/`studio_ai_test.go` не гонял.
- **Ветка `managed=false` (прод-путь, не-Windows/нет npx/не-loopback)** — в среде Windows+loopback+npx
  недостижима штатно; E3-e2e по этой причине SKIP. Нужен запуск с `OPENCODE_URL` не-loopback или без `npx`
  (напр. временно убрать npx из PATH) — за создателем/менеджером.
- **Реальный клик по `#btnAiStart`/`#btnAiStop` в браузере** — e2e проверяет наличие/состояние и
  индикатор (E1/E4), но кнопки не нажимались (E3 SKIP); клик-поведение и UX текстов оценивались по
  ручкам (`curl`) и `updateAIStatus()`, не глазами игрока.
- **Реальный запуск `start-all.cmd` с `AI=1`** — не выполнялся (поднял бы весь стек сервисов);
  проверена только статика (кодировка/нумерация/`:report`).
- **`/global/health` живой пробой как канонический эндпоинт (F7)** — из-за `401` (см. выше) подтвердить
  нельзя; состояние `running` получено по владельцу порта, а не по health-JSON с `version`.
- **Побочный DB-артефакт:** в ходе проверки п.5 зарегистрирован тестовый player `qa_ai_role_`
  (остаётся в dev-БД); в репозиторий ничего не попало.

## Предложения в чек-лист (применит @manager)
