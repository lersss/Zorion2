## Найденное

- Багов фикса не найдено.
- **⚠️ Наблюдение (не блокер):** селект «система-назначение» контрактов
  (`[data-contract-dest-world]`) на каждом тике автообновления на доли секунды
  показывает плейсхолдер (`opts=1, value=''`), затем значение восстанавливается
  (сэмплы: t=0..2 значение есть, t=3 плейсхолдер, t=4 значение есть, …). Причина —
  опции `loadDestWorlds` грузятся асинхронно, возврат значения происходит после их
  вставки. Функционально значение не теряется; при чтении «в момент тика» можно
  увидеть пустое поле. Стоит учесть при «живой» реактивной модалке (отдельный эпик).
- `renderCard` в `panel.js` не завершается переводом строки в конце файла
  (нет newline) — косметика, не влияет.

## Не проверено живьём

- **Вкладка «Магазин» при автообновлении (п.5).** Почему: админу вкладка скрыта
  (`marketTabVisible` → `knowledgeMode()==='admin'`), а для игрока нужен отдельный
  сценарий «знание + орбита + автообновление». Живой выбор слота и выкуп проверены
  `market-check.js`, персистентность — только юнит-тестом. Чтобы закрыть: e2e-сценарий
  игрока (как в `market-check.js`) + `debugAutoRefreshPlanet=1`; либо временно разрешить
  вкладку админу.
- **Карточка спутника (п.8).** Почему: у планет dev-БД, доступных прогону, нет
  спутников (в схеме нет колонки — спутники формируются на генерации, газовых
  гигантов со спутниками в мире не встретилось). Чтобы закрыть: мир с газовым гигантом
  со спутниками в `QA_WORLD`.
- **Устаревшее замыкание `planets` в `index.js` (требование 4 фикса).** Почему: не
  воспроизводил клик по строке сразу после `refreshPlanets` (нужен точный тайминг).
  По коду `window.updateRightPanel`/`showStarCard`/клик строки читают `modalState.planets`
  — фикс на месте.
- **«Вид с орбиты»** — вне задачи (по решению создателя мигание оставлено), не проверял.
- **UX глазами игрока** (ощущение «мигания» панели при тике) — вкусовое, требует
  живого взгляда создателя.

## Предложения в чек-лист (применит @manager)

- Регрессионный кейс на неразрушающую перерисовку (админ, `debugAutoRefreshPlanet=1`,
  2+ тика): форма «Построить» (тип/владелец/население/статус), скролл `#right-panel`,
  раскрытые детали строения и столицы, поля «Залежи» и «Контракты».
- Отдельный кейс изоляции A→B→A: значения «Залежи» планеты A не переезжают на B и
  возвращаются на A (переключение через реальный `selectPlanetInModal`, иначе
  автообновление откатывает на A — при ручном `updateRightPanel` без
  `selectedPlanetIndex`).
- Пометить в чек-листе, что вкладка «Магазин» недоступна админу by design — для её
  проверки нужен игрок с знанием/орбитой.
