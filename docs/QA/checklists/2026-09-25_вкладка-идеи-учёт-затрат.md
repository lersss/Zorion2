## 2. Сверка денег — ОК (главное)

Независимый SQL по всем ассистентским сообщениям проекта Zorion
(`message JOIN session`, `lower(directory) LIKE '%zorion%'`,
`data LIKE '%"role":"assistant"%'`, `SUM(json_extract(data,'$.cost'))`):

| Источник | Значение |
|---|---|
| Мой SQL, всего | **$500.7813** (100 813 сообщений, 2 241 сессия) |
| `/api/ideas?period=all` → `totals.cost` | **$500.78** |
| `totals.attributed` | $329.41 |
| `totals.unattached` | $171.37 |
| `attributed + unattached` | **$500.78** = `totals.cost` ✅ |

Закрытие сходится в пределах цента (500.7813 → 500.78). Числа «живые»: между запросами агенты
дописывают траты, поэтому снапшоты немного плывут (первый запрос дал 500.74, затем 500.78) —
это ожидаемое поведение догрузки, а не потеря денег. Сумма по линиям сервером не делится
(каждая сессия считается ровно один раз): `lines+unattached.sessions = totals.sessions = 2242`.

**Косметическое замечание (не баг):** сумма *округлённых до цента* значений, которые видит
пользователь, не равна карточке «Всего за период»: `Σ lines.cost = 329.46` и
`Σ unattached.cost = 171.21` → 500.67 против 500.78 (разница 0.11) из-за округления каждой из
184 линий и 293 деревьев. Серверные (неокруглённые) суммы точны, `attributed+unattached` сходится —
расходится только отображение.

## Найденное (не блокирует)

1. **Сумма показанных линий не равна карточке «Всего»** (`tools/agent-dash/ideas.js:99-111`):
   `Σ lines.cost (329.46) + Σ unattached.cost (171.21) = 500.67` против `totals.cost = 500.78`.
   Причина — округление каждой линии/дерева до цента (`ideas.mjs:12`, `:423`, `:511`), а не потеря
   денег: серверные суммы сходятся. Severity: косметика. Возможное лечение — показывать в карточках
   те же округлённые суммы или добавить оговорку в подпись.
2. **`totals.files = 307` при 158 файлах в репозитории на сейчас** (`tools/agent-dash/ideas.mjs:460`).
   Считаются все имена, когда-либо записанные в истории (переименования/удаления/разные пути
   воркспейса). Может вводить в заблуждение в шапке «файлов идей: 307» (`ideas.js:87`). Severity: подпись.
