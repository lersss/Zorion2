## Наблюдения (не дефекты ЧК2)

1. **`кислотные_дебри` не находится фильтром «комфортного давления».** Планеты с этим биомом имеют давление вне `[0.2, 5.0] атм` (первый резолв вернул пусто). Отдельным резолвом без фильтра биом найден, `view_source=catalog`. На вид/данные не влияет — заметка для будущих прогонов/гейта комфорта.
2. **Пиксельная сверка регресса «до/после» на одной планете не выполнялась** (см. «Чего не проверил»). Эквивалентность доказана на уровне рецепта: резолв-вид `леса`/`джунгли`/`грозовая_степь` побитово равен HEAD↔work, а детерминизм (п. 10) гарантирует идентичность кадра при равном рецепте.
3. **Контактный лист** визуально: `металлические_рощи` ↔ `блуждающие_рощи` — ближайшая пара по «общему виду» (оба буро-оливковые с куполами), но разведены палитрой и `crest`-гребнями; остальные пары читаются с первого взгляда. Оценка — глазом @tester (см. границу покрытия).

## Чего не проверил (граница покрытия)

- **Пиксельный регресс «до/после» на одной планете** для `леса`/`джунгли`/`грозовая_степь`: клиент всегда получает текущий справочник с сервера (нет точки инъекции HEAD-рецепта). `git show`/`cat-file` заблокированы песочницей — HEAD-справочник восстановлен из контекста `git diff` (0 удалённых строк), резолв-вид сданных биомов побитово равен; прямое пиксельное сравнение «до»-кадра невозможно без подмены серверных данных.
- **«Узнаваемость» силуэтов глазами игрока** — оценка различимости по контактному листу + метрики силуэта/палитры/декора, не UX-метрика. Окончательно — гейт «офигеть» создателя.
- **Пиксельное «орбита = прогулка».** Проверено на уровне контракта (единый `color` для `biomeColorFor`/`SurfaceBiomeColorHex`, `palette.base==color`, живой `v7`-кэш); прямое сравнение пикселей картинки планеты и земли в прогулке не делал — в прогулке цвет искажён атмосферой и слоем суток (дизайн).
- **Ночные кадры** 11 новых биомов — не снимал (чек-лист ЧК2 про различимость/горизонт днём).
- **Гейт жизни для `hang`/лиан** — по спеке осознанно не фильтруется жизнью (§4.6.10 п.10); код не проверял сверх этого (дефектом не считается).
- **Экстремальные/некомфортные планеты** — кадры сняты на первых доступных планетах с биомом; на жёстких планетах погода/HP могут менять кадр.
- **Визуальная «одна ли полоса» горизонта** — проверил данные (у всех 11 по 2 пояса с `parallax` 0.5/0.7) и кадры; построчного анализа «не сливается ли пояс с небом» (как оговорка ЧК1 по `травяные`) не делал — на глаз создателя.
