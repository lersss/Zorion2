## Примечания / наблюдения (не баги)

1. **Дублей определений нет.** `grep` по `web/studio.html` по всем 16 вынесенным
   именам не находит ни одной `function …` — инлайн-копий не осталось, вынос чистый
   (иначе инлайн перекрывал бы вынесенные версии).
2. **П.6 — только плейсхолдер.** При дефолтном фильтре (ни один тир не выбран,
   обе галки сняты) `renderGoodsSprav` кладёт в `#spravList` один `<div class="empty-note">`,
   а не карточки: критерий пункта (`children > 0`) выполнен, но ветка отрисовки
   карточек `renderGoodsSprav` в п.6 не исполнялась. Худшего о ней не скажу — каркас
   отработал без ошибок. Ветка карточек по построенному списку проверена в п.7 на
   `renderProdSprav` (8 карточек).
3. **Экспорт (п.8d)** — единственное действие прогона, пишущее файл: сервер
   отдаёт снимок `catalog-20260925.json` (322 записи), `content/catalog.json` в
   рабочем дереве и до прогона был изменён. В БД каталог не мутировался, таблицы
   не тронуты. Клик по экспорту предусмотрен самим чек-листом (п.8).
4. Имена вида `загрузка`/`логин`-оверлеев: `#studioLoginOverlay` → `display=none`
   (не `flex`) — доступ под `skycomposer` получен.

## Что не проверено (границы покрытия)

- **Ветка отрисовки карточек `renderGoodsSprav` под непустым фильтром** (выбран тир
  + галка «используемые/неиспользуемые») — в п.6 сработал только `empty-note` из-за
  дефолтного фильтра; проверка «список реально заполняется товарами» в этом же
  прогоне не делалась (лимит — один заход на пункт). Чтобы закрыть: прогон с
  выставленными тирами и галками.
- **Мутирующие ветки `dialogs.js`/`producers_ref.js`**: `askDeleteGood`/
  `confirmDeleteGood`/`doDeleteGood`, `askAddParent`/`addParent`, `saveRecipeRate`,
  `changeProdCategory`, `startProdRename`/`commitProdRename`, `unbindFactoryRecipe` —
  требуют `POST/PUT/DELETE` каталога, запрещено чек-листом. Проверено только
  существование и живой рендер непишущих путей (`renderSprav`, `renderProdSprav`,
  `openProdPopup`/`renderProdPopup`/`recipesBlock`/`prodSpecRows` через попап).
- **Визуальное качество** модалки, справочника и попапа (вёрстка/читаемость) —
  глазами игрока, вне авто-смоука; скриншот `qa-studio-chk5.png` приложен для
  визуальной оценки.
- **`saveRecipeRate` фактическая запись числа** (пусто vs 0 vs отрицательное) —

- **Гонки/конкурентность** — правка чисто фронтовая (JS), `-race`/Go-DoD не гонялись
