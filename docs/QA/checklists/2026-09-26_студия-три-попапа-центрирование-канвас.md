# QA-прогон: студия — три попапа центрируются по канвасу (--panel)

- **Дата:** 2026-09-26
- **Агент:** @tester (независимый прогон)
- **Задача:** `#proposalsPopup`, `#descPopup`, `#importPopup` в `web/studio.html`
  переведены на центрирование по канвасу через ту же переменную `--panel`, что и
  `#detailPopup`/`#catPopup`/`#effPopup`, плюс класс `.expanded` при свёрнутой
  панели. Перетаскивания у этих трёх попапов нет.
- **Файлы под проверкой:** `web/studio.html`, `web/static/js/studio/init.js`. Go не менялся.
- **Окна:** **1280×800** и **1024×700** (не как у разработчика).
- **Метод:** свой headless-Chrome скрипт (`playwright-core` + системный Chrome), без админ-БД:
  токена нет → `auth.js` рисует логин-оверлей, сетевых вызовов к `/studio/api/*` нет.
  Логин-оверлей и `.overlay` скрыты, попапы открыты прямым `display:flex`, панель
  свёрнута **реальным кликом** `#panelToggle` (перед кликом попапы прятались, чтобы
  не перекрывать кнопку). Скрипт удалён после прогона.

## Дополнительно проверено

- **Нет перетаскивания у трёх попапов:** `startPopupDrag` вызывается только для
  `#detailPopup` (`init.js:312`), `#catPopup` (`init.js:319`), `#effPopup` (`init.js:325`);
  ни `#proposalsPopupHead`, ни `#descPopupHead`, ни `#importPopupHead` не имеют обработчиков — подтверждено grep по `web/static/js/studio/*.js`.
- **Свёртывание реальным путём:** `togglePanel` (`init.js:353-359`) ставит `.expanded`
  и на `#canvasWrap`, и на все 6 попапов; живой клик подтвердил `expanded=true` на
  `#canvasWrap` + трёх целевых попапах, канвас расширился до `r=1268`/`r=1012`, центр
  попапов совпал с новым центром канваса (d=0).
- **Скриншоты:** `tools/e2e/artifacts/qa-pop3-1280x800-open.png`, `...-collapsed.png`,
  `qa-pop3-1024x700-open.png`, `...-collapsed.png`.

## Чеклист непроверяемого

- **Реальный admin-контент.** Прогон без админ-БД: тела трёх попапов пусты/минимальны,
  а не настоящие (предложения ИИ, описания, дифф импорта). Геометрия (ширина/центр)
  задаётся только CSS `width:min(...)` и от контента не зависит, но фактическую высоту
  и вёрстку с длинным контентом при реальных данных я не видел. Закрыть: прогон с
  учёткой admin/skycomposer.
- **Перетаскивание трёх попапов** (проверено только отсутствием обработчиков, не
  «тянул» их мышью) — по заданию перетаскивания у них нет, отдельным drag-сценарием
  не проверялось.
- **Промежуточные/большие окна** (например 1920×1080, 1366×768, мобильные) — вне
  задания; поведение детерминировано CSS от `--panel`, живыми числами не подтверждено.
- **Вкусовая оценка** «правильно ли попап смотрится по центру канваса» — решение создателя.
