- **Снимковый (snapshot) режим знания как таковой** — в прогоне достигнут режим **scan** (игрок на орбите звезды, сканер в радиусе). Отдельный `snapshot` (посещённая планета → снимок на момент отлёта) не снимался: для него нужен реальный отлёт с планеты и ожидание; блок знания проверен на scan-режиме (та же плашка, тот же путь перерисовки). При необходимости — отдельный прогон с отлётом.
- **Карточка спутника без админ-роли** (player) — проверена на игроке (см. B2). «Корабль» в тултипе агента виден только admin/skycomposer (player строку не получает by design) — player-ветка тултипа не проверялась, это не баг.

- **Полный перебор экстремальных планет** (например, карточки с NaN/Inf) — вне блока, не гонялся.
