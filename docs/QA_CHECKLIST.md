## Актуализация

- Кейсы в чек-лист — только то, что Go-автотесты НЕ покрывают (сквозное, конкурентность, UI). Автотесты не дублируем.
- Кейсы зон добавляются в основном из найденных багов (регрессионные).
- Перевод кейса в Ядро — только по решению игрока, критерий: «поломка = нельзя играть / краш / потеря прогресса». Удаление из Ядра — тоже решение игрока.
- Новая подсистема/пакет → новая зона (добавляет @manager при маршрутизации).
- При каждом прогоне @tester перезаписывает только дату в колонке «Последняя проверка»; если нашёл сценарий вне чек-листа — строка «Предложение в чек-лист: …» в отчёте прогона.
- В отчётах: «прогнал: Ядро + зона <X>».
