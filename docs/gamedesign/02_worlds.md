## 2.1. Генерация миров

- **Алгоритм:** Пуассона с кластерной структурой.
- **Координаты:** целочисленные, внутри круга радиуса MapSize.

**Параметры (настраиваются в админке):**

| Параметр | По умолчанию |
|----------|--------------|
| Количество миров | 1000 |
| Количество кластеров | 20 |
| MapSize (радиус круга) | 8000 |
| minDist (мин. расстояние) | 150 |
| Радиус кластера | 1200 |
| Расстояние между кластерами | 200 |
| Процент выбросов | 30% |

**Выбросы** (с 2026-09-11): распределяются **гауссовым смещением от случайного
кластерного центра** (std = `ClusterRadius`) — чаще ближе к кластерам, реже
у их границ и краёв галактики, вместо равномерного разброса по кругу.
`generateOutlierPosition` в `poisson.go`.

**Типы систем (распределение):**

| Тип | Доля |
|-----|------|
| Одиночная звезда | 85% |
| Двойная звезда | 5% |
| Кратная (3+) | 2% |
| Чёрная дыра | 1% |
| Нейтронная звезда | 1% |
| Протозвезда | 1% |
| Экзотическая | ~5% |

## 2.2. Спектральные классы

**Распределение** близко к реальному (M — самая частая), но с чуть большим количеством «интересных» звёзд для геймплея:

| Класс | Доля | Диапазон T (K) |
|-------|------|----------------|
| O | 0.5% | 30000–50000 |
| B | 2% | 10000–30000 |
| A | 4% | 7500–10000 |
| F | 7% | 6000–7500 |
| G | 12% | 5200–6000 |
| K | 17% | 3700–5200 |
| M | 32% | 2400–3700 |
| L | 8% | 1300–2400 |
| T | 8% | 700–1300 |
| Y | 9.5% | 300–700 |

**Почему не «как в реальности»:** в Млечном Пути 76% звёзд — класса M, а O/B/A встречаются крайне редко. Если бы мы сделали так же, игрок почти не видел бы «интересных» (горячих, ярких) звёзд. Поэтому распределение сдвинуто в сторону более разнообразных систем.

## 2.4. Параметры звезды

Каждая звезда имеет:
- **Название** — генерируется по слогам (латиница).
- **Спектральный класс** — O, B, A, F, G, K, M, L, T, Y.
- **Температуру в K** — согласована со спектром (см. таблицу выше).
- **Цвет на карте** — определяется спектральным классом.

## 2.5. Расширяемость

- Параметры генерации (MapSize, minDist, кластеры, выбросы) — настраиваются через админку.
- Распределение спектральных классов — в `internal/generator/galaxy/galaxy.go` (`spectralWeights`).
- Диапазоны температуры — там же.
- Кластерная структура — отключаемая (если `ClusterCount = 0`, используется равномерная генерация).

## 2.6. Регионы галактики

Регион — сектор галактики вокруг кластерного центра. Нужны, чтобы на малом зуме
карта показывала структуру галактики (цветные «туманности» с названиями), а не
бессмысленный набор точек.

**Генерация** (в `internal/generator/galaxy/galaxy.go`):
- Один регион на кластерный центр, радиус = `ClusterRadius`.
- Выбросы и добивка приписываются ближайшему региону (`WorldCount`).
- Имя — `internal/names.GenerateRegionName`: кириллица, курируемые корни +
  окончания, правило созвучия (согласная+гласная на стыке), ~30% с префиксом
  («Сектор …», «Туманность …»). Пространство ~540 базовых имён — хватает
  на сотни регионов.
- Цвет — из палитры `regionColors` (по индексу региона).

**Хранение:** таблица `regions` (миграция `000015`), заполняется в той же
транзакции, что и `worlds` при `GenerateUniverse`. На старых данных пусто.

**API:** `GET /api/regions` — регионы, пересекающие viewport.
