# 03. Планеты

**Обновлено:** 2026-09-13

---

## 3.1. Количество и распределение

Количество планет зависит от спектрального класса звезды:

| Класс | Планет |
|-------|--------|
| O, B, A | 0–8 |
| F, G | 2–8 |
| K, M | 0–6 |
| L, T, Y | 0–4 |

---

## 3.2. Архетипы планет

Конструктор из 5 категорий черт:

- **Архетип:** жаркий, умеренный, холодный, экстремальный, изменчивый.
- **Поверхность:** базис для композиции (см. `04_composition.md`).
- **Гидросфера:** океаны, озёра, ледяной покров, подлёдная, сухая, кислотная.
- **Атмосфера:** азотно-кислородная, углекислая, плотная, разреженная, ядовитая, облачная, туманная, электрическая, парниковая, водородно-гелиевая, гелиевая, азотная, водородная, метановая.
- **Биосфера:** стерильная, микробная, растительная, грибная, симбиотическая, светящаяся.

~500 комбинаций. Загружается из `config/planet_archetypes.json`.

**Баланс биосферы (2026-09-11):** в умеренном архетипе биосферные формы
подняты (леса 0.20, луга 0.16, джунгли 0.12, болота 0.07; океаны/скалы
снижены до 0.13), чтобы леса могли доминировать. Чтобы луга/джунгли/болота
тоже встречались, добавлены **биосферные ниши** (`composition_modifiers.go`):
джунгли — тёплые влажные (вода > 60%, T > 300), болота — обильная вода при
умеренном тепле (вода > 55%, T 270–330), луга — умеренная вода (20–45%).
Вне ниш леса — дефолтный биом. Итог: все 4 биосферные формы доминируют
(~4% планет).

**Поля архетипа:**
- `base_surface` — базовые веса форм поверхности.
- `base_subterrain` — базовые веса типов недр.
- `allowed_hydrospheres` / `allowed_atmospheres` / `allowed_biospheres`.
- `temperature_min/max` — диапазон температуры.
- `water_chance` / `life_chance` — вероятности.
- `mass_min/max` — диапазон массы в земных единицах.

## 3.3. Газовые гиганты

Для горячих звёзд (O, B, A) на дальних орбитах (index ≥ 3) с шансом 80%.

**Свойства:**
- H-He атмосфера (водородно-гелиевая, водородная, гелиевая).
- Большая масса (50–300 M⊕).
- Низкая плотность (0.15–0.25 в единицах Земли).
- Множество спутников (3–10).
- Ресурсы: энергия, редкие элементы, газы.
- Нет композиции поверхности — только атмосфера.

**Спутники** — полноценные локации (см. `04_composition.md`).

## 3.4. Масса и размер

**Масса — первичный параметр.** Задаётся архетипом.

| Тип планеты | Масса (M⊕) |
|-------------|-----------|
| Малая (Марс, Луна) | 0.1–0.5 |
| Землеподобная | 0.5–3 |
| Суперземля | 3–8 |
| Газовый гигант | 50–300 |

**Размер вычисляется через плотность:**

```
R = (M / ρ)^(1/3)
```

где ρ — плотность в единицах Земли:

| Состав | Плотность |
|--------|-----------|
| Газовые гиганты | 0.15–0.25 |
| Ледяные | 0.5–0.8 |
| Океанические | 0.8–1.0 |
| Скалистые | 0.9–1.3 |
| Металлические | 1.2–1.6 |

**Проверка:** Земля (M=1, ρ=1) → R=1. Юпитер (M=318, ρ=0.24) → R≈11.

## 3.5. Ядро планеты

**Ядро — первичная сущность**, определяющая температуру поверхности, магнитное поле, геологическую активность.

**Параметры:**

| Поле | Диапазон | Что значит |
|------|----------|-----------|
| Type | металлическое / силикатное / ледяное / экзотическое | Состав |
| MassPercent | 5–60% | Доля от массы планеты |
| Activity | 0–100 | Жидкое ядро, конвекция |
| Radioactivity | 0–100 | U, Th, K |
| Age | 0.1–13 млрд лет | Возраст (общий с системой) |

**Генерация:**
- **Type** — от массы: M>5 → металлическое, 0.5–5 → металлическое/силикатное, <0.5 → силикатное/ледяное/экзотика.
- **MassPercent** — от массы: 25–40% для землеподобных, 20–40% для газовых, 5–25% для малых.
- **Activity** — от архетипа + доли магматических камер в недрах.
- **Radioactivity** — от доли радиоактивных зон в недрах.
- **Age** — один на систему, зависит от спектра звезды.

**Вклад в температуру:**

```
base_heat  = Activity × 1.5 + Radioactivity × 2.5   (0–400 K)
age_factor = max(0.15, 1.0 - Age/15)
mass_factor = MassPercent / 30
HeatContribution = base_heat × age_factor × mass_factor
```

**Ожидаемое распределение типов:**
- металлическое ~55%
- силикатное ~30%
- ледяное ~12%
- экзотическое ~3%

## 3.6. Физическая температура

### 3.6.1. Равновесная температура

```
T_eq = 278.7 × L^0.25 / sqrt(r)
```

где:
- `L` — светимость звезды (в солнечных единицах).
- `r` — орбитальный радиус: `0.4 × 1.7^orbitIndex` (в а.е.).
- `278.7` — солнечная постоянная (равновесная T Земли без атмосферы).

### 3.6.2. Корректировки

```
T_albedo = T_eq × (1 - albedo)^0.25
T_green  = T_albedo × greenhouse_factor
T_final  = T_green + internal_heat + tidal_heat
```

где:
- **albedo** — от доминирующей формы поверхности (лёд 0.65, скалы 0.15, океаны 0.06).
- **greenhouse_factor** — от типа атмосферы (разреженная 1.0, азотно-кислородная 1.1, углекислая 1.3, парниковая 2.5).
- **internal_heat** — вклад ядра (см. 3.5).
- **tidal_heat** — приливный нагрев (только для спутников).

### 3.6.3. Ограничения

- Clamp по диапазону архетипа (`temperature_min/max`).
- Абсолютные границы: [20, 2500] K.

### 3.6.4. Ожидаемое распределение

- Медиана: 300 K (+27 °C).
- Жилая зона (200–400 K): 40–45% планет.

## 3.7. Вода и жизнь

**Вода:**
- Зависит от температуры, гидросферы архетипа, случайного шанса.
- Конкретные гидросферы (`океаны`, `озёра`, `ледяной покров`, `подлёдная`) переопределяют значение.

**Жизнь:**
- Только при наличии воды (>10%), T 200–400 K и неядовитой атмосфере.
- Вероятность определяется биосферой архетипа (`life_chance`).

**Обитаемость:**
- Жизнь + вода >10% + T 200–350 K + атмосфера ≠ ядовитая.

## 3.8. Геймдизайнерские типы планет

Классификация по **композиции**, а не по одному `type`. Порядок проверок — от специфичных к общим.

| Тип | Условия |
|-----|---------|
| Газовый гигант | is_gas_giant |
| Радиоактивная | radioactive = true |
| Землеподобная | habitable + life + есть скалы + есть океаны/озёра |
| Океаническая | dominant == океаны + water > 60 |
| Ледяная | dominant == ледники, или T < 200 |
| Вулканическая | лава + вулканические поля ≥ 20% |
| Пустынная | пески ≥ 25% + water < 25 |
| Стеклянная | стеклянные поля ≥ 15% |
| Металлическая | металлические поля ≥ 15% |
| Органик | доминируют биосферные формы |
| Скалистая (базовая) | fallback |

**Никакой «не определена»** — fallback есть всегда.

## 3.9. Композиция планеты (сводка)

Помимо архетипа, каждая планета получает две независимые композиции:

- **Поверхность** — 16 форм с процентами.
- **Недра** — 17 типов с процентами.

Подробности — в `04_composition.md`.

Газовые гиганты — исключение: у них нет композиции поверхности, но есть спутники.

## 3.11. Реестр полей `planet.data` (инвентарь)

Единый источник правды для правил генерации поселений (пресетов) —
реестр `internal/generator/settlement/fields.go`. Его отдаёт админке
`GET /admin/settlement-fields`. Этот раздел — инвентарь того, что уже
есть в `planet.data`, чтобы не изобретать велосипед. Один факт — одно место:
кто-нибудь может начать дизайн «полей не хватает» — сверяйся сюда.

**Легенда:** ✅ — открыто в реестре пресетов и можно фильтровать;
◽ — ключ есть в `planet.data`, но в реестре не открыт (могут использовать
пресеты с доработкой реестра); ➖ — в данных и реестре нет (новая механика).

### Числа (number)

| Поле | Диапазон в данных | Статус |
|------|-------------------|--------|
| `temperature` | 20–2500 K | ✅ |
| `water_percent` | 0–100 % | ✅ |
| `mass` | 0.1–300 M⊕ | ✅ (подсказка до 10 — поправить) |
| `size` | 0.43–12.6 R⊕ | ✅ (открыто 2026-09-13) |
| `gravity` | 0.29–3.18 g (M/R²) | ✅ (открыто 2026-09-13) |
| `density` | 0.15–1.8 (в ед. Земли) | ✅ (подсказка до 8 — поправить) |
| `moons` | 0–10 | ✅ |
| `development_level` | 0–1 (только у обитаемых) | ✅ |
| `system_age` | 0.1–13 млрд лет | ✅ |

### Строки (string)

| Поле | Значения | Статус |
|------|----------|--------|
| `atmosphere` | 14 типов | ✅ |
| `biosphere` | 6 типов | ✅ |
| `hydrosphere` | 6 типов | ✅ |
| `type` | 11 геймдизайнерских типов | ✅ |
| `surface_dominant` | 16 форм + `газовый_гигант` | ✅ (открыто 2026-09-13) |
| `archetype` | жаркий/умеренный/холодный/экстремальный/изменчивый | ✅ |
| `political_system` | демократия/диктатура/…/нет | ◽ |
| `description` | текст описания | ◽ (в правилах не нужен) |

### Булевы (bool)

| Поле | Статус |
|------|--------|
| `life` | ✅ |
| `radioactive` | ✅ |
| `is_gas_giant` | ✅ (запасной ключ; выводится и из `surface_dominant`) |

### Объекты/вложенные (не фильтруются правилами напрямую)

| Поле | Что внутри | Статус |
|------|-----------|--------|
| `surface_composition` | веса 16 форм | ◽ |
| `subterrain_composition` | веса 17 типов недр | ◽ |
| `core` | type, mass_percent, activity, radioactivity, age, is_active, is_metallic | ◽ |
| `resources` | сводка ресурсов | ◽ |
| `satellites` | спутники газовых гигантов (у каждого тоже `gravity`) | ◽ (уровень спутников) |

### Уже есть в физике, но не в данных (пересчитать можно)

Эти величины вычисляются в `internal/generator/planet/`, но в `planet.data`
не записываются. Если понадобятся пресету — материализовать по образцу
`gravity` (2026-09-13), не пересоздавая с нуля:

- `albedo` — `computeAlbedo` (0.05–0.7 по доминирующей форме).
- `greenhouse` — `computeGreenhouse` (множитель парника по атмосфере, до 2.5).
- `t_eq` — равновесная температура от звезды (без альбедо/парника).
- `core_heat` — вклад ядра в K (`Core.HeatContribution()`).
- `orbit_index` / радиус орбиты — живут в `PlanetData.OrbitIndex`, в JSON нет.

### В модели нет вовсе (потребуют новых механик)

`orbital_period` (год), `rotation/day_length`, `axial_tilt`, `eccentricity`,
`atmospheric_pressure`, `escape_velocity`, `magnetic_field` (есть только
косвенно `core.is_active`).
