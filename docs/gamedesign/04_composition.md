# 04. Композиция планет

**Обновлено:** 2026-09-10

Этот файл описывает три связанные темы:
- Композиция поверхности (16 форм).
- Композиция недр (17 типов).
- Спутники газовых гигантов.
- Матрица совместимости форм и типов.

---

## 4.1. Композиция поверхности

### 4.1.1. Список форм (16)

**Твёрдые (литосферные):**
1. Скалы
2. Пески / пустыни
3. Кратеры
4. Стеклянные поля (оплавленная поверхность от радиации/жары)
5. Металлические поля (обнажённая металлическая кора)

**Вулканические:**
6. Лавовые поля (активная магма)
7. Вулканические поля (потухшие вулканы)

**Ледяные:**
8. Ледники
9. Мёрзлые газы

**Водные:**
10. Океаны
11. Озёра / реки

**Биосферные:**
12. Луга / степи
13. Леса
14. Джунгли
15. Болота
16. Коралловые рифы

Атмосфера — отдельно, не занимает площадь.

### 4.1.2. Правило отображения

В карточке планеты **нулевые значения не показываются**.

Пример:

```
Планета Акса
Поверхность: 30% скалы, 40% ледники, 30% океаны
```

### 4.1.3. Алгоритм генерации

1. **Базовая связка «архетип → базовые веса»** (из `config/planet_archetypes.json`).
2. **Корректировка по температуре:**
   - T > 700 K → доля лавовых полей ×1.8
   - T < 200 K → рост ледников и мёрзлых газов
   - T 300–380 K → биосфера вверх
3. **Корректировка по воде:**
   - water > 70% → океаны ×2.0
   - water < 5% → океаны, озёра, болота, коралловые рифы удаляются
4. **Рандом ±20%** на каждую форму.
5. **Разрешение конфликтов** по матрице совместимости: несовместимая форма с меньшим весом удаляется. Если веса равны — случайная.
6. **Нормализация** суммы долей к 100%.

**Лимит форм отсутствует.** Ограничение только матрицей совместимости. Минимум — одна форма.

### 4.1.4. Связь «поверхность → плотность»

Плотность планеты зависит от доминирующей формы поверхности:

| Доминирующая форма | Плотность (в единицах Земли) |
|--------------------|------------------------------|
| Ледники, мёрзлые газы | 0.5–0.8 |
| Океаны, озёра | 0.8–1.0 |
| Скалы, пески, кратеры | 0.9–1.3 |
| Металлические поля | 1.2–1.6 |
| Стеклянные поля | 1.0–1.2 |

Это влияет на размер планеты (см. `03_planets.md`, раздел 3.4).

## 4.2. Композиция недр

### 4.2.1. Список типов (17)

1. Пустая порода — балласт, без ресурсов
2. Магматические породы — гранит, базальт, габбро
3. Метаморфические породы — мрамор, сланец, кварцит
4. Осадочные породы — известняк, песчаник, глина
5. Рудные жилы — железо, медь, олово, титан
6. Редкоземельные жилы — литий, тантал, ниобий
7. Радиоактивные зоны — уран, торий
8. Угольные пласты
9. Нефтяные карманы
10. Газовые карманы — метан, CO₂, гелий
11. Подземные воды — водоносные слои
12. Подземные льды
13. Магматические камеры — активная магма
14. Кристаллические жилы — самоцветы
15. Соляные купола — соль, гипс
16. Пещерные системы — карстовые полости
17. Металлические ядра — плотные металлы в глубине

### 4.2.2. Отличие от поверхности

- Ресурсы поверхности игрок собирает **вручную** (мини-игра) или NPC-фракции.
- Ресурсы недр добываются **только заводом**.

### 4.2.3. Композиция

Типы на планету с процентами, без лимита. Пример:

```
Планета Акса
Поверхность: 30% скалы, 40% ледники, 30% океаны
Недра: 60% пустая порода, 25% рудные жилы, 15% подземные воды
```

### 4.2.4. Связь «поверхность → недра» (мягкая)

| Поверхность | Вероятные недра |
|-------------|-----------------|
| Скалы | Магматические, метаморфические породы, руды |
| Вулканические поля | Магматические камеры, руды, сера |
| Пески | Осадочные породы, соляные купола, нефть |
| Океаны | Подводные руды, нефть на шельфе |
| Ледники | Подземные льды, кристаллические жилы |
| Кратеры | Руды от метеоритов, редкие металлы |
| Биосферные | Почва, угольные пласты |

### 4.2.5. Влияние на ядро

Композиция недр напрямую влияет на ядро (см. `03_planets.md`, раздел 3.5):

- **Доля магматических камер** → активность ядра.
- **Доля радиоактивных зон** → радиоактивность ядра.
- **Наличие металлических ядер** → тип ядра (металлическое).

## 4.3. Спутники газовых гигантов

Газовые гиганты **не имеют собственной композиции поверхности** — только атмосфера.

Однако у каждого газового гиганта есть **3–10 спутников**, каждый — **полноценная локация**:

- Своя **композиция поверхности** (те же 16 форм + матрица совместимости).
- Свои **ресурсы** (генерируются по общим правилам).
- Своя **физическая температура** — комбинируется из трёх источников:
  - внутренний нагрев от газового гиганта (`giantTemp × 0.3`);
  - приливный нагрев (`400 / orbitIndex³`);
  - остаточный нагрев от звезды (обычно слабый).
- Может быть **жизнь** (редко — например, подлёдные океаны).
- Может быть **поселение** (задел на будущее).

**Распределение температур спутников:**

| Диапазон | Что получается |
|----------|----------------|
| > 700 K | Раскалённый, вулканизм (Ио-подобный) |
| 400–700 K | Горячий, лава и вулканы |
| 250–400 K | Умеренный, жидкая вода, плотная атмосфера |
| 180–250 K | Ледяной, подповерхностный океан (Европа-подобный) |
| < 180 K | Холодный, лёд и мёрзлые газы |

Спутники — часть звёздной системы. На карте отображаются в модальном окне рядом с газовым гигантом.

## 4.4. Матрица совместимости

### 4.4.1. Концепция

Симметричная матрица N×N. Диагональ всегда `true`. Симметрия A↔B = B↔A.

- Уникальных значений: **136** для поверхности (16 форм).
- Уникальных значений: **153** для недр (17 типов).

### 4.4.2. Категории

- `subterrain` (недра) — 17 типов.
- `surface` (поверхность) — 16 форм.

Обе категории хранятся в одной таблице `compatibility_matrix`, разделяются по полю `category`.

### 4.4.3. Хранение

В БД:

```sql
CREATE TABLE compatibility_matrix (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    category VARCHAR(50) NOT NULL,
    type_a VARCHAR(100) NOT NULL,
    type_b VARCHAR(100) NOT NULL,
    compatible BOOLEAN NOT NULL DEFAULT TRUE,
    updated_at TIMESTAMPTZ DEFAULT NOW(),
    UNIQUE(category, type_a, type_b)
);
```

Хранятся только **запрещённые** пары (`compatible = FALSE`). Если пары нет в БД — формы совместимы.

### 4.4.4. Дефолты

Файл `config/compatibility_defaults.json`. При пустой БД — загружаются при старте. Кнопка «Сбросить к дефолту» в админке.

### 4.4.5. Кеш

Матрица читается из БД при старте и кешируется в памяти. При изменении через админку — обновляется БД и кеш.

### 4.4.6. API

- `GET /admin/compatibility?category=surface|subterrain`
- `POST /admin/compatibility` — батч-обновление
- `POST /admin/compatibility/reset?category=...` — сброс к дефолтам

### 4.4.7. Использование при генерации

Первый тип выбирается случайно. Каждый следующий — проверяется на совместимость со всеми уже выбранными. Несовместимые — пропускаем.

### 4.4.8. Дефолтные запреты для недр

| Пара | Причина |
|------|---------|
| Магматические камеры ↔ Подземные льды | Расплав vs лёд |
| Магматические камеры ↔ Угольные пласты | Уголь сгорит |
| Магматические камеры ↔ Нефтяные карманы | Нефть сгорит |
| Магматические камеры ↔ Газовые карманы | Газ сгорит |
| Магматические камеры ↔ Подземные воды | Вода испарится |
| Магматические камеры ↔ Соляные купола | Соль расплавится |
| Радиоактивные зоны ↔ Нефтяные карманы | Радиация разложит |
| Радиоактивные зоны ↔ Угольные пласты | Радиация разложит |
| Радиоактивные зоны ↔ Газовые карманы | Радиация разложит |
| Радиоактивные зоны ↔ Подземные воды | Радиация загрязнит |

### 4.4.9. Дефолтные запреты для поверхности

| Пара | Причина |
|------|---------|
| Лавовые поля ↔ Ледники | Взаимоисключающие |
| Лавовые поля ↔ Мёрзлые газы | Взаимоисключающие |
| Лавовые поля ↔ Океаны | Взаимоисключающие |
| Лавовые поля ↔ Озёра / реки | Взаимоисключающие |
| Лавовые поля ↔ Леса | Сгорят |
| Лавовые поля ↔ Джунгли | Сгорят |
| Лавовые поля ↔ Болота | Испарятся |
| Лавовые поля ↔ Луга / степи | Сгорят |
| Лавовые поля ↔ Коралловые рифы | Погибнут |
| Ледники ↔ Джунгли | Взаимоисключающие |
| Ледники ↔ Болота | Замёрзнут |
| Мёрзлые газы ↔ Джунгли | Взаимоисключающие |
| Мёрзлые газы ↔ Леса | Замёрзнут |
| Кратеры ↔ Биосферные формы | Жизнь не успевает восстановиться |
| Кратеры ↔ Коралловые рифы | Разрушение рифов |
