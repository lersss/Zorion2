## 7.1. Карта миров

- **2D Canvas.**
- **Зум** (колёсико + кнопки) — от 2% до 1000%.
- **Панорамирование** (перетаскивание).
- **Кнопка «Найти меня»** — центрирование на текущем мире.
- **Цвет миров** соответствует спектральному классу звезды.
- **Размер миров** зависит от спектрального класса.
- **Клик по миру** → открывается модальное окно системы.
- **Фильтры** — панель под шапкой:
  - Фильтрация по планетам (наличие, жизнь, обитаемость, тип поверхности, ресурсы).
  - Бэкенд-фильтрация, debounce, счётчик активных фильтров, спиннер.
- **Сохранение вьюпорта** — позиция и масштаб в `sessionStorage`. Восстанавливаются при перезагрузке и после применения фильтров.

### 7.1.1. Регионы (малый зум)

- При зуме ниже порога (`scale < 0.05`) вместо «бессмысленных шариков» кластеров
  карта показывает **регионы галактики**: диаграмма Вороного по кластерным центрам,
  каждая ячейка залита своим цветом, границы — цветные линии, название — в центре.
  Ячейки не пересекаются и замощают всю галактику.
- Регионы генерируются при `GenerateUniverse` (по одному на кластерный центр,
  выбросы приписываются ближайшему), хранятся в таблице `regions`.
- Цвет — из палитры генератора, имя — `names.GenerateRegionName`
  (кириллица, курируемые корни, правило созвучия).
- Данные: `GET /api/regions` (все регионы — для Вороного нужны все центры).
- На малом зуме звёзды не рисуются — только регионы (точки некрасивы и
  дёргаются при перекластеризации). Клик всё равно зуммирует к ближайшему кластеру.

### 7.1.2. Зум

- `minZoom` привязан к размеру галактики: на максимальном отдалении вся галактика
  помещается в экран (радиус берётся из центров регионов, пересчёт при ресайзе).
- Отображение зума: минимум «1%», при масштабе «вся галактика» — подпись «Галактика».
- Отдаление ускоряется при приближении к минимуму — не нужно крутить колесо десятки раз.

## 7.2. Модальное окно системы

### 7.2.1. Общее

- Отображает **звезду** (цвет и размер по спектру) и **планеты на орбитах**.
- Планеты имеют **процедурные текстуры**, генерируемые на сервере.
- **Зум** (колесо мыши) и **панорамирование** (перетаскивание).
- **Мини-карта** в углу — общий вид системы (TODO: несовпадение вьюпорта).
- **Закрытие:** клик на оверлей или ESC.

### 7.2.2. Правая панель

Список планет (таблица) или детальная карточка с вкладками:
- Общее
- Ресурсы
- Поселения
- Фракции

**Клик по планете** (на Canvas или в таблице) — выбор планеты, подсветка золотым кольцом, показ детальной информации.

### 7.2.3. Газовые гиганты

Отображаются как центральное тело. Вокруг — **спутники** (см. `04_composition.md`, раздел 4.3).

Клик по спутнику — открывается его карточка.

## 7.3. Карточка планеты

Карточка содержит:

### 7.3.1. Общее
- Тип (геймдизайнерский).
- Температура.
- Вода (%).
- Атмосфера.
- Биосфера.

### 7.3.2. Ядро (новое)
- Тип (металлическое, силикатное, ледяное, экзотическое).
- Активность (0–100).
- Радиоактивность (0–100).
- Возраст (млрд лет).
- Флаги: активное / металлическое / радиоактивное.

### 7.3.3. Физика (новое)
- Масса (в земных).
- Размер (радиус, в земных).
- Плотность (в единицах Земли).
- Альбедо (если показываем).

### 7.3.4. Поверхность
Только ненулевые компоненты.

Пример:
```
Поверхность: 30% скалы, 40% ледники, 30% океаны
```

### 7.3.5. Недра
Только ненулевые типы.

Пример:
```
Недра: 60% пустая порода, 25% рудные жилы, 15% подземные воды
```

### 7.3.6. Ресурсы
Список с иконками категорий (🪨 Атрокс, 🔥 Бролин, 💨 Зорнит).

### 7.3.7. Поселения, фракции
Списки (когда появятся механики).

### 7.3.8. Правило отображения
**Нулевые значения не показываются.** Ни в поверхности, ни в недрах.

## 7.6. Админка

### 7.6.1. Управление
- Миры: создание, удаление, пагинация, поиск.
- Генерация вселенной (настраиваемые параметры).
- Генерация планет.
- Генерация фракций.
- Прогресс-бары с возможностью остановки.

### 7.6.2. Статистика планет

- Общая сводка (миров, планет, обитаемых, с жизнью, средние параметры).
- Распределение по типам поверхностей (доминирующие).
- Распределение по формам (count + share + avg).
- Распределение по типам недр (count + share + avg).
- Распределение по типам ядер.
- Распределение по геймдизайнерским типам.
- Распределение по спектральным классам.
- Аномалии (отклонения от ожидаемых значений).
- Сортировка таблиц по клику на заголовок.

### 7.6.3. Вкладка «Совместимость»

- Матрица N×N для поверхности и недр.
- Подвкладки «Недра» и «Поверхность».
- Таблица с чекбоксами.
- Кнопки «Сохранить» и «Сбросить к дефолту».
