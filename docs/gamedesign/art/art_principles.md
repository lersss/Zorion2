# Общие принципы генерации спрайтов (art_principles.md)

> Общие правила AI-генерации визуальных сущностей Zorion (спрайты кораблей, рас,
> звёзд, планет и т.д.) через Stable Diffusion (ComfyUI + Juggernaut XL +
> ControlNet). Применимо к ЛЮБОЙ сущности — конкретика по сущностям в отдельных
> доках этой папки (`art_ships.md` и т.д.). Зафиксировано 2026-09-16.

**Стек (проверено):**
- ComfyUI на `C:\ComfyUI` (вне репо), API `http://127.0.0.1:8188`
- Python 3.10.6, torch 2.5.1+cu121, RTX 4060 Ti 16 GB
- Модель **Juggernaut XL v9**, ControlNet **canny-sdxl-1.0**, апскейл **4x-UltraSharp**
- Скрипты: `tools/comfy_api.ps1`, `tools/process_ship.py`, `tools/batch_concepts*.ps1`
- Принятые ассеты: `ai_drafts/final_accepted/` (вне git)

## 1. Главные принципы (универсальны для всех сущностей)

1. **txt2img не даёт контроль формы.** SDXL при жёстких промптах срывается в
   сюрреализм, рисует «нос к зрителю», переворачивает объект. Текст НЕ управляет
   перспективой и ориентацией.
2. **Рабочий путь — ControlNet Canny + img2img от цветного силуэта.** Форму
   задаёт силуэт (нарисованный программно), текстуру/цвета — SDXL.
3. **Двухэтапный процесс обязателен** для текстуры: (1) форма, (2) детализация.
4. **Ориентацию задаёт СИЛУЭТ, а не промпт:** «корма/база» слева, «нос/перед»
   справа, асимметрия. Симметричные силуэты SDXL разворачивает произвольно.
5. **Концепты («сущность в образе слова»)** — лучший способ получить дикое
   разнообразие. Рабочий процесс: пачка 10–20 → создатель отбирает номерами.

## 2. Силуэт (универсальные требования)

- Холст **1024×1024**, фон чёрный `(5,5,5)`, вид сверху, «нос» вправо.
- **Модули цветные**: основной корпус крем `(232,224,186)`, детали сталь
  `(120,140,170)`, акценты бронза `(140,90,45)`, тёмные элементы `(40,44,55)`,
  стекло/кабина `(180,210,235)`, свечение/огонь `(230,120,40)` — по смыслу
  сущности. Между модулями тёмные границы `(12,12,12)`.
- **Асимметрия обязательна**: база/дюзы слева, выступающая часть справа.
- **Запас от краёв**: масштабировать до ~82% холста + центрировать (~90 px).
- **Огонь/свечение только в силуэте на корме** — иначе SDXL размазывает по всему.
- «Нос» = светлая кабина/стекло, НЕ синий (синий читается как «дюзы»).

## 3. Двухэтапный процесс

### Этап 1 — форма (img2img + ControlNet)
- Canny (low 0.2 / high 0.5 — НОРМАЛИЗОВАННЫЕ 0–0.99!) → ControlNetApply
  (strength 1.5) → VAEEncode силуэта → KSampler.
- **denoise 0.85, steps 40, cfg 7, dpmpp_2m/karras**.
- Промпт: концепт + «top-down flat view, horizontal, [перед] pointing FORWARD to
  the right, [корма] at the LEFT rear, perfectly flat, no perspective, game
  asset, 2D sprite, centered, single [сущность], on black background, no text,
  no watermark».

### Этап 2 — детализация (img2img без ControlNet)
- **denoise 0.45–0.55, steps 40, cfg 7.5, dpmpp_2m/karras**.
- Промпт: «ENTIRE [сущность] covered with dense mechanical texture, panel lines,
  greebles, rivets, vents, weathering, subtle gradients, glowing details, rich
  palette, **no orange, no flames**, neutral [корма] at left rear, maximal
  detail, masterpiece».
- Эффект: уникальных цветов растёт с ~25 до ~1200+ — текстура появляется.

## 4. Пост-обработка (`tools/process_ship.py`)

- **Фон режем ПО ЦВЕТУ, а не rembg** (rembg режет объект): фон Juggernaut
  ровный тёмный ~(21,23,26) — вырезаем в пределах `BG_TOL=40` от углов.
- **Крупнейший связный компонент** (scipy) — убирает «мусор».
- **Сглаживание границ** (морфология) — убирает зубцы.
- **Кадрирование + паддинг 6 px → 200×200** (ImageOps.pad, центр).
- **Нормализация ориентации** (`--no-orient` для особых форм).
- Hi-Res по желанию: 4x-UltraSharp → 2048 → img2img denoise 0.35–0.5 → снова
  process_ship.

## 5. Рабочий процесс с создателем

1. Пачка 10–20 (каждый — новый концепт-слово).
2. Превью-сетка с номерами → создатель: «оставить N, M / выкинуть K»,
   «повернуть на 90/180».
3. Принятые — в `ai_drafts/final_accepted/`, остальное удаляется.
4. **Правило:** новые генерации — ТОЛЬКО с НОВЫМИ словами/форм-факторами.

## 6. Операционные грабли (сессия)

1. PowerShell + инлайн `$` ломаются — batch-скрипты файлами, запуск с
   `-ExecutionPolicy Bypass -File`.
2. Фоновые пачки умирают при прерывании сессии — скрипт пишет лог
   (`Add-Content`) и поддерживает продолжение (`-StartNum -StartSeed`).
3. ComfyUI при простое умирает — проверять `/system_stats` перед пачкой.
4. Браузер кэширует картинки — обновлять `Ctrl+Shift+R`.
5. Скачивание 2–7 GB: curl `-C -` (resume), проверять процесс (умирает),
   скорость ~40 MB/мин, размер по Content-Length сервера.
