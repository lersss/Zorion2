# 13a. Гибель поселений: механизм модификаторов

**Создано:** 2026-09-12
**Статус:** черновик
**Связано с:** `13_settlements.md`, `18_needs.md`, `17_decay.md`, `11_production.md`

## Правило

Гибель поселения считается через **модификаторы**: событие кладёт на поселение
модификатор, поселение агрегирует свои модификаторы и реагирует. Источник
проблемы поселению **безразличен** — он атрибут, а не логика.

```
Событие (среда при генерации, взрыв, катастрофа, терраформирование)
   → модификатор { тип, интенсивность, источник, снятие }
   → поселение агрегирует по типу → λ (смерть) + вторичные (стабильность)
```

модификатор:
- `тип` — ось среды: температура, радиация, токсичность, болезни, стабильность, …
- `интенсивность` — величина (защита — отрицательная);
- `источник` — читается игроком («взрыв магната X»);
- `снятие` — длительность / до события / пока не изменится среда / бесконечно.

Типы модификаторов — **класс, а не перечень** (§GD: примеры открыты). Среда
планеты — стоячий модификатор, создаётся при генерации, снятие «пока не
изменится среда»; терраформирование пересчитывает стоячий набор. Тика нет —
только события и ленивый пересчёт (инвариант 2).

## Агрегация: правило анти-абьюза

По каждому типу:
- **Угроза = максимум по источникам.** Тысяча «чайников» по +1° даёт +1°,
  а не +1000°.
- **Защита — по ширине (покрытию населения), не по силе.** Стек не усиливает:
  тысяча куполов — это защита тысяч человек, а не иммунитет одного. Каждый
  защитный вклад вычитает свою эффективность из угрозы для своих N человек.

Следствие, принятое явно: **стекование не работает**. Это цена за простоту
и за то, что абьюз невозможен математически, а не экономически.

## Рабочий пример: температура

Жара и холод — **один механизм**: выход за диапазон устойчивости в любую
сторону даёт смертность. Одна кривая, одна проверка.

```
D = |T_эфф − комфорт|,   T_эфф = МАКС по источникам
база поселения: термоустойчивость C₀ (есть у всех)
купол: { N, C } — защищает N человек, вычитая C из D для них

группа под защитой k:  D_k = max(0, D − C₀ − C_k)
открытые:              D_k = max(0, D − C₀)

λ(D_k) — кривая severity: 0 в терпимой зоне → растёт → насыщается на λ_max
ускорения у жары НЕТ
dp/dt = −λ(D_k)·p_k      // смерть по каждой группе
```

Проверки абьюза: 1000 чайников → D от максимума, λ≈0; 1000 куполов {N=100} →
покрывают 100k человек (ширина); 1000 шуб {N=1, C=10} против 0 Кельвина →
их люди видят D−10, всё равно смертельно, остальные открыты.

## Термоустойчивость как атрибут поселения

Сопротивление среде (термо-, радио-, гермо-) — **атрибут поселения**, рядом со
стабильностью и терпением. Модель меняется с «планета горячая → смерть» на
«среда против устойчивости поселения».

**Хук магната:** магнат вкладывается в устойчивость своего поселения и
поднимает эффективную температуру среды рядом (взрыв, техногенная катастрофа).
Умирают поселения с низкой устойчивостью, свои — выживают. Фабрика конкурента
не уничтожается (инвариант 4) — она становится мёртвым грузом, людей нужно
завозить заново.

## Вторичные эффекты — второй ярус

Длительная жара даёт не только прямую смерть, но и вторичные эффекты, которые
читает карточка (§7.4.3) через стабильность: болезни в полосе 50–100°C (при
100°C+ бактерии гибнут — но там уже прямая смерть), стабильность ↓,
производительность заводов (при 70°C рабочие дома). Это отдельный слой от λ,
в пробу чистой смертности не входит.

## Атрибуция

Источник модификатора читается игроком — агрессия атрибутируема, есть контрплей
и сдержанность (согласуется с §17.5.2 «вмешательства видны в логе мира»).
**Открыто:** источник всегда виден или бывает анонимным?

## Цена и режим отказа

- **Цена:** механизм сложнее одной формулы `h` — нужна инфраструктура
  модификаторов (агрегация, хранение, снятие). Платим за расширяемость и
  анти-абьюз.
- **Как сломается:** если агрегацию поставить неверно — абьюз (сумма). Если
  типов модификаторов станет слишком много — каждая ось требует своей
  устойчивости и проверки; сдержанность держит §18.1.2 (среда выбирает 1–2
  жёсткие потребности на поселение).

## Инварианты

- **2 (стоимость не от размера галактики):** тика нет, расчёт по событию и при
  чтении. Не нарушен.
- **9 (много причин — один исход):** механизм коллапса один (население убывает →
  гибель), причина — текст по доминирующему модификатору. Не нарушен.
- **10 (сущность оправдана решением):** каждая защита/устойчивость связана с
  выбором игрока (купол, прокачка устойчивости). Не нарушен.
- **4 (офлайн не теряет имущества):** поселение NPC, фабрика не уничтожается,
  становится мёртвым грузом. Не нарушен.

## Открытые вопросы

- Форма кривой λ(D): как быстро severity достигает λ_max за порогом.
- Шкала устойчивости: диапазон в градусах, наследуемый / прокачиваемый.
- Атрибуция: всегда видна или бывает анонимной.
- Агрегация вторичных модификаторов (стабильность): максимум или сумма.
- Купол с флагом «повреждён» (§18.3.3): что с покрытыми людьми.
- Где хранятся модификаторы поселения, как инвалидируются (ленивый пересчёт).
