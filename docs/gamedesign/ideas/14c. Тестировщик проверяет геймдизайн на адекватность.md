# 14c. Новая роль @balancetester — тест баланса на адекватность

**Создано:** 2026-09-14
**Статус:** Применено (роль + гейт), `tester.md` откачен, ожидает первого прогона
на `14b`
**Приоритет:** фича (процесс агентов)
**Связано с:** `.opencode/agents/tester.md`, роль @manager (гейты), `docs/QA_CHECKLIST.md`,
идея `14b` (перекалибровка температуры — первый кандидат на такую проверку)

---

## Сырое пожелание (создатель, 2026-09-14)

> «Я хочу чтобы тестировщик тестировал геймдизайн на адекватность, а не только
> техническую реализацию.»

## Контекст

Тестер сейчас проверяет: diff, слои симптома, DoD (`go build/vet/test`),
негативные/краевые сценарии, чек-лист. **Адекватность дизайна** — соответствие
чисел здравому смыслу, инвариантам геймдизайна (`18a`, инварианты в
`docs/gamedesign/`), формулировкам спек — не проверяется нигде; ограничивается
личным мнением дизайнера. Пример из сессии: калибровка температуры (573 K →
t50% 5.6 ч при физической мгновенной смерти) — дизайн-решение прошло без
независимой проверки на адекватность.

## Что сделано (2026-09-14, решение создателя «тестер здравого смысла перед создателем»)

- Создатель уточнил: **не расширять** @tester (у него своя техническая методика,
  диффы, QA-чеклист — лишний контекст), а создать **новую роль без лишнего
  контекста** — только баланс на адекватность.
- Создан `.opencode/agents/balancetester.md`: критерии (здравый смысл/физика/
  эталон создателя, инварианты `docs/gamedesign/`, согласованность спека↔код↔таблицы,
  «что увидит игрок»), запрет «не предлагать числа вместо дизайнера», без
  технической методики и QA-чеклиста.
- `.opencode/agents/tester.md` — **откачен** к исходному (технический прогон).
- `.opencode/agents/manager.md` — гейт: после `@designer`, **до показа создателю**,
  для балансных фич — прогон `@balancetester`; мелкие фичи/баги — без прогона;
  числа менялись → повторный прогон.
- Первое применение: `14b` (перекалибровка температуры).

## Маршрут

Изменение процесса/промтов агента (правка `.opencode/` — через skill
customize-opencode) → гейт: одобрение создателя → применение + прогон по `14b`.
