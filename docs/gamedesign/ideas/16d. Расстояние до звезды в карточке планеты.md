## Сырое пожелание (создатель, 2026-09-14)

> «Фича в бэклог: добавить в карточку планеты расстояние до звезды в
> астрономических единицах»

## Факты из кода (менеджер, проверено)

- Радиус орбиты в а.е. уже считается генератором:
  `orbitRadiusByIndex(index) = 0.4 × 1.7^index` (`internal/generator/planet/
  physics.go`, клэмп index < 1 → 1; от него считается температура планеты —
  `computeEquilibriumTemp`).
- `planets.orbit_index` есть в БД и в JSON (`internal/models/planet.go`),
  отдаётся в ответе API.
- В UI (`web/static/js/modal/`) орбиты рисуются визуально по `orbit_index`
  (layout.js), но числовое расстояние до звезды не показывается нигде.
- Вывод: значение скорее всего выводится из `orbit_index` без миграции БД
  (одна формула с генератором — нет расхождений). Техрешение — @developer.

## ТЗ (готово, ответы создателя 2026-09-14)

1. **Место показа** (решение создателя «выбери подходящее» → менеджер/разработчик):
   строка «Расстояние до звезды: N а.е.» в блоке физических данных карточки
   планеты в модалке системы (рядом с температурой/гравитацией/радиоактивностью).
2. **Точность вывода** (решение создателя): **до 1 знака** («0.7 а.е.»);
   крупные орбиты (десятки/сотни а.е.) — тоже до 1 знака после запятой
   (например «12.3 а.е.»), без научной записи.
3. **Источник** (решение создателя): **радиус орбиты генератора** —
   `0.4 × 1.7^orbit_index` а.е. (та же функция, из которой генератор считает
   температуру; `orbitRadiusByIndex` в `internal/generator/planet/physics.go`,
   клэмп index < 1 → 1). Отдельное поле/миграция БД не вводятся.

Техрешение @developer: откуда брать число (сервер добавит `distance_to_star` в
JSON планеты из `orbit_index` одной формулой — предпочтительно, один источник
правды; либо клиент посчитает формулу сам — одинаковая математика, но две
точки правды) — решает разработчик на этапе реализации.

## Критерии готовности

- В блоке физических данных карточки планеты видно «Расстояние до звезды: N а.е.».
- N для орбиты с индексом k равно `0.4 × 1.7^k` (с клэмпом k<1→1), округлено
  до 1 знака, без научной записи (например «0.7 а.е.», «12.3 а.е.»).
- Значение совпадает на сервере и на клиенте (нет расхождения формул).
- DoD по `AGENTS.md` §2 (если правка затронет Go).
