## Сырое пожелание (создатель, 2026-09-14)

> «Баг: время полета корабля не зависит от расстояния»

## Диагностика (менеджер, факт из кода)

`internal/handlers/travel_handlers.go:118–129` (`StartTravel`):

```go
dx := fromWorld.CoordX - targetWorld.CoordX
dy := fromWorld.CoordY - targetWorld.CoordY
dist := math.Sqrt(dx*dx + dy*dy)

speedFactor := 0.3
duration := time.Duration(dist*speedFactor) * time.Second
if duration < 3*time.Second { duration = 3 * time.Second }
if duration > 60*time.Second { duration = 60 * time.Second }
```

- Формально зависимость есть: `dist × 0.3 сек`, но **жёсткий кап 60 сек**
  срезает её для всех полётов с dist > 200:
  - dist ≤ ~10 → 3 сек (мин);
  - dist ~100 → 30 сек;
  - dist ≥ 200 → 60 сек (всегда).
- Масштаб галактики: миры в круге радиуса `MapSize` (по умолчанию 8000,
  `WorldSpread 20`, `MinDist` соседних миров ~100–300,
  `internal/generator/galaxy/`); админ-дефолт генерации — `MapSize 8000`
  (`internal/handlers/admin_universe.go:121`). Расстояние между соседними
  мирами чаще ≥ 200 → **почти все полёты упираются в потолок 60 сек**, время
  не зависит от расстояния. Замечание создателя подтверждается.

## ТЗ (черновик)

- Время полёта должно зависеть от расстояния между мирами на всём игровом
  диапазоне: убрать/пересмотреть кап 60 сек и скорость 0.3 сек/ед (константы
  произвольные). Что считать «правильным» временем полёта (эталон) — вопрос
  создателю на уточнении (например: to ближний мир ~секунды-минуты, дальний —
  минуты-часы?).
- Не менять сам трэвел-менеджер (`internal/travel/manager.go` — он честно
  ждёт переданный `duration`) — правка только в расчёте `duration` в
  `StartTravel`.
- Баланс-компонент не затронут (полёты не трогают население/экономику).
- DoD по `AGENTS.md` §2.

## Критерии готовности (черновик)

- Полёт к ближней и дальней звезде даёт разное время, пропорциональное
  расстоянию (в рамках выбранного эталона). Соседние миры ≠ максимальное время.
- Тест: юнит-тест на расчёт `duration` от расстояния (рёбра: 0, мин, среднее,
  дальнее) — до фичи красный, после зелёный (TDD).

## Триаж (решение создателя, 2026-09-14)

- Баг **в бэклог** целиком (полная зависимость времени от расстояния — решается
  отдельно, ждёт эталона времени полёта).
- Но **сейчас выполняется быстрая правка:** кап времени полёта 60 сек → **20 сек**
  (строки `travel_handlers.go:127–129`). Это сужает «мёртвую зону» (зависимость
  от расстояния сохранится до dist > ~66), не решает баг полностью;
  полное решение — в бэклоге по эталону.
