## Что переводим

- **Холод** (T < 200 K): сейчас временно полюсная кривая B (λ-модель, жёсткий
  ноль T ≤ 100 K → +Inf) — нарушает эталон «порог-переключатель запрещён».
  Перевести в рекурсивную R-компоненту (как жара): плавная сходимость,
  сохранение эталона «−200 °C (73 K) → минуты».
- **Гравитация**: сейчас черновая линейная severity с жёстким нулём (λ-модель).
  Перевести в R-компоненту; гравитация двусторонняя (и перегрузка, и невесомость).

## Гипотезы (скрытые, для @writer/@scientist)

Прогоны 2026-09-14:
- промежуточный холод −100 °C (зона 100–200 K — самая неясная);
- гравитация 3g (перегрузка).

## Опусы @writer/@scientist (сетка 2026-09-14)

Полное вымирание (вилки писатель/учёный; данные для контрольных точек R_компонент):

**Холод (°C):** −50 → полное ~дни–недели (улица: минуты–часы, поселение дни–недели); −100 → ~2 недели (улица 1–10 мин); −200 → ~часы–дни (минуты, эталон «минуты»); −250 → ~часы (секунды–минуты).

**Гравитация (g):** 0,3 → ~годы (не смертельно, атрофия мышц/костей, поселение живёт); 2 → ~дни–недели; 3 → ~дни (стоя — G-LOC минуты, лежа — часы); 5 → ~часы–дни (секунды–минуты); 10 → ~часы (секунды, разрыв тканей).

**Радиация:** ×100 (~10 мГр/год) → ~годы–десятилетия (не острая, онкология); ×10 000 (~1 Зв/год) → ~недели–месяцы (острая лучевая, 2–6 нед); «смертельная за часы» (10–50 Зв) → ~дни; «за минуты» (≫50 Зв) → ~часы (нейро-сосудистый синдром).
