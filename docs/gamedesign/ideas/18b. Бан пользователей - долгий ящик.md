# 18b. Бан пользователей — в долгий ящик

**Создано:** 2026-09-14

**Приоритет:** фича (отложена)

## Суть

Блокировка входа/доступа пользователя без удаления учётки: колонка
`users.is_banned`, гейт в логине и `/me`, пометка в профиле. Упоминалось в схеме
прав ролевой модели (идея `18a`), решено не делать в спринте ролевой модели.

**Решение создателя (2026-09-14):** «Бан - в долгий ящик бэклога». В спринте
ролевой модели ( `99.2.14` ) — только удаление учётки (`DELETE /admin/users/{id}`).

## Когда брать в работу

По приоритету создателя; отдельным входом, не вместе с ролевой моделью.
