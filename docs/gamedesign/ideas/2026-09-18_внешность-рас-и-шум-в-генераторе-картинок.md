## Разбор менеджера

**Что есть сейчас:**
- `docs/gamedesign/races/*.md` — 60+ лор-файлов рас; раздела «Внешний вид» нет (обрывки в «Живость. Сцена»).
- Арт-студия `cmd/art-studio`: промты строятся случайным подбором из глобальных словарей `config/art/forms.json` (`character`, `parts`, `shapes`, `struct`) + `config/art/families.json` (`forms`/`materials`/`glows` расы, `extra`/`anchor`/`scene` семьи). `BuildPrompt`/`BuildPromptWide` (prompt.go).
- **Глобальные словари перекошены под горячие/вулканические семейства**: половина `parts` — `lava-fingers`, `basalt-pillars`, `sulfur-veins`, `ember-streams`… и т.п. Для холодных/водных/планктонных рас это мусор. Плюс `shapes` содержит `pyramid`, `obelisk`, `spire` — нерелевантно гуманоидам; морфная ветка использует «alien humanoid race» / «alien creature» (BuildPromptWide) — для планктона даёт лицо.

**Решение по п.2 (менеджер):**
- **Док-база:** раздел «Внешний вид» в `docs/gamedesign/races/*.md` — подробное описание: силуэт/форма, материал, свечение, характерные детали, палитра, среда/фон, **чего у расы НЕТ** (запреты/нерелевантные теги).
- **Машинный источник:** `config/art/families.json` — у расы новое поле (напр. `appearance` + `blocked`): структурированная копия для генератора. `blocked` — список запрещённых тегов, по которым **фильтруются глобальные словари** при подборе элемента (substring-матчинг). Промпт собирается из отфильтрованного пула → шум уходит, **вариативность остаётся** (пул по-прежнему большой, выбор случайный).
- Фолбек: если после фильтрации пул пуст — не выдавать пустой промт (сохранить минимум).

## ТЗ (кратко; детали — в спеке)

1. **Доки:** раздел «Внешний вид» в файлах рас пилотного набора (формат — в спеке; затем масштабирование на все 60).
2. **Конфиги:** `config/art/families.json` — поля внешности/запретов у рас пилота.
3. **Код:** `cmd/art-studio` — фильтрация словарей по `blocked` в `BuildPrompt`/`BuildPromptWide` (+ `forms.json` shapes при FormsFor, если применимо); фолбек при пустом пуле; тесты.
4. **Пилот (6 контрастных рас):**
   - **Прибрежные** (F1, id 4; `coastal.md`) — гуманоиды → кейс «пирамида/геометрия».
   - **Метан-планктон** (F3, id 12; `methane_plankton.md`) — планктон → кейс «alien рисует лицо».
   - **Глубинники** (F1, id 3; `deep_dwellers.md`) — мягкотелые глубоководные → вулканический словарь шумит.
   - **Крио-рои** (F2, id 9; `cryo_swarms.md`) — рои ледяных осколков.
   - **Туман-рои** (F3, id 14; `mist_swarms.md`) — рои пыли в тумане.
   - **Кшарры/Соляные** (F5, id 23; `saltfolk.md`) — контрольный: горячая раса, вулканический словарь уместен (проверка, что фильтрация не обедняет вариативность).
5. **Проверка:** ручной прогон генерации пилота (вариации от эталона), перегенерация эталонов разрешена.
