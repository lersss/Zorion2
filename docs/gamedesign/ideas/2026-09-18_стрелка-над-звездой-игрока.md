## 1. Диагноз (что есть сейчас)

- Шапка карты: маленькая серая подпись «Текущий мир: <имя>» — легко не заметить.
- Текущая звезда подсвечена слабым жёлтым свечением (теряется среди свечений всех
  остальных звёзд и экзотики).
- **Корабль игрока рисуется на карте только во время полёта** (`drawFlight` в
  `map_render.js`). Когда игрок прилетел и «стоит» на звезде — его корабля на
  карте нет вовсе, остаётся только слабое свечение.
- Кнопка «Найти меня» 🎯 (`centerOnAgent`) — действие по кнопке, а не постоянный
  пассивный индикатор.

**Корень:** после прилёта на звезду нет явного пассивного маркера «ТЫ ЗДЕСЬ».

## 2. Решение

Анимированная стрелка-пин (SVG, золотая капля с остриём вниз) над звездой
`currentWorldId` — DOM-элемент поверх канваса:

- **Почему DOM + CSS, а не canvas:** анимация (покачивание) через CSS transform
  идёт в композиторном потоке браузера — бесплатно, без постоянной перерисовки
  канваса (полный `draw()` 60 FPS ради покачивания — расточительно; паттерн
  лёгких DOM-слоёв уже используется в `npc_agents.js` для тултипов).
- Позиция обновляется в `draw()` (`map_render.js`): панорамирование/зум/события
  всё равно рисуют кадр — стрелка синхронна с картой.
- `pointer-events: none` — не перехватывает клики/драг карты.
- Видимость: есть `currentWorldId`, не в полёте (в полёте корабль и так виден),
  звёзды рисуются (`scale >= regionNamesZoom`), позиция звезды в кадре.
- Позиция звезды: из кластеров (одиночная `sid === currentWorldId`) или из
  `state.worlds` (координаты мира игрока, `/me` → `fetchWorldByID`).

## 5а. Реализация (2026-09-18, @manager, мелкая правка)

1. `web/map.html`: `#player-arrow` (SVG-пин, золотой градиент `#fde68a→#f59e0b`,
   белая обводка + блик-кружок, остриё внизу) внутри `#canvas-wrapper`,
   `hidden` по умолчанию.
2. `web/static/css/map.css`: `#player-arrow` absolute, `transform: translate(-50%,
   -100%)` (остриё — точно на точке звезды), `pointer-events: none`, z-index 15
   (под тултипом 20), `drop-shadow`; анимация `player-arrow-bob` (translateY
   0→−5px, 1.6 s ease-in-out infinite) на внутреннем `svg` (не конфликтует с
   позиционированием внешнего div).
3. `web/static/js/map/map_render.js`: `updatePlayerArrow()` — видимость (не в
   полёте, есть `currentWorldId`, `scale >= regionNamesZoom`, звезда в кадре с
   запасом 50px), позиция из кластеров (`cnt===1 && sid===currentWorldId`) или
   фолбэк из `state.worlds`; вызов в конце `draw()`.

**Почему DOM+CSS, а не canvas:** анимация в композиторном потоке — бесплатно,
без полного `draw()` 60 FPS ради покачивания.
