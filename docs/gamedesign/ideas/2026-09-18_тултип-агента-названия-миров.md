## 0. Пожелание создателя (2026-09-18)

«Текущий мир и целевой мир в тултипе агента должны быть названиями, а не айди
миров».

## 1. Диагноз (что есть сейчас)

- `web/static/js/map/npc_agents.js` → `showNPCTooltip`: строки «Текущий мир» и
  «Целевой мир» показывают **обрезанный айди мира** (`short = id.slice(0,8)+'…'`),
  полный айди — только в `title` при наведении.
- Сервер (`GET /api/npc/positions`) отдаёт в `InterpolatedPosition` только
  `current_world_id` / `target_world_id` — **названий нет** (`internal/npc/position_cache.go`).
- При этом названия доступны серверу: `worldGrid.byID` (gridWorld.name) строится
  из `mapcache.World` (в снапшоте карты есть `Name`).

**Корень:** клиент не получает названия миров агента — только айди.

## 2. Решение

Сервер добавляет в `InterpolatedPosition` поля `current_world_name` и
`target_world_name` (берутся из `worldGrid.byID`), клиент показывает их в тултипе.
Расширение ответа аддитивное (новые JSON-поля) — существующие потребители не
ломаются; API-контракт по существу не меняется.

## 3. ТЗ (выполняет @manager, мелкая правка)

1. `internal/npc/worldgrid.go`: хелпер `nameOf(id string) (string, bool)` — имя
   мира из `byID` (nil-безопасно, как `coordsOf`).
2. `internal/npc/position_cache.go`: поля `CurrentWorldName string`
   (`json:"current_world_name"`) и `TargetWorldName *string`
   (`json:"target_world_name,omitempty"`); заполнение в `interpolatePosition`
   для текущего и целевого мира.
3. `internal/npc/position_cache_test.go`: имена в тестовой сетке + проверки
   `CurrentWorldName`/`TargetWorldName` (TDD).
4. `web/static/js/map/npc_agents.js`: `showNPCTooltip` — показывать
   `current_world_name` / `target_world_name`; фолбэк на обрезанный айди, если
   имени нет (защитно, в норме имени всегда есть — позиция не отдаётся, если
   мира нет в сетке).

Косметика отображения: БД/баланс/миграций не трогает.
