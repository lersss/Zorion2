## Пожелание создателя (2026-09-19)

> Сделай из админки возможность выйти на карту, а на карте — в админку

## Уточнения (2026-09-19)

1. Кнопка «В админку» — **только на карте** (`/map`), не на дашборде и контрактах.
2. Видна только ролям `admin`/`skycomposer` (по роли из `/me`); обычным игрокам — не показывается вовсе.
3. **В админке отдельной кнопки нет** (уточнение создателя после гейта): переход на
   карту — по **клику на планету 🌍 в левом верхнем углу шапки** (тот же `goToMap()`).

## Текущее состояние

- **Админка** (`web/admin.html`, роут `/admin`): токен в `localStorage['adminToken']`,
  роли admin/skycomposer (спека 99.2.14). Кнопок навигации на игровые страницы нет
  (и кнопки выхода нет — вне скоупа).
- **Карта** (`web/map.html`, роут `/map`): шапка с кнопками «🏠 Дашборд» (`/`) и
  «📋 Контракты» (`/assignments`); игровой токен `localStorage['token']`; роль уже
  известна клиенту — `state.userRole` заполняется из `/me` (`data.js`, идея 28a).
- Токены игровой и админский — **один и тот же JWT от `POST /login`** (auth.js),
  хранятся под разными ключами localStorage. → переходы можно сделать бесшовными:
  при переходе копировать токен в нужный ключ, повторный логин не нужен.

## План (мелкая клиентская фича)

Критерии «мелкая»: нет новой сущности/таблицы/миграции, нет чисел баланса,
~30 строк, API-контракт не трогается (только localStorage + переходы).
→ **быстрый путь**: менеджер делает сам (исключение «Мелкие правки»,
решение создателя 2026-09-16) → автоспавн `@tester` (обязателен; клиентский
флоу — e2e-смоук `tools/e2e/map-check.js`) → **один итоговый гейт** → коммит
(приёмка создателя = «ок» на итоговом гейте).

**Правки:**

1. `web/admin.html` — шапка: заголовок «🌍 Админка Zorion», клик по 🌍 (`onclick="goToMap()"`)
   → карта (уточнение создателя: без отдельной кнопки).
2. `web/static/js/admin/main.js` — `goToMap()`: скопировать `adminToken` → `token`
   (тот же JWT), `location.href = '/map'`; вывесить на `window`.
3. `web/map.html` — в шапку кнопка «⚙️ Админка» (`#adminNavBtn`, скрыта по
   умолчанию `style="display:none;"`).
4. `web/static/js/map/data.js` — в `loadUserData()` после установки `state.userRole`:
   показать `#adminNavBtn`, если роль ∈ {admin, skycomposer}.
5. `web/static/js/main.js` — клик по `#adminNavBtn`: скопировать `token` →
   `adminToken`, `location.href = '/admin'`.

**Поведение:** админ из админки → карта открывается сразу (токен тот же);
с карты → админка открывается сразу. Обычный игрок кнопку «В админку» не видит.
Админка без админского токена (не залогинен) — оверлей логина перекрывает
иконку 🌍 (inset:0, z-index:9999), кликнуть нельзя — норма.
