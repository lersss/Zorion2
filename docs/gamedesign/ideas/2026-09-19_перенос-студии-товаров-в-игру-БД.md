## 0. Пожелание создателя (2026-09-19)

> «Как работает удаление и бан?» → разбор (ответил). Далее:
>
> «Я могу как-то добавить товар в категорию "ресурс"?» → разбор: ресурсы — отдельный
> каталог на сервере, read-only в студии. Далее:
>
> «Давай так: 1. ресурсы больше не read-only, 2. У ресурсов может быть разный Tier,
> 3. их так же можно добавлять, удалять, банить и тд — никаких привелегий.»
>
> Уточнения (ответы на 4 вопроса скоупа):
> 1. Переносим ВСЮ студию, можно разбить на итерации и даже сессии.
> 2. Свой URL — шапка админки мешать будет.
> 3. Работаем с базой игры напрямую, а не с JSON.
> 4. Данные удаляем, кроме T0, которые есть в игре уже (ресурсы тира 0 из
>    Go-каталога internal/resource).

## 1. Решения (зафиксированы)

1. **Ресурс — «добываемый» товар, не производимый**: у ресурса НЕ может быть
   дочек (рецептов/слотов). Ресурс всегда лист дерева.
2. **Ресурсы без привилегий**: можно добавлять, удалять, банить, разбанивать,
   переименовывать, менять категорию и тир.
3. **Перенос студии в игровой сервер** (`cmd/server`): данные — в PostgreSQL
   (таблицы каталога), UI — на собственном URL (НЕ админка, без её шапки).
4. **state.json и текущие данные**: удаляем (не переносим), кроме ресурсов T0.
5. Разбиение на итерации/сессии — см. §5.

### Решения по вердикту критика (2026-09-19, создатель)

- **К1 (сидер)**: реальные вещества (`real.go`, 111) **переносим в игровой
  контент** — сидер БД = все 131 ресурс (слой 20 + витрина 111). Витрина
  «Реальные вещества» (94a) **переделывается: смотрит в контент (БД)**, а не в
  `real.go`. Эталон «витрина ≠ контент» (2026-09-18) пересмотрен создателем.
- **С1 (источник правды)**: **БД — источник правды** для каталога (ресурсы +
  товары). Go-каталог `internal/resource` перестаёт быть источником; читатели
  (94a витрина, проверки «все накормлены»/посредственность, forage, валидатор
  студии, будущий генератор полей) переходят на БД.
- **С3 (тир ресурса)**: развилка «тир назначаемый или вычисляемый» сохраняется
  (как у товаров: оверрайд ?? вычисленный; у ресурса вычисленный = 0, т.к.
  рецепта нет). Ресурсу можно **назначить тир** — для удобства разграничения
  «редких» и обычных ресурсов (презентация/сортировка; игровой эффект не
  заявлен).
