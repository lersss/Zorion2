## 2. Диагноз (менеджер, 2026-09-20)

Кнопки «Остановить» (`cancel*Btn` в `web/admin.html`, изначально `display:none`)
показываются только из `pollJob(...)`, интервал которого создаётся **в момент
запуска** джоба на текущей странице (`startPacman()`, `generateUniverse()` и др.).
После F5/повторного открытия админки `pollIntervals` пуст, кнопка навсегда остаётся
скрытой, а джоб продолжает работать. Пакман реально съел 929 из 30000 миров до
ручной отмены через API.

Бонус-причина «не видна»: блок пакмана спрятан на вкладке «Генерация» →
подвкладка «Звёзды» → блок «🗑️ Удалить все миры»; если активна другая вкладка
(восстановленная из `localStorage` после F5), кнопки нет на экране вовсе.

## 3. ТЗ (быстрый путь, только клиент админки)

1. **Красная кнопка-стоп у заголовка «🌌 Генерация»** (`web/admin.html`, карточка
   с `<h2>🌌 Генерация</h2>`, строка ~103), рядом с заголовком, **над** подвкладками
   «Звёзды / Планеты / Поселения / …»: красный квадрат (стоп), по умолчанию скрыта.
   Видна всегда, когда крутится **любой** джоб генерации; клик — подтверждение →
   отмена текущего running-джоба; скрывается по завершении/отмене.
2. **Восстановление состояния после перезагрузки**: при загрузке админки
   (`initAdminData`) и при активации вкладки «Генерация» — опрос статусов всех
   джобов одним-двумя запросами по списку (`generate_universe`, `generate_planets`,
   `generate_factions`, `generate_resources`, `generate_race_settlements`,
   `regenerate_planets`, `generate_npc`, `hypothesis`, `pacman`) через
   `/admin/generate-status?job=X`; для каждого `running` — показать его
   прогресс-контейнер и кнопку остановки в его секции (существующие механизмы
   `pollJob`), запустить интервал опроса. Пакман после F5 снова останавливаем.
3. Сервер и API не трогаем (ручки `/admin/generate-cancel` и
   `/admin/generate-status` уже принимают любой `JobType`).
