## Пожелание (создатель, дословно-сжато)

1. В арт-студии нужно кроме семейства возможность выбрать расу в генераторе эталонов.
2. Промты «по умолчанию» должны быть по каждой расе, а не в общем по семейству: расы внутри семейства очень разные.
3. Нужна кнопка «пересобрать промт» (обновить, согласно файлу в /races).
4. Вопрос: что делает кнопка «Обновить пример»? (отвечено менеджером: новый случайный seed из тех же пулов; файлы не читает/не правит).

**Уточнения создателя (2026-09-20):**
- **Вопрос 1 (поведение без выбора расы):** вариант **А** — оставить «все расы» (текущее: случайная раса на каждого кандидата) + конкретные расы семейства.
- **Вопрос 2 (граница расовое/семейное):** «что у нас в сценах? у нас везде же одинаковый фон — вырезанный для пнг?» → объяснено (scene — описание среды в промпте, фон вырезается rembg в прозрачный PNG; негатив — negative prompt SDXL, общий на семейство). Решение: **«ок, сцены не важны»** — сцены/негативы/морф-пулы остаются **семейными**; расовыми становятся материалы/свечения/формы/внешность (appearance) + фильтр blocked.
- **Вопрос 3 (что собирать из лор-файла):** вариант **А** — только помеченные строки «Для генератора (appearance)» и «Для генератора (blocked)» из раздела «Внешний вид» (надёжный парсинг, машинная проекция по 98a).
- **Вопрос 4 (нет раздела у расы):** «надо дописать внешний вид значит» — **дописать разделы «Внешний вид» во все лор-файлы рас** (сейчас у 6 пилотных, осталось 53).

## Разбор менеджера

**Что есть сейчас:**
- Вкладка «Эталон» (`/genref`, `cmd/art-studio`): выбирается только **семейство** (+ морф/персонаж/количество). Кандидаты генерируются «по всему семейству»: `BuildPromptWide(rng, fam, -1, ...)` — `raceIdx = -1` → для каждого кандидата **случайная раса** семейства (материал/свечение/форма прыгают от кандидата к кандидату). Раса привязывается только при назначении эталона (select на карточке кандидата). Панель «Итоговый промпт» на «Эталонах» показывает «первую расу как представителя» (комментарий в JS).
- Вкладка «Отбор» (`/genvar`, `BuildPrompt`): выбор расы уже есть, промпты расовые (от эталона расы).
- `BuildPromptWide` уже умеет фиксированный `raceIdx >= 0` (расовые mat/glow/form/appearance + фильтр blocked по морф-пулам) — нужен только прокинутый параметр.
- `families.json`: сцена (`scene`), негативы (`neg`/`anthro_neg`), морф-пулы (`beast_forms`/`anthro_forms`/`anthro_clothes`) — **поля семейства**; у расы — `forms`/`materials`/`glows`/`appearance`/`blocked`. Подтверждено: сцены у рас нет.
- Лор-файлы `docs/gamedesign/races/*.md` — 60 файлов; раздел «Внешний вид» (формат 98a §3, маркеры «**Для генератора (appearance):**» / «**Для генератора (blocked):**») — у **6 пилотных** рас (coastal, deep_dwellers, methane_plankton, cryo_swarms, mist_swarms, saltfolk). → **дописать 53**.
- Маппинг раса → файл уже есть: `loadRaceSlug` (имя расы без числового префикса «NN » ↔ `config/races.json` → slug), `s.loreDir` (`race_info.go`). Лор-файлы читаются с диска при запросе (`/race-info`); конфиги `families.json` — только при старте (reload-механизма нет — кнопка «пересобрать промт» добавит).
- Фон картинок вырезается (rembg → прозрачный PNG для спрайта); scene влияет только на атмосферу кадра.

**Решение (менеджер, по уточнениям создателя):**
1. **Вкладка «Эталон» — селект расы** (вариант А): «все расы» (текущее поведение) + конкретные расы семейства. При выбранной расе:
   - `/genref` принимает `race`; кандидаты генерируются от выбранной расы (`BuildPromptWide` с фиксированным `raceIdx`): материалы/свечения/формы/внешность от расы, `blocked` фильтрует пулы; сцены/негативы/морф-пулы — семейные (решение создателя «сцены не важны»).
   - Мета кандидатов: `RaceID` = выбранная раса (сейчас — случайная).
   - Селект на карточке кандидата предзаполнен выбранной расой.
   - Панель «Итоговый промпт» на «Эталонах» показывает промпт выбранной расы (сейчас — первую расу семейства).
2. **Кнопка «Пересобрать промт»** (панель «Итоговый промпт», рядом с «Обновить пример»): перечитывает лор-файл расы (`docs/gamedesign/races/<slug>.md`), извлекает из раздела «Внешний вид» строки «**Для генератора (appearance):**» и «**Для генератора (blocked):**», **обновляет машинную проекцию** (`appearance`/`blocked` в `config/art/families.json` на диске), перезагружает конфиг в памяти, пересобирает авто-промпт в панели. Если у расы нет раздела «Внешний вид» — сообщение (после контентной части — не должно случаться).
3. **Контент:** дописать разделы «Внешний вид» в 53 лор-файла рас (6 пилотных есть) по формату 98a §3 + машинная проекция в `families.json` (appearance/blocked), с критериями 98a §5.6 (кросс-конфиг тест «не мёртвые токены», длина/формат).

**НЕ в скоупе:** вкладка «Отбор» (уже расовая); люди F0 (`humans.json` — отдельная вкладка, не в families.json); игровой сервер; переработка сцен на расовые (решение создателя «сцены не важны»).
