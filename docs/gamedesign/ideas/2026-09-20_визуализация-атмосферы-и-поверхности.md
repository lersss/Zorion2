## 2. Рамки (решения создателя 2026-09-20)

1. **Порядок:** визуализация делается **после релиза биомов** (биомы поставляют
   куски поверхности с параметрами, из которых строится картинка).
2. **Скоуп вектора** (зафиксировать после релиза биомов, последовательность):
   1. тщательная проработка биомов;
   2. визуализация атмосферы + поверхности;
   3. большая сгенерированная картинка планеты в модалке (вид с орбиты, когда
      на планету прилетели);
   4. высадка.
3. **После сессии** — дать задание на картинки (промт), чтобы создатель увидел
   результат глазами.

## 3. Что уже есть (контекст, проверено менеджером 2026-09-20)

- **Атмосфера в каскаде — объект** (`atmosphere.go`, `AtmosphereData`): состав
  газов в %, давление, парниковый эффект, масса, высота, средняя молекулярная
  масса; тип классифицируется (`classifyAtmosphere`); есть `cloudFraction`
  (облачная доля по типу атмосферы).
- **Визуал планеты** (`planet_image.go`): картинка по `visualType`
  (rocky/earth/ice/lava/gas) + `applyPostProcessing` (тень, блик, «ободок»
  атмосферы по флагу `hasAtmosphere`). Атмосфера визуально **не связана** с её
  реальными параметрами; биомы как куски поверхности на картинке **не видны**.
- **Картинка планеты** отдаётся через `/api/planet-image`; большой вид планеты
  с орбиты в модалке системы — **отсутствует**.
- **Модалка системы** (`web/static/js/modal/tabs.js`) показывает состав строкой
  (`surface_composition` / `subterrain_composition` / `atmosphere`) — это то, что
  станет объектами биомов/недр.

## 4. Черновой скоуп (уточнится после релиза биомов)

1. **Визуализация поверхности из биомов:** 100% кусков поверхности → текстура
   (цвет/вид местности берём из параметров биома).
2. **Визуализация атмосферы по параметрам:** состав, давление, облачность —
   вместо косметического «ободка».
3. **Большая картинка планеты в модалке** (вид с орбиты), когда на планету
   прилетели.
4. **Высадка** (отдельно, после визуала; вектор «Игрок»/«Поселения»).

## 7в. Решения гейта 2 (стилистика + видимость, 2026-09-20, создатель)

- **Стиль — один универсальный: А «Орбитальная съёмка»** (мягкий реализм).
  Референс `ai_drafts/planet_concepts/A_orbital.png` — ориентир по духу (не
  буквальная цель: блики/фототекстуры будут проще, процедурно). Один генератор
  на все размеры (канвас орбит ~20–40px / большая «вид с орбиты» 256–512px).
- **Честное заслонение:** плотная атмосфера (высокое давление/облачность/
  парниковый эффект) скрывает поверхность — облачный покров/дымка, биомы не
  видны. Правило заслонения задаёт @gdesigner/@designer (порог по параметрам
  атмосферы). Это же чинит «газовые гиганты без биомов» (99.2.28 §9.5).
- **Заглушка для чужих систем (гейт видимости 77a решён):** если планета и
  игрок в РАЗНЫХ звёздных системах — генерится заглушка (вид не раскрывает,
  что это за планета: тип/поверхность/атмосферу) — честно, игрок не может
  понять издалека. Игрок в ТОЙ ЖЕ системе → честная картинка. Внутри системы
  игрок и так видит детали (модалка, знание).
- **Админы видят всё:** admin и skycomposer (тоже админ, только супер) —
  полная картинка всегда, без заглушек (роль определяется как в видимости 77a).
- **Критик по дельте (гейт 2): 8 находок (средних 4, мелких 4), крупных нет.**
  Решения создателя по С1–С4:
  - **С1 (заслонение раскрывает атмосферу) — снят:** «давай без фанатизма,
    просто по картинке не будет понятно, что на планете есть. В любом случае
    нужно будет прилететь и просканировать планету, чтобы определить проценты
    поверхности, и опуститься, чтобы исследовать состав недр». Заслонение
    показываем свободно (не «отчёт бесплатно», а вид).
  - **С2 (авторизация картинки) — ОК:** запрос картинки несёт токен игрока и
    его позицию (эндпоинт становится авторизованным; заглушка решается на
    сервере, не клиентом).
  - **С3 (заглушка при знании) — заглушка СНИМАЕТСЯ при знании о планете**
    (скан при прошлом визите / купленный отчёт → честная картинка; иначе
    заглушка).
  - **С4 (скан vs заслонение) — снят:** проценты поверхности узнаются только
    сканом (прилёт + скан), недры — посадкой; заслонение — косметика над
    известным знанием, 77a не трогаем.
- **Контракт картинки (входы):** seed + биомы + атмосфера + role + позиция
  игрока (своя/чужая система) + знание о планете; заглушка — отдельный режим;
  заслонение — слой облаков поверх поверхности; кэш-ключ расширяется: булев
  признак «своя/чужая» + role (2–3 варианта на планету, не системы×планеты).
