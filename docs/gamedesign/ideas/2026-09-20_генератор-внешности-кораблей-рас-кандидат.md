## Суть (задел)

**Генератор внешности кораблей рас в арт-студии** — будущий релиз: из описаний
`docs/gamedesign/races/ships/<id>.md` (60 файлов) генерировать спрайты кораблей
рас. Входные данные **уже готовы** (контент-фича «Корабли рас и кабины связи»,
сдана 2026-09-20): в каждом файле — поля для генератора:

- **`texture`** — английская промпт-фраза текстуры/цвета/материала (этап 2
  детализации SDXL);
- **`silhouette`** — ТЗ на рисунок силуэта (вход ControlNet Canny: модули,
  асимметрия «корма слева, нос справа», «нос = светлая кабина», запас ~90 px);
- **`blocked`** — теги-запреты (substring-фильтрация словарей генератора).

Пайплайн — существующий `docs/gamedesign/art/art_ships.md` (силуэт → ControlNet
Canny + img2img → этап детализации → пост-обработка `process_ship.py`): форма
задаётся силуэтом, промпт управляет текстурой/цветами.

## Открытые вопросы (для будущего дизайна)

- где будут жить сгенерированные корабли рас: слой расового визуала агентов
  (точка замены `spriteForAgent`, 61b И8) / кабина-фон экрана связи (будущая
  механика «связь с кораблём») / энциклопедия (86a);
- совместимость с реестром 21 спрайта (61b — легаси, не трогается);
- пайплайн: ручной отбор создателем по пачкам (как 29a: пачка 10 → отбор
  номерами) или автоматический;
- связь с арт-студией (98a/98b): отдельная вкладка «Корабли рас» или переработка
  race-генератора.

## Уточнения создателя (раунд 1, 2026-09-20)

Ответы на вопросы менеджера перед запуском дизайна:

1. **Инструмент (A1):** отдельная вкладка «Корабли рас» в работающей арт-студии
   (Go, отдельный инструмент), панель промпта 98b (tags/override).
2. **Силуэты:** скрипт-генератор силуэтов из поля `silhouette` (как
   `make_race_silhouettes*.py` у рас) — желаемый путь; НЕ ручная отрисовка.
3. **Вариантов на расу:** 3 кандидата, отбор.
4. **Встройка:** пока хранится в студии, рантайм/агентов НЕ трогаем; смотрим, как
   генерится кабина и корабль. Выбранную кабину желательно уметь проносить в
   генератор по расам (как у аватаров людей: выбранный аватар = ref-эталон,
   генерация вариаций img2img от него).
5. **Хранилище:** `ai_drafts/final_accepted/` — почистить существующее (27 legacy)
   и складывать расовые корабли туда же.
6. **Пилот:** люди + 6 рас внешности (coastal, methane_plankton, deep_dwellers,
   cryo_swarms, mist_swarms, saltfolk) — подтверждён.

**⚠️ Живое уточнение, конфликтующее с промтом (правило 99a):** в текущем промте
записано «Кабины (интерьер) — НЕ в этом релизе; релиз = только спрайты кораблей».
Ответ создателя «будем смотреть, как генерится кабина и корабль» расширял скоуп:
в студии должны генерироваться И кабина, И корабль, выбранная кабина проносится в
генератор по расам. **Закрыто раундом 2 (2026-09-20):**

- **«Кабина» = интерьер-фон** (место аватара при будущей связи) — подтверждено
  создателем.
- **«Давай сначала корабль»** — кабина в ЭТОМ релизе НЕ делается; релиз = только
  спрайты кораблей (первоначальный промт остаётся в силе). Кабина — отдельный
  будущий шаг; пронос выбранной кабины в генератор по расам (как у аватаров
  людей) — задел на тот шаг, в дизайне этого релиза только зафиксировать точку
  (раздел «Кабина» в `races/ships/*.md` — текстовый задел, полей генератора нет).

Противоречие снято: промт возвращается к «релиз = только корабли» (раздел «Промт
для запуска», п.4).

## Промт для запуска (ТЗ на дизайн, решение создателя 2026-09-20, актуализирован 2026-09-20)

**Задача:** спроектировать генератор спрайтов кораблей рас в арт-студии по лору
(60 рас). Входные данные **готовы** — `docs/gamedesign/races/ships/<id>.md`:
поле `silhouette` (ТЗ на силуэт: модули, асимметрия «корма слева, нос справа»,
«нос = светлая кабина», запас ~90 px) → вход ControlNet; `texture` (англ.
промпт-фраза текстуры/цвета/материала) → этап 2 детализации SDXL; `blocked`
(теги-запреты) → фильтрация словарей (аналог 98a).

**Пайплайн — существующий** `docs/gamedesign/art/art_ships.md`: силуэт (рисунок,
модульная палитра: корпус крем/крылья сталь/дюзы тёмные/кабина светлая) →
ControlNet Canny + img2img (denoise 0.85, strength 1.5) → этап 2 детализации
(denoise 0.45–0.55, промпт = `texture` расы + общая механическая текстура) →
пост-обработка `tools/process_ship.py` (вырез по цвету фона, крупнейший связный
компонент, 200×200, нос вправо). Отбор создателем пачками (как 29a: пачка 10 →
номера).

**Решения создателя (раунды 1–2, 2026-09-20) — учесть в спеке:**
- **Инструмент (A1):** отдельная вкладка «Корабли рас» в работающей арт-студии
  (Go, отдельный инструмент, не переработка race-генератора); панель промпта 98b
  (tags/override) для кораблей. Переиспользовать свежий паттерн студии
  (сдана 2026-09-20, коммиты 203918a/dafd6dc): «лор-файл → машинная проекция →
  reload без рестарта» (`rebuild_prompt.go`/`families_patch.go` — механика для
  `races/ships/*.md`: texture/silhouette/blocked) и селект расы (как в «Эталонах»).
- **Силуэты:** скрипт-генератор силуэтов из поля `silhouette` (как
  `make_race_silhouettes*.py` у рас) — НЕ ручная отрисовка.
- **Вариантов на расу:** 3 кандидата, отбор.
- **Хранилище:** `ai_drafts/final_accepted/` — почистить существующее (27 legacy)
  и складывать расовые корабли туда же.
- **Пилот:** люди + 6 рас внешности (coastal, methane_plankton, deep_dwellers,
  cryo_swarms, mist_swarms, saltfolk) → все 60.

**Проектировать (дизайн, по гейтам):**
1. Конвейер: как `silhouette`-ТЗ превращается в силуэт (скрипт-генератор,
   переиспользование модульной палитры art_ships §2.1); как `texture`
   вставляется в промпт этапа 2; как `blocked` фильтрует словари.
2. Хранилище результата: реестр 60 кораблей рас (кандидаты: отдельный Go-реестр
   по образцу `ShipSprites` / `config` / `web/static/sprites/race_*.png`); 21
   спрайт — легаси, НЕ трогать; `spriteForAgent` — точка замены под расовый
   визуал (61b И8) — решить, куда ляжет слой расовых кораблей (пока хранится в
   студии, рантайм/агентов НЕ трогаем).
3. UI: вкладка «Корабли рас» в арт-студии (98a/98b); панель промпта (98b:
   tags/override) для кораблей.
4. Кабины (интерьер) — НЕ в этом релизе (решение создателя «давай сначала
   корабль»); релиз = только спрайты кораблей; зафиксировать точку проноса
   выбранной кабины в генератор по расам (задел на будущий шаг, раздел «Кабина»
   в `races/ships/*.md` — текстовый, полей генератора нет).
5. Скоуп пакетов: пилот (6 рас 98a + люди) → все 60; отбор создателем пачками.
