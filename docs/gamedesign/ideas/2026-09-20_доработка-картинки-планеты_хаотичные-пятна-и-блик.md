## 3. ТЗ (что делаем)

### 3.1. Поверхность без читаемых кругов

Текущий алгоритм `blobs()` сеет пятна-круги с fbm-границами — круги читаются. Задача дизайна:
новый способ представления поверхности, где доли биомов {form, share} всё ещё определяют вид
(честность к данным сохраняется), но форма — хаотичная, без кругов. Кандидаты на рассмотрение
(решает дизайн-этап, не фиксируем заранее): поляр/симплекс-шум по долям с масками доминирования,
Voronoi с деформацией границ (клетки должны быть неузнаваемы), потоковые/турбулентные деформации
кругов, многослойный шум с регионами и т.п. Требования:

- доли биомов приближённо сохраняются (картинка — «вид, не отчёт», С1/С4 прошлой спеки);
- все биомы состава (share ≥ 1%) видимы;
- детерминизм: одинаковый вход → одинаковый PNG (кэш-ключ остаётся);
- стиль А «Орбитальная съёмка» сохраняется (мягкий реализм);
- атмосфера/рельеф/альбедо-модуляция (§4.1 прошлой спеки) продолжают работать поверх.

### 3.2. Блик от звезды

Сейчас блик одинаковый на всех картинках, неестественный, отвлекает. Задача:
- блик должен выглядеть естественно (фаза/положение по орбите или симуляции освещения?) или быть
  приглушён; желательно разнообразие между планетами;
- сильно отвлекающий блик убрать/ослабить;
- у гигантов/колец блик согласован с кольцами;
- заглушка блик не даёт (нейтральна).

### 3.3. Реальная атмосфера (полный контракт @gdesigner)

Из §12.1 прошлой спеки: реальная атмосфера для честных картинок —
- состав → цвет дымки (Σ тинтов × %);
- давление/высота → толщина лимба;
- τ_IR → glowBoost;
- cloudFraction → облака.
Входы: `atmosphere_data` (сейчас скрыта для player — strip). Решение создателя «можно» снимает
ограничение И1? **Вопрос на дизайн-этап:** как вводить атмосферные входы без утечки скрытых
данных игроку (77a И1): прошлая спека сознательно не пускала атмосферные числа в картинку,
чтобы картинка не раскрыла игроку скрытый состав. Варианты: картинка честная только там, где
знание уже есть (своя система/скан/админ) — тогда атмосферные числа допустимы на входе
(они уже раскрыты знанием?); или остаёмся на производной. Решает создатель на гейте дизайна.

## 5.2. Решения гейта дизайна (создатель, 2026-09-21)

1. **Семантика `full`: вариант A — вся своя система.** Реальная атмосфера видна у всех планет
   своей системы (в малой текстуре и в большой «Вид с орбиты»); админ — всегда.
2. **Режимы атмосферы:** реальная — только присутствие/своя система + админ (`full`);
   известные (скан/отчёт) — упрощённая (`honest`, производная); чужая без знания — заглушка
   (`stub`). Покупка отчётов об атмосфере не обесценивается.
3. **Свет от звезды:** v1 — световой вектор закреплён за планетой (детерминированно, от seed);
   реальная фаза по орбите отложена (кандидат §10.3 спеки).
4. Точность долей ±30% — принято. Версия кэша — ручной инкремент при визуальных правках — принято.

## Приложение A. Визуальный контракт @gdesigner (2026-09-21)

> Полный контракт по форме поверхности, блику, реальной атмосфере и заглушке — вход для спеки
> @designer. Зафиксирован здесь по находке критика (прошлый контракт @gdesigner не был
> задокументирован). Часть C (атмосфера) — устоявшаяся, ранее не записанная; части A/B —
> новые (замена `blobs()`/фиксированного блика).

**A. Форма поверхности без кругов (Рекомендация 1 — принята @gdesigner):** «поле высот +
регионы». Низкочастотный fbm E(p) (3 октавы, ~1.2–1.5 цикла на диаметр) даёт 2–5 крупных масс
(континентов/океанов, 30–60% радиуса), внутри — регионы биомов (10–25% радиуса, мягкие границы
2–3 px @512), мелкие биомы (share 1–5%) — 3–10 вкраплений (3–8% радиуса). Береговая линия —
доменный варп 10–15% + ridged «эрозия»; полярные крио-биомы стягиваются к полюсам (широтный
фактор). Сэмплинг на сфере (`spherePoint`). Честность: бюджет площади ≈ share ±30% (вид, не
отчёт), все биомы share ≥1% видимы (мин. 1 регион/1–3 вкрапления). Категория → зона высот
(вода→низ, крио→верх+полюса, вулканизм→верх, биосфера/литосфера→середина; при переполнении —
перелив). Детерминизм — от seed. Запасная (Рекомендация 2, сильный доменный варп пятен) —
отклонена @gdesigner (риск смазанного вида, круги при слабом варпе вернутся).

**B. Блик от звезды:** единый световой вектор `L` от seed (`az = 2π·rng`, `el = 20°+40°·rng`) —
разные планеты, детерминизм. Терминатор/тень/спекл/кольца — от одного L. Спекл приглушён в 3–5 раз
(сила ≤0.25, было 0.8), цвет не белый, по типам: гигант (pow 8, 0.10–0.18), лёд (pow 30–40,
0.15–0.25, `#f0f8ff`), вода (pow 20, 0.12–0.20, `#fff8e0`), пустыня/камень (pow 12, 0.05–0.10),
лава (pow 16, 0.08–0.15, `#ffb060`), плотная атмосфера (pow 4–6, широкий ореол, цвет дымки),
тонкая атмосфера — **блика нет**. Атмосферная составляющая: `atmGlint = glowStrength·(0.5+0.5·diffuse)·edgeFactor`,
≤0.2, цвет дымки. Кольца: яркость по дню/ночи от L (день 0.8–1.0 / ночь 0.35–0.5), тень планеты
на кольце 0.25–0.35, лёгкий тинт дымкой 10–20%; геометрия/базовый цвет не меняются.
**Открытый вопрос:** реальная фаза по орбите (положение звезды/наблюдателя) требует новых входов
+ оси кэша — на v1 свет от seed.

**C. Реальная атмосфера (полный контракт, ранее только тезис):**
- **Цвет дымки:** `hazeRGB = Σ(тинт[газ]×share[газ])/100`, `haze = lerp(hazeRGB, белый, 0.35)`.
  Тинты: H₂ `#c8ccd8`, He `#d8dce4`, N₂ `#b8c8dc`, O₂ `#a8c0e8`, CO₂ `#e0c898`, CH₄ `#a8ccd8`,
  H₂O `#c0d8e8`, SO₂ `#e8d0a8`, NH₃ `#d0c0e0`, H₂S `#e0d8b0`, N₂O `#b8d0e0`, Ar `#d8d8d8`,
  прочие `#cccccc`. Калибровка: Земля `#cfdaea`, Венера `#e0d2b8`, Марс желтизна α~0.05,
  Юпитер `#d7dae2`. Альфа дымки `clamp(0.05 + 0.20·log10(1+P), 0.03, 0.45)`.
- **Лимб:** `limbPx(512) = clamp(1 + 2.5·log10(1+P), 1, 12) × (SH/8)^0.5`, `limbAlpha =
  clamp(0.12 + 0.22·log10(1+P), 0.08, 0.65)`. Калибровка: Марс 1 px/0.12, Земля ~1.75 px/0.19,
  Венера ~8 px/0.65.
- **Свечение:** `glowStrength = clamp(τ_IR/4, 0, 1)`, цвет = haze, `glowWidth = limbPx×(1+glowStrength)`,
  `glowAlpha = 0.25·glowStrength` (было — жёстко `#ffc878` только у вулканических; теперь любая
  планета с атмосферой, цветом своей дымки).
- **Облака:** `f_c = cloudFraction(label, P)` (существующая в `atmosphere.go`); пороги заслонения
  те же (§3.4 прошлой спеки: ≥0.7 полное, 0.35–0.7 частичное, <0.35 дымка); цвет облаков = haze
  осветлённый 30%. Гиганты: пятна не добавляем, «поверхность» = полосы, тонированные дымкой.
- **Фолбэки (старые миры без `atmosphere_data`):** нет данных → производная §4.4 (палитра по
  типу); `composition` пуст → haze по типу; `pressure_atm` ≤0 → лимб 1 px/0.08, дымка 0.03,
  свечение 0, облака 0; `tau_ir` нет → свечение 0; `scale_height_km` нет → SH=8.

и свечение; кольца нет; полосатость/градиент — как сейчас. Закрывает находку критика M4.
