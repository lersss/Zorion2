## 1. Пожелание (создатель, 2026-09-20)

> «Ты умеешь делать иконки через нашу арт-студию? Можешь нагенерить иконок на
> новые типы поверхностей? Можешь сделать это через художника отдельной задачей?»

Отдельная задача, маршрут — @artist (ComfyUI-пайплайн: силуэт → форма →
детализация → пост-обработка → превью-сетка → отбор создателя).

## 2. Уточнение (ответы создателя, 2026-09-20)

1. **Объём:** только поверхности (биомы); типы недр — не сейчас.
2. **Размер:** 200×200 — «жирно» для иконок (это размер спрайтов-объектов).
   Сверено с UI проекта (иконки в интерфейсе — 16–30 px; состав планеты —
   текст + символ). **Принято: исходник 48×48, на экране ~24 px** (чёткость
   на retina, файл лёгкий).
3. **Стиль:** художник предложил 3 варианта (А — плоский значок-символ,
   B — мини-пейзаж, C — геральдика-бляха). **Создатель выбрал B — мини-пейзаж**
   (2026-09-20). Учтено: стиль B — full-bleed (небо заполняет кадр), поля
   теряются; основная пачка перегенерируется в стиле B.
4. **Порядок:** первая пачка ~15–20 самых заметных биомов (землеподобные:
   леса/луга/океаны/болота; токсичные: Кислотные дебри, серные поля,
   химический иней; крио: метановые моря, углеводородные равнины, инеевые
   рощи; жаркие: лава, магмовые океаны, вулканические поля; экзотика:
   кристальные/кремниевые рощи и т.п.), дальше — остальные пачками.

## 4. Критерии готовности (первая пачка)

1. Превью-сетка иконок ~15–20 ключевых биомов (номера 1..N, подписи — имена
   биомов из каталога).
2. **Стиль B — мини-пейзаж** (выбор создателя 2026-09-20); основная пачка
   перегенерирована в нём.
3. Иконки **48×48**, прозрачный/средовой фон (мини-пейзаж), на экране ~24 px,
   готовы к встраиванию в карточку/модалку планеты.
4. Именование файлов — по id биома из каталога (например `кислотные_дебри.png`),
   чтобы developer встроил без переименований.
