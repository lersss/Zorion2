### 1. Каталог `docs/gamedesign/races/ships/`

- Файл на расу: `humans.md`, `ammonia.md`, … — по id расы (60 шт, включая людей).
- **Шаблон файла** (проектирует @designer, сверяя с «Внешним видом» рас и

  - **Внешний вид корабля** — силуэт, материал, свечение, характерные детали,

  - **Интерьер кабины** — обстановка, освещение, среда (атмосфера/температура/

- **Форма корабля — по лору расы** (раунд 2, п.1): у роёв/не-существ — их
  скопление/носитель (чем летает рой), у Миров-машин — автоматизированные

  легаси, отдельно).
- Ограничение: кабина — **место аватара** (не полноценный 3D-интерьер),
  описание даёт фон/обстановку/свет для будущего экрана связи.
