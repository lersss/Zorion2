## 1. Пожелание (создатель, 2026-09-20)

> «Почини еще пакмана: почему-то потерялась правка, что он ест ближайшую звезду.
> Он снова носится по всей галактике.»

Уточнение при проверке (живой замер): «Вот прямо сейчас — носится» — прыжки между
последовательно съедаемыми звёздами 15 000–27 000 единиц при карте 34 000.

## 2. Диагноз (менеджер, 2026-09-20)

Правка «ест ближайших» **не терялась** — она не дошла до кнопки:

- Серверный дефолт и решение создателя от 2026-09-20 («пусть он всё-таки как-то
  ближайшие кушает, иначе мечется по галактике») — `nearest`; сервер берёт его,
  только когда `trajectory` в запросе пуст.
- Кнопка «👾 Запустить Пакмана» в админке (`web/static/js/admin/generation.js`)
  с самого начала (коммит 7b4b9b5) **жёстко слала** `trajectory: 'spiral'`,
  перекрывая дефолт. Файл с тех пор не менялся — при смене серверного дефолта
  кнопку не поправили.

Доказательства: замер менеджера через API без `trajectory` — шаги 180–300
(плавное поедание); замер живого джоба из кнопки — прыжки 15–27 тыс. (спираль
прыгает между кольцами).

## 3. Правка (быстрый путь, мелкая — правило «Мелкие правки»)

`web/static/js/admin/generation.js` (startPacman): тело запроса
`{worlds_per_second, batch_size: 200, trajectory: 'nearest'}` (было `'spiral'`),
комментарий над функцией приведён в соответствие. Других мест отправки
`trajectory` в клиенте нет (проверено по коду). API-контракт не меняется,
сущностей/миграций нет, ~2 строки — мелкая правка, сделана менеджером.
