## Решения создателя (2026-09-20, ответы на уточнения)

1. **Зоны:** работаем с доками в первую очередь; Go не трогаем, пока нет реальной токен-боли.
2. **Метрика успеха** (критерии «готово») — все три приняты:
   - (а) стартовый контекст агента сокращён измеряемо (замер до/после);
   - (б) ни один **активный** док не требует чтения целиком >50–60 КБ — большее либо порезано на секции, либо в индексе явно «читай только §X»;
   - (в) правило «один факт — одно место», без дублей при порезке.
3. **Архив закрытого:** спеки/идеи закрытых фич сносим в `docs/specs/_archive/` и `ideas/_archive/` (история в git, из активных индексов убираются). Создатель: «спеки по идее второй раз после закрытия идеи и смотреть почти не надо».
4. **Порезка гигантов:** только адресно и вдумчиво («каждый надо резать вдумчиво, если есть такая потребность»), НЕ механически по лимиту.
5. **impact_map (63 КБ × каждый прогон критика):** создатель: «правка промта — это ничего» — согласие на оптимизацию, НО конкретная дельта промта @critic подаётся отдельным вопросом на гейте (правило 62a, общее «ок» её не покрывает).
