## Ответы создателя (дословно, 2026-09-20)

### Корабль и полёт

**1. Эмблема корабля (61b §12).** «Не в MVP точно, косметика».
→ Решение роадмапа: косметический слой поверх спрайта+цвета, не в MVP.
В FAQ не входит (не эталон физики).

**2. Топливо / топливный бак (91a).** «да».
→ Решение роадмапа: ограничитель дальности полёта, вводим (срок — после MVP,
точный порядок — при планировании). Ранее зафиксировано в 77a: «дальность полёта
по топливному баку ещё будет ограничиваться».

**3. Транспондер (77b).** «запиши в идеи, но это после MVP».
→ Решение роадмапа: сущность-анонимность на чужих радарах, после MVP.
Идея 77b уже есть (сырая) — добавить пометку «решение создателя 2026-09-20:
после MVP».

**4. Звёздный атлас / карта региона (77c).** «да».
→ Решение роадмапа: торговая сущность «карта региона» (зажигает звёзды сектора),
вводим. Идея 77c уже есть (сырая) — добавить пометку «решение создателя
2026-09-20: да, вводим».

### Разведка

**5. Аватары рас в отчётах разведки (67a).** «Аватары мы получаем когда
связываемся с кораблём».
→ Решение дизайна: аватары рас игрок получает при контакте с кораблём (расы),
не через отчёты. Связь с 77a (контакт/радар). В FAQ не входит.

### Товары и производство

**6. «Престиж» товаров (топовые товары).** «контент».
→ Решение: «престиж» — контент-атрибут, не механика (на тиры/контракты не влияет).

**7. «Промышленный кластер» (топовые товары).** «Бонус будет в логистике и так.
Специально не вводим».
→ Решение: отдельную ГД-сущность не вводим; бонус связности производства
приходит через логистику (существующие механики).

**8. «Прозвища товаров» (топовые товары).** «не делаем, слишком большой скоуп».
→ Решение: не делаем.

**9. Технологические чертежи (99a/99a.3).** «Да».
→ Решение роадмапа: будущая сущность, вводим (задел; порядок — при планировании).

### Расы

**10. Внешность расы (98a).** «Внешность расы генерит контентмейкер через
арт-студию».
→ Эталон процесса: внешность расы (что видит игрок) создаёт контентмейкер через
арт-студию (98a/98b), не игровой эталон физики. В FAQ-счётчик не входит.

**11. Опознание расы по внешности при первом контакте (2026-09-20 арт-студия).**
«да».
→ **Эталон игрового восприятия (настоящий, в FAQ):** при первой встрече игрок
видит только описание внешности (контент разделов «Внешний вид»), имя расы
раскрывается после изучения. Вносится в `22_races.md` §7 (Эталоны и решения
создателя, FAQ).
