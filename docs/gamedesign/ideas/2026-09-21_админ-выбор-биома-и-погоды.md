---

## 2. Решения создателя

1. **Выбор биома — только среди биомов самой планеты** (не любой биом игры).
   Причина (разъяснена создателю): `NormalizeSurfaceBiome` заменяет чужой биом
   доминирующим биомом планеты — админ выбрал бы «океан», получил «горы». Плюс
   ИП-1' требует `biome ∈ biomes` планеты; «любой биом игры» ломал бы инвариант.
2. **Погода — админу дать принудительный выбор** (для сплошного обхода
   биомов × погод).
3. **Только роль админа** (`admin`/`skycomposer`) — обычный игрок получает жребий
   как сейчас. Проверка **на сервере** (не только скрытие пункта в UI).

---

## 3. ТЗ (черновик, уточнить перед стартом)

**Сервер:**
1. `POST /api/surface/land` — необязательное поле `biome` в теле. Если задано:
   принимать только от роли `admin`/`skycomposer` (иначе игнорировать / 400);
   валидировать через `NormalizeSurfaceBiome`/`walkBiomeValid` — биом обязан быть
   у планеты (`share > 0`), иначе 400 «Нет такого биома на планете».
2. Не задано или роль не админ — существующий жребий ∝ `share` (§5.1), без изменений.
3. Идемпотентность (шаг 2 §6.1) — как сейчас: рефреш не перебрасывает биом.
4. Погода: пакет прогулки — необязательное поле `weather` (id из `WEATHER`), только
   для админа; клиент при наличии — использует его вместо случайного расписания.

**Клиент:**
5. `showPlanetMenu` (`events.js`): при роли админа пункт «Высадиться» раскрывается
   подменю со списком биомов планеты (имя + доля) + строка «Случайно (как игрок)».
   Для не-админа — как сейчас.
6. `surface_main.js`: если в пакете есть принудительная погода — не крутить
   расписание, показывать её; добавить (для админа) быстрый переключатель погоды.
7. Формулировки/пиксели подменю — @uidesigner.

**Ограничения:** новых таблиц/миграций нет; API-контракт `land` расширяется
аддитивно (необязательные поля); правило «биом — биом этой планеты» не трогаем.

**DoD:** `go build ./...`, `go vet ./...`, `go test -race -short`; `node --check`;
e2e `tools/e2e/surface-walk-check.js` + новый сценарий «админ выбирает биом →
высадка в выбранный биом»; проверка, что не-админ выбор проигнорирован.
