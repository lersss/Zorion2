# Баг — карточка спутника сбрасывается на карточку планеты

**Создано:** 2026-09-21
**Статус:** ✅ исправлено 2026-09-21 (коммит `62650c2`): карточка спутника больше
не сбрасывается на карточку планеты при фоновом обновлении данных
**Приоритет:** баг (🟡 — некритичный, фикс быстрый)
**Вектор:** **Игрок** (UI игрока — модалка системы, `web/static/js/modal/*`)

---

## Пожелание (создатель, 2026-09-21)

> Нажимаешь на спутник гиганта в карточке планеты — через секунду перекидывает
> на карточку гиганта.

---

## Диагноз (проверено по коду)

**Корень:** карточка спутника живёт только в DOM и не сохраняется в состоянии
модалки. Любая перерисовка правой панели (`renderRightPanel` → пересоздание
карточки планеты) затирает карточку спутника и возвращает карточку родительской
планеты (гиганта).

Карточка спутника рендерится `renderSatelliteCard()` (в `tabs.js`) по клику на
элемент списка спутников, но в состоянии (`modalState`) не фиксируется факт
«открыта карточка спутника X». Поэтому при перерисовке панели рендер идёт по
`selectedPlanetIndex` + активной вкладке → карточка планеты.

**Два источника перерисовки, из-за которых баг виден «через секунду»:**

1. Асинхронный запрос `/me` (роль игрока + межзвёздный полёт) приходит после
   открытия модалки. Гвард в `index.js` (после установки `modalState.role` /
   `modalState.interstellarFlight`) вызывает `renderRightPanel(...)` для
   выбранной планеты — карточка спутника затирается. Срабатывает у игроков с
   ролью (admin/skycomposer) и при активном межзвёздном полёте.
2. `refreshPlanets()` (кнопка «Обновить» в карточке, автообновление в админке
   раз в 3 с) → `renderRightPanel(...)` → карточка планеты.

**Итог:** карточку спутника нельзя удержать открытой — её сбрасывает первый же
фоновый апдейт.

---

## Предлагаемый фикс (для @developer)

Сохранять выбор спутника в состоянии и восстанавливать при перерисовке панели:

- Ввести в `modalState` поле выбранного спутника (например,
  `selectedSatellite = { planetIndex, satIndex }` или `{ planetId, satId }`).
- При клике по спутнику (`data-sat-idx`) — записывать выбор в состояние.
- При «← К планете» и переключении вкладки карточки планеты — сбрасывать выбор.
- При `renderCard` (после `switchTab`) — если выбранный спутник принадлежит
  текущей планете, рендерить карточку спутника вместо обычной вкладки.
- Выбор сбрасывается при закрытии модалки / уходе со списка планет (как и
  `selectedPlanetIndex`).

Этот же механизм автоматически чинит оба источника перерисовки (`/me` и
`refreshPlanets`), т.к. оба проходят через `renderRightPanel`.

## Проверка

- Клиентский флоу (модалка, клики) — обязателен e2e-смоук `tools/e2e/map-check.js`
  (правило менеджера 2026-09-18, правило тестера).
- Ручной сценарий: открыть карточку планеты со спутниками → клик по спутнику →
  подождать 3–5 с → карточка спутника не сбрасывается. Воспроизвести в админке
  (автообновление) и у обычного игрока (асинхронный `/me`).
