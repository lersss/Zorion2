## Правки создателя после прослушивания (2026-09-21, вторая итерация)

Синтез-версия прослушана и **отвергнута** («ужас, а не звуки»). Три правила:

> 1. закрытие чего бы то ни было нельзя сопровождать звуком!
> 2. а вот как раз открытие модалки, клик по планете - можно попробовать (сейчас нет). Приятный звук - на успешное действие!
> 3. Полет ужасен. Найди какой-то нормальный звук полета.

Расшифровка (что делаем):
1. **Закрытие никогда не звучит:** закрытие модалки, крестики, «Закрыть», скрытие
   уведомления, отмена, выход — тишина. Общий щелчок на **все** кнопки (включая
   админку) убрать: он и озвучивал закрытия.
2. **Открытие — звучит:** открытие модалки системы и клик/выбор планеты — мягкий
   **приятный** звук, попробовать. Успешное действие (success-уведомление) тоже
   приятный звук, не резкий.
3. **Звук полёта — нормальный файл**, не синтез. Найти подходящий (ровный гул +
   старт/прибытие).

Итог по источнику: переходим на **аудиофайлы** (тот самый «гибрид → файлы»), синтез
для полёта и тонов отбрасывается.

## Объём (что делаем / что НЕ делаем)

**Делаем (аудиофайлы, Kenney CC0 — см. `web/static/audio/SOURCES.txt`):**
1. **Звук отклика (только положительные/нейтральные действия):** открытие окна системы,
   выбор планеты, успешное действие (success-уведомление), ошибка (error-уведомление).
2. **Звук полёта:** старт, зацикленный ровный гул на время перелёта, прибытие.
   Громкость/характер гула не зависит от длительности полёта.
3. **Управление звуком:** выключатель (вкл/выкл) в localStorage, кнопка на карте.

**Ключевые правила (создатель, 2026-09-21):**
- **Закрытие никогда не звучит** (модалка, крестики, «Закрыть», скрытие уведомления,
  отмена, выход).
- **Звук только на карте и в её модалке**, точечными врезками. Общий щелчок на все
  кнопки не делаем вовсе.

**НЕ делаем сейчас (отложено):**
- событийные сигналы (конец постройки, прилёт флота, атака) — следующий слой;
- атмосферные фоны (карта, биомы, расы) — после основы;
- фоновый звук чужих флотов/агентов (в мультиплеере даёт кашу);
- звук для surface-страницы — только карта на этом шаге (у surface свой отдельный
  `notify`, `ui/toast.js` он не тянет — проверено критиком);
- **админка — НЕ трогаем** (решение создателя 2026-09-21, вторая итерация,
  отменяет прежнее В1=Б): никакого звука в админке.

## Ключевые технические ловушки (обязательно учесть, иначе регресс)

1. **Node-граф админки.** `web/frontend_test.go` (`TestAdminFrontendLoadsInNode`)
   исполняет весь граф `admin/main.js` (через `modal/events.js` → `ui/toast.js` →
   возможно новый звуковой модуль) в Node под DOM-стабом **без** `AudioContext`.
   Аудио-модуль НЕ должен обращаться к `window`/`AudioContext`/`document` на верхнем
   уровне: только ленивое создание по первому звуку, с проверкой наличия
   API. Иначе красный `go test ./...` (админка «не грузится»).
2. **Автоплей браузера.** `AudioContext` стартует в `suspended` до первого
   взаимодействия пользователя — инициализировать/`resume()` по первому клику.
   **Отказ `resume()`/ошибка создания аудио — глушить в `try/catch`, ни одного
   unhandled rejection:** e2e-смоук `tools/e2e/map-check.js` валит прогон при любом
   `pageerror`/ошибке в консоли — аудио не должно ронять смоук.
3. **Файлы, а не синтез.** Звуки грузятся из `web/static/audio/` (локально, с диска).
   Загрузка — ленивая, только на карте, внутри функций (не на верхнем уровне модуля),
   чтобы не трогать Node-граф админки. Аудиофайл, загруженный один раз, кэшируется.
4. **Мультиплеер-контекст** не затронут (звук чисто клиентский, общих map/Go-структур
   не касается).
5. **Не дублировать звуки на одном событии.** Прибытие уже озвучивается тостом
   (`map/data.js` — `checkCompositeArrival` шлёт `notifyInfo('🚀 Прибыли…')`),
   а `map/animation.js` в тот же момент вызывает `hideFlightPanel()`. На одно событие —
   ровно один звук: либо сигнал прибытия полёта, либо тост, но не оба. Техника —
   стоп гула + один сигнал, без наложения (см. ТЗ).
6. **Гул — идемпотентный и живучий:** `startFlight` вызывается повторно в полёте
   (редирект/разворот 61a) — перед стартом глушить предыдущий гул (не накладывать);
   полёт после F5 восстанавливается **минуя** `startFlight` (`map/data.js`,
   `user.flight`) — гул нужно поднимать и там, иначе «летим, но тихо».
7. **F5 в полёте: гул не возвращается (баг создателя).** Политика браузера запрещает
   аудио до первого жеста после загрузки страницы, а гул стартует при инициализации —
   `play()` отклоняется. Нужно «ожидание гула»: если воспроизведение гула не началось,
   повторить попытку на первом же клике/клавише/touch (одноразовый слушатель,
   вешается на активации страницы). Без этого баг не уходит.
8. **Гул через Web Audio, НЕ через `<audio>` (баг 2026-09-21: пауза ~0.3 с между
   повторами).** Обычный `<audio loop>` вставляет разрыв на стыке — слышно паузу
   тишины. Гул (и, для единообразия и надёжности, все звуки) играть через Web Audio:
   `AudioContext` + `decodeAudioData` → кэш буферов → `AudioBufferSourceNode`
   с `loop = true`. Плюс: Web Audio устраняет и задержку первого проигрывания,
   и гэп. `AudioContext` создаётся лениво и `resume()` после первого жеста
   (автоплей) — это же закрывает ловушку 7 (гул поднимается после жеста).

## ТЗ на разработку (переработка)

- **Модуль** `web/static/js/ui/sound.js` — **перевести на Web Audio** (ловушка 8):
  `AudioContext` (лениво) + `decodeAudioData` (кэш буферов по роли) + `AudioBufferSourceNode`
  (`loop = true` для гула, плавный `GainNode`-фейд при остановке). Обычный `<audio>`
  даёт паузу на стыке — не использовать.
  Карта ролей `ROLE_FILE` (единственное место с путями):
  - `ui_open` → `interaction.ogg`, `ui_select` → `interaction.ogg` (открытие и выбор
    звучат одинаково — решение создателя);
  - `ui_success`, `flight_start`, `flight_arrive` → `confirm.ogg` (подтверждение
    действия: старт, прибытие, успех);
  - `ui_error` → `error.ogg`;
  - `flight_hum` → `flight_hum.ogg` (зациклен, плавное затухание).
- **Флаг активации страницы:** звук играет только после явной активации (её вызывает
  карта); до активации все play-функции — no-op (админка молчит).
- **Фикс F5 (ловушка 7):** «ожидание гула» + повторная попытка поднять гул на первом
  жесте игрока (одноразовый слушатель ставится при активации), чтобы гул возвращался
  после перезагрузки в полёте. На Web Audio это то же место, где делается `resume()`
  контекста.
- Состояние (вкл/выкл, громкость) — localStorage `zorion.sound`, дефолт «вкл», ~0.4.
- Весь код безопасен для Node-графа (ловушка 1): никаких `document`/`Audio`/`fetch`
  на верхнем уровне. Guard — `typeof AudioContext`; отказ `play()`/загрузки —
  `try/catch` + `p.catch(()=>{})`, ни одного unhandled rejection.
- **Убрать** общий щелчок (`installClickSound`) — уже убран, не возвращать.
- **Точечные врезки (только карта/модалка):**
  - тосты `error`/`success` → `error` / `confirm`; `info` — молча;
  - `openSystemModal` → `interaction`;
  - выбор планеты (клик по планете/строке в модалке) → `interaction`;
  - `startFlight` → `confirm` + гул; восстановленный полёт после F5 → гул (без `confirm`);
  - завершение/прибытие → стоп гула + `confirm` (один раз, без дубля с тостом);
  - `closeModal`, крестики, «Закрыть», скрытие уведомления — **без звука**.
- **Композитный маршрут (99.2.30) / внутрисистемный полёт (99.2.27):** гул непрерывный
  через сегменты, `flight_arrive` — только в конце маршрута (`checkCompositeArrival`),
  не на стыке сегментов.
- **UI:** кнопка звука (вкл/выкл) в шапке карты (`map.html`), отражает состояние,
  переживает F5.
- **Стиль/имена:** рядом с `ui/toast.js`, ES-модуль с явным `.js` в импорте.

## Критерии приёмки

- **Закрытие — тишина:** закрытие модалки, крестики, «Закрыть», скрытие уведомления,
  отмена — ни одного звука.
- **Открытие/выбор — звучат:** открытие окна системы и выбор планеты
  (`interaction.ogg`), успех и ошибка (`confirm.ogg` / `error.ogg`); `info` — молча.
- **Полёт:** `confirm.ogg` на старт → зацикленный `flight_hum.ogg` всё время перелёта →
  `confirm.ogg` на прибытие (один раз); гул гарантированно останавливается при завершении.
- **F5 в полёте — гул возвращается** (баг создателя, ловушка 7): сразу может быть тихо
  (браузер), но на первом клике/клавише гул подхватывается.
- **Админка молчит**; кнопка звука на карте выключает/включает всё, выбор переживает F5.
- `go build ./...`, `go vet ./...`, `go test -race ./...` — зелёные
  (в т.ч. `TestAdminFrontendLoadsInNode`).
- e2e-смоук `tools/e2e/map-check.js` — клиентский флоу карты не сломан
  (JS-ошибок/тостов-ошибок нет; аудио не даёт unhandled rejection).
