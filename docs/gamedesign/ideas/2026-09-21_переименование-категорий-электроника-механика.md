## 0. Пожелание создателя (2026-09-21)

> «Лучше переименовать категории тогда: Механика, Электроника.»

Итог (подтверждено создателем «без разницы» по порядку):
- **«комплектующие» → «Электроника»** — проводящая начинка (проводимость ↑, `T_melt` ↑, химактивность ↓);
- **«детали» → «Механика»** — несущее/подвижное (твёрдость, плотность, `T_melt`).

Состав 13 категорий не меняется, меняются только два имени. Старая пометка
«детали против комплектующих — возможно, одно» снимается: категории оставлены
двумя, имена сделаны описательными по природе (электрика/механика), а не по
собирательному слову.

## 1. Факты (сверка с кодом, 2026-09-21)

- **Список категорий** — `internal/goodsstudio/model/state.go` `DefaultCategories`
  (13 позиций, сид `goods_catalog_seed`); в БД — таблица `categories` (kind='good').
- **Корзина Автофабрики** — `seed_producers.go`: `input.consumables = ["детали","комплектующие"]`
  (корзина роботов, `19_robots.md`); на живой БД правится миграцией.
- **Товары** — `goods.category_id` (составной FK `(kind, category_id)`), при импорте
  топ-каталога товары стоят в категориях «детали»/«комплектующие».
- **«Детали» как обычное слово** (детали корабля/арта/расы) в доках — НЕ трогаем
  (см. §3, дельта точечная).

## 2a. Миграция 000053 (data-миграция)

Три блока (образец — 000051: name_norm литералами нижнего регистра, не через
`lower()` — коллация C, `docs/PITFALLS.md` «БД и шелл»):

1. `UPDATE categories SET name/name_norm` — «комплектующие»→«электроника»,
   «детали»→«механика» (только `kind='good'`; ресурсные не трогаются).
2. `UPDATE goods SET category_id` — товары спорных категорий переезжают на новые id.
3. `UPDATE producer_types ... jsonb_set(input, '{consumables}', ...)` — корзина
   Автофабрики: строки «детали»→«механика», «комплектующие»→«электроника».

Порядок относительно сида: миграции применяются ДО `goodsstudio.Seed` — на свежей
БД категорий ещё нет, UPDATE холостые, сид создаёт новые имена; на существующей —
UPDATE переименовывает, маркерный сид пропускается. Оба пути дают один результат.
