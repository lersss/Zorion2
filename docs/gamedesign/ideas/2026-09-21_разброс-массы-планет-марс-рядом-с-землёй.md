# Широкий физичный разброс массы планет — чтобы рядом с Землёй мог встать Марс

**Дата:** 2026-09-21
**Вектор:** Генерация
**Статус:** уточнение завершено, маршрут — дизайн (спека физической модели разброса)

## Пожелание (сырое, от создателя)

1. «Мне не нравится, что у нас каждая следующая планета строго тяжелее предыдущей по номеру орбиты.»
2. Уточнение вопросами менеджера: «я хочу честную по физике модель, но чтобы появился Марс, её нужно расширить.»

**Смысл:** тренд «дальше от звезды — тяжелее» сам по себе верен и остаётся. Проблема — его
**стерильность**: разброс так узок, что порядок масс почти всегда совпадает с порядком орбит.
Нужно резко расширить разброс так, чтобы планета, стоящая в богатой зоне, могла остаться
лёгкой (Марс), а системы перестали быть предсказуемыми по одному номеру орбиты.

**Ярдстик (решение создателя 2026-09-21):** реальные системы — Солнечная — должны
воспроизводиться: Меркурий 0.055, Венера 0.815, Земля 1.0, Марс 0.107 M⊕.

## Что проверено (факты, 2026-09-21)

Модель массы после спеки `2026-09-21-масса-каменистых-и-ледяных-планет.md` (коммит `a8a8304`):

```
M = clamp( B · M₀ · (a_норм/a_⊕)^0.5 · 10^(0.5·[Fe/H]) · ζ,  0.02, 8 )
a_норм = r/√L,  r_i = 0.4·1.7^i·√L  →  шаг по орбите ×1.7
ζ ~ logN(0, 0.4) — на планету;  B ~ logN(0, 0.5) — один ролл на систему
```

- Средний рост массы на одну орбиту = √1.7 = **×1.30 (+30%)** — отсюда «каждая следующая тяжелее».
- ζ даёт разброс ±1σ = ×1.49 / ×0.67, то есть соседние планеты **меняются местами примерно в трети случаев** — модель НЕ строго монотонна, но крупных провалов не даёт.
- Замер медиан (`go test -run TestMassSpreadAcrossOrbits -v`, seed 20260923, G-звезда): орбиты 1/3/5/7 → **0.769 / 1.297 / 2.184 / 3.741 M⊕**.
- Марс-подобное отклонение (планета в ~10 раз легче соседа) в текущей модели практически невозможно: для этого нужен разброс ζ на порядок шире.
- Сама спека-источник (§4.2 п.6) сравнивает модель с Солнечной системой: «Венера 0.815 / Марс 0.107» против модельных «0.77 / 1.30» — то есть расхождение было известно, но не устранено (задача тогда была другая — убрать полки 0.10/8.00).

**Почему в реальности тренд ломается:** диск наружу действительно богаче (аннулярная масса
∝ r^0.5), но итоговая масса планеты зависит ещё и от истории формирования — обрезка роста
притяжением гиганта (Марс, Grand Tack), потери на близких к звезде орбитах (Меркурий),
миграции. Тренд — «сколько материала доступно», а не «сколько планета набрала».

## Решения создателя

- 2026-09-21: **тренд сохранить** (физически честен), **разброс резко расширить** — чтобы Марсы/Меркурии стали обычным делом. Формулировка: «хочу честную по физике модель, но чтобы появился Марс, её нужно расширить».
