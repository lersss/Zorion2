## 0. Пожелание создателя (2026-09-21)

> «Если выбран фильтр по расе в шапке (семейство или точная раса), при создании
> через пустой слот нового завода по умолчанию проставлять выбранное в фильтре.»
> Уточнение: **берём отдельной задачей ПОСЛЕ «Люди → F0»** (решение создателя
> 2026-09-21: «после»).

## 1. Факты (сверка с кодом, 2026-09-21)

- **Узел-приглашение категории** (пустой слот) — `openProdCreatePopup` +
  `doProdCreate` (`web/studio.html`): расовость из фильтра шапки **УЖЕ
  подставляется** — «Семейство» → `body.race_family`; «Раса» →
  `body.race_family` + `body.race`; «Универсальный» → без расовости.
  Реализовано в задаче дерева построек (2026-09-21). То есть пожелание в этой
  части уже выполнено.
- **Кнопка «+ тип»** (`prodAdd`, `web/studio.html:1660`): создаёт тип
  (`parent_id NULL`) с телом `{name, kind}` — **расовость из фильтра НЕ
  подставляется**. Это и есть «дыра»: правило работает для одного пути
  создания и не работает для другого.
- Типы без автоматики (Поселение, Лаборатория, Энергостанция) создаются именно
  через «+ тип».

## 2. Что значит «доделать» (черновик объёма)

1. Решить: подставлять расовость из фильтра и в «+ тип» (или только в пустые
   слоты категорий — там уже работает). **Вопрос к создателю.**
2. Если да — `prodAdd` передаёт `race_family`/`race` из текущего уровня
   расовости (тот же паттерн, что `doProdCreate`).
3. Согласовать с переключателем расовости (§5 дерева построек) и с F0-задачей
   (список семейств, порядок F0→F1…F9→robotic) — чтобы не конфликтовать.

## 3. Развилки (к создателю на гейте)

1. Подставлять ли расовость в «+ тип» тоже — или только в пустые слоты
   категорий (где уже работает)?
2. Если фильтр «Семейство» (не конкретная раса) — тип создаётся с
   `race_family` = семейство, `race` = NULL. Так ли для типов без категории?
3. Тип может быть без категории и без автоматики — расовость ему нужна или
   тип всегда универсальный? (Сейчас узел-приглашение наследует уровень, у
   «+ тип» — нет.)

**Закрыто 2026-09-21 — решение создателя: «подставляй».** То есть «+ тип»
ведёт себя как узел-приглашение пустого слота; развилки 1–3 снимаются,
вопрос «нужна ли расовость типу» решён положительно.

Критерии «мелкая» (`manager.md`) выполнены: нет новой сущности/таблицы/миграции,
