## 1. Факты (текущее состояние)

- **Фракции.** Таблица `factions` есть (миграция `004_factions.sql`): имя, тип,
  родной мир (`homeworld_id`), strength, ресурсы, цвет, описание. Генератор
  `internal/generator/faction/faction.go` создаёт 1–3 фракции на каждую
  обитаемую планету (случайное имя, тип из ~75, `strength` всегда 1, описание по
  шаблону). Запуск — админ-эндпоинт `/admin/generate-factions`.
- **Фракции невидимы игроку.** В карточке системы вкладка «Фракции» — заглушка
  «🏛️ Данные о фракциях будут доступны позже» (`web/static/js/modal/tabs.js:607`).
- **Строений нет.** Таблицы `buildings` в БД нет; `settlements` (9 колонок)
  владельца не имеет.
- В dev-БД фракций **0** (таблица пустая).
- Дизайн релиза 2 в целом решён в спеке фабрик: таблица `buildings` (§3.2),
  владельцы у всех строений (`owner_type`/`owner_id`, три класса: player/faction/
  agent), население строений, разблокировка предмет-рецептом + снабжением.
- **Следующий свободный номер миграции:** **000056** (последняя на диске —
  `000054`; 000055 заявлена под рецепты студии, файла ещё нет — проверено

## 2. Ответы создателя (2026-09-21)

1. **Объём первой итерации** — только фундамент: строения появляются в мире +

   итерации.
2. **Что владелец даёт сейчас** — только факт «чей это завод» (показываем).

3. **Откуда строения берутся в мире** — **«столица» фракции**: постройка,
   тип — «другое» (ничего не производит).
4. **Судьба нынешнего генератора фракций** — на усмотрение менеджера (см. §3).
5. **Поселения** — владельца пока НЕ получают.

## 3. Решение менеджера (по п. 4 «на твоё усмотрение»)

**Оставляем существующий генератор фракций; владельцами столиц становятся
реальные сгенерированные фракции**, а не единая фракция-заглушка.

Обоснование: генератор уже написан (0 новой работы); владелец-фракция сразу
осмыслен и даёт основу под будущие фракционные заводы; единая заглушка «на всё»
дала бы одну столицу на всю галактику — мир не наполняется.

⚠️ **Конфликт с доком:** решение 3b.6.9 спеки фабрик («сгенерированный контент
принадлежит ЕДИНОЙ фракции-заглушке») на столицы не распространяется. Поселения
в этой итерации владельца не получают (п. 5), поэтому фактического противоречия
нет; при закрытии задачи — правка формулировки спеки/ГДД (правило создателя 99a).

### 4.1. Границы первой итерации (фиксируем, чтобы не расползлось)

- **Входит:** сущность «строение»; генерация столиц по фракциям; владелец
  (faction) + показ владельца; минимальное взаимодействие (открыть/посмотреть).
- **НЕ входит:** население строений, снабжение, разблокировка производства,
  тир как гейт, механики перехода/отжима, владельцы поселений, автофабрики/
  платформы/лаборатории, энергостанция, инвентарь предметов.
