## 2. Диагноз (проверено воспроизведением)

**Симптом:** в чистой копии `origin/master` (последний запушенный коммит `4c86040`)
сборка падает:

```
# zorion/internal/handlers
internal/handlers/admin_universe.go:631:38: undefined: repository.ResolveDefaultSettlementTypeID
```

**Причина — не ошибка самого кода, а «половинчатость» коммита.** Коммит «фракции»
`7966a78` (ветка «одна фракция на расу со столицей») вместе со своими правками унёс
кусок **чужой, ещё не завершённой** задачи «экономика поселения — итерация 4»: в
`internal/handlers/admin_universe.go` (файл общий, см. `COORDINATION.md` §«Пересечения
итерации 4») попала правка `GeneratePrototypePlanet` — резолв типа поселения и колонка
`settlement_type_id` в INSERT. Сам помощник `ResolveDefaultSettlementTypeID` живёт в
`internal/repository/economy_repository.go`, который остался **незакоммиченным** →
в запушенной ветке вызов есть, функции нет.

**Почему локально зелено:** в рабочем дереве функция лежит (незакоммиченная правка
итерации 4), поэтому `go build ./...` локально проходит. Ловушка уже описана
(витрина §7) — повторилась на новом файле.

**Проверка фикса (вариант «откат куска»):** в чистой копии `origin/master` убрал
случайный блок из `admin_universe.go` → `go build ./...` и `go vet ./...` зелёные
(проверено 2026-09-22, временный worktree в `%TEMP%\opencode`, после проверки удалён).

**Состояние схемы БД:** миграция `000067_settlement_type.sql` (колонка
`settlements.settlement_type_id`) — тоже незакоммичена. Значит, даже если «докоммитить»
только функцию, на проде колонки нет → INSERT из `GeneratePrototypePlanet` упадёт в
рантайме (админ-страница «прототип-планеты»).

## 3. Варианты фикса (решает создатель)

1. **Откат случайного куска в запушенной ветке (быстро).** Вернуть
   `GeneratePrototypePlanet` в `admin_universe.go` к состоянию до `7966a78` (~11 строк,
   один файл, админ-страница прототипа работает как раньше). Деплой зелёный сразу;
   остальная незакоммиченная работа не трогается. Итерация 4 при своём коммите вернёт
   этот кусок вместе с миграцией и функцией (кусок восстанавливается из `7966a78`).
   Файл под меткой итерации 4 в `COORDINATION.md` → нужна её снимающая передача/уведомление.
2. **Докоммитить всю итерацию 4 целиком.** На диске 37 файлов / ~1400 строк, все 5
   точек INSERT на месте, тесты `repository`/`handlers`/`economy/settlement` зелёные
   (проверено `go test -short` 2026-09-22). Тогда деплой поедет сразу с фичей и её
   схемой. Минус: это публикация незавершённой задачи без её собственных гейтов
   (@reviewer/@tester) и без ведома её сессии.
3. **Не трогать до конца задачи** — деплой будет падать до её коммита.
