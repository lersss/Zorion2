## Суть

Продолжение рецепта 2026-09-21 (чистый txt2img, 3/4 сверху, нос вправо,
frame-check, Hi-Res, ручная приёмка). Задача — довести до **всех 60 рас** и
**выпилить легаси**:

1. **Генерация 63 кораблей** по победившему рецепту (`art_ships.md` §2.0):
   - 59 обычных рас × 1 корабль;
   - люди × 4 типа (starship/cruiser/carrier/fighter) — разные корабли.
2. **Люди: 4 разных `texture`** (правка лора `races/ships/humans.md` +
   `config/art/ships.json`) — иначе 4 корабля по одной texture выйдут клонами.
3. **Выпил 21 легаси-спрайта** в игре (отдельный этап разработки, после
   генерации): реестр `ShipSprites`, `LegacyShipIconMap`, `DefaultShipIcon`,
   `spriteForAgent`, файлы `web/static/sprites/*.png`.

**Рецепт (не меняется):** Juggernaut XL v9; txt2img 1024×1024, steps 32,
cfg 6.0, dpmpp_2m/karras; ракурс «dorsal three-quarter view…, nose pointing
right»; негатив формы + морское/авиационное + blocked расы; frame-check
(край < 8 px или вытянутость < 1.3 → другой seed); вырез hyst(12/40) +
fill_holes; 200×200, нос вправо; Hi-Res 4x-UltraSharp → 1536 → img2img
denoise 0.40.

## Техническое препятствие (найдено 2026-09-22)

**`clearShipsPool` чистит пул перед каждым стартом** (`ships_job.go`): UI-кнопка
пачки стирает предыдущие кандидаты. Прогнать «пилот 5 → остальные 58» через
текущий UI нельзя без потери. Нужен режим **«генерация без чистки пула»**
(накопительный прогон) — правка кода студии (`@developer`), объём малый.

**Решение по пилоту:** запускать через `genbatch` по 5 рас без перезапуска
(пока пул пуст) — либо через правку накопительного режима. Объём правки
согласуется с @developer.

## ТЗ (для @developer + @designer)

### A. Правка лора людей (контент, зона контента/дизайна)

- `races/ships/humans.md`: 4 секции `texture` (starship/cruiser/carrier/fighter)
  с разными материалами; либо производные поля.
- `config/art/ships.json`: 4 записи под люди (`humans_starship`,
  `humans_cruiser`, `humans_carrier`, `humans_fighter`).
- ⚠️ Это меняет контракт «одна раса = одна texture» → нужен формат для
  рас с несколькими типами кораблей. Дизайн формата — за @designer.

### B. Режим накопительной генерации студии (код, @developer)

- `/ships/genbatch` (или новый `/ships/genall`) без `clearShipsPool` — чтобы
  пилот и остаток жили вместе.
- Тест: пул сохраняется между вызовами.

### C. Генерация 63 кораблей (операция, менеджер + создатель)

- Пилот 5 рас: users ×4 + coastal + silicon_guardians + methane_plankton +
  sulfur_nests.
- Гейт создателю: 5 готовых → ок/крутим.
- Остаток: 55 рас + оставшиеся юзерские типы.

### D. Выпил легаси-иконок (код, @developer) — после генерации

- Реестр `ShipSprites`: 21 легаси → расовый набор (63).
- `LegacyShipIconMap` / `DefaultShipIcon` / `spriteForAgent` — разобрать
  потребителей (старые `ship_icon` в БД игроков!), не сломать.
- Удалить 21 PNG из `web/static/sprites/`.
- Обязательный отчёт об анализе потребителей легаси на гейте (AGENTS.md §4).
