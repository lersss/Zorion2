## Суть

Продолжение рецепта 2026-09-21 (чистый txt2img, 3/4 сверху, нос вправо,
frame-check, Hi-Res, ручная приёмка). Задача — довести до **всех 60 рас** и
**выпилить легаси**:

1. **Генерация 63 кораблей** по победившему рецепту (`art_ships.md` §2.0):
   - 59 обычных рас × 1 корабль;
   - люди × 4 типа (starship/cruiser/carrier/fighter) — разные корабли.
2. **Люди: 4 разных `texture`** (правка лора `races/ships/humans.md` +
   `config/art/ships.json`) — иначе 4 корабля по одной texture выйдут клонами.
3. **Выпил 21 легаси-спрайта** в игре (отдельный этап разработки, после
   генерации): реестр `ShipSprites`, `LegacyShipIconMap`, `DefaultShipIcon`,
   `spriteForAgent`, файлы `web/static/sprites/*.png`.

**Рецепт (не меняется):** Juggernaut XL v9; txt2img 1024×1024, steps 32,
cfg 6.0, dpmpp_2m/karras; ракурс «dorsal three-quarter view…, nose pointing
right»; негатив формы + морское/авиационное + blocked расы; frame-check
(край < 8 px или вытянутость < 1.3 → другой seed); вырез hyst(12/40) +
fill_holes; 200×200, нос вправо; Hi-Res 4x-UltraSharp → 1536 → img2img
denoise 0.40.

## Техническое препятствие (найдено 2026-09-22)

**`clearShipsPool` чистит пул перед каждым стартом** (`ships_job.go`): UI-кнопка
пачки стирает предыдущие кандидаты. Прогнать «пилот 5 → остальные 58» через
текущий UI нельзя без потери. Нужен режим **«генерация без чистки пула»**
(накопительный прогон) — правка кода студии (`@developer`), объём малый.

**Решение по пилоту:** запускать через `genbatch` по 5 рас без перезапуска
(пока пул пуст) — либо через правку накопительного режима. Объём правки
согласуется с @developer.

### Чекпоинт 2026-09-22 (вырез закрыт: magenta-фон + `edge`; чекпоинт/коммит/пуш)

**Итог по вырезу (проверено на 57 кадрах; всё ушло в коммит):**

1. **Хромакей по magenta не сработал.** Juggernaut XL по промпту «flat chroma
   magenta background» даёт **градиент**, а не ровную заливку: у Алмазных
   «магента-ность» (`m = min(R,B)−G`) падает с ≈158 до ≈38, у Прибрежных в фон
   примешивается cyan (половина фона `m ≈ −170`). Ключ по цвету
   (`remove_bg_chroma`, `--method chroma`) такой фон не берёт: остаётся ореол,
   а при понижении порога выедается тёмный корпус (у Алмазных медиана `m`
   корпуса совпадает с фоном — ни один tol не разделяет). Метод **выведен из
   конвейера**, оставлен в коде для сравнения/отката.
2. **Рабочий рецепт — magenta-фон + `edge`** (flood от рамки не пересекает
   кромки по Собелю от размытой яркости). Порог подобран зондом
   tol ∈ {40,60,80,100,120} на 14 кадрах (`ai_drafts/tol_probe/`):
   - **чёрный фон (55 старых кадров): `--tol 40`** — на tol ≥ 80 тёмный корпус
     выедается (доля съеденного корпуса: Алмазные 0.21–0.24, Дисковые 0.31,
     Силикатные рои 0.34);
   - **magenta-фон (s56/s57): `--tol 100`** — амплитуда фон-градиента ≤ ~70,
     корпус цел.
   `tools/ship_recut_pool.py` сам определяет фон по рамке (`is_magenta_bg`) и
   берёт нужный tol (`--tol 40`, `--tol-magenta 100`); студийный
   `cmd/art-studio/postproc/ship.go` — 100 (для новых magenta-генераций).
3. **Пул (57) перерезан** `tools/ship_recut_pool.py` (сырьё — `C:\ComfyUI\output`
   по seed из `meta.json`); отчёт `ai_drafts/ships_recut.json`;
   `ai_drafts/final_accepted/ships/` (14) не тронут.
4. **Артефакты приёмки:** `ai_drafts/ships_recut_montage.png` (все 57),
   `ai_drafts/ship_recut_before_after.png` (10 рас: raw | hyst 12/40 | edge tol),
   `ai_drafts/tol_probe/`.
5. **Результат:** корпус вернулся целиком у Алмазных s13, Небесных глубоких s14,
   Лавовых s22, Силикатных роёв s37, Курильщиков s42, Вулканитов s52;
   Гейзерные s18 — корпус цел, но с остатком фона.
6. **Остаток — дефект ГЕНЕРАЦИИ, не выреза:** фон вышел не однотонным у s16
   Дисковые (коричневый «горизонт планеты»), s18 Гейзерные (серо-бурые блоки),
   s20 Горнила, s26 Туман-рои, s29 Подземные (жёлтая подложка), s48 Серные рои

7. **DoD зелёный:** `go build ./...`, `go vet ./...`, `go test -race -short`
