## 1. Пожелание создателя (2026-09-22)

> «подними все сервера наши» → «можно один экзешник, который все сервера поднимает?»
> → «или батник» → «батник пока».

Потребность за этим: одно действие вместо «вспомнить, что и в каком порядке запускать».
Сейчас локальный запуск — ручная последовательность: база → игровой сервер → генерация
картинок → учёт агентов → арт-студия, и каждое поднятие заново изобретает «как отвязать
процесс, чтобы он не умер вместе с консолью».

## 2. Решение (батник, не экзешник)

**Файл:** `start-all.cmd` в корне проекта (двойной клик). Причина выбора батника —
создатель: «батник пока»; аргумент менеджера: нулевая сборка, правится за секунду,
не устаревает; экзешник отложен (собирать из нашего кода, если понадобится тихий запуск
без окна).

**Поведение:**
- Порядок: база (с ожиданием готовности) → Redis (служба Windows) → игровой сервер →
  генерация картинок → учёт агентов → арт-студия.
- **Повторный запуск безопасен:** живоe пропускается (проверка порта), дублей слушателей
  не появляется.
- Каждый сервер поднимается в отдельном свёрнутом окне, независимо от окна батника.
- В конце — таблица «что получилось» по портам, адреса игры/студии/учёта и пути логов.
- Переключатели в начале файла: генерация картинок, учёт агентов, арт-студия (`1`/`0`);
  по умолчанию поднимается всё.
- Флаг `--no-pause` — не ждать нажатия клавиши (для запуска из скриптов).
- Погашения серверов в этом заходе нет (кнопка «погасить всё» — отдельно, если попросит).

**Что поднимается и где:** база — `C:\pgsql` (`pg_ctl`), Redis — служба Windows,
игровой сервер — `go run ./cmd/server` (ключи сессий берутся из `.env` сам),
картинки — `C:\ComfyUI` (venv, порт 8188), учёт агентов — `tools/agent-dash`, арт-студия —
`go run ./cmd/art-studio`.

## 3. Ловушка формата файла (найдено в работе, 2026-09-22)

Батник в репозитории **обязан** быть **CRLF + cp866 (OEM)**. Первый вариант был записан
UTF-8 с LF: `cmd.exe` рвёт парсинг (исполняет обрывки строк и русских слов как команды),
причём симптом неочевиден — вывод обрезан, ошибки вида `'порт' is not recognized`.
Кодировка консоли на машине — 866; в начале файла стоит `chcp 866` для страховки.

## 4. Что проверено вживую (менеджер, 2026-09-22)

- Холодный старт: погашены база и игровой сервер → батник поднял базу, дождался её,
  затем собрал и поднял игровой сервер; итог — шесть «ок».
- Повторный запуск при живых серверах: шесть «уже работает», повторных слушателей нет.
- Отдельно: погашен «учёт агентов» → батник поднял только его.
- После холодного старта `/health` → OK, `/status` → «All systems ready»; генерация
  картинок, учёт агентов и арт-студия отвечают 200.
