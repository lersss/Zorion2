## 2. Что сделано (инструмент)

**`tools/db.ps1` — однократная обёртка над psql.** Создан и проверен 2026-09-22.

- Обходит кодировку (UTF-8 для ввода/вывода), многострочный SQL (временный
  `.sql`-файл + `cmd /c`), пароль (`PGPASSWORD`), `ON_ERROR_STOP=1`.
- Вызовы: `-Sql "..."`, `-File q.sql`, либо stdin (конвейер).
- Файл ASCII-only — обходит ловушку PowerShell 5.1 с русскими комментариями в
  `.ps1` (первая редакция именно на этом и упала — воспроизведена боль агентов).

**Проверено (2026-09-22):**
- `-Sql "SELECT ... FROM planets"` → вывод корректен, `exit 0` (203679 планет);
- многострочный SQL через stdin → корректно, `exit 0`;
- `PSParser::Tokenize` (синтаксис PS) → OK.

Остаточная косметика: метку psql `(1 строка)` консоль при захвате вывода
показывает битой (`(1 ������)`) — это окружение захвата, не скрипт; на данные не влияет.
