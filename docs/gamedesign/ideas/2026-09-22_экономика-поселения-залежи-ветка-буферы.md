## 2. ЭПИК — список работ по итерациям (трекер)

### Итерация 1 — Залежи на поверхности — ✅ реализовано 2026-09-22 (коммит `3208cad`)
- **1.1.** Конфиг биома: **таблица ресурсов**, которые могут здесь генерироваться. Поля записи: ресурс каталога + шанс/вес появления + диапазон богатства. Один биом — много ресурсов. **Для пилота — один ресурс: пища.**
- **1.2.** Генерация залежей при генерации планеты: из биомов поверхности (доля/площадь биома → сколько залежей и насколько жирных).
- **1.3.** Залежь — **объект**: планета + ресурс + слой (поверхность) + богатство + **запас** (конечный, потом расходуется добычей).
- **1.4.** Видимость: залежь показываем **только при знании планеты** (как прочие детали).
- **1.5.** Просмотр: в админке (для песочницы) и/или на карточке планеты при знании.
- **1.6.** **Инструмент админа: добавить залежь на планету вручную** (требование создателя — чтобы можно было поставить залежь без генерации).

### Итерация 2 — Ветка поселения: входной и выходной буфер + рецепт — ✅ реализовано 2026-09-22 (коммит `85f6539`)
- **2.1.** У поселения — ветка со ссылкой на **рецепт каталога** (веток может быть несколько; пилот — одна).
- **2.2.** **Входной буфер** (ресурсы, видит только админ) и **выходной буфер** (то, что даёт рецепт).
- **2.3.** Рецепт реально превращает вход в выход (состав `recipe_components` входит в петлю).
- **2.4.** Админ-действие **«добавить ресурсы»** во входной буфер — без добычи.
- **2.5.** **(уточнение 2026-09-22)** Переработка вход → выход идёт **фоном по времени** (ленивый пересчёт, свой чек-поинт) — фон переехал из итерации 4 в итерацию 2 по решению создателя.

### Итерация 3 — Добыча — ✅ реализовано 2026-09-22 (коммит `6a563fa`), @tester 14/14 PASS
- **3.1.** Ветка черпает из залежей **своей планеты** во входной буфер и **уменьшает запас залежи** — «ровно под переработку», та же скорость от населения (п.24); порядок «вход первым, залежь добором»; залежь от крупной к мелкой (п.25).
- **3.2.** Ленивый пересчёт добычи по времени (тот же проход и та же чек-точка `processed_at`, без тика).
- **3.3.** Выработанная залежь (`amount = 0`) скрыта от игрока и видна админу (п.26); дубликат ресурса в рецепте считается один раз (п.28).

### Итерация 4 — Потребление населением + типы поселения (🔄 в дизайне, старт 2026-09-22)
- **4.1.** **Потребление**: население съедает часть **выхода** ветки — `eat = k_типа · население · Δt` (линейно от населения, **своя** скорость; п.31). Остаток копится в **выходном буфере**; для медианного поселения еда чуть медленнее производства (п.34).
- **4.2.** Видимая петля в карточке: вход / выход / **съедено** / остаток-«осадок» (п.33).
- **4.3.** **Тип поселения — настоящая структура** (п.32): тип — подтип справочника строений («Поселение» → родитель, **один** подтип сейчас); связь «поселение → его тип» реальная, `k` настраивается у типа **в студии**. Голод — отдельная задача (п.35); потолок буфера — не вводим (п.36).

### Уточнения приёмной 2026-09-22 (итерация 3, старт)

24. **Модель добычи — «ровно под переработку»** (вариант Б), **скорость зависит от населения**. Добыча не идёт своим отдельным потоком: за один проход времени ветка берёт из залежи столько, сколько готова переработать (та же скорость `k·population/complexity`, что у переработки, `k` = 2.78·10⁻⁸). Вход остаётся проходным, единственный предел — сама залежь; второй ручки-скорости не заводим. Вариант «независимый поток + растущий вход» отложен до итерации 4 (потребление/потолки).
25. **Связь ветка ↔ залежь — без настройки:** ветка черпает из залежей **своей планеты** и только по ресурсам, перечисленным в её рецепте (для «Пищи» — мясо + вода); ресурсы вне рецепта не трогает. На планете с несколькими залежами одного ресурса ветка берёт **по одной — от крупной к мелкой**; истощилась — переходит к следующей.
26. **Истощение залежи: запись остаётся** (запас 0, не исчезает из данных, в минус не уходит), **но выработанную залежь видит только админ** (дебаг); игроку пустая залежь не показывается вообще («*игрок не видит этого стыда*»).
