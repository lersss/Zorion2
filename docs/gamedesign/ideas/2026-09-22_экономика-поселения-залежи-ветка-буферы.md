## 2. ЭПИК — список работ по итерациям (трекер)

### Итерация 1 — Залежи на поверхности — ✅ реализовано 2026-09-22 (коммит `3208cad`)
- **1.1.** Конфиг биома: **таблица ресурсов**, которые могут здесь генерироваться. Поля записи: ресурс каталога + шанс/вес появления + диапазон богатства. Один биом — много ресурсов. **Для пилота — один ресурс: пища.**
- **1.2.** Генерация залежей при генерации планеты: из биомов поверхности (доля/площадь биома → сколько залежей и насколько жирных).
- **1.3.** Залежь — **объект**: планета + ресурс + слой (поверхность) + богатство + **запас** (конечный, потом расходуется добычей).
- **1.4.** Видимость: залежь показываем **только при знании планеты** (как прочие детали).
- **1.5.** Просмотр: в админке (для песочницы) и/или на карточке планеты при знании.
- **1.6.** **Инструмент админа: добавить залежь на планету вручную** (требование создателя — чтобы можно было поставить залежь без генерации).

### Итерация 2 — Ветка поселения: входной и выходной буфер + рецепт
- **2.1.** У поселения — ветка со ссылкой на **рецепт каталога**.
- **2.2.** **Входной буфер** (ресурсы, видит только админ) и **выходной буфер** (то, что даёт рецепт).
- **2.3.** Рецепт реально превращает вход в выход (состав `recipe_components` входит в петлю).
- **2.4.** Админ-действие **«добавить ресурсы»** во входной буфер — без добычи.

### Итерация 3 — Добыча
- **3.1.** Ветка черпает из залежи во входной буфер и **уменьшает запас залежи**.
- **3.2.** Ленивый пересчёт добычи по времени (тот же приём, что население/полёты — без тика).

### Итерация 4 — Ленивая петля и потребление
- **4.1.** Переработка вход → выход считается фоном по времени (лениво).
- **4.2.** Часть **уничтожается** (на людей), часть копится в **выходном буфере**.
- **4.3.** Видимая петля в карточке: вход / выход / что уничтожено / запас.

### Позже (за пределами итераций 1–4)
- Рост населения и удовлетворение потребностей (корзина/стабильность/терпение) — канон `18_needs`/`13_tiers`.
- Истощение залежей, видимое на поверхности (в «прогулке»).
- Постройка «склад»/автономия (канон-конфликт — см. §6).
- Рынки; расовые ветки; компонентная переработка во всей глубине.
- Лестница/связь с фабриками (`producer_types`/`producer_recipes`) — при надобности.

## 3. Решения создателя (свод)

1. **Песочница**, NPC-поселение людей (F0), не игрок.
2. **Биом → таблица** возможных ресурсов (не один).

5. Ветка **уменьшает залежь** и **перерабатывает**: часть уничтожается, часть в буфер.
6. **Рецепт входит в петлю** сразу (не задел).
7. **Добыча — отдельная механика**; на ближайшей итерации — ручная кнопка «добавить ресурсы» во вход.
8. **Залежи видимы только при знании планеты** (вариант «а», снят жёсткий стоп).
9. Идём **несколькими сессиями** по списку §2 (этот документ — трекер).
10. Рост/потребности — позже.
11. Залежь — **с конечным запасом** (расходуется добычей).
12. Нужен **инструмент админа: добавить залежь на планету** вручную.
13. **Пилотный ресурс — один: пища.**
14. **План зафиксирован 2026-09-22; итерация 1 стартует с чистой сессии.**

## 5. Модель (предложение; финализирует @designer на итерацию)

- **Ресурсы биома:** таблица (в конфиге биома или отдельная сущность) «биом × ресурс каталога × шанс × диапазон богатства».
- **Залежь (`deposits`)** — объект на планете: `planet_id, good_id, stratum('surface'), wealth, amount` (запас). Состыковать с planned `99.2.5`.
- **Ветка поселения (`settlement_branches`)** — ссылка на рецепт + **буфер входа** и **буфер выхода** (форма — JSONB или таблица, за дизайнером) + скорость переработки.
- **Петля** — ленивая по Δt: добыча (итерация 3) → вход → рецепт → выход; часть уничтожается (население).
