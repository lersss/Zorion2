Уточнение: подпись кнопки выхода — просто **«Вернуться»** (решение создателя 2026-09-23; ранее
была «Вернуться на карту», решение 2026-09-22).

## Диагноз (проверено приёмной по коду)

Выход из мини-игры один: кнопка выхода и Esc → пауза → «Вернуться…» (`web/belt.main.js callShip`,
`belt_ui.js`). После `leave()` идёт `window.location.href = '/map'` — попап системы **не
открывается**, игрок оказывается на карте галактики. Попап сам не всплывает: его открывает клик по
звезде (или автооткрытие после межзвёздного маршрута — маркер `compositeRoute`,
`web/static/js/map/data.js` `checkCompositeArrival` + `openSystemModal`). Та же картина у выхода из
прогулки по планете (`web/static/js/surface/surface_main.js` → `/map`).

## ТЗ (объём v1 — только добыча)

1. **Выход из добычи** (кнопка выхода и Esc → пауза → выход): после успешного `leave()` игрок
   попадает на карту, и **попап системы пояса уже открыт** — той системы, в которой он остался
   (позиция `orbit` пояса). В попапе видно бейдж «● Вы в поясе» (штатная логика строки пояса).
2. **Подпись кнопки** выхода — «**Вернуться**» (и подсказка «трюм полон» с той же кнопкой).
3. **Механизм** — по образцу автооткрытия после межзвёздного перелёта: страница добычи оставляет
   сессионную метку «вернуться к системе», карта при загрузке её читает и открывает попап
   (`openSystemModal`). Камеру не двигать: вьюпорт и так стоит там, где игрок уходил.
4. **Инварианты не ломать:** межзвёздное автооткрытие (`compositeRoute`), полёт и его полоса,
   поведение карты без метки (обычный заход — попап не всплывает сам).
