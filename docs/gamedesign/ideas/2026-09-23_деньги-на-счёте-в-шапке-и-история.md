## 5. UI-спека (@uidesigner, 2026-09-23)

### 5.1. Баланс — строка в двух шапках

**Формат подписи (решение создателя, менять нельзя):** `Счёт: 10 000 Cr` — число с
разделителем тысяч, символ `Cr` через пробел. Разделитель — `Number(n).toLocaleString('ru-RU')`
(даёт неразрывный пробел, визуально корректно), затем `+ ' Cr'`.

**Дашборд** (`web/index.html`, блок `.info`, строки 116–121). Сейчас 4 строки:
Имя / Корабль / Текущий мир / Статус полёта. Добавляется **5-я строка последней** —
тем же паттерном `<p>`, что и соседи:
`<p><strong>Счёт:</strong> <span id="accountBalance">—</span></p>`.
Строка стоит после «Статус полёта» и до кнопок — шапка остаётся «карточкой агента»,
деньги замыкают список. Подпись в `<strong>` уже даёт ровно «Счёт: …».

**Карта** (`web/map.html`, `#header`, строки 11–28). В правой группе (`margin-left:auto`)
перед `<span id="currentWorldLabel">` добавляется пара:
`<span id="accountBalanceLabel">Счёт:</span> <strong id="accountBalance">—</strong>`,
оформление — как у `currentWorldLabel` (`color:#94a3b8`, `margin-right:1rem`), сумма —
унаследованным `<strong>` (белая). Порядок в шапке: **счёт → текущий мир → кнопки**
(сначала «кто я по деньгам», потом «где я»). Кнопки (Дашборд/Админка/Пакман/Звук) не трогаются.

Число обновляется один раз при загрузке страницы. На карте — из `loadUserData()`
(`web/static/js/map/data.js`), рядом с заполнением `#currentWorldName`.

### 5.2. История операций — вкладка «💳 Счёт» (вариант C, решение создателя)

Создатель выбрал **вариант C**: история живёт в отдельной 6-й вкладке «💳 Счёт».
Добавляем кнопку `data-tab="tab-account"` в `.dashboard-tabs` (после «📖 Энциклопедия»)
и панель `.tab-pane` с `id="tab-account"`; новая вкладка подхватывается существующим
механизмом (`activateDashboardTab`, ключ `dashboardActiveTab`) — механику вкладок
не переписываем. Внутри — одна карточка «💳 Счёт»: сводка баланса + список операций.

**Форма карточки:**
```
💳 Счёт
  Баланс: 10 000 Cr                       ← сводка, крупнее строк списка
  ─────────────────────────────────
  Стартовый капитал        +10 000 Cr     ← тип | сумма со знаком
  23.09.3026, 14:05                       ← дата (meta, приглушённая)
  ─────────────────────────────────
  Залог по контракту        −300 Cr
  23.09.3026, 16:40
```
Строка — две колонки: слева тип операции + дата (мелким `#94a3b8`), справа сумма
со знаком. Разметку удобно собрать по образцу `.cargo-row` (info слева, значение
справа) — классы свои (`money-*`), но ритм и цвета из той же палитры дашборда
(`#1e293b`/`#334155`/`#94a3b8`/`#cbd5e1`).

**Даты — общий игровой календарь (решение создателя).** Дату берём из серверной
метки операции `occurred_at` и показываем через **импорт `gameDate` из
`web/static/js/game_date.js`** → «23.09.3026, 14:05» (UTC, год +1000, как у всех
поверхностей дат). Системные часы игрока и `toLocaleString` не используем —
второго форматирования дат не заводим.

**Человекочитаемые типы** (из `operations[].kind`, открытый список — неизвестное
не ломает UI):
| `kind` | подпись |
|---|---|
| `admin_seed` | Стартовый капитал |
| `escrow_lock` | Залог по контракту |
| `escrow_release` | Выплата по контракту |
| `escrow_return` | Возврат залога |
| `contract_work_earn` | Заработок по подряду |
| (иное) | Операция по счёту |

> Подпись `admin_seed` → «Стартовый капитал» **оставляем** на случай, если запись
> когда-нибудь появится в журнале (тип остаётся в открытом списке). По решению
> создателя «б» стартовые 10 000 в журнал сейчас не пишутся — у нового игрока
> история пуста.

**Сумма:** `delta > 0` → `+10 000 Cr` (зелёный), `delta < 0` → `−300 Cr` (красный).
Знак — типографский минус `−` (U+2212). Цвета gain/loss в палитре проекта не заданы —
предлагаю нейтральные семантические `+ #4ade80` / `− #f87171` (принято по
предложению дизайнера; если @gdesigner закрепит иные — взять его).

### 5.3. Состояния

| Состояние | Шапка (дашборд/карта) | Карточка истории |
|---|---|---|
| Загрузка | `—` (плейсхолдер, как сейчас в разметке) | `⏳ Загрузка…` (`.money-status`) |
| Успех | `Счёт: 10 000 Cr` | сводка баланса + список |
| Пусто (`operations` пуст) | число есть | «Операций пока нет.» (`.money-empty`) |
| Ошибка (`fetch` не ок, не 401/403) | `—` | `❌ Не удалось загрузить счёт` (`.money-status`); страница работает дальше |
| 401/403 | — | очистить токен, редирект на `/login-page` (как `cargo.js` / `handleUnauthorized`) |

Крайние случаи: баланс `0` показываем как `Счёт: 0 Cr` (не прочерк); нечисло/NaN →
`—` (битые данные не рисуем, приём из `cargoNum`); разметку строк собираем через
`escapeHtml` (импорт из `cargo.js` — уже экспортирован).

## 7. Решения создателя (2026-09-23)

1. **История операций — вариант C:** отдельная вкладка «💳 Счёт» в дашборде (6-я вкладка
   + панель `#tab-account`). Внесено в §5.2/§5.4; варианты A/B сняты с выбора.
2. **Даты истории — серверное время, не системные часы игрока:** отображение через общий
   игровой календарь `gameDate` (`web/static/js/game_date.js`: UTC, год +1000, формат
   «23.09.3026, 14:05») от серверной метки операции `occurred_at`. `toLocaleString`/
   локальное время не используем. Внесено в §5.2, §5.4.
3. **Стартовые 10 000 в журнал не пишем (решение «б»):** у нового игрока история пуста →
   «Операций пока нет». Критерий приёмки №2 в §5.4 заменён; подпись `admin_seed` →
   «Стартовый капитал» оставлена в открытом списке типов (§5.2) на случай появления записи.

**Мелочи приняты по предложению дизайнера:** порядок строки баланса (последней в шапке
дашборда; на карте — счёт перед текущим миром), подписи типов операций (§5.2), цвета
+/− (`+ #4ade80` / `− #f87171`) — если @gdesigner закрепит иные, взять его.
