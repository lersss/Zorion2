## ✅ Источник «мира расы» уже есть (найдено 2026-09-23, чужая работа в master)

Коммит `7966a78` «одна фракция на расу со столицей на её родной планете» даёт
**готовую связь раса → родная планета**:
- `factions.race_id` (миграция `000066`, уже в master) — одна фракция на расу;
- `factions.homeworld_id` — **родная планета расы** (её поселение с наибольшим
  населением; tiebreak — меньший `planet_id`, детерминированно;
  `internal/generator/faction/faction.go::GenerateFactions`);
- `buildings(building_type='capital', owner_type='faction', owner_id=faction)` —
  столица фракции на родной планете.

**Следствие для агентов:** хоумворлд агента = `factions.homeworld_id` его расы
(через `factions.race_id`). Новую связь/таблицу «мир расы» **не изобретать** —
брать из фракций (правило «что бывает — каталог, что стоит — buildings»,
COORDINATION.md). Открытый вопрос «если у расы несколько миров — какой брать»
снят: берём `factions.homeworld_id`.

## Суть (что делаем)

1. **Перенести расовые корабли в игру:** 129 PNG → `web/static/sprites/` (или отдельный каталог `web/static/sprites/races/`), реестр `ShipSprites` → расовый (по слагам + типы людей).
2. **`npc_agents.race_id`** (новая колонка) — раса агента; при генерации раскидывается **рандомно** по 60 расам.
3. **Хоумворлд агента** = мир, где его раса живёт (кластер расы). Связь: раса агента → кластер/поселения этой расы → мир `homeworld`.
4. **Игрок = человек**: `users.race_id = 'humans'` (бэкфилл/дефолт), корабль по расе (случайный тип из 4).
5. **Выпил 21 легаси:** пул-реестр 21, маппинг legacy-иконок (`LegacyShipIconMap`), дефолт-полумесяц, 21 PNG, `ship_options`. ⚠️ `spriteForAgent` **не удаляется, а меняет вход**: корабль агента — по его расе, не по общему пулу 21 (M1). Старые `ship_icon` игроков — **разовая миграция** на людской корабль.
6. **Рассадка агентов на корабли расы:** агент при создании получает корабль своей расы (детерминированно от `(race_id, id)`); расам без корабля и всем, кому расовый не выдан, — **нейтральный корабль-фолбэк**.
