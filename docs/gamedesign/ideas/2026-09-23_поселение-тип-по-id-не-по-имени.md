## 1. Баг (подтверждён по коду и БД)

Создатель переименовал тип поселения «Обычное поселение» → «Городок» (в БД `producer_types.id=148`, `name_norm='городок'`). `ResolveDefaultSettlementTypeID` искал тип по `name_norm = 'обычное поселение'` → возвращал `0` → **новые поселения создавались с `settlement_type_id = NULL`** (нет норм потребления, нет голода; механика стадий на поле опирается). Существующие 34 403 поселения не затронуты — тип проставлен миграцией `000067`.

Найдено `@critic` при прогоне идеи стадий (крупная находка), подтверждено менеджером по коду.
