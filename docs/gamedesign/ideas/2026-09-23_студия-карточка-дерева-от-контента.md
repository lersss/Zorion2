## 1. Что было

Карточка подтипа в дереве построек (canvas, ветка студии «Производители») рисовала строку «производит: <список>» **одной строкой с обрезкой**: `truncPx(produces, CARD_W - 16, 28)` на `y+68`. Названия товаров пропадали.

Дополнительно `@tester` нашёл **предсуществующий** баг: `centerProdTree()` не вписывал дерево по ширине — формула умножаала `maxCols` (уже в пикселях) на `(CARD_W + GAP_X)`, давая `w ≈ 1.64 млн`; плюс минимальный зум `0.2` не позволял уменьшить до нужного `0.134`. Дерево обрезалось по краям (замер: `minX=-226`, `maxX=1280` при канвасе 1054).

## 2. Что сделано (коммит `8b755d5`, только `web/studio.html`)

1. **Хелпер переноса** `wrapPx(s, maxPx)` рядом с `truncPx`: перенос по фактической ширине (`ctx.measureText`); слово шире строки обрезается `truncPx`.
2. **Высота карточки** `prodCardHeight(n)`: базовая `CARD_H` (86) без строк «производит»; иначе `max(CARD_H, 68 + (lines-1)*12 + 8)` (`LINE_H = 12`). Ширина карточки **остаётся фиксированной** (`CARD_W`) — горизонтальная раскладка дерева построена на фиксированной ширине.
3. **Раскладка** `prodTreeLayout()`: высота ряда по глубине = максимум высоты карточек ряда; `y` узла = `PAD + сумма(высоты предыдущих рядов + ROW_GAP)`; возвращает `h` (id→высота) и `treeH`. Горизонтальная часть не менялась.
4. **Отрисовка** `renderProdTree()`: карточка по её высоте; строки «производит» — по одной на `y+68+i*12`.
5. **Рёбра** `orthoEdge(a, b, aH)` — необязательный третий параметр высоты родителя (по умолчанию `CARD_H`), чтобы не трогать граф «Товары».
6. **Хит-тест** `prodTreeHitTest()` — по высоте узла.
7. **Центрирование** `centerProdTree()` — высота из `L.treeH`; формула ширины исправлена: `w = L.maxCols - GAP_X + PAD`.
8. **Нижняя граница зума** — общая константа `MIN_ZOOM = 0.1` (была жёсткая `0.2`) в трёх местах: колесо, вписывание графа «Товары», `centerProdTree()`; авто-вписывание не уходит ниже доступного вручную.

Граф «Товары» (`computeLayout`, `centerGraph`/`centerTop`) не менялся.
