## 2. Объём шага 1 (согласовано создателем)

В правой панели студии на вкладке «Производители» — переключатель **«Постройки | Товары»**:

1. По умолчанию «Постройки» (текущее поведение — список типов построек); выбор запоминается.
2. Режим «Товары» показывает **ровно тот же справочник каталога**, что на вкладке «Товары» (пилюли тиров, галки «используемые/неиспользуемые», фильтр по категории, поиск, карточки; общий код отрисовки — чтобы списки не разъезжались), вместе с его фильтрами, которые в этом режиме становятся видимыми.
3. Переключение влияет **только на правую панель**: канвас остаётся деревом построек, не перерисовывается.
4. Объём шага — чисто визуальный: серверную часть и БД не трогаем, данные уже приходят в студию.
