## Догон (2026-09-24, вечер): модель помощника студии — `opencode-go` DeepSeek

**Решение создателя:** «переключи на дипсик от Go» — после живой жалобы «жму
"заполнить комплектующие" — результата нет».

**Что показала диагностика (менеджер, живые замеры):**

- товар «Бытовая техника» — 2 пустых слота, помощник запущен и здоров
  (`/global/health` → 1.18.32), кнопка живая: дело не в UI и не в слотах;
- прямой замер того же пути, каким ходит студия (`POST /session` →
  `POST /session/{id}/message`): простой вопрос — **11,5 с** и мусорный ответ
  («ok.ok.ok…» с повторами); реальный промпт состава — **ответа не было 150 с**;
  поздний ответ пришёл через **100+ с** и содержал **11300 символов одного и того
  же фрагмента** `{"ok":true}`;
- прямой запрос к провайдеру Gonka: работает, но ~**5 токенов/с** (шард
  `devshard-…`);
- студия ждёт **45 с на попытку × 3** (решение 2026-09-24) → предложений не
  дождаться ни разу; строка об ошибке живёт в отчёте 8 с — со стороны это и
  выглядит как «результата нет».

**Что сделано:** в личном `.env` (в `.gitignore`, не коммитится)
`OPENCODE_MODEL=opencode-go/deepseek-v4.1-flash`; игровой сервер перезапущен
(модель читается один раз при старте, помощник перезапуска не требует — модель
передаётся в теле запроса).

**Живая проверка после переключения (2026-09-24):** `GET /studio/api/state` →
`model=opencode-go/deepseek-v4.1-flash`, `ai.state=running`; прогон через API
`POST /studio/api/goods/414/fill` → **10 с** → **2 предложения** (kind=new, обе
категории валидны), отчёта об ошибке нет; предложения сняты `fill/cancel`
(состояние студии чистое).

**Личный конфиг opencode** (`~/.config/opencode/opencode.jsonc`, вне репозитория):
модель по умолчанию тоже переключена на `opencode-go/deepseek-v4.1-flash`
(отдельное «да» создателя, 2026-09-24) — одна строка, JSON-структура проверена по
факту, копию с секретами не оставляли. Действует для новых сессий агентов;
помощник студии модель берёт из `.env` сервера, к нему это не относится.
