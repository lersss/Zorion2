# Баг — из межзвёздного полёта нельзя назначить целью пояс

**Создано:** 2026-09-24
**Статус:** ✅ исправлено 2026-09-24 (коммит `xxx`): пояс можно назначить целью
из межзвёздного полёта — пункт «🚀 Лететь» больше не скрывается при активном
межзвёздном (композитный маршрут, спека 99.2.30 §6.2)
**Приоритет:** баг (🟡 — некритичный, фикс быстрый)
**Вектор:** **Игрок** (UI игрока — модалка системы, ПКМ-меню пояса)

---

## Пожелание (создатель, 2026-09-24)

> из межзвездного перелета нельзя назначить полёт на кольцо астероидов

Подтверждено создателем: сценарий — в межзвёздном полёте открыть модалку
системы и назначить целью пояс; пункта «🚀 Лететь» по поясу нет.

---

## Диагноз (проверено по коду)

**Корень:** в ПКМ-меню пояса (`modal/events.js`, `showBeltMenu`) пункт «🚀 Лететь»
скрывается безусловной проверкой `!modalState.interstellarFlight` — то есть при
любом активном межзвёздном полёте. У планеты и компаньона такой проверки нет:
они блокируются только когда игрок стоит в своей системе (`if (myPos) { … }`),
а в чужой системе / в полёте пункт «Лететь» ведёт композитным маршрутом.

**Почему проверка лишняя:** режим полёта в модалке даёт `flightModeForSystem()`
(спека 99.2.30 §6.2): при активном межзвёздном полёте он всегда `composite`
(даже в своей системе), а композитный пункт при межзвёздном **не блокируется**
— это `/travel`-редирект с текущей точки корабля (61a), не 400. Внутрисистемный
старт при межзвёздном дал бы 400, но до него в этом состоянии дело не доходит
(`intra` = false). Итог: пояс — единственный объект, у которого пункт прятался
зря; серверная часть для пояса идентична планетной (валидация destination,
автостарт `autostartIntra`, редирект 61a).

---

## Фикс (мелкая правка, менеджер сам)

`web/static/js/modal/events.js`, `showBeltMenu`: убрать `&& !modalState.interstellarFlight`
из условия видимости пункта «🚀 Лететь»; обновить комментарий (ссылка на §6.2).
Пояс начинает вести себя как планета: своя система → внутрисистемный полёт,
чужая система / межзвёздный полёт → композитный маршрут.

Затронуто: только клиент модалки. Сервер, данные, баланс, API — не тронуты.
