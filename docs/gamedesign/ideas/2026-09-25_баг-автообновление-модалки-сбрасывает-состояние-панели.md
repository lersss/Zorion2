# Баг — автообновление модалки сбрасывает состояние правой панели

**Создано:** 2026-09-25
**Статус:** ✅ исправлено 2026-09-25: автообновление карточки планеты не сбрасывает состояние правой панели (форма «Построить», фракция/тип/население, прокрутка, раскрытые детали, слот магазина, админ-формы) и не выбивает фокус/открытые списки (обновление откладывается до ухода фокуса)
**Приоритет:** баг (🔴 текущий — блокирует тестирование эпика «Постройка структур на планете»)
**Вектор:** **Игрок** (UI игрока — модалка системы, `web/static/js/modal/*`)

---

## Пожелание (создатель, 2026-09-25)

> При автообновлении модалки слетает выбранный раздел в правой части, ничего не
> могу построить.

Уточнение создателя: **«посмотреть что ещё сбивается, кроме этой формы. Ничего
не должно»**.

Решение создателя (2026-09-25): делаем **неразрушающую перерисовку** сейчас;
«живую» реактивную модалку (подписка на изменения + серверные события) —
отдельным эпиком позже, с этим багом не смешиваем.

---

## Диагноз (проверено по коду)

Перерисовка правой панели идёт из `renderRightPanel` → `renderCard`
(`web/static/js/modal/panel.js`), который заново вставляет `panel.innerHTML` и
вызывает `renderTabContent` (`tabs.js`). Всё состояние интерфейса, которое
хранится **не** в `modalState`, а в замыканиях/локальных переменных/DOM,
теряется при каждой перерисовке.

Источники перерисовки: автообновление карточки (отладочный тумблер в админке,
`debugAutoRefreshPlanet`, раз в 3 с → `refreshPlanets`), кнопка «🔄 Обновить»,
асинхронный `/me`, события прилёта.

Что уже сохранено правильно (образец механизма — идея
`2026-09-21_баг-карточка-спутника-сбрасывается-на-планету.md`):
`modalState.activeTab` (вкладка) и `modalState.selectedSatellite` (карточка
спутника). Значит, лечится тем же приёмом — состоянием в `modalState`
(или модульной памяти) + восстановлением после рендера.

## Аудит: что слетает при перерисовке

### Форма «⚙ Построить» (`build.js`, `initBuildPanel`)
Всё состояние — локальный объект `state` в замыкании; контейнер заново отдаётся
как `display:none` (`buildPanelContainerHtml`).
- открыта/закрыта (`container.style.display`);
- `loaded`/`loading` — форма грузится заново, лишний запрос `/build-options`;
- справочник типов `typesById`;
- класс владельца `ownerType`;
- выбранный владелец `ownerId`/`ownerName` + подсветка строки;
- результаты поиска `resultsItems`;
- выбранный тип структуры (`#build-type`);
- поле «Население» (`#build-population`);
- строка статуса/результата (`#build-status`, «Построено: …», ошибки);
- подсветка невалидных полей;
- скролл списков владельца (`#build-owner-faction`, `#build-owner-results`).
- Смежное: у `loadOptions` нет гварда `isConnected` — незавершённая загрузка
  пишет в уже отсоединённый контейнер (ср. гварды в `tabs.js`, `market.js`).

### Правая панель в целом (`panel.js`)
- позиция скролла `#right-panel` — сбрасывается в начало при каждом рендере.

### Вкладка «Строения» (`structures.js`)
- раскрытые инлайновые детали строения (`[data-building-details]`, `display`).

### Вкладка «Фракции» (`tabs.js`)
- раскрытые детали столицы (`[data-faction-details]`, `display`).

### Вкладка «Магазин» (`market.js`)
- выбранный универсальный слот (`selectedSlot`) — сбрасывается на первый;
  вместе с ним теряется пересчёт «Итого» с выкупом.

### Админ-формы во вкладках (`tabs.js`)
- «Залежи»: выбранный ресурс `#deposit-good-select`, поля богатства/запаса,
  статус `#deposit-add-status` (кэш справочника `depositResourcesCache`
  переживает, но не выбор игрока);
- «Ветки»: `recipe_id`; «добавить во вход» — ресурс и количество;
  «задать нагрузку» — тип эффекта и нагрузка;
- «Задания/Контракты»: заголовок, цена, система-назначение, статус публикации.

### Смежный баг (данные, не интерфейс) — `index.js`
`renderModal` захватывает локальный `const planets`, на который замкнуты
`window.updateRightPanel` и слушатель клика по строкам. После `refreshPlanets`
(замена `modalState.planets` на новый массив) эти обработчики продолжают
держать старый массив — клик открывает карточку по устаревшему снимку.

## Предлагаемый фикс (для @developer)

Сделать перерисовку правой панели **неразрушающей**: сохранять состояние
интерфейса и восстанавливать его после каждого рендера. Обновление данных
(население, тренды) при этом продолжает работать как сейчас.

Требования:
1. Всё перечисленное в аудите переживает `renderCard`/`renderTabContent`/
   переключение вкладки и повторное открытие карточки: форма «Построить» целиком,
   скролл панели, раскрытые детали, выбранный слот магазина, поля админ-форм.
2. Форму «Построить» не перезапрашивать без нужды (сохранять загруженные опции).
3. Механизм — по образцу `activeTab`/`selectedSatellite` (память в `modalState`
   или модульная память), чтобы он автоматически покрывал все источники
   перерисовки.
4. Починить устаревшее замыкание `planets` в `index.js` (читать
   `modalState.planets`).
5. Не ломать экспортируемые чистые функции модулей — на них завязаны фронт-тесты
   (`web/frontend_*.go`, исполняются в Node).

### Дополнение (решение создателя 2026-09-25): не трогать форму, пока в ней фокус

Значения при перерисовке сохраняются, но сама перерисовка выбивает фокус/курсор и
закрывает открытый выпадающий список (нативный `<select>`). Решение: пока фокус на
редактируемом элементе внутри правой панели — **автообновление откладывается** и
применяется по уходу фокуса. Ручная «🔄 Обновить» и прочие явные пути — немедленно.
Реализовано: `isEditableControl` (`ui_state.js`), флаг `autoRefreshDeferred`
(`state.js`), `onAutoRefreshTick`/`isPanelBusy`/`onPanelFocusOut` (`panel.js`).

## Проверка

- Клиентский флоу (модалка, клики, формы) — обязателен e2e-смоук
  `tools/e2e/map-check.js` (правило менеджера 2026-09-18, правило тестера).
- Ручной сценарий (автообновление включено, `debugAutoRefreshPlanet=1`):
  1. открыть карточку планеты → включить «⚙ Построить», выбрать тип/владельца/
     население → подождать 6–10 с → форма открыта, выбор на месте, «Построить»
     работает;
  2. прокрутить карточку вниз → подождать 6–10 с → прокрутка на месте;
  3. раскрыть детали строения и детали столицы → подождать → не свернулись;
  4. «Магазин»: выбрать не первый слот → подождать → выбор на месте;
  5. админ-формы «Залежи»/«Ветки»/«Контракты»: заполнить → подождать → значения
     на месте;
  6. вкладка и карточка спутника — не слетают (регресс старого фикса);
  7. **фокус**: поставить курсор в поле «Население» (и открыть список фракций) →
     подождать 8 с → фокус и открытый список на месте, панель не перерисовывалась;
     кликнуть мимо → данные обновились.
