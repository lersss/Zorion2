# Уборка хвостов по пакетам (экономно по токенам)

**Дата:** 2026-09-26
**Статус:** ✅ пакеты «Студия» (`ec99c42`) и «Панель/карточка» (`efbda453`) сданы; ⬜ следующие пакеты ждут
**Пожелание создателя:** закрывать накопленные хвосты кода пакетами, экономно по
контексту: где можно — оптом (один инстанс на зону/файл), где нельзя (крупные
распилы, разные зоны) — отдельным свежим инстансом разработчика, чтобы он не тянул
неиспользуемый контекст.

## Принципы батчинга (согласовано с создателем)

- **Один инстанс = одна зона/файл.** Правки в одном месте — один разработчик,
  контекст переиспользуется.
- **Разные зоны — разные свежие инстансы.**
- **Крупные монолиты — всегда отдельный инстанс** (по одному), заранее дробим на
  подэтапы.
- **Пакет мелких = один разработчик → один прогон тестера → один гейт** («быстрый путь»).
- В ТЗ — только файлы и номера хвостов этого пакета, реестр не пересказывать.

## Пакет «Студия» (сдан `ec99c42`)

**Хвост №11.** При перетаскивании попапа он «прыгает» и улетает за экран: drag брал
`offsetLeft/offsetTop` (позиция до `transform`), а не визуальные координаты.
**Исправлено:** общий приём `startPopupDrag`/`movePopupDrag` — позиция из
`getBoundingClientRect()`, при старте ничего не скачет; движение клампится в область
канваса; устойчиво и к «попап шире области».

**Хвост №12.** Попап детали центрировался по всей `#main` (панель 320 px справа).
**Исправлено:** центр и ширина попапов считаются от одной переменной `--panel:320px`
(при свёрнутой панели `--panel:0px`); применено к `#detailPopup`, `#catPopup`,
`#effPopup`. Приёмы «ширина из `#main`, центр по канвасу» больше не расходятся.

**Добито решением создателя (2026-09-26):** тем же приёмом переведены
`#proposalsPopup`, `#descPopup`, `#importPopup` (у них drag нет — только
центрирование и ширина). Тестер независимо 6/6 (окна 1280×800, 1024×700;
16 замеров; 0 JS-ошибок).

**Проверка:** разработчик живьём 26/26 (+14/14 по трём попапам); тестер независимо
7/7 и 6/6 (панель открыта/свёрнута; drag без прыжка, дельта, кламп к краю; 0 JS-ошибок).
Отчёты: `docs/QA/checklists/2026-09-26_студия-попапы-хвосты-11-12.md`,
`...-повторный-прогон.md`, `...-студия-три-попапа-центрирование-канвас.md`.

**Сдано:** коммит кода `ec99c42` (`web/studio.html`, `web/static/js/studio/init.js`).
