## Сырое пожелание

Создать NPC-агентов в первом приближении.

## ТЗ (по словам создателя)

### Что делает NPC-агент

1. **Перемещается по галактике** — летает между звёздами/планетами.
2. **«Смотрит» на планеты** — прибыл → обновляет данные о населении поселения.
3. **Сообщает о прибытии** — пуш-уведомление админам + skycomposer (выключается в админке).

### Поведение (первое приближение)

- Простое: долетел до планеты → посмотрел → сообщил.
- Без сложного ИИ, торговли, добычи — только наблюдение.

### Видимость

- **На карте** — виден игроку (иконка, метка).

### Управление

- **Админка** — вкладка «NPC», настройка агентов (создание, удаление, включение/выключение уведомлений).

## Решения создателя (2026-09-14)

| Параметр | Решение |
|----------|---------|
| Скорость | Настраивается в админке; дефолт = скорость игрока (`npcSpeedFactor = 0.3`) |
| Маршрут | Рандом в радиусе 1000 от текущей позиции, иначе ближайший |
| Триггер | Автоматически (агент автономен после создания) |
| Формула длительности | `duration = dist × 0.3`, мин 3с, без потолка 20с (вариант A) |
| Уведомления | WebSocket batch `npc_arrivals_batch` (дроссель 1/5с, ≤100, избыток в total) |
| Кому | Всем подключённым (标记 на доработку: по роли после 99.2.14) |
| Видимость на карте | Когда видны имена звёзд (порог nameDisplayThreshold) |
| Лог наблюдений | Только `last_observed_at` |
| Масштаб | Архитектура рассчитана на сотни тысяч агентов (batch, сетка, snapshot, дроссель) |
