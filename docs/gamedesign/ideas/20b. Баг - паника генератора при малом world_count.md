# 20b. Баг - паника генератора при малом world_count

**Дата:** 2026-09-15
**Приоритет:** 🟡 (некритичный — бэклог)
**Статус:** Новый

---

## Сырое пожелание / описание

Генератор галактики падает с паникой при малом `world_count`.

## Суть бага

`internal/generator/galaxy/poisson.go:129` — `g.rng.Intn(perCluster/2)`:
при `world_count=3` (дефолт `cluster_count=20`) → `clusterPoints=2`, `perCluster=1`
→ `Intn(0)` → panic.

Воспроизводится стабильно: `POST /admin/generate {"world_count":3}` →
`generate-status` = `{"error":"panic: invalid argument to Intn","status":"error"}`.

С `world_count=1000` или `cluster_count=1` — работает.

## Контекст

Найден тестировщиком при прогоне фичи NPC-агентов (2026-09-15). Не зона NPC
(генератор), блокирует создание малых вселенных в админке.

## Критерий готовности

`POST /admin/generate` с малым `world_count` (2–5) и дефолтным `cluster_count`
не падает; регрессионный тест на малые `perCluster` (Intn с нулевым/отрицательным
аргументом не вызывается).
