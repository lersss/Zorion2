## Сырое пожелание (создатель, 2026-09-15)

> «доделай изменение населения: естественная рождаемость»

## Решения создателя (2026-09-15, финальные)

1. **Темп:** медленный рост — планеты в нормальных условиях растут (предпосылка).
2. **Форма:** «просто делай формулу смертности со знаком минус *2».
   Итог (после обсуждения): **две ручки в админке** —
   - **СПЖ** (средняя продолжительность жизни, дефолт 50 лет);
   - **коэффициент рождаемости `k`** (дефолт 2).
   Формула:
   ```
   R_ест  = 1/СПЖ                      (смертность, база; рампа [15,30] °C как есть)
   R_рожд = −k × R_ест                 (рождаемость = k × смертность, знак минус)
   нетто  = (1 − k)/СПЖ
   ```
   k=1 → равновесие (нетто 0); k=2 → медленный рост (нетто −1/СПЖ = −2%/год при
   СПЖ 50); k=0 → чистая убыль. «×2» = дефолт k.
3. **Расы (будущее):** у новых рас может быть своя СПЖ/коэффициент. Сейчас —
   **две глобальные ручки** (проще), но СПЖ/`k` держим **переменными, не
   константами** — чтобы потом без миграции пересадить в профиль устойчивости
   (`ToleranceProfile`, 18a). Решение создателя 2026-09-15.
4. **Потолок 120 лет — УБРАН СОВСЕМ** (решение создателя 2026-09-15: «Не, убрать
   совсем. Ненужная штука»). Потолок был «выключателем»: обнулял население при
   `age ≥ 120 лет` независимо от знака r — ломал рост. С рождаемостью его смысл
   («исходные поселенцы умрут, новых нет») исчез. Третьей ручки НЕ будет — ручки
   две (СПЖ, k). Остаётся только технический guard переполнения `time.Duration`
   (~292 года) в дате «Вымерло» — без балансного смысла. Равновесие (k=1) и рост
   (k>1) живут вечно; медленная убыль без среды (k=0, pop 10⁹, ~800 лет) — запись
   «Вымерло» не создаётся (дата за лимитом времени).
5. **Будущие механики** (война, эпидемия, переток, сквоттинг) — **отдельными
   членами R-гирлянды** (`ChangeComponents`), в рождаемость НЕ встраиваются
   (решение создателя 2026-09-15).
6. **Диапазоны ручек:** СПЖ 1..500 лет, k 0..10 — приняты («1 — идет», 2026-09-15).

## Факты из кода (менеджер, проверено)

- `NaturalChangeRate = 1/LifeExpectancySeconds`, СПЖ = 50 лет (константа,
  `internal/economy/settlement/change_components.go:21-33`).
- `NaturalComponent(tempK)`: рампа [15, 30) °C → `NaturalChangeRate·(T−15)/15`;
  ≥ 30 °C → полная; < 15 °C → 0 (`change_components.go:84-94`).
- `ChangeComponents` — единственная точка сборки суммы R; рост = отрицательная
  компонента (`r < 0` → `(1−r) > 1`, уже поддерживается `Population`).
- Возрастной потолок: `Recompute` возвращает 0 при `age ≥ MaxLifespanSeconds`
  (120 лет) — **независимо от знака r** (`recompute.go:37-39`) — надо править
  под решение 4.
- `DeathTime` при `r ≤ 0` → `ok=false` (не вымирают), кроме age ≥ 120 → ceiling
  (`death.go:35-40`) — согласовать с потолком.
- `NDead` и `MinPersistInterval` — уже `var` в памяти; прецедент настроек из
  админки — NPC (`internal/npc/settings.go`, GET/PATCH `/admin/npc/settings`,
  in-memory, сброс на дефолт при рестарте).
- Админка: вкладка «Основное» (`tab-main`) сейчас — только краткая статистика
  (`web/admin.html:29-38`); вкладки переключает `tabs.js`; роуты — `cmd/server/main.go`.
- Предпросмотр `GET /admin/mortality-preview` уже умеет `r < 0` (t_death = +Inf →
  скрыт; `admin_mortality.go:59-64`), projection — по той же формуле.
- Эталон «+30 °C → вымирание ~1000 лет» (18a FAQ) — был без рождаемости; с
  рождаемостью в комфорте (30 °C) станет нетто-ростом — **эталон пересмотреть**.

## Числа (референс от @scientist, 2026-09-15)

- Земля: рождаемость ≈ 17‰, смертность ≈ 8‰ → отношение ≈ **2.1–2.2 : 1**
  (растущий мир, +0.9%/год). Дефолт `k=2` = почти точное земное среднее.
- В модели при СПЖ 50, k=2: в комфорте (30 °C, без др. угроз):
  `R_total = R_ест − 2·R_ест = −2%/год` → **нетто-рост +2%/год, удвоение ~35 лет**
  (режим «растущей колонии»).
- В нуле рождаемости (ниже 15 °C, рампа не работает) → только убыль.

## Критерии готовности (черновик)

- `R_total = R_ест − k·R_ест + R_жара + R_холод + R_гравитация + R_радиация` —
  рост в комфорте (k > 1), убыль вне; k настраивается.
- В админке («Основное») — крутилки СПЖ и коэффициента рождаемости; сохранение
  меняет расчёт населения; дефолты 50 лет и 2.
- Потолка 120 лет нет нигде (модель, тесты, доки); равновесие/рост живут вечно.
- Тесты зелёные: `go build` + `go vet` + `go test ./...` (DoD, AGENTS §2).
