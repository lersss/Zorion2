# 29a. Корабли для агентов — AI-генерация (ComfyUI)

**Дата:** 2026-09-15
**Пожелание:** Корабли для NPC-агентов (вид сверху), разнообразные и стильные, похожие на референсы, а не монотонные кирпичи.
**Приоритет:** средний
**Статус:** 🔄 дизайн/ассеты — в работе (выбор модели для генерации)

---

## Проблема

- Текущие 21 SVG — один силуэт, просто разные цвета («кирпичи»).
- Параметрический генератор (спека 99.2.15) — «отстойно работает».
- SVG-вектор не может дать текстуру/детализацию референсов — нужен растр (PNG).

## Решение (выбрано создателем)

**AI-генерация + ретушь** (вариант 2): Stable Diffusion через ComfyUI.

## Ход работы (2026-09-15)

1. **Установлен ComfyUI** на `C:\ComfyUI` (вне репо):
   - Python 3.10.6 (отдельный, без изменения PATH) в `C:\Users\admin\AppData\Local\Programs\Python\Python310`
   - torch 2.5.1+cu121, torchvision 0.20.1, torchaudio 2.5.1
   - Модель SD 1.5 `v1-5-pruned-emaonly.safetensors` (4.27 GB)
   - API на `http://127.0.0.1:8188`
   - Починен comfy-kitchen (замена `list[int]` → `List[int]` в 13 файлах — баг совместимости с torch < 2.6)
2. **Скрипты в `tools/`** (коммитятся):
   - `comfy_api.ps1` — генерация: `Send-ComfyPrompt` (workflow txt2img), `Send-ComfyShipPrompt` (4 стиля: organic/military/sleek/industrial)
   - `process_ship.py` — пост-обработка: rembg (прозрачный фон) + кадрирование + вписывание в 200×200 + нормализация ориентации (нос вправо)
   - `diagnose.py` — диагностика пикселей (фон/bbox)
3. **Пробные генерации на SD 1.5** — отклонены создателем:
   - фон не чёрный (промпт «black background» игнорируется), «пёстрый»
   - ориентация «куда попало»
   - силуэты не корабельные («шляпа») — SD 1.5 слаба для sci-fi-техники
4. **Решение:** ставим **Juggernaut XL v9** (доработанная SDXL, сильна в технике) — скачивается в `C:\ComfyUI\models\checkpoints\juggernaut-xl-v9.safetensors` (~6.8 GB).
