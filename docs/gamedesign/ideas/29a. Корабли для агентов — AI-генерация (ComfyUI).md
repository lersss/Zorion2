## Уроки генерации (2026-09-15, записаны для будущего)

1. **txt2img не даёт контроль формы** — SDXL при жёстких промптах («no perspective») срывается в сюрреализм («картины Дали»). Нужен ControlNet.
2. **ControlNet Canny + img2img (цветной модульный силуэт) — рабочий путь**: img2img с denoise 0.85 + ControlNet strength 1.5 держит форму; цветной силуэт (каждый модуль — свой цвет) даёт цвета по модулям.
3. **Двухэтапный процесс:** (1) форма — img2img+ControlNet denoise 0.85; (2) детализация — img2img без ControlNet denoise 0.45–0.55 (добавляет текстуру, сохраняя форму). 928→1283 уник. цветов — текстура появилась.
4. **Оранжевые/яркие акценты размазываются по корпусу** («дюзы из живота») — в этапе 2 запрещать: «no orange, no flames»; дюзы/свечение задавать только в этапе 1 на корме.
5. **Синий нос читается как «попа с дюзами»** (выхлоп) — нос = светлая кабина-стекло (GLASS), дюзы только на корме.
6. **Мелкие модули (крылья/хвост) сглаживаются в основной цвет** — делать их контрастнее в силуэте.
7. **Силуэт не должен касаться краёв холста** — масштабировать до ~82% + центрировать (запас ~90 px со всех сторон), иначе нос обрезается.
8. **Прозрачный фон** — обработка по цвету фона (не rembg): фон SDXL ровный тёмный ~21,23,26, вырезаем по близости к нему + крупнейший связный компонент (мусор).
9. Результат пока «простенький, но корабль» — дизайн можно усложнять (модули/силуэты/детализация).
10. **Концепты («корабль в образе слова») дают дикое разнообразие** — дом/цветок/дракон/призрак/сигарета/лампочка/кот/череп/стрекоза/черепаха. Рабочий процесс: пачка из 10 → создатель отбирает номерами.
11. **«NO flames» в промпте не спасает от оранжевого** — надёжно лечится пост-обработкой: оранжевые пиксели (r>180, 80<g<190, b<120) → золото/нейтральный цвет.
