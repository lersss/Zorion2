# 29a. Корабли для агентов — AI-генерация (ComfyUI + ControlNet)

**Дата:** 2026-09-15
**Пожелание:** Корабли для NPC-агентов (вид сверху), разнообразные и стильные, похожие на референсы, а не монотонные кирпичи.
**Приоритет:** средний
**Статус:** 🔄 ассеты — ControlNet-подход (скачивается модель, силуэты готовы)

---

## Проблема

- Текущие 21 SVG — один силуэт, просто разные цвета («кирпичи»).
- Параметрический генератор (спека 99.2.15) — «отстойно работает».
- SVG-вектор не может дать текстуру/детализацию референсов — нужен растр (PNG).

## Решение (выбрано создателем)

**AI-генерация + ретушь**: Stable Diffusion через ComfyUI.

## Ход работы (2026-09-15)

1. **Установлен ComfyUI** на `C:\ComfyUI` (вне репо):
   - Python 3.10.6 (отдельный) в `C:\Users\admin\AppData\Local\Programs\Python\Python310`
   - torch 2.5.1+cu121, torchvision 0.20.1, torchaudio 2.5.1
   - Модель **Juggernaut XL v9** (доработанная SDXL, сильна в технике) — `juggernaut-xl-v9.safetensors`
   - Починен comfy-kitchen (`list[int]` → `List[int]`, баг совместимости)
   - API на `http://127.0.0.1:8188`
2. **Скрипты в `tools/`** (коммитятся):
   - `comfy_api.ps1` — генерация: `Send-ComfyPrompt` (txt2img), `Send-ComfyControlNet` (по силуэту), `Send-ComfyShipPrompt` (4 стиля)
   - `process_ship.py` — пост-обработка: вырез фона по цвету + крупнейший связный компонент (мусор убирается) + кадрирование + 200×200 + ориентация
   - `diagnose.py` — диагностика пикселей
   - `make_silhouettes.py` — генерация 4 силуэтов кораблей для ControlNet
3. **Пробные генерации txt2img — отклонены:**
   - SD 1.5: «шляпы», пёстрый фон, ориентация «куда попало»
   - Juggernaut XL: сюрреализм («картины Дали») при жёстких промптах («no perspective»)
   - Вывод: txt2img не даёт контроль формы. **Нужен ControlNet.**
4. **Текущий подход: ControlNet Canny.**
   - 4 силуэта готовы: `C:\Zorion2\ai_drafts\silhouettes\` — arrow (стрела), cruiser (крейсер), hawk (ястреб), freighter (грузовик). Белый на чёрном, 1024×1024, нос вправо.
   - Модель `controlnet-canny-sdxl-1.0.safetensors` (~2.5 GB) скачивается в `C:\ComfyUI\models\controlnet\`.
   - SDXL раскрасит силуэты строго по контуру → гарантированный top-down корабль.
