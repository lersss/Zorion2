# 30c. Фон «звёздное небо» на близких зумах (ощущение движения в полёте)

**Создано:** 2026-09-15
**Статус:** Выполнено (2026-09-15, менеджер — мелочь, одобрено создателем).
Ожидает одобрения + коммит по «го».
**Приоритет:** идея (атмосфера/космосим)

---

## Суть (создатель, 2026-09-15)

Сейчас при близких зумах отсутствует фон. Особенно при перелётах нет
ощущения движения — «как будто летим в пустоте», звёзд на фоне не видно.
Теряется ощущение космосим-объёма («бесплатный объём»).

Гипотеза: **на каком-то зуме показывать фон «звёздное небо»**.

Требования создателя: не конкурировать с нашими звёздами, ненавязчиво,
очень дёшево для браузера.

## Решения создателя (2026-09-15)

1. Только на близких зумах (на дальних и так ~100k звёзд).
2. Параллакс — пробуем.
3. Плотность — средне.
4. Итог по скорости: ближний слой параллакс 0.06 (в 2 раза быстрее исходного 0.03), дальний слой в 10 раз медленнее (0.006), еле заметно.

## Реализация (менеджер, 2026-09-15)

Дизайн — `@designer`, спека `docs/specs/_archive/30c.1-starfield-background.md` (В1).
Реализация прототипа — `@developer` (`web/static/js/map/starfield.js`),
проверка — `@tester` (пройдено). Дальше — итерации чисел по ощущениям
создателя (менеджер, мелочь).

### Итоговый `starfield.js`

- **Два слоя параллакса.** Ближний: точки alpha 0.15–0.35, параллакс 0.06.
  Дальний: совсем тусклые точки alpha 0.05–0.12, параллакс в 10 раз
  медленнее (0.006). Дальний рисуется первым (под ближним).
- **Тайл 256×256, 60 точек, `mulberry32(42)`** — генерируется один раз
  (`initStarfield`), никакого per-frame random. Два тайла (ближний/дальний).
  Цвет `#c8d6e5` (холодный бело-голубой), точки 1–2 px, без свечения.
- **Порог:** scale ≥ 1.0, плавная альфа 0→1 на 1.0→1.5.
- **Поведение при зуме (ключевая доработка):** фон привязан НЕ к
  `offsetX*PARALLAX` напрямую, а к накопленному смещению, которое растёт
  ТОЛЬКО при панорамировании (scale между кадрами не менялся). При изменении
  scale фон стоит на месте — дальние звёзды не «едут» от зума (первый вариант
  давал эффект «при зуме двигаешь дальние звёзды», неестественно).
- Отрисовка: один `fillRect` на слой с `createPattern` — дёшево
  (2 fillRect за кадр, < 0.1 мс).
- Мерцание: один `sin(timeMs*0.001)` на кадр, среднее по слою, едва заметно
  (создатель подтвердил: мерцание не мешает).

### Правки файлов

- `web/static/js/map/starfield.js` — новый модуль (~110 строк).
- `web/static/js/map/map_render.js` — импорт, `initStarfield()` в
  `resizeCanvas()`, вызов `drawStarfield()` в `draw()` после `clearRect` до
  `drawGrid`.
- `docs/ARCHITECTURE.md` §2 — строка в дереве `web/static/js/map/`.
- Статика с диска (`noCache`), рестарт не нужен.
