## Факты, собранные из кода (менеджер)

- env (`internal/config/config.go`): `DATABASE_URL` и `REDIS_URL` и `JWT_SECRET`
  (≥32 байта) — обязательны (log.Fatal); `SERVER_PORT` (дефолт 8080),
  `TICK_INTERVAL_SEC` (дефолт 3), `SKYCOMPOSER_BOOTSTRAP_USERNAME/PASSWORD` —
  необязательны; `.env` необязателен (godotenv, env приоритетнее).
- Миграции: `migrations.Apply(db)` на старте (`cmd/server/main.go:73` +
  `migrations/migrations.go`): вшиты в бинарник через embed, применяются
  неприменённые по `schema_migrations`, `.down.sql` не применяются, для
  вручную накатанной БД — baseline.
- Bootstrap skycomposer — после миграций, до HTTP (пока в БД 0 skycomposer'ов).
- `config/ship_visual.json` — обязателен (log.Fatalf без него) — визуал кораблей.
- Прод: Amvera (`amvera.yml`: Dockerfile, containerPort 8080, persistenceMount
  /tmp; БД внешняя), сборка из git → **деплой = git push**.
- Пост-деплой вручную: 🌌 Генерация (вселенная), 🚀 Корабли (`＋10` × 5 категорий,
  каталог в памяти перезагружается сам — рестарт не нужен), 👁️ NPC по надобности,
  `VACUUM (ANALYZE)` при деградации фильтров — руками, миграцией нельзя (STATUS §3).
- Прод-юзер `amvera_test` уже зарегистрирован.
