# 32a. Формат @writer/@scientist — не только «дневник выжившего»

**Дата:** 2026-09-15
**Приоритет:** низкий (правка промтов, не игровая фича)
**Статус:** готова к разносу дельт (@dispatcher)

## Пожелание создателя

«Нам надо в случае с учёным и писателем не зацикливаться на дневнике выжившего:
этот формат — только про выживание, узкий спектр фич покрывает».

## Решение (согласовано с создателем 2026-09-15)

1. Формат @writer/@scientist **подбирается под гипотезу**, а не по умолчанию
   «выживание». «Дневник последнего выжившего» — частный случай для фич про
   убыль/выживание.
2. **Проектирование гипотезы** (новый подраздел в `manager_details.md`, вариант В):
   - гипотеза рождается **против заложенных цифр дизайнера** (контр-проверка,
     не творчество);
   - менеджер решает, какую цифру фича должна подтвердить/опровергнуть
     (смертность, поток, масштаб, темп), и подбирает сценарий + формат под неё:
     убыль → среда «сколько людей переживает»; рынок → торговый дом «что
     проходит через кассу»; война → «как долго держится сторона»; заводы →
     «сколько производится за смену»;
   - гипотеза обязана давать **число или диапазон** — нет цифры, значит плохая;
   - **до прогона** менеджер сверяет сценарий с дизайнером («попадаю в твою
     фичу?») — независимость менеджера сохраняется, дизайнер проверяет, что
     мерить не притянуто за уши.
