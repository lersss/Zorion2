## Суть

Наблюдение создателя: «у чёрных дыр нет температуры, цвета, радиуса, возраста?
Мне кажется, это плохо». Подтверждено на мире **Iffaegan** (ЧД, 18.8 M☉,
без аккреции): карточка звезды показывает **прочерки** по температуре, цвету,
радиусу, светимости, возрасту — заполнена только масса (19 M☉). Причина:
`web/static/js/modal/panel.js` для `star_type ≠ star` сознательно ставит «—»
по всей спектральной инфо (чтобы не врать «как Солнце»), но перебор: спека
99.2.4 §8 даже обещала «тёмная» вместо «0 K» — до кода не дошло.

Создатель: «я не спрашиваю как сейчас, я хочу понять как правильно» →
подключён @scientist (физика, см. ниже).

## Физика (вердикт @scientist, 2026-09-15)

- **Температура:** у самой ЧД нет фотосферы — «нет фотосферы / не излучает»,
  а не «0 K» (температура Хокинга ~миллиардные доли K — не для игрока).
  С аккреционным диском — показывать температуру **диска** (миллионы K у
  внутреннего края, тысячи у внешнего).
- **Цвет:** сама дыра — чёрная тень; видимое — диск: голубовато-белый (внутр.
  край) → красный (внешний). Без диска объект почти невидим.
- **Радиус:** горизонт событий ≈ **3 км на массу Солнца**; для 5–20 M☉ —
  15–60 км. Показывать как «радиус горизонта», не «поверхности».
- **Светимость:** собственная — нет («не излучает»); диск — 0.001–1000 L☉
  (типично), до 10⁸–10⁹ у экстремально активных.
- **Возраст:** время с коллапса предшественника (~20–60 M☉, жившего 5–15 млн
  лет). Потолок — возраст Вселенной **~13.8 млрд лет**; галактический
  реалистичный максимум ~13 млрд. **10 млрд в игре — не физический максимум,
  а потолок генератора.**
- **Возраст и планеты (вердикт):** наличие планет и диска определяется историей
  (взрыв, вещество), а **не возрастом**. Диск — временное явление (тысячи–
  миллионы лет), к возрасту в млрд лет почти не привязан. Возраст меняет лишь
  «зрелость» поверхностей (остывание, кратеры) на шкале сотен млн–млрд лет.
  → **возраст на генерацию планет почти не влияет**: нужен как витринное
  значение + консистентность `system_age` планет.

## Решения создателя (2026-09-15)

1. Наполнять карточку честной физикой — **да**.
2. Возраст: раз на генерацию планет не влияет — храним для витрины +
   наследования; диапазон генератора **2–13 млрд лет** (галактический максимум,
   «поехали» вместо 2–10).
3. Скоуп: **все экзотики** (ЧД, ЧД+аккреция, нейтронная, WD, протозвезда),
   а не только чёрные дыры.

## ТЗ (для @designer, детали — в спеке)

1. **Карточка звезды** (`web/static/js/modal/panel.js`): для всех экзотик —
   честные значения вместо «—»:
   - Температура: ЧД — «тёмная / не излучает»; ЧД+аккреция — диск
     (см. п.4); нейтронная/WD/протозвезда — уже показываются, проверить.
   - Цвет: по палитре карты (ЧД «чёрный», диск «голубовато-белый»,
     нейтронная «голубой», WD «белый/серебристый», протозвезда
     «красно-оранжевый»).
   - Радиус: ЧД — горизонт ≈2.95 км × M/M☉ (из `stellar_mass`); нейтронная
     ~10–15 км; WD ≈0.01 R☉; протозвезда — порядка R☉ (сжимается).
   - Светимость: ЧД — «нет (не излучает)»; диск 10²–10³ L☉ (спека §5.1);
     нейтронная 0.01–1; WD 10⁻²–10⁻⁴; протозвезда 1–10².
   - Возраст: из новой колонки `worlds.age`.
2. **Миграция** `worlds.age` (млрд лет, nullable): заполнение при генерации
   экзотики, диапазон 2–13.
3. **Консистентность:** планеты экзотики наследуют возраст мира в `system_age`
   (сейчас роллят независимо `determineSystemAge("")`).
4. **Баг микроквазара:** ЧД с `subtype accretion` сейчас получает
   `worlds.temperature = 0` — спека §5.1 требует температуру диска. Решить:
   хранить T диска в `worlds.temperature` или ветка UI по `stellar_mods`.

## Критерий готовности

Карточка Iffaegan и любой другой экзотики показывает честные значения по всем
полям (температура/цвет/радиус/светимость/возраст), без прочерков там, где
данные есть. Возраст мира хранится и наследуется планетами. DoD:
`go build`, `go vet`, `go test ./...` + `node --check` по изменённым JS.
Прогон @balancetester (числа физики) — после дизайна.
