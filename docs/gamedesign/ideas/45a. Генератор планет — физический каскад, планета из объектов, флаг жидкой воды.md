> Которые будут содержать свои объекты, которые в сумме будут давать 100%

## Трактовка (менеджер, подтверждается на гейте дизайна)

Крупная переработка генератора планет вокруг **трёх физических входов**:
свойства звезды, ядро, расстояние до звезды. Цель — генератор, где физика
**вычисляется** (энергобаланс), а не подгоняется под игровой результат.

Границы и развилки (см. раздел «Решения создателя» — часть уже дана в
диалоге 2026-09-16):

1. **Каскад:** физика первым слоем, косметика вторым, и косметика не может
   противоречить физике. Слои:
   1. Звезда → L, T_eff, масса, возраст, металличность?
   2. Орбита → r, период, эксцентриситет?
   3. Планета → масса, состав → ρ, R, g
   4. Ядро → тип, размер, активность → внутреннее тепло
   5. Температура → T⁴-энергобаланс от потоков → T_поверхности
   6. Атмосфера → состав, давление P → парник → уточнённая T
   7. **Флаг** → «возможна жидкая вода» (фазовая диаграмма при T, P)
   8. Поверхность → генерируется С УЧЁТОМ флага (флаг false → нет
      океанов/озёр/болот/кораллов)
   9. Недра / вода% / жизнь / классификация

2. **Планета = составной объект** из четырёх частей: `атмосфера`,
   `поверхность`, `недра`, `ядро`. Поверхность/недра уже композиции с
   процентами (16/17 форм, сумма 100%). **Атмосфера перестаёт быть
   текстовым полем** («тип») и становится объектом: состав газов в процентах
   (N₂, O₂, CO₂, H₂, He, CH₄, H₂O…), сумма = 100%. Из состава + массы +
   гравитации → **давление у поверхности** и **размер/толщина атмосферы**;
   из состава и давления → честный парник (оптическая толщина), вместо
   множителя 1.0–2.5. Тип атмосферы («азотно-кислородная», «парниковая»…) —
   производный ярлык, не хранимое поле.
   Это возврат к редизайну «планеты в объекты», о котором создатель говорил
   2026-09-13 (см. `18a_population_death.md` §«Область»).

3. **Флаг жидкой воды — бинарный** `liquid_water_possible: true/false`.
   Заготовка для будущего генератора поверхностей. Производные (T, P, точка
   замерзания, точка кипения, вода%) лежат в данных рядом — градация
   («местами/стабильно/обильно») вычисляется потом из них, флаг не меняется.

## Научный аудит (@scientist, 2026-09-16) — основа дизайна

Учёный разобрал текущую модель и целевую. Ключевые поломки физики (чинить):
- **Светимости O/B** занижены на 1–3 порядка (O=1000 L☉ vs реальные 10⁴–10⁶) —
  вход в T, иначе планеты у горячих звёзд не выжжены.
- **Вклад ядра до 372 K** — завышение ~3 порядка (реально ≪0.1 K для зрелых
  каменных). Значим только у молодых (<0.5–1 млрд лет), приливных спутников,
  молодых/массивных гигантов. Для зрелых — обнулять.
- **Парник как множитель 1.0–2.5 + сложение кельвинов** — не работает
  (Венера: голая 232 K → 737 K, ΔT=+500 K). Физика: энергобаланс
  T⁴ = (F★(1−A)+F_int+F_tidal)/(4σ) · (1+¾τ_IR), парник через оптическую
  толщину τ_IR.
- **Плотность «от формы поверхности»** — подмена объёмного свойства;
  плотность от состава + гравитационного сжатия.
- **Обитаемость «200–400 K»** — без давления даёт ложных кандидатов (Марс:
  T в диапазоне, но вода не живёт при 0.006 атм; Венера: 500 K при 92 атм —
  вода жидкая выше 100 °C). Правильно — **фазовая проверка воды при (T, P)**.
- **Планет у O/B почти нет** (фотоиспарение, короткая жизнь).

Недостающие параметры (критичные, см. полный список в диалоге менеджера с
@designer/@scientist 2026-09-16):
- звезда: металличность [Fe/H], снеговая линия (r_ice ≈ 2.7·√L а.е.),
  поток звёздного ветра/XUV;
- орбита: период, эксцентриситет, приливный захват (критичен у M-звёзд);
- планета: объёмный состав, escape-скорость, гравитационное сжатие;
- ядро: потоки Вт/м² (радиогенный, аккреционный, приливный) + масса
  радионуклидов U/Th/K вместо «очков 0–100»;
- атмосфера: состав (парциальные давления), давление в атм, оптическая
  толщина в ИК;
- вода/жизнь: давление для жидкой воды, радиационный фон.

## Решения создателя (2026-09-16, из диалога)

1. **Температура — на новой** T⁴-модели (энергобаланс), не на старой.
2. **Атмосфера — объектом** (состав в %, давление, размер), а не текстовым
   полем. Планета = объекты «атмосфера/поверхность/недра/ядро».
3. **Флаг воды — бинарный** (`liquid_water_possible: true/false`).
4. Развилки «ядро обнуляем для зрелых планет?» и «обитаемость через
   давление?» — перешли в дизайн (создатель задал направление «заготовка +
   каскад»; детали на гейте дизайна).
