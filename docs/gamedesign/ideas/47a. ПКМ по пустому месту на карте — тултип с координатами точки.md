# 47a. ПКМ по пустому месту на карте — тултип с координатами точки

**Создано:** 2026-09-16
**Статус:** Реализовано, тестер ПРОЙДЕНО. Ожидает «го» создателя + коммит.
**Приоритет:** мелочь/UX

---

## Суть (создатель, 2026-09-16)

Правый клик на карте на пустом месте (не на звезде) → тултип с
координатами точки. Уточнение создателя: **без дробной части** (целые).

## Текущее поведение

`web/static/js/map/events.js`, `initContextMenu()`: ПКМ по канвасу — только по
одиночной звезде открывает контекстное меню мира («Перелететь»). На пустом
месте (и на кластере) — `hideWorldMenu()`, ничего не происходит, открывается
браузерное меню.

## Реализация (менеджер, 2026-09-16)

Мелкая фронтенд-фича (нет сущностей/миграций/баланса/API) — быстрый путь:
`@developer` → `@tester` → один гейт создателю.

**Сделано @developer** (правки только в `web/static/js/map/events.js`, +51 строка):

- `#coords-tooltip` — ленивый div по образцу `#npc-tooltip` (fixed,
  pointer-events: none, z-index 1100, тёмная палитра, у правого края — влево).
- Ветка «не одиночная звезда» в `initContextMenu()` (пустое место ИЛИ кластер):
  `e.preventDefault()` (браузерное меню подавлено) + тултип
  `Координаты: (x; y)` с целыми (`Math.round`) мировыми координатами точки.
- Скрытие: mousemove/mouseleave канваса, левый mousedown документа, ПКМ по звезде.
- Логика звезды/меню мира/hover не тронута.

**Доработка по создателю (2026-09-16): убран драг на правую кнопку.**
В `initPanZoom()` (events.js) mousedown стартовал драг на любой кнопке —
ПКМ дублировал драг левой (и вдобавок триггерил `scheduleReload` на mouseup).
Теперь драг только на левой (`e.button === 0`); ПКМ отдан тултипу координат
и меню мира.

**Доработки по создателю (2026-09-16): показ на нажатии + мин. время жизни 3 с.**

- Тултип показывается **на нажатии** ПКМ (canvas `mousedown`, button 2), а не
  на отпускании (`contextmenu`) — как «клик», а не «release». `contextmenu`
  только гасит браузерное меню (preventDefault всегда) и по звезде открывает
  меню мира.
- **Минимальное время жизни 3 с**: движение/увод мыши не прячет тултип
  раньше 3 с — `hideCoordsTooltipGuarded()` ставит один таймер на остаток
  (guard на `coordsHideTimer` — таймеры не плодятся). Повторная ПКМ в течение
  3 с сбрасывает таймер и перезапускает отсчёт.
- Жёсткое скрытие (сразу): ЛКМ (document mousedown button 0), ПКМ по звезде
  и ПКМ по тултипу звезды (меню мира).
- Минор тестера P3 закрыт: в обработчике ПКМ по тултипу звезды добавлен
  `hideCoordsTooltip()`.
