# 49a. Карточка звезды — развести «Возраст» и «Срок жизни»

**Создано:** 2026-09-16
**Статус:** ✅ готово (мелкая правка, сделана менеджером по «го»; тестировщик не привлекался — косметика в JS)

## Суть

Вопрос создателя (2026-09-16): «Возраст: Короткий (до 10 млн лет) — что это
значит? возраст или сколько осталось жить?» (звезда Nares, класс O).

Разобрано по коду (`web/static/js/modal/panel.js`, `getSpectralInfo`):
- Для **обычных звёзд** карточка показывает **не возраст, а срок жизни класса**
  (время на главной последовательности): O — «до 10 млн лет», B — «50 млн»,
  G — «до 10 млрд», M — «триллионы». Сколько звезда уже прожила и сколько
  осталось — не показывается (для обычных звёзд `worlds.age = NULL`, реш. 41a).
- Для **остатков и протозвёзд** карточка показывает **реальный возраст системы**
  (`worlds.age`, 41a: остатки 2–13 млрд лет, протозвезда 1–10 млн «молодая»).

Одна надпись «Возраст» смешивала два понятия → путаница.

## ТЗ

1. `web/static/js/modal/panel.js`, карточка звезды (строка 222): подпись поля
   сделать зависящей от типа:
   - обычная звезда (`exotic == false`) → **«Срок жизни»** (значение из
     справочника по спектральному классу);
   - остаток/протозвезда (`exotic == true`) → **«Возраст»** (реальное значение
     `worlds.age`).

## Решение

- [x] 2026-09-16, менеджер: строка 222 `panel.js` → `<strong>${exotic ? 'Возраст' : 'Срок жизни'}:</strong>`. Один тернарник, стиль совпадает с соседними строками (215–221). Go не затронут; `node --check` не требуется (правка в шаблонной строке).
- Мелочь по решению 41a («подсказка убрана») не пересекается.

## Критерий готовности

Карточка звезды: у обычных звёзд (Nares, класс O) поле подписано «Срок жизни»;
у экзотики — «Возраст» с реальным значением. DoD: JS-правка, визуальная проверка карточки.
