## Суть

Пожелание создателя: «Убери координаты из правой части вкладки, добавь в шапку
модалки». Уточнения (2026-09-16):
1. переносим **только координаты**, светимость остаётся в карточке звезды;
2. **финальный вид**: координаты прямо рядом с названием в шапке —
   `Nemurzan (99, -1775)`; спектральный класс из шапки убран; слово
   «координаты» не пишем; дробь отброшена (целые); разделитель пары —
   **запятая** (решение создателя 2026-09-16: точка с запятой плоха, запятая
   безопасна — дробей больше нет).

## Текущее состояние (из кода)

- `web/static/js/modal/panel.js` — карточка звезды (правая панель модалки):
  строка `Координаты: (x; y)` в списке параметров, сразу после «Светимость».
- `web/static/js/modal/index.js` — шапка модалки: заголовок
  `Имя (спектральный класс)` + строка чипов («тип системы», «тип объекта»,
  модификаторы).

## Правка (мелкая, менеджер, 2026-09-16)

1. `panel.js` — убрать строку «Координаты» из карточки звезды и осиротевшие
   переменные `coordX`/`coordY` (использовались только в этой строке).
2. `index.js` — заголовок шапки: `Имя (спектр)` → `Имя (X, Y)` — целые
   (`Math.trunc`, дробь отброшена), без слова «координаты», разделитель —
   запятая (решение создателя), «—» при отсутствии поля; спектральный класс
   из шапки убран (остаётся в карточке звезды и бейдже; тип экзотики —
   в чипах и карточке).
3. `index.js` — чип `координаты: (x.xx; y.xx)` из строки чипов НЕ добавлялся в
   финал (первая версия была чипом — заменена на заголовок по итерации
   создателя).
4. `state.js` + `index.js` — удалены осиротевшие поля `worldCoordX`/`worldCoordY`
   и их присваивания (после переноса никто не читает).

Итерация по тестеру (B-фикс): в первой версии falsy-проверка `coordX ? …`
трактовала 0 как отсутствие — twin-миры из «Проверки гипотез» живут ровно в
(0,0) и (600,0) и показали бы «—». Исправлено на `typeof === 'number'`:
0 → `0`, «—» только при отсутствии поля.
