## Одобренные определения (дословно)

**Кривая компоненты R** — сегментная функция влияния среды на изменение
населения: для каждой компоненты (жара, холод, гравитация, радиация) задаёт
долю убыли R по оси условия X. Формат — упорядоченный массив узлов + изгибы
сегментов; за краями кривая = константа (значение крайнего узла). Редактируется
мышкой в балансер-UI, хранится в пресетах кривых (JSON). *Источник:*
`99.2.17-balancer-ui.md` §2, `99.2.12-temperature-mortality-calibration.md` H2,
`99.2.13-other-factors-r-model.md`.

**Газовый гигант** — класс планеты с честной физикой: радиус насыщается
~11–12 R⊕ (электронное вырождение держит радиус ~1 R_J от ~1 до ~80 M_J),
плотность растёт с массой. Диапазон массы: 15.9…4131 M⊕; выше 13 M_J (4131 M⊕)
— коричневый карлик. Температура по каскаду. *Источник:*
`99.2.15-honest-gas-giants.md`, `99.2.20-planet-physics-cascade.md` §3.3.

**Пресет** — именованный набор параметров, применяемый целиком, а не по частям:
в «Балансировке» — пресеты кривых компонент (JSON-файл на сервере), в генерации
планет — пресеты физического каскада, в UI — пресеты вида/раскладки. Один
пресет — одно целостное состояние инструмента или генератора. *Источник:*
`99.2.17-balancer-ui.md` §1, `99.2.20-planet-physics-cascade.md`,
`03_planets.md`.
