## Пожелание (создатель, 2026-09-16)

> «Смотри, я решил так решить проблему населенности: Мы вводим новые
> "инопланетные" расы, существование которых не зависит от воды. Нужно это
> записать в идею, на основе которой другая команда разработает эти расы»

## Проблема, которую решает

После честного физического каскада (45a/99.2.20) **обитаемая доля планет
~1.8%** (смоук): жизнь привязана к жидкой воде (флаг `liquid_water_possible`),
а вода — к узкому фазовому окну (T 273–373 K, P ≥ 0.006 атм). Вселенная
выходит «пустой»: почти все миры мертвы. Создатель решил **не балансировать
генератор** (не раздувать обитаемость ручками), а **расширить понятие
жизни**: ввести расы/жизнь, существование которых НЕ зависит от воды.

## Трактовка (менеджер)

Жизнь в игре перестаёт быть синонимом «вода + землеподобность». Вводятся
«инопланетные» расы с иной основой существования (не водной биохимией):
- возможные основы: аммиак/метан (холодные миры, T < 273), энергия
  излучения/тепла (радиационные, жаркие), кремний/кристаллы, сероводород,
  экзотика (связана с идеей 54a — фантастические ядра/звёзды);
- флаг `liquid_water_possible` перестаёт быть единственным гейтом жизни;
- каждый тип расы имеет свои физические условия существования (свой
  «фазовый» диапазон: T, P, состав атмосферы, радиация, внутреннее тепло).

Это **ТЗ-основа для другой команды** (дизайн рас) — по маршруту: дизайн →
разработка.

## Решения создателя (2026-09-16, уточнение)

1. **Расы — полноценные**: «именно отдельные расы, свои поселения, и тд, со
   своей биологией. огромная фича». Это НОВАЯ сущность (раса), не расширение
   биосферы-ярлыка. У каждой расы: своя биология (основа существования,
   не водная), свои поселения, свои условия пригодности.
2. **Вода для людей**: «если есть наличие как таковое водорода и кислорода,
   то воду люди могут каким-то образом произвести» — пригодность для людей
   расширяется: жидкая вода ИЛИ доступны H + O (атмосфера: H₂/O₂/H₂O;
   недра: лёд) → вода синтезируема/добываема. Направление для R-модели/
   `settlement.Suitable` (отдельная правка, не для рас).
3. **Биосфера**: существует как ярлык-поле `planet.data.biosphere` (6 типов:
   стерильная/микробная/растительная/грибная/симбиотическая/светящаяся),
   категория архетипа; влияет на композицию/описания/аудит; сущностью с
   поселениями НЕ является. Расы — отдельная сущность, вне биосферы. В
   контенте уже есть аномалия «биосфера без воды» (аммиак/метан) — задел.
4. **Приоритет**: для отдельной команды, запуск — **перед сдачей 45a**.

## Развилки (вопросы создателю, 2026-09-16)

1. **Сфера**: расы — это (а) замена «жизни» для неводных миров (life = true
   на другой основе, минимально), (б) отдельная ось «тип жизни»
   (водная/аммиачная/энергетическая/кремниевая — расширяет классификацию),
   (в) полноценные NPC-фракции/агенты (как 20a)? Рекомендация: (б) как
   первый шаг. → **Решено: (в+), полноценные расы со своими поселениями и
   биологией.**
2. **Игрок-человек**: поселения людей по-прежнему требуют воды (R-модель
   18a не меняется) — расы для «населённости мира», не для поселений
   игрока? Или люди тоже адаптируются (крупно)? → **Решено: люди получают
   возможность производить воду при наличии H + O (п.2 решений), расы —
   отдельно.**
3. **Совместимость**: биосфера (6 типов) и описания (~700 текстов) —
   расширяем новыми типами/тегами или расы отдельным слоем (вне биосферы)?
   → **Решено: расы — отдельная сущность вне биосферы (п.3 решений).**
4. **Приоритет**: сейчас (45a не сдана — встроить в каскад) или бэклог
   (идея-ТЗ, ждёт команду)? → **Решено: отдельная команда, перед сдачей
   45a.**

## Уточнение сессии 2026-09-16 (расширяет ТЗ; ответы создателя по номерам)

Продолжение 55a. Задача этой сессии — **креативно сгенерировать 50 рас,
исходя из базовой физики планет** (главная работа сессии, большая доработка).

1. **Связь с 55a** — да, это продолжение 55a (расширяю её новыми деталями).
2. **Скоуп «основы»** — задача сессии: креативно сгенерировать расы из
   базовой физики планет. См. п.3 (масштаб).
3. **50 рас** — это большая доработка, главное, что надо сделать в сессии.
4. **Кластерная привязка** — кластер = **доминирующая раса** (homeworld).
   На «выбросах» — **подселение** рас из соседних кластеров, если возможно
   по их физиологии. На одной планете возможно **сосуществование поселений
   двух рас**.
5. **Подножный корм / базовые ресурсы** — закладываем **каркас** (раса →
   свои базовые ресурсы/подножный корм), конкретные данные — позже (при
   новой ресурсной модели 99.2.5).
6. **Приоритет** — ждём физический каскад 45a (коммитится) → после него
   стартуем. Пока — запустить интервьюера для сбора замысла по 50 расам.

### Решения по векторам (пожелание создателя)

1. Разнообразить игровой процесс.
2. Расширить понятие «жизнь»: для людей сейчас генерируется 2–6% пригодных
   для жизни планет.
3. Тоньше настраивать поведение, дипломатию и привычки рас. Разные
   приоритеты для агентов — в будущих релизах.
4. Разные корабли, лучше визуал.
5. Разные «потребительские» повадки в разных кластерах.

### Что это меняет

- «Подножный корм» и базовые ресурсы для разных рас — разные.
- В кластере с большим шансом генерируются звёзды, подходящие для жизни
  расы, привязанной к кластеру (homeworld).

### Зависимость от 45a

Физика планет для рас опирается на **доделки 45a** (ядро → 5 физических
типов, недра/поверхность без полосы архетипа, вода из H+O для людей — п.2
решений 55a). Основная интеграция рас стартует после доделок 45a. Сейчас
(до них) — только интервьюер + креативный сбор 50 рас.
