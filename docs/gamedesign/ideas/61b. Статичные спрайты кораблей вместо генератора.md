## Решения создателя (уточнение 2026-09-16)

1. **Генератор — легаси.** Убираем целиком: генератор деталей `internal/generator/ship/`, таблицу `ship_parts` (миграции 000027/000028), каталог `ship_catalog.go`/`ship_repository.go`, вкладку «Корабли» в админке (`admin_ship_parts.go`, `web/static/js/admin/ships.js`), конструктор в дашборде, `GET /api/ship-parts`, `users.ship_visual`. Замена — статичные спрайты (как раньше `ship_icon`).
2. **Цвет — нюанс с градиентами.** Спрайты рисованы с градиентами/текстурой; просто залить одним цветом нельзя. Нужно найти решение, чтобы **оставить выбор доминирующего цвета** (оттенок поверх градиентов, а не замена цвета). Если решение найдётся — отлично; иначе — корабль цельный как нарисован (решение за создателем, дизайнер должен предложить варианты).
3. **Агенты NPC:** детерминированно от id агента получают один из 21 спрайта (чистая функция, ноль хранилища). Позже переделаем: у каждой расы будет свой визуал кораблей (не сейчас).
4. **Маппинг:** старые `users.ship_icon` (21 SVG-имя) → новые PNG (фолбэк на дефолт для неизвестных).
5. **Старые 21 SVG + `ships.json` — удаляем** из репо (в отличие от прежнего решения «оставить до 1.0» — отменено).
6. **Ассеты:** принятые 21 PNG копируются в `web/static/sprites/` и коммитятся (сейчас в `ai_drafts/`, вне git).
