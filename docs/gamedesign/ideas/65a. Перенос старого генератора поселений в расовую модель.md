## Пожелание создателя (2026-09-17)

После фичи «Расы» (расовый генератор поселений стал единственным путём
расселения: доминанта кластера + сосед на выбросах, люди — раса `humans`)
старый человеческий генератор поселений становится дублем. Создатель:
«мне не надо уже селить отдельно людей», «можно аккуратно перенести старый
генератор в новую модель расселения», «то есть нужные фишки оттуда перенести».

## Замысел (согласован с создателем 2026-09-17)

**Перенести нужные фишки старого генератора в расовую модель, старый скрыть (не удалять).**

### Что переносится (фишки, подтверждены создателем 2026-09-17)

1. **Chance** (шанс заселения планеты 0–1) — «да». Сейчас у доминанты селится
   всегда, если пригодна; переносится параметром в расовый генератор
   (`RaceGenConfig`).
2. **Population** (fixed/random, настраиваемый диапазон) — «да». Сейчас жёстко
   100k–1B (`buildRaceSettlement`); переносится стратегия (Kind: fixed/random,
   Min/Max) как параметр расового генератора.
3. **Settleable** (пригодность планеты в данных: политика/тип/описания) —
   **Вариант А (принят создателем)**: флаг остаётся «пригодность для людей»,
   но пересчитывается через **`RaceSuitable(humans)`** вместо пресета
   (`settlement.Suitable`) — единый источник пригодности. Скрытие пресета не
   ломает cascade.go/classify.go/descriptions_tags.go.
   **Побочно (из диалога создателя):** «мне нужно будет прогонять каждую расу
   на близнецах» — RaceSuitable готов, нужен интерфейс выбора расы в «Проверке
   гипотез» — **отдельный кусок, НЕ в этой задаче** (отметить в бэклог).
4. **NeighborChance** (крутилка подселения соседа на выбросах, дефолт 0.3) —
   сейчас лежит в `settlement_preset.json`; переносится в конфиг расового
   генератора (отдельный файл или поле пресета рас, не в старом пресете).

### Что скрывается (старый генератор, код остаётся)

- Роут `/admin/generate-settlements` — убрать из регистрации (main.go).
- Кнопка «Генерация поселений» в админке — убрать из UI.
- `Model`/`DefaultModel`/пресет `settlement_preset.json` (Suitability) — скрыть:
  файлы/функции пометить «скрыт (65a), устарел — расовый генератор заменяет»,
  не удалять (можно вернуть/удалить позже).
- `GenerateSettlements` (человеческий проход) — скрыть, не вызывать.

### Нюансы (проверить при переносе)

1. **Водность** — карточка людей `liquid_water: true` (флаг), старый пресет
   требовал `water_percent ≥ 10`. Проверить, что RaceSuitable(humans) покрывает
   водность (или добавить проверку водности).
2. **Газовые гиганты** — у людей `gravity 0.8–1.2`; убедиться, что гиганты не
   проходят (или явно исключить).
3. **Settleable** — данные уже сгенерированных планет в БД не пересчитываются
   (бэкфилл запрещён, решение создателя 2026-09-14) — флаг меняется только для
   новых генераций.
4. **Близнецы** (twin.go) используют `settlement.Population` и `Chance` — их
   НЕ ломать (типы Population остаются в пакете settlement, расовый генератор
   их переиспользует).
