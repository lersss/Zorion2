## Разнообразие вариаций — арт-ТЗ @artist (2026-09-17)

**Проблема:** вариации от эталона получались 99% копией (было: img2img без ControlNet,
denoise 0.35). Попытка №2 (ControlNet Canny от РЕНДЕРА эталона + форма из общего словаря
337k + denoise 0.6) — «одинаковые и не похожи на эталон».

**Диагноз @artist:**
1. Canny от рендера эталона (LoadImage срезает альфу, под прозрачностью — мусор и
   внутренние текстуры) → плотная карта запирает и форму, и текстуру → одинаковые.
2. Форма из общего словаря (337k) конфликтует с формой эталона → SDXL выводит одно
   «среднее» → не похожи и одинаковы. Словарь форм — ТОЛЬКО для кандидатов
   (BuildPromptWide), не для вариаций.
3. Негатив самоконфликтный: запрещает материал/цвет/«creature» самой расы.
4. Одноэтапность — мёртвая зона: текстура и форма в одном латенте, одним denoise не
   разделить → нужен двухэтапный процесс (art_principles §3).

**Арт-ТЗ (воркфлоу вариаций):**
- **Этап A — форма:** LoadImage эталона → ImageToMask(alpha) → ThresholdMask(0.5) →
  MaskToImage (белое на чёрном, БЕЗ текстуры) → Canny(0.2/0.5) → ControlNetLoader
  (controlnet-canny-sdxl-1.0) → ControlNetApplyAdvanced (strength 1.2–1.5, мягкие семьи
  0.6–0.9; start 0.0, end **0.7–0.8**) → VAEEncode от плоского силуэта → KSampler
  (denoise 0.8–0.85, positive ["13",0], negative ["13",1]) → SaveImage.
- **Этап B — детализация:** img2img от вывода A БЕЗ ControlNet, denoise 0.45–0.55,
  steps 40, cfg 7.5, промпт «dense {mat} texture, {character} {parts}, maximal detail».
- **Промпт этапа A:** «abstract structure», race_form — из УЗКОГО списка расы
  (идентичность), mat/glow расы, деталь-ось «лица» = {character} {parts} из forms.json
  (500 комбо) + scene + seed. НЕ RandomForm.
- **Негатив лёгкий** (для вариаций): убрать запреты материала/цвета/«creature»,
  оставить text/watermark/anthropo/дефекты.
- KSampler negative = ["13",1] (CN-обработанный), не ["3",0].
- Грабля №4: «abstract structure» вместо «non-organic alien creature» (магнит к голове).
- Грабля №3 (портреты на весь кадр): уходит сама — маска эталона фиксирует кадрирование.

**Критерий приёмки (@artist):** силуэт повторяет эталон (IoU альфа-масок > 0.85); пачка
N=8 → ≥7 разных текстур; палитра из materials расы; нет антропо; пост 200×200.

**План:** A/B-тест — сначала минимальный фикс (Canny от маски + лёгкий негатив +
race.Forms вместо RandomForm + end 0.7), пачка 8, проверка создателем; если ок —
полный двухэтапный (этап B).

## Что переносится (из прототипа, проверено)

## Функционал (из спеки art_studio_spec.md + уточнений 66a)

- Один инструмент с вкладками: «Отбор», «Эталон» (+ «Люди»).
- Вкладка «Отбор»: семейство → раса → **«СГЕНЕРИРОВАТЬ РАСУ (N)»** (всегда строго от
  эталона, img2img, denoise ползунок 0.25–0.6) + **«СГЕНЕРИРОВАТЬ ЭТАЛОНЫ (N)»** (refcand,
  широкий поиск). Принятые → `final_accepted/<FAM>/r<race_id>/NN.png`, ресайз 200×200.
- Вкладка «Эталон»: статус эталонов ✓/·, ряд миниатюр, сетка кандидатов (select расы +
  «Эталон»), сброс эталона.
- Прогресс/СТОП/индикатор состояния, авто-обновление 3с, дифф-рендер (карточки не
  сбрасываются), localStorage, no-cache.
- Один процесс, фикс-порт, защита от дублей (спека §4.7).
- Студия людей (F1): оси рандома (пол/раса/возраст/причёска/одежда/броня/шлем), галка
  «без голых», отбор, обрезка снизу ползунком.
- Конфиги: словарь форм (300k+), семейства F2–F9 (заполнить из спеки 99.2.21), негативы,
  оси рандома — JSON, редактируемые без кода.

## Критерии приёмки (спека §5.4)

1. Художник генерирует пачку рас и отбирает без ручного запуска скриптов.
2. Поток «кандидаты → эталон → вариации» работает.
3. Прогресс/СТОП/индикатор работают; авто-обновление не сбрасывает выбор.
4. Вырезка фона чистая (проверка на подложке-кабине).
5. Принятые — 200×200 прозрачные PNG в final_accepted.
