# 68a. Домик напротив населённых планет в списке звезды

**Создано:** 2026-09-17
**Статус:** готово к проверке
**Приоритет:** мелочь (косметика, вектор «Визуал»)

## Суть

В списке планет в карточке звезды модалки системы явно отмечать населённые
планеты значком (домиком), чтобы по списку было видно, где живут люди.

## Правка (2026-09-17, менеджер, мелкая)

`web/static/js/modal/panel.js`, функция `planetsTable()` (список планет в
карточке звезды): если `planetPopulationAt(p, Date.now()) > 0` — перед
названием планеты в первой колонке вставляется `<span title="Населена">🏠 …</span>`.

- Населённость через уже импортированную `planetPopulationAt` (учитывает
  и `settlements`-массив, и фолбэк `planet.population`) — новый импорт не нужен.
- Кликабельность строк (`tr[data-index]`) не ломается: span внутри `<td>`,
  события всплывают до `tr`.
