# 69a. Убрать «показать все» на поверхностях и недрах в карточке планеты

## Сырое пожелание (создатель, 2026-09-17)

> «убрать из модалки в карточке планеты "показать все" на поверхностях и недрах.
> Фактически они прячут 1-2 строчки, бесполезные.»

## Факты из кода (менеджер, проверено 2026-09-17)

- `renderComposition()` (`web/static/js/modal/tabs.js`, стр. 94) обрезает список
  форм до 7 (`limit = 7`) и при остатке рисует кнопку «▼ показать все (N)».
  Вызывается для блоков «Поверхность» и «Недра» карточки планеты
  (`renderGeneral`, стр. 191, 195) и карточки спутника (стр. 261, 266).
- Кнопка прячет 1–2 строчки — обрезка бесполезна, только лишний клик.
- CSS для `.show-more-btn` нет (кнопка инлайн-стилями). Обработчики кнопки —
  `renderTabContent` (стр. 434–445) и `renderSatelliteCard` (стр. 282–292),
  после правки осиротеют.
- `renderComposition` вне `tabs.js` не используется (админский
  `renderCompositions` в `hypothesis.js` — другой, редакторы пресетов).
- Вывод: чисто фронтовая косметика, Go/БД/API не трогаем, рестарт сервера не
  нужен (статика с диска, noCache).

## ТЗ

1. В блоках «Поверхность» и «Недра» карточки планеты и спутника показывать
   **весь список форм сразу** — без обрезки и без кнопки «показать все».
2. Полоска композиции, иконки, проценты — без изменений.
3. Убрать мёртвый код: параметр `limit`, блок `hasMore`/hiddenList/кнопка,
   обработчики `.show-more-btn` (оба места), комментарий «Также вешает
   обработчики на кнопки "показать все"».

## Критерии готовности

- В модалке планеты/спутника в «Поверхность» и «Недра» видны все формы сразу.
- Кнопок «показать все»/«скрыть» в модалке нет (в админке — своя, не трогаем).
- `go build ./...` (на всякий случай) + проверка @tester.
