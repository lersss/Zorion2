## Сырое пожелание (создатель, 2026-09-17)

> «Вынести информацию о звезде из модалки в тултип при наведении на звезду.»

Уточнения (создатель, ответы на вопросы менеджера):

1. **Тултип — В МОДАЛКЕ**: при наведении на звезду на схеме системы (канвас).
   На компаньонах тоже должен работать тултип с их характеристиками.
   Текст сократить — тултип компактный. «Посмотрим, как выглядит и примем решение».
2. Карточку звезды из правой панели модалки — **убрать**.
3. Масса и возраст — уже есть в данных модалки, их показываем.
4. Количество планет в тултип НЕ выносим — дублируется в «Планеты (N)».

## Факты из кода (менеджер, проверено 2026-09-17)

- Модалка системы: `web/static/js/modal/` (index.js, events.js, modal_render.js,
  panel.js, layout.js, state.js, utils.js).
- **Карточка звезды** — `renderStarCard()` (`panel.js` стр. 171): спектр, тип,
  планеты в системе, температура (°C + K), масса (`formatStellarMass`),
  компаньон (`companionBlock`), цвет, радиус, светимость, срок жизни/возраст,
  описание. Для обычных звёзд справочник `getSpectralInfo(spec)` (стр. 233),
  для экзотики — `exoticStarInfo()` (стр. 62). Правая панель по умолчанию
  (selectedIndex === null) рисует именно её (`renderRightPanel`, стр. 121).
- **Hover на канвасе** — `modal/events.js`: `hitTest` (стр. 27) проверяет ТОЛЬКО
  главную звезду (`layout.mainX/mainY`) и планеты. Компаньоны НЕ хит-тестятся.
  `modalState.hoveredObject` — строка `'star'` или `{type:'planet',index}`.
  Тултипа при наведении сейчас нет (только подсветка + cursor).
- **Компаньоны** — `modal/state.js`: `companion` (спектр), `companionColor`,
  `companionMass`, `companionTemp` (K), `companionSepAU` (а.е.),
  `extraCompanions` (массив `{spectral_class, temp, sep_au, ...}`).
  Геометрия: `modal/layout.js` `computeLayout` → `stars` (kind: main/companion/extra)
  с координатами x/y/radius. Шапка модалки уже показывает чипы «тип системы»,
  «тип объекта», модификаторы (`index.js` стр. 240–268) — их НЕ трогаем.
- Данные звезды: `modalState.worldTemperature` (K), `stellarMass` (M☉),
  `worldAge` (млрд лет), `spectralClass`, `starType`, `stellarMods`.
- Клик по звезде на канвасе сейчас → `window.showStarCard()` (`index.js` стр. 375)
  → карточка звезды. После правки клик по звезде = сброс к списку планет.
- Панель по умолчанию после правки = только список планет (таблица «Планеты (N)»).

## ТЗ

1. **Тултип при наведении на звезду на канвасе модалки** (главная + компаньон +
   внешние компаньоны). Позиционирование у курсора, скрытие при уходе мыши и при
   драге. Стиль — как coords-tooltip карты (`#1a1a2e`, border `#334155`, radius 8,
   тень, padding 8–10px, font-size ~0.9rem, pointer-events: none, z-index высокий).
2. **Содержимое тултипа — компактно, вся информация из карточки звезды** (без
   количества планет):
   - Главная звезда: тип (человекочитаемый: `getSpectralInfo(spec).type` /
     `starTypeLabel`), температура (°C + K, как в карточке), масса
     (`formatStellarMass`), цвет, радиус, светимость, срок жизни/возраст,
     описание — одной короткой строкой (для обычных звёзд). Для экзотики —
     `exoticStarInfo()`.
   - Компаньон: тип по спектру (или «Компаньон»), температура, масса,
     разделение пары (а.е.), цвет/радиус/светимость по спектру (`getSpectralInfo`).
   - Внешний компаньон (`extra_companions`): спектр, T, разделение, цвет/радиус/
     светимость по спектру.
   - У компаньонов и внешних — строка «До доминантной: N а.е.» (доработка
     создателя 2026-09-17: формулировка «Разделение» заменена на понятную
     игроку; «Расстояние до доминантной» сокращено до «До доминантной»).
3. **Карточка звезды из правой панели убирается**: панель по умолчанию (и по
   клику на звезду) — только список планет «Планеты (N)». Удалить мёртвый код
   карточки (инфо-блок, `companionBlock`, `getSpectralInfo` остаётся — нужен для
   тултипа). Чипы шапки и название модалки — без изменений.
4. **Ховер-подсветка** (`modal_render.js` стр. 117): подсвечивать и компаньонов
   (по `layout.stars`), не только главную.
5. Бэкенд не трогаем (Go/БД/API без изменений), рестарт сервера не нужен
   (статика с диска, noCache).

## Критерии готовности

- При наведении на главную звезду в модалке — компактный тултип со всей
  информацией о звезде; на компаньона/внешнего — с их характеристиками.
- Тултип скрывается при уходе мыши/драге; клик по звезде возвращает панель к
  списку планет.
- В правой панели по умолчанию — только «Планеты (N)», инфо о звезде там нет.
- `node --check` для изменённых JS + проверка @tester (визуальный осмотр на
  создателе).
