## Пожелание (создатель, 2026-09-17)

> «Некоторые расы при уничтожении дают ценные для других рас ресурсы. Нужна
> проработка.»

## Уточнение сессии (2026-09-17, ответы создателя по номерам)

1. **Что такое «уничтожение»** → фактически **«мёртвые тела представителей
   рас»**. Механики уничтожения сейчас нет, но **войны будут** (задел на
   будущее).
2. **Как добываются ресурсы** → **нужна проработка** (белое пятно, решается
   при дозревании).
3. **Связь с «Артефактами рас» (99.2.21 §11)** → **никакой**. Это отдельная
   механика с отдельной реализацией: артефакты — товары, которые раса
   *производит* при жизни; здесь — ресурс из *тел* расы.
4. **Главная цель фичи** → **драйвер войны**. Тела рас — ценный ресурс для
   других рас → у игрока/агентов появляется мотив воевать за них.

---

## Что это меняет (смысл)

- У рас разная биохимия (аммиачники, серные, кремниевые, терморедокс —
  55a/56a, спека 99.2.21): то, что для одной расы — просто тело, для другой —
   ценный ресурс (биоматериал, сырьё, «компонент»).
- Война (механики которой пока нет) получает экономический смысл: воюют не
  за территорию ради территории, а за ресурс, который дают тела врага.
- Ложится на будущий вектор войн; сейчас — только задел, ничего не
  проектировать механически.

## Белые пятна (для проработки при дозревании)

- **Как добываются ресурсы из тел** (Б): трофеи после боя? сбор на месте
  гибели? разборка/переработка тел (как в «Серных источниках» — атмосферный
  экстрактор)? Игрок это делает или агенты?
- **Какие расы «ценные»** и для кого: матрица «раса-донор × раса-потребитель»
  (что из чьего тела ценно) или общий слой?
- **Механика войны отсутствует** — драйвер будет реализован вместе с войнами
  или раньше (что-то, что уже сейчас даёт ценность тел)?
- **Связь с ресурсной моделью 99.2.5** — входит в универсальный слой ресурсов
  или отдельный слой «биоматериалы»?

## Границы (что точно НЕ входит)

- **«Артефакты рас» (99.2.21 §11)** — не трогаем, отдельная сущность.
- **Механика войн** — не проектируется сейчас (только мотив для будущего).
