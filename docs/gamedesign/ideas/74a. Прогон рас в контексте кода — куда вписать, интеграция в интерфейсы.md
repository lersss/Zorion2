пакет спек, куда добавить расы, по трём направлениям: **бэк** (код/API/
генерация), **UX** (интерфейсы), **доки** (коррекция + проверка на легаси
всего объёма документации).

**Шаги:**
1. **Код:** карта вписанности рас — где `race_id`/`RaceID`/`races`/слой
   `robotic` используются (регионы, поселения, генераторы, API, фронт), где
   расы ещё не вписаны (UI/API/механики). Пометки «куда просятся».
2. **Спеки/идеи:** собрать обещания по расам, не реализованные в коде
   (отчёты «тип жизни/раса», territory роботов «по условиям», механики-
   кандидаты, корм/артефакты при 99.2.5).
3. **Доки:** проверить на легаси весь объём документации — устаревшие
   утверждения, противоречащие модели рас (поселения, биосфера-ярлык,
   роботы, экономика/деньги-лор торговцев 64a, пригодность людей).
4. **Результат:** пакет предложений (спеки по направлениям + дельты доков)
   → гейт создателя.

**Границы:** ревизия и предложения; правки доков — по «го» создателя,
дельты — через владельцев доков / @dispatcher (горячие); код не пишем.
