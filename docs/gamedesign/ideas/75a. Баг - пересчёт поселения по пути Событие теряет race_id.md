## Пожелание

Создатель: «Ictemsun — рядом нет секторов людей. Как здесь поселились люди?» и
«открыл Urlumcry — поселения — было написано "Поселение 1 раса люди" — и через
некоторое время сменилось на Микротрещинные».

## Диагноз

Люди на Ictemsun НЕ живут. Поселение планеты Ictemsun (мир Kelkol, координаты
−21228, −7587) — раса `microcrack` (Микротрещинные), планета в регионе «Луанон»
(доминанта — microcrack). Человеческий регион в этой вселенной один — «Мирон»
(≈ −30436, −1173), все 64 человеческих поселения вокруг него.

Баг отображения: `internal/repository/economy_repository.go`,
`RecomputeSettlementPopulation`, путь «событие» (Δt ≥ MinPersistInterval):
транзакция `SELECT id, planet_id, population, population_exact, stability,
computed_at, created_at, updated_at FROM settlements WHERE id = $1 FOR UPDATE`
**не выбирает `race_id`** → возвращённый объект теряет расу → `race_id` пуст →
`attachSettlements` даёт `race_name = raceName("") = «Люди»` →
`tabs.js:366` рисует «Люди».

Последовательность «сначала Люди, потом раса»: первый ответ (ΔT большой) —
путь «событие» → расы нет → «Люди»; автообновление через 3 с (`panel.js:136`)
— ΔT мал → путь «простой визит» (race_id сохраняется) → «Микротрещинные».

## ТЗ

1. В путь «событие» `RecomputeSettlementPopulation` добавить `race_id` в SELECT
   (и в Scan) — возвращаемый объект сохраняет расу.
2. Тест: путь «событие» с поселением расы возвращает `RaceID` (регрессия).
