### Как морфы работают в коде (проверено по `cmd/art-studio/generator/prompt.go`)

- `BuildPromptWide(..., morph)`: `"beast"` → `fam.BeastForms` (при пустом списке — фолбек на глобальный `beast_forms` из `forms.json`, 60 фраз); `"anthro"` → `fam.AnthroForms` (фолбек — глобальный `anthro_forms`, 43 фразы); `"xeno"/"amorph"/"crystal"/"mech"/"titan"` — только глобальные списки (`forms.json`, 25–40 фраз).
- `NegFor(fam, morph)`: морфам нужен СВОЙ негатив — `fam.AnthroNeg`. Если его нет — берётся общесемейный `fam.Neg`, а в нём есть запреты `human/face/head`, конфликтующие с промптом морфа.
- `fam.AnthroClothes` подставляется в промпт морфа как `wearing <фраза>`.
- Итог: у F2/F3/F6–F9 морф «Звероморфный»/«Антропоморфный» идёт не по материалу семьи, а по общему словарю — то есть «финалить» = дать этим семействам свои морф-наборы, как у F4/F5.

### Часть 1 — морф-наборы F2, F3, F6, F7, F8, F9

Каждому из этих семейств в `config/art/families.json` добавить по образцу F4/F5:
