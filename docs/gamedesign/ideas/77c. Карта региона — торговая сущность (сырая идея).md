## Как это вписывается в 77a

- Гибрид «звёздное поле» (решение 2026-09-17): за радаром все звёзды видны
  как **безымянные точки** (имени/данных нет, клик не открывает, полёт-цель
  недоступна). Чтобы «зажигать» звезду, нужно знание (личный каталог /
  отчёт).
- **Проблема:** индивидуальные отчёты (10_exploration §10.3) — штучный товар,
  на каждый далёкий сектор нужно покупать множество. Мелкая рутина, не
  ощущается как «исследование».
- **Карта региона** — альтернатива / дополнение: один предмет, который
  «зажигает» **все звёзды целого кластера/региона сразу**. Игрок купил карту
 北方ного сектора → десятки далёких точек стали целями для полёта. Масштаб
  вселенной ощущается через такой «прорыв информации», а не через один отчёт.

## Отличие от отчёта (10_exploration)

| | Отчёт (10.3) | Карта региона (77c) |
|---|---|---|
| Что открывает | Одну планету (детали: поверхность, недра, атмосфера, поселения) | Все звёзды региона (имя, спектр, число планет → полёт-цель) |
| Глубина | Полная (недра/атмосфера) | Поверхностная (только звезда как цель) |
| Что делает «знанием» | Личный каталог планеты | Личный каталог звёзд региона |
| Источник | Лаборатории, рынки | Рынки / тorgовые станции |

Карта **не заменяет** отчёт — она «зажигает» звёзды (цели для полёта), но
детали планет по-прежнему требуют отчёта или скана (в пределах радара).
Синергия: купил карту сектора → увидел звёзды → полетел → сканировал планеты
своим сканером → купил отчёт о недрах только для нужной. Пошаговое открытие.

## Формат (замысел создателя)

В Space Rangers «карта сектора» — покупаемый предмет, раскрывающий
исследованную область. Формат предварительный:
- Тип предмета: карта (отдельный тип, не оборудование).
- Зона действия: кластер / регион (привязка к `regions.id` или к
  географической зоне на карте).
- Действие: все звёзды внутри зоны → «зажигание» (запись в
  `player_planet_knowledge` как «звезда известна» — координаты + имя +
  спектр + планеты; детали планет — пустые).
- Цена / доступность — за решением при реализации рынков.
