## Текущее состояние (проблема)

Две расы с корнем «сол» в названии — близнецы, игрок путает:

| | **Солевые** (23, saltfolk) | **Соляные** (49, salt_bridge) |
|---|---|---|
| Основа | эвтектики расплавов | эвтектики хлоридов/сульфатов (мост сера↔жара) |
| T-окно | opt 600–800, surv 550–900 | opt 450–600, surv 420–680 |
| Потребление | РАС 50 · ГРД 30 · СКФ 15 · CO2 5 | РАС 45 · СЕР 25 · ГРД 20 · CO2 10 |
| Атрибуты | агр 60 · люб 65 · репр 100 · дипл 40 · уст 40 | агр 50 · люб 55 · репр 60 · дипл 50 · уст 50 |
| Дом | F/G/K, горячие миры (эвтектики) | F/G/K, горячие миры (эвтектики) — **то же** |
| Bulge | hot | hot |

**Корень:** разница чисто количественная (Соляные = «Солевые помягче + примесь
серы»). Та же планета-ниша, тот же bulge, тот же профиль осей. Названия —
однокоренная пара («солевые»/«соляные»), путаются. Плюс «соляные купола»
(ресурс) и «соляные отмели» (биом Прибрежных) замусоривают термин.

**Контекст-ограничение:** ниша «мост сера↔жара» уже занята Приливными (43, F4,
«по потреблению прибит к F4»). Соляные (49) — второй такой же мост, прибитый к
F5. Два моста на одно место.

## Решение создателя (вводные для дизайна)

1. Разводить **смыслово** — серьёзные развилки, не косметика имён.
2. Имена — **полная свобода** дизайнеру, вплоть до имён собственных (не
   обязательно описательные). Критерий: оба названия читаются по-разному, ни в
   одном нет корня «сол».
3. Приливных (43) НЕ трогаем; дизайнер обязан учесть, что их ниша занята, и не
   дублировать.

## Что нужно (ТЗ для @designer)

### 1. Две новые концепции рас
Для каждой: название + новый ID (без «salt» в обоих, без корня «сол»), основа,
кто это (биохимия словами), как живут, характер, ниша («зачем»), сосуществование.
Развилки — серьёзные: разные среды/фазы вещества, разный темп, разная
энергетика, разный социальный профиль. Не менее двух заметных осей разведения.

### 2. Числа (для config/races.json)
Окна (temperature/pressure/radiation/heat_flux/gravity), атмосфера (need/poison),
атрибуты (6 осей), потребление (13 осей, сумма = 100), forage, home, bulge.
Обоснование каждого сдвига: почему не пересекается с соседями.

### 3. Сверка с соседями (обязательная)
- не дублировать Приливных (43) — мост сера↔жара;
- не слиться с соседями F5: Лавовые (24), Сверхкритические (25), Термо-рои (26),
  Микротрещинные (27), Жаркие пепловые (28), Гейзерные (29), Радиотолерантные (30), Молодые (31);
- не превратиться в клон серных F4 (СЕР-доминанта без своей механики);
- F5 не остаётся без «солевого» полюса (эвтектики) — как минимум одна из рас
  сохраняет полюс, иначе F5 теряет визитную карточку.

### 4. Влияние на смежное (пометить, НЕ проектировать)
- R-кривые: `docs/specs/99.2.23-race-r-curves-twins.md` (строки про солевых),
  `config/race_balancer.json` (card_hash пересчитается, кривые — перекалибровка);
- тест `internal/generator/settlement/races_test.go` (ссылки на salt_bridge);
- переименование ID = миграция данных (settlements.race_id, regions.race_id) —
  решает разработка, пометить в спеке.

## Критерий успеха

- Две расы читаются как разные виды: не совпадают ни названия, ни ниша, ни
  минимум две оси карточки (среда/темп/характер/энергетика).
- Ни у одной нет корня «сол» в названии; названия не путаются между собой и с
  ресурсами («соляные купола») / биомами («соляные отмели»).
- Нет дублей с Приливными (43) и соседями F5/F4 — сверка проведена и
  зафиксирована в спеке.
- Числа валидны: потребление = 100, окна в пределах каскада, poison O₂ у обеих
  (терморедокс, яд O₂ — инвариант F5).
