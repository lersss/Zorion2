## Суть

Эксперимент: в промптах кандидатов и вариаций заменить субъект
«abstract object / abstract structure» на **«personage»** — и посмотреть, как
отреагирует генератор (гипотеза создателя: слово не humanoid, но тянет к
«характерной фигуре», SDXL мягче добавит человеко-подобные формы без полного
гуманоида). НЕ гуманоид: негативы (`fam.Neg`/`LightNeg`) с запретами
human/face/head остаются — конфликт «personage vs no human features» это и есть
предмет эксперимента.

## Решения менеджера (мелкая фича/эксперимент — решено самостоятельно)

1. **Переключатель, не замена:** добавляем **галочку «персонаж (тест)»** на
   вкладке «Эталон» (рядом с генерацией кандидатов), по умолчанию **выкл**
   (текущее поведение). Вкл → кандидаты и вариации используют «personage».
   Быстрый A/B без правок конфигов и рестартов.
2. **Область:** и кандидаты (`BuildPromptWide`, morph=""), и вариации
   (`BuildPrompt`) — «этому всему», как просил создатель. Морф-ветка (антропо/
   зверо) не трогается.
3. **Формулировка:** субъект «a personage» вместо «an abstract object / an
   abstract structure». Точное слово/формулировку можно крутить после первого
   прогона (результат эксперимента) — ручка в коде/конфиге, не в контенте.
4. Запреты «no human features» в шаблоне кандидатов оставляем как есть при
   первом прогоне (чистый эксперимент: меняется только субъект). Если конфликт
   убьёт эффект — следующим шагом уберём «no human features» из шаблона при
   включённой галочке (ручка).

## ТЗ (зона @developer)

1. **UI** (`cmd/art-studio/web/index.html`, вкладка «Эталон»): галочка
   «персонаж (тест)» (default выкл) → параметр в запросы `/genref` и `/genvar`.
2. **Backend/генератор:** `GenRef`/`GenVar` (или хендлеры) принимают
   `personage` bool; `BuildPromptWide` (morph="") и `BuildPrompt` — при
   `personage=true` субъект «a personage» вместо «an abstract object / an
   abstract structure».
3. **Тест:** DoD `go build/vet/test`; юнит-тест: при personage=true промпт
   содержит «personage», при false — «abstract object/structure».
4. В `ref_job.go`/`race_job.go` пробросить флаг до `BuildPromptWide`/`BuildPrompt`
   (в meta.json можно пометить, но не обязательно).

## Границы

- Негативы и морф-ветку не трогаем (эксперимент чистый: только субъект).
- Контент рас (`config/art/*.json`) не трогаем.
- Если эксперимент не сработает — галочка остаётся выключенной, поведение
  прежнее; правка не ломает ничего.
