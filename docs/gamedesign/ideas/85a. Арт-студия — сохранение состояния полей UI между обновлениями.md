## Суть

После перезагрузки страницы все поля UI арт-студии должны восстанавливать
**последнее состояние пользователя**, а не дефолтные значения. Касается всех
полей: галка «персонаж (тест)», селекты семейств/рас (все вкладки), счётчики
штук, ползунки (разнообразие, свобода формы, отпускание, палитра), размеры.

Уже есть localStorage для активной вкладки/семейства/расы (67a.1 §6.3) —
расширить на ВСЕ поля.

## ТЗ (зона @developer)

1. **`cmd/art-studio/web/index.html`:** общий механизм персистентности —
   на каждый управляющий элемент (select, checkbox, input[number], input[range])
   вкладок «Отбор»/«Эталон»/«Люди»:
   - при изменении (`change`/`input`) — сохранять `{id: value}` в localStorage
     (один ключ, например `studio-ui-state`);
   - при инициализации — восстанавливать, **только если значение валидно**
     (опция/значение существует; иначе — дефолт);
   - галка «персонаж» восстанавливает последний выбор пользователя, дефолтное
     `checked` — только при первом запуске (нет сохранённого значения).
2. Не ломать дифф-рендер/авто-обновление (3 с): восстановление — один раз при
   init, дальше только события пользователя.
3. **Тест:** DoD `go build/vet/test` (Go не меняется — проверка глазами логики
   JS; в отчёте — какие поля покрыты).
