## ТЗ (что должно получиться)

### Часть 1 — контент семейства F1 «Водные» (зона @designer)

В `config/art/families.json` добавить блок `F1`, имя `F1 Водные`, 3 расы:

- id «2», name «2 Океаниды», basis «вода, океаны»;
- id «3», name «3 Глубинники», basis «вода подлёдного океана»;
- id «4», name «4 Прибрежные», basis «вода + соляные отмели».

Имена/basis — из `99.2.21` §5 (таблица F1) и `config/races.json`. У каждой расы: `forms` (в диапазоне инварианта 2–60; состав в одном стиле с 78a — расширенные forms у остальных семейств), `materials` 2–3, `glows` 2–3 — по основам/средам водных (вода, океанская биосфера, подлёдный океан, хемосинтез, соляные отмели). Промпты — английские, имена — русские.

Общесемейные шаблоны F1: `extra` / `anchor` / `scene` / `neg` — по образцу F2 (в F2 neg запрещает human/лицо — для нечеловеческих водных это уместно; среда — вода/подводный фон, не абстрактная платформа).
