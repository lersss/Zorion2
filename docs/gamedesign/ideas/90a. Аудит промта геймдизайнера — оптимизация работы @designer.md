## Дельты (дословные формулировки правок в `.opencode/agents/designer.md`)

### Д1 (ВЫСОКИЙ). Добавить в раздел «Правила», после строки «"Один факт — одно место": в спеке ссылайся на дизайн-доки, не дублируй.»

Добавить пункт:

```
- **Impact map (`docs/impact_map.json`, реестр каскадных влияний, 83a):** правка спеки или GDD, затрагивающая сущность из реестра (конфиги рас, race_balancer, settlements.race_id, `22_races.md`, спеки `99.2.N`) — сверься с ним: «меняем X → смотрим на Y»; обнови все места с kind=duplicates (спека ↔ GDD ↔ конфиги), чтобы «один факт — одно место» не порождал рассинхрон.
```

**Зачем:** зона дизайнера целиком состоит из сущностей реестра (races.json,
race_balancer.json, settlements.race_id, 99.2.21, 22_races.md с каскадами
duplicates/writes на конфиги, GDD и расовые доки). AGENTS.md §27 требует сверки,
но ни один промт её не операционализирует → рассинхрон ловят @balancetester/
@reviewer → лишняя итерация.

### Д2 (ВЫСОКИЙ). Заменить абзац «Счётчик открытых вопросов» (строки 131–135)

Было: «Счётчик двигает агент, правящий FAQ» (дизайнер сам меняет `faq_counter.md`).
Стало:

```
- **Счётчик открытых вопросов** — `docs/gamedesign/faq_counter.md` (ровно одна
  цифра): файл — горячий док, его пишет только `@dispatcher` (AGENTS.md §4.21), сам
  счётчик НЕ трогай. Дописал в FAQ вопрос без ответа («эталон не задан») или
  вписал ответ — передай менеджеру дельту на счётчик (раздел «Разнос по докам» в
  своей идее), дальше разнесёт @dispatcher. Считаются все открытые вопросы
  эталонов включая FAQ-разделы в идеях (`docs/gamedesign/ideas/`) до переноса в GDD.
```

**Зачем:** правило в промте от 2026-09-14 устарело — решение о @dispatcher как
единственном писателе горячих доков от 2026-09-16 (44a). Счётчик сейчас = 10 =
порог, сессия закрытия FAQ объявлена — правило будет исполняться немедленно;
иначе дизайнер пишет чужой горячий док напрямую (два «единственных писателя»).

### Д3 (СРЕДНИЙ). Заменить фрагмент шага 1 про `docs/GD_PROMPT.md`

Было: «`docs/GD_PROMPT.md` (правила дизайна)».
Стало:

```
`docs/GD_PROMPT.md` (правила дизайна; читай только ради канонических
«Двенадцати инвариантов» — на них ссылаются GDD-доки по номерам, «Принятых
решений» и «Чего не делать»; рамку «без доступа к репозиторию» из его шапки
игнорируй — у тебя доступ есть, источник фактов — GDD-доки и
`DB.md`/`ARCHITECTURE.md`),
```

**Зачем:** GD_PROMPT.md — самодостаточный брифинг «для чистой сессии без доступа
к репозиторию», его шапка противоречит рабочему процессу дизайнера (у него
доступ есть, шаг 3 промта требует сверки с DB.md/ARCHITECTURE.md). Чтение нужно
(это единственный канонический источник «Двенадцати инвариантов»), но рамка
сбивает. Заодно дельта на `docs/INDEX.md` строка 85 (подпись GD_PROMPT.md →
«источник канонических инвариантов для @designer») — зона @dispatcher, сдана в
«Разнос по докам» (см. ниже).

### Д4 (СРЕДНИЙ). Заменить строку шага 2 «…релевантные спеки.»

Было: «2. Проверь текущее состояние: `99_roadmap.md` §99.2/§99.3, релевантные спеки.»

### Д5 (НИЗКИЙ). Заменить фрагмент «…коротко фиксируй в идее/спеке.» (строки 54–55)
