## Пожелание (создатель, 2026-09-17)

«Игроки оффлайн не должны показываться на карте» → после уточнения: **на карте
должны отображаться только игроки в полёте. То же касается и агентов.**

## Диагноз

`GET /api/players/positions` (`internal/handlers/players_positions.go`) отдаёт
**всех** пользователей с `current_world_id` — независимо от активности. Игрок,
залогинившийся неделю назад, до сих пор висит на карте точкой «в системе X».
Понятия «онлайн» в системе нет, и оно не нужно — замысел проще:

- показывать только корабли, которые **движутся** (в полёте);
- стоящие в системе (idle) — скрывать.

То же для NPC-агентов: `GET /api/npc/positions`
(`internal/handlers/npc_positions.go` → `internal/npc/position_cache.go`) отдаёт
всех агентов (idle и flying) — оставить только `Flying`.

## Решение (решения создателя 2026-09-17)

1. **Игроки:** в `PlayersPositions` отдавать только тех, у кого активный полёт
   (`travelManager.GetFlight(u.ID) != nil`). Позиция — уже интерполированная
   (ветка «в полёте»), статус в ответе всегда «в полёте». Ветка «в системе X»
   остаётся в коде нетронутой (хирургично: не трогаем то, что не сломано;
   недостижимая ветка — не мусор, убирать не просили).
2. **Агенты:** в `Positions` (или в фильтре видимости) оставлять только
   `Status == models.NPCAgentStatusFlying`.
3. **Админка (И7):** фильтр «только в полёте» применяется **ко всем ролям**
   одинаково (вариант a, решение создателя): admin/skycomposer тоже видят только
   летящих. Карта едина.
4. **Клиент:** правок не требует — рисует ровно то, что пришло с сервера
   (`map_render.js` по `state.playerPositions`, `npc_agents.js` по positions).

## ТЗ (для developer)

- `internal/handlers/players_positions.go`: в цикле по `users` — `continue`,
  если `h.travelManager.GetFlight(u.ID) == nil` (после проверки
  `u.ID == userID` / `CurrentWorldID == nil`; до расчёта координат). Для
  admin/skycomposer фильтр тот же (вариант a).
- `internal/handlers/npc_positions.go`: фильтр `Status == Flying` — до/вместе с
  фильтром радиуса для player, и безусловно для admin/skycomposer.
  Место фильтра — в `Positions` (общий для всех ролей) либо в
  `filterPositionsByVisibility` (только player) + отдельно для админов —
  решает developer, главное: **все роли получают только летящих**.
- Тесты: игрок без полёта не отдаётся / с полётом отдаётся (статус «в полёте»);
  агент idle скрыт / flying отдан; админ тоже видит только летящих.
- DoD: `go build ./...`, `go vet ./...`, `go test ./...` (локально без `-race`,
  решение создателя 2026-09-12).
