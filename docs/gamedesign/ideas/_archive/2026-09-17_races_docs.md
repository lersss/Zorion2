# Дописка доков по расам

**Дата:** 2026-09-17
**Пожелание:** Нужны художественные и научные описания на каждую расу (60 шт.)
**Приоритет:** Высокий
**Статус:** Готово (2026-09-17, гейт пройден, коммит eeb8696)

---

## Текущее состояние

В `docs/gamedesign/races/` 60 файлов по одной расе. У каждой есть базовый черновик:
- Кто это
- Происхождение (пусто — белое пятно)
- Как живут
- Характер
- Зачем (ниша)
- Сосуществование
- **Живость** (пусто — помечена как зона @writer)

## Что нужно

### 1. Художественное описание (@writer)
Заполнить секцию **«Живость»** для каждой расы:
- Короткий эпизод/мини-рассказ (абзац-два), передающий ощущение жизни расы
- Без игровых терминов и чисел баланса
- Бытовой язык, правдоподобие
- Место —.home-планета расы по умолчанию

### 2. Научное описание (@scientist)
Дополнить секции **«Кто это / Как живут / Сосуществование»**:
- Физика и биохимия (как именно работает жизнь)
- Экология (ниша, энергетика, взаимодействие со средой)
- Оценки по времени (эволюция, цивилизация)
- Честная физика без «игровой абстракции»

## Подход

60 рас —巨大ный объём. Запускать батчами по 10 рас параллельно (@writer + @scientist на каждый батч).

## Критерий успеха

- У каждой из 60 рас заполнена секция «Живость»
- У каждой из 60 рас дополнены секции «Кто это / Как живут / Сосуществование» фактами
- Описания не дублируют друг друга, передают уникальность расы
