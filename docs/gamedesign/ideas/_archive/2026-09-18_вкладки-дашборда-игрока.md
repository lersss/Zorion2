## Компоновка (решение создателя 2026-09-18: «ок, делаем» — вариант 2)

**Шапка — всегда видима (каркас):** карточка «Ваш агент» — имя, корабль-превью,
текущий мир, статус полёта, кнопки «Контракты / Карта миров / Выйти».
Навигация и статус полёта не прячутся.

**Таб-бар под шапкой — 4 вкладки:**

1. **🛸 Корабль** — оборудование (91a): силуэт со слотами (радар/сканер/двигатель)
   + сводные характеристики. Целиком как есть.
2. **🎨 Внешний вид** — селектор (61b): сетка 21 спрайта + палитра 9 цветов
   + «Оригинал» (NULL) + статус сохранения. Целиком как есть, палитра
   переносится без изменений (включая обязательный «Оригинал», 61b §5.5).
3. **📊 Статистика** — миры посещены, полёты, «открыто X из Y» + заметка про
   журнал открытий (86a).
4. **📖 Энциклопедия** — разделы рас/звёзд/планет/ресурсов/кораблей/лор-терминов
   (86a).

**Паттерн:** как в админке (`.tab-btn`/`.tab-pane`, `tabs.js`), стиль — в тон
дашборда (инлайн CSS в `index.html`, тёмная тема). Активная вкладка — в
localStorage, **ключ `dashboardActiveTab`** (не пересекается с `adminActiveTab`,
`token`, `shipIcon`/`shipColor`, `zorion.journal`). Дефолт при первом заходе —
«Корабль»; сохранённый id панели не найден — fallback на «Корабль».

**Явное решение создателя (2026-09-18):** селектор 61b получает **свою вкладку**,
а не встраивается в раздел 91a. Это осознанное уточнение прежнего решения
«61b не переносится, легаси в стороне» (91a §3.3/И5, 86a §4.4): селектор по-прежнему
НЕ встроен в раздел «Корабль», но переезжает в собственную вкладку дашборда —
по явному «ок» создателя.
