**Статус:** Готово (2026-09-15). Подтверждение создателя: «ок». Вердикт @tester: ПРОЙДЕНО.

## Сырое пожелание (создатель, 2026-09-15)

> «Не могу поменять вес черной дыры в типах систем. При нажатии "сохранить
> конфиг" — никакой реакции. В логах: generation.js:809 Uncaught (in promise)
> TypeError: Cannot read properties of null (reading 'value') at
> saveGenConfig (generation.js:808:18) ... Плюс если сохранить конфиг работает
> на все блоки, надо это как-то подсветить, он сейчас внутри блока "среднее
> количество планет"»

## Диагностика (менеджер, факты)

- Стек: `saveGenConfig` (generation.js:808-809) — цикл `SYSTEM_TYPES` читает
  `document.getElementById(stId(key)).value` без null-проверки (строка 809).
  При отсутствии элемента — `TypeError`, выбрасывается ДО `try` (сборка body
  на стр. 803-825 вне try) → кнопка молчит, сообщения «❌» нет.
- Это ровно та ловушка, что отметил @tester после фикса 39a: в
  `recalcGenWeights` null-проверки добавлены, в `saveGenConfig` — нет.
- **Корень бага (нашёл @tester в первом прогоне):** `stId` в
  `generation.js:707-709` НЕ конвертирует snake_case в camelCase (в отличие от
  `mrId`/`pmId`): `stId('black_hole')` → `stBlack_hole`, а в DOM —
  `stBlackHole`; `stId('white_dwarf')` → `stWhite_dwarf`, а в DOM —
  `stWhiteDwarf`. Последствия: `loadGenConfig` не заполняет ЧД/белый карлик,
  `recalcGenWeights` не считает их проценты, `saveGenConfig` находил null →
  падение (39c), после null-фикса — молчаливый 0. Проверено на свежей отдаче
  сервера: `stBlack_hole` = 0 вхождений, `stBlackHole` = 2. Гипотеза «старая
  вкладка» (стр. ниже) НЕ подтвердилась — баг воспроизводится на свежей
  странице.
- Причина отсутствия `stBlackHole` в DOM у создателя уточняется (гипотеза:
  давно открытая вкладка со старой версией страницы; на отдаваемом сервером
  `/admin` все 8 элементов `st*` присутствуют, дубликатов id нет — проверено).
- Незащищённые чтения в `saveGenConfig`: `spectral` (sw*), `system_types`
  (st*), `planet_means` (pm*), `stellar_mass_ranges` (mr*_min/max). Всего
  4 цикла.
- UX: кнопки «💾 Сохранить конфиг» / «🔄 Перечитать» физически находятся в
  карточке «Среднее количество планет» (admin.html стр. 201-205), хотя
  сохраняют весь конфиг генерации (веса + средние + массы). Подсказки в
  других карточках («Сохранение — кнопкой "Сохранить конфиг" ниже/выше»)
  недостаточно заметны.

## ТЗ

1. **JS (`web/static/js/admin/generation.js`, `saveGenConfig`):** добавить
   null-проверки во все 4 цикла чтения (по образцу фикса 39a и `loadGenConfig`):
   отсутствующий элемент = 0 для весов/средних; для диапазонов массы — пропуск
   пары, если нет min или max. Хирургически, больше ничего не менять.
2. **UX (admin.html, после согласования с создателем):** подсветить, что
   кнопка общая для всех блоков (см. «Решение по UX» ниже).

## Критерии готовности

- `saveGenConfig` не падает при отсутствии любого элемента из четырёх разделов
  (smoke-тест с заглушкой document).
- При всех существующих элементах поведение не меняется (сохраняется весь
  конфиг).
- `node --check web/static/js/admin/generation.js` — зелёный.
- Go не менялся → DoD `go build/vet/test` не требуется.

## Реализация (2026-09-15)

1. **JS** (`web/static/js/admin/generation.js`, `saveGenConfig`): все 4 цикла
   чтения обёрнуты в null-проверки по образцу 39a: отсутствующий элемент = 0
   для весов/средних; для диапазонов массы — пара пропускается, если нет min
   или max. `node --check` — зелёный.
2. **JS корень** (`stId`, генерация.js): добавлена конвертация snake_case →
   camelCase как в `mrId`/`pmId` — `stId('black_hole')` теперь `stBlackHole`.
   Чинит заполнение/проценты/сохранение весов ЧД и белого карлика во всех трёх
   местах (loadGenConfig, recalcGenWeights, saveGenConfig). Все 8 ключей
   SYSTEM_TYPES проверены скриптом.
3. **HTML UX** (`web/admin.html`): карточки «Веса спектральных классов»,
   «Веса типов систем/объектов», «Среднее количество планет», «Масса звёзд»
   объединены в общий блок `<div class="card gen-config">⚙️ Конфиг генерации`
   с подписью; кнопки «💾 Сохранить конфиг» / «🔄 Перечитать» и
   `genConfigResult` перенесены из карточки планет вниз общего блока; в
   карточке планет вместо кнопок — подсказка; подсказки в карточках весов и
   массы обновлены («кнопка внизу общего блока»). Баланс div: 228/228.
4. **CSS** (`web/static/css/admin.css`): `.gen-config` — рамка поярче
   (2px #3d3d6e), вложенные `.card` чуть темнее (#16162a).
