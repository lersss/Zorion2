## Сырое пожелание (создатель, 2026-09-17)

> «В разделе „Генерация" внутренние разделы не дропдауном, а подвкладками сделать.»

Уточнения: нет — пожелание чёткое, косметика. Все 6 подразделов (Звёзды, Планеты,
Поселения, Гипотезы, NPC-агенты, Фракции) — кнопками-подвкладками в стиле верхних
табов админки (`.admin-tabs`). Сохранение выбранной подвкладки между сессиями
(localStorage `adminGenSubTab`) — сохраняем как есть.

## Факты из кода (менеджер, проверено 2026-09-17)

- `web/admin.html` стр. 57–75: вкладка `#tab-generation`, переключение подразделов —
  `<select id="genSubTab" onchange="switchGenSubTab()">` (дропдаун, опции
  stars/planets/settlements/hypothesis/npc/factions).
- `web/static/js/admin/generation.js` стр. 368–395: `switchGenSubTab()` читает
  значение селекта и скрывает/показывает `#tab-generation .gen-sub` блоки
  (`genSub-<name>`), при `stars` — `loadGenConfig()`; `applyGenSubTab()` —
  восстановление сохранённой подвкладки из localStorage (вызывается из
  `tabs.js` при активации вкладки).
- Стиль кнопок-табов уже есть: `web/static/css/admin.css` стр. 642–675
  (`.admin-tabs button`, `.active`, hover, медиа-запрос flex). Переиспользуем.
- Больше нигде `genSubTab` не используется (grep по html/js подтвердил).
- Спека `docs/specs/99.2.3-generation-tuning.md` §2 фиксирует «подвкладки-дропдаун»
  — после правки дельта в спеку/горячие доки (см. «Разнос по докам»).

## ТЗ

1. **admin.html**: заменить карточку с дропдауном (стр. 60–75) на
   `<div class="admin-tabs gen-subtabs">` с кнопками
   `<button class="gen-subtab-btn" data-gen-sub="<name>" onclick="switchGenSubTab('<name>')">`
   (Звёзды/Планеты/Поселения/Гипотезы/NPC-агенты/Фракции). У кнопки stars —
   класс `active` как дефолт.
2. **generation.js**: `switchGenSubTab(name)` — принимает имя подвкладки явно
   (без аргумента — восстановление из localStorage), переключает `.gen-sub`
   блоки и класс `active` у кнопок (`b.dataset.genSub === target`), при
   `stars` — `loadGenConfig()`, сохраняет в localStorage. `applyGenSubTab()`
   вызывает `switchGenSubTab()` без аргумента.
3. **admin.css**: `.gen-subtabs { margin-bottom: 0; }` (переиспользуем стили
   `.admin-tabs`, у которого margin-bottom 16px — для карточки много).
4. Бэкенд/Go/БД не трогаем; статика с диска noCache — рестарт не нужен.

## Критерии готовности

- В разделе «Генерация» вместо дропдауна — ряд кнопок-подвкладок в стиле верхних
  табов; активная подсвечена.
- Клик по кнопке показывает соответствующий блок (Звёзды/Планеты/Поселения/
  Гипотезы/NPC/Фракции), выбранная подвкладка сохраняется и восстанавливается
  при повторном открытии вкладки.
- `node --check` изменённых JS + визуальная проверка @tester.

## Маршрут

Мелкая правка (косметика UI, без новых сущностей/чисел/API) → менеджер делает
сам, DoD + @tester, один гейт создателю, коммит менеджером после «го».

**Выполнено (2026-09-17):** менеджер сделал сам (мелкая правка, «ок» создателя
получено). Код: `web/admin.html` — дропдаун заменён на ряд кнопок
(`.admin-tabs.gen-subtabs` + `.gen-subtab-btn`, data-gen-sub, inline onclick);
`generation.js` — `switchGenSubTab(name)` принимает имя явно, подсвечивает
активную кнопку, выбор в localStorage (`adminGenSubTab`), при stars —
`loadGenConfig()`; `applyGenSubTab()` без аргументов (совместимо с tabs.js);
`admin.css` — только `.gen-subtabs { margin-bottom: 0 }` (переиспользуют
`.admin-tabs`); `tabs.js` — обновлён комментарий. DoD (build/vet/test, node

noCache, остатков дропдауна нет; визуал в браузере — на создателе). Go/БД/API
не тронуты, рестарт сервера не нужен.
