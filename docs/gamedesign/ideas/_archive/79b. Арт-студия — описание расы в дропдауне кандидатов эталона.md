## Решения менеджера (проверено и решено самостоятельно — мелкая фича/UX)

1. **Источник описания:** **полный лор расы** из `docs/gamedesign/races/<slug>.md`
   (уточнение создателя 2026-09-17: «нужна полная лорная информация по расе,
   чтобы выбрать для нее эталон. Сейчас просто мини-строка, мало инфы»).
   `basis` (короткая строка) — только фолбек, если файл/слаг не найден.
   Маппинг арт-id («51») → slug (`archivists`) — через `config/races.json`
   (имя расы из families.json без числового префикса ↔ `name` в races.json).
   Лор остаётся в одном месте (`docs/gamedesign/races/*.md`), студия его
   **читает**, не копирует.
5. **Состав лора в тултипе (анализ менеджера 2026-09-17, уточнение создателя**
   **«только лор + внешний вид + повадки»):** структура всех 60 файлов едина —
   7 секций (`Кто это / Происхождение / Как живут / Характер / Зачем (ниша) /
   Сосуществование / Живость`); механик/окон/атрибутов в файлах нет (они в
   config/races.json). Лишнее в тултипе — научно-числовые абзацы (вторые) внутри
   секций и шапка-метаданные. Правило отбора:
   - `Кто это`, `Как живут`, `Сосуществование` — только **первый абзац** секции;
   - `Живость` — **целиком** (Сцена = внешний вид, Суть = повадки/сущность);
   - `Происхождение`, `Характер`, `Зачем (ниша)` — целиком;
   - шапку (заголовок, `**Семейство:**`/`**ID:**`/`**Основа:**`) — убрать;
   - заголовки секций оставить читаемыми (навигация в скролл-панели).
2. **Область:** только дропдаун на карточках кандидатов вкладки «Эталон»
   (рядом с кнопкой «Эталон», `select#raceSel-<file>`), как просил создатель.
   Остальные селекты студии не трогаем (при желании расширим позже).
3. **Тултип не перекрывает список:** нативный `<select>` не умеет тултипы по
   пунктам (и подсказка поверх списка блокирует клики) → на карточках кандидатов
   ставим **кастомный дропдаун**: пункты списком; при наведении на пункт описание
   показывается в **отдельной панели подсказки сбоку/внизу карточки**, не поверх
   списка; список остаётся полностью кликабельным.
4. **Позиция подсказки (уточнение создателя 2026-09-17):** подсказка должна
   открываться **рядом с дропдауном, плавающей, поверх всего** (НЕ в потоке
   карточки под кнопками — первая версия открывалась «под дропдауном», что
   неудобно). Итоговое требование: плавающий тултип **сбоку от раскрытого
   списка** (по умолчанию справа, у правого края экрана — слева), высокий
   z-index (поверх карточек/изображений), **не пересекает сам список** (смещение
   ≥8px), показывается при наведении на пункт, скрывается при уходе/закрытии.

## Что проверено менеджером (факты)

- `/ref` (вкладка «Эталон») возвращает `raceStatus`, `raceOptions` (HTML строки
  `<option value=...>имя</option>`), `cands`. Карточка кандидата в
  `index.html` (~строки 425–451): `<img>` + `<select id="raceSel-<file>">${j.raceOptions}</select>`
  + кнопка «Эталон» (`setRef`).
- Дифф-рендер авто-обновления (3 с) сохраняет выбор: читает `select[id^="raceSel-"]`,
  восстанавливает значения — при замене на кастомный дропдаун это поведение
  сохранить (значение `raceSel-<file>` не должно сбрасываться).

## ТЗ (зона @developer)

1. **Backend:** новый эндпоинт `GET /race-info?fam=<F>&race=<id>` → JSON
   `{race, name, basis, lore}`: `lore` — полный текст
   `docs/gamedesign/races/<slug>.md` (маппинг арт-id → slug: при старте читать
   `config/races.json`, построить name→slug; имя расы из families.json без
   числового префикса «NN »); если слаг/файл не найден — `lore = basis`
   (фолбек). Текст можно слегка почистить от markdown-маркеров (`#`, `**`),
   заголовки секций оставить читаемыми.
2. **Frontend:** на карточках кандидатов вкладки «Эталон» нативный select →
   кастомный дропдаун:
   - пункты списком (div), выбор работает как раньше (значение сохраняется в
     `raceSel-<file>`, подсветка «у расы есть эталон», `setRef`);
   - при наведении на пункт — **полный лор** расы в **большой плавающей панели**
     **сбоку от списка** (ширина ~400px, max-height ~60vh, `overflow-y:auto`),
     z-index высокий, **не пересекает сам список**; панель **интерактивна**
     (можно скроллить/читать — `pointer-events:auto`), остаётся открытой, пока
     курсор на списке или панели; скрывается при уходе с обоих или закрытии
     списка;
   - фетч лора — по требованию при наведении, с кэшем по расе (не дёргать
     эндпоинт на каждое наведение);
   - авто-обновление не сбрасывает выбранный пункт (дифф-рендер сохранён).
3. **Тест:** DoD `go build/vet/test`; юнит-тест маппинга арт-id → slug
   (несколько рас F2–F10) и фолбека на `basis`.
