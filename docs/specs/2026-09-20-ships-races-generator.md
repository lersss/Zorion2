## 1. Цель и скоуп

**Генератор спрайтов кораблей рас в арт-студии** — отдельная вкладка «Корабли рас» в работающей Go-студии (`cmd/art-studio`). Входные данные **готовы** — `docs/gamedesign/races/ships/<id>.md` (60 файлов): поле `silhouette` (ТЗ на силуэт) → скрипт-генератор силуэтов → ControlNet Canny + img2img; `texture` (англ. промпт-фраза) → этап 2 детализации SDXL; `blocked` (теги-запреты) → фильтрация словарей (аналог 98a). Пайплайн — существующий `art_ships.md` (форма = силуэт, промпт = текстура). Отбор создателем пачками (как 29a).

**Решения создателя (раунды 1–2, 2026-09-20) — учтены:**
1. Отдельная вкладка «Корабли рас» в арт-студии (Go, отдельный инструмент, не переработка race-генератора); панель промпта 98b (tags/override).
2. Силуэты — скрипт-генератор из поля `silhouette` (как `make_race_silhouettes*.py` у рас), НЕ ручная отрисовка.
3. 3 кандидата на расу, отбор.
4. Хранилище: `ai_drafts/final_accepted/` — почистить 21 корабельный legacy (anchor…volcano); расовые корабли — в отдельную подпапку `ships/`; аватары людей/рас (race_*.png, папки F2/F3/F8, anim/, preview_humans/) НЕ трогаем; рантайм/агентов НЕ трогаем.
5. Пилот: люди + 6 рас внешности (coastal, methane_plankton, deep_dwellers, cryo_swarms, mist_swarms, saltfolk) → все 60; отбор пачками (пачка 10 → номера).
6. Кабины — НЕ в этом релизе («давай сначала корабль»); зафиксировать точку проноса выбранной кабины в генератор по расам как задел (§7).

**В скоупе:** спека (конвейер, конфиги, хранилище, UI, пилот/пачки, инварианты). Код Go, Python-скрипт силуэтов, конфиги, UI — зона @developer (этап разработки по этой спеке).

**НЕ в скоупе (границы — §13):** кабины (задел §7); рантайм/агенты (`spriteForAgent`, `web/static/sprites/`, `internal/models/ship_sprites.go`); 21 спрайт — легаси; `config/races.json`/`race_lore.json`; энциклопедия 86a; механика «связь с кораблём» (кандидат); словарь концептов `art_ships.md` §6 (для 21 спрайта, не расширяем).

**Природа сущностей (разбор по PITFALLS «событие vs лог», до ТЗ):**
- `config/art/ships.json` — **конфиг-проекция** (kind=duplicates) лор-файлов `races/ships/*.md`, как `families.json` ↔ `races/*.md` (98a). Не событие, не лог. Владелец: 60 рас — карта `slug → запись`; 61-я раса = новый файл + пересборка. Расширяемость: схема переживает второй тип (кабина — НЕ в этой схеме, отдельный будущий конфиг, §7).

## 3. Конвейер генерации

### 3.1. Силуэт: `silhouette`-ТЗ → скрипт-генератор

**Скрипт:** `tools/make_ship_silhouettes.py` (Python, как `make_race_silhouettes*.py`; запускается Go-студией как подпроцесс — паттерн rembg, 67a.1 §7.1). Вход: `config/art/ships.json` (поле `silhouette`) + `config/art/ship_dict.json` (словарь форм). Выход: `ai_drafts/ships_pool/silhouettes/<slug>.png` — холст **1024×1024**, фон чёрный `(5,5,5)`, вид сверху, **нос вправо**, запас ~90 px (масштаб до ~82% + центрирование), палитра модулей art_ships §2.1, границы-линии `(12,12,12)` между модулями.

**Парсер ТЗ** (структура `silhouette` единообразна — форма в плане, нос/корма, детали, «модули: …», асимметрия, «запас от краёв ~90 px»):
1. **Форма** — первое ключевое слово из `ship_dict.forms` (крыло, баржа, капсула, тигель, оболочка, сосуд, склянка, капля, клин, диск, кольцо, шар, рой…). Не найдено → фолбек `capsule` + warning в лог.
2. **Модули** — секция «модули: …» (до «асимметрия»/«запас»): пары `<имя> <цвет>` через запятую. Тип модуля — по ключевым словам (корпус, крылья/стабилизаторы, хвост/оперение, дюзы/сопла, кабина/капюшон/кромка/стекло/линза/датчик/глаз/накопитель/ядро/светл*, свечение/прожилки/пятна/расплав, сваи/опоры, щупальца/антенны, паруса/реснички, жабры, каналы, пузыри, шлейфы). Неизвестный модуль → пропускается + warning.
3. **Детали** — остальной текст ТЗ: слова из `ship_dict.details` (щупальца, сваи, оперение, паруса, каналы, пузыри, жабры, шлейфы, прожилки, пятна, стабилизаторы) → идут в промпт этапа 1 (§3.2).
4. **Ориентация** — «нос справа, корма слева» по построению (форма рисуется носом вправо); «нос = светлая секция» (кабина/линза/датчик/глаз/накопитель/ядро/светл* — Миры-машины «датчиковая линза-глаз», эхо чужих «светлая гранёная секция-накопитель», магнетофаги «ядро-ловушка») → светлый модуль справа.

**Библиотека форм** (Python-функции, параметрические: длина/ширина/скругление/сужение): `wing, capsule, barge, crucible, envelope, vessel, flask, drop, wedge, disc, ring, sphere, swarm` (13 шт). Покрывают формы пилота: крыло (humans), баржа (coastal), капсула (cryo_swarms, methane_plankton), тигель (saltfolk), оболочка (mist_swarms). Округлый мягкий корпус глубинников (deep_dwellers) — слова «капсула» в ТЗ нет → фолбек-капсула + warning парсера (M1). Баржа пепельных (ashfolk) — вне пилота, добивается итеративно после пилота. Непокрытые формы 60 рас — итеративная доводка: после пилота **инвентаризация непокрытых форм по всем 60 ТЗ** (прогон парсера → список рас, ушедших в фолбек-капсулу), добор функций в библиотеку итеративно; правка ТЗ не требуется (C4.3).

**Модули-примитивы** (поверх формы, контрастные цвета art_ships §2.1): корпус = форма (крем `(232,224,186)`); крылья = сталь `(120,140,170)` полигоны по бокам; хвост/оперение = бронза `(140,90,45)` или бело-голубое (кабина-цвет) слева; дюзы = тёмные `(40,44,55)` блоки слева; кабина/капюшон/кромка = светлая `(180,210,235)` справа; свечение = огонь `(230,120,40)` (тёплые слова ТЗ: оранжев*/янтарн*/угольн*/расплав* — стемминг по корню, падежные формы покрываются: жёлтые/жёлтый, янтарные/янтарный) или голубое `(120,220,235)` (холодные: голуб*/сине-зелён*/бледн*/ледян*); непокрытый цвет → фолбек нейтральный тёплый (огонь) по умолчанию (M2); сваи/щупальца/паруса/жабры = сталь/бронза линии и дуги; каналы/прожилки/пятна = огонь/голубое линии и точки. **Точные цвета ТЗ в силуэт НЕ переносятся** (они уходят в `texture`, этап 2) — силуэт про форму и контраст модулей (art_ships §3.6).

**FIRE-модуль** (огонь/свечение) рисуется **только если** в ТЗ явно указано тёплое свечение (расплав*, уголь*, янтар*, огонь* — стемминг, как в словаре цвета выше) — иначе дюзы тёмные без свечения (art_ships §3.4: «убрать FIRE из силуэта — надёжно»). Пост-фикс оранжевых пикселей (art_ships §3.4) — опция, по умолчанию выключена (у солевых/пепельных оранжевый — суть).

### 3.2. Промпт этапа 1 (форма, ControlNet Canny + img2img)

**Workflow `ShipStage1Workflow`** (новый, `comfy/workflow.go`): LoadImage(силуэт) → Canny (low 0.2 / high 0.5) → ControlNetApplyAdvanced (strength **1.5**, start 0.0, end 1.0) + VAEEncode(силуэт) → KSampler (denoise **0.85**, steps **40**, cfg **7.0**, dpmpp_2m/karras) → VAEDecode → SaveImage (raw этапа 1). Параметры — art_ships §2.2.

**Промпт (BuildShipPrompt1):**
```
{concept}, {details}, top-down flat view, horizontal, nose pointing FORWARD to the right,
engine at the LEFT rear, perfectly flat, no perspective, game asset, 2D sprite, centered,
single ship, on black background, no text, no watermark
```
- `{concept}` — английское концепт-слово формы из `ship_dict.forms[form].concept` (напр. «wing-shaped hull», «barge», «capsule», «crucible», «envelope»). Форма фиксирована лором расы — концепт не выбирается из словаря art_ships §6 (тот — для 21 спрайта, не расширяем).
- `{details}` — 2–3 случайные детали из извлечённых (§3.1 п.3), маппинг `ship_dict.details` (русское → англ. фраза), **отфильтрованные по `blocked`** (§3.4); пусто → не добавляется.
- Ориентационный хвост — дословно art_ships §2.2.
- `tags` (98b) — в конец, перед «no text, no watermark».

### 3.3. Промпт этапа 2 (текстура, img2img без ControlNet)

**Workflow `ShipStage2Workflow`** (новый; img2img от raw этапа 1): LoadImage → VAEEncode → KSampler (denoise **0.45–0.55**, steps **40**, cfg **7.5**, dpmpp_2m/karras) → VAEDecode → SaveImage (raw этапа 2). Параметры — art_ships §2.3.

**Промпт (BuildShipPrompt2):**
```
{texture расы}, {texture-теги}, maximal detail, masterpiece, no text, no watermark
```
- `{texture расы}` — поле `texture` из `ships.json` (дословно).
- `{texture-теги}` — 2–3 случайных тега из `ship_dict.textures`, **отфильтрованных по `blocked` и `blocked_by`** (§3.4); теги делятся на тёплые/нейтральные/холодные (`warmth`); **тёплые теги включаются ТОЛЬКО если в `texture` расы есть тёплое слово** из `ship_dict.warm_markers` (substring, регистронезависимо; у людей texture = «cold engine glow, no bioluminescence» → тёплые теги не попадают); пусто → не добавляется.
- **«no orange, no flames» и «neutral engine nozzles» НЕ включаются глобально** (развилка 2): оранжевый расплав солевых/угольное свечение пепельных — суть; убирается через отсутствие FIRE в силуэте (§3.1), `blocked`/`blocked_by` (§3.4) и правило тёплых тегов выше (C2).

### 3.4. `blocked` → фильтрация словарей (аналог 98a §5.1)

- Переиспользуется `filterPool` (98a §5.1: подстрока, регистронезависимо; пустой `blocked` → пул без изменений).
- **Фильтруются:** (а) детали этапа 1 (§3.2), (б) текстурные теги этапа 2 (§3.3) — по `blocked` и по `blocked_by` тега: тег исключается, если любой токен из его `blocked_by` присутствует в `blocked` расы (substring, регистронезависимо; простое правило — только по `blocked`, без проверки silhouette/«Чего НЕТ»). Фолбек: пул пуст после фильтрации → исходный пул (98a §5.2 п.1) / элемент не добавляется.
- **Не фильтруются:** `texture` расы (курируется контентмейкером, как `forms/materials/glows` — 98a §4.2), концепт формы (фиксирован лором), ориентационный хвост.
- **Кросс-конфиг-тест — мягкий** (развилка 5): каждый токен `blocked` всех 60 рас проверяется на совпадение со словарями `ship_dict.json` (details/textures); токен без совпадений → **warning в лог и в UI-отчёт** («неработающие токены»), не ошибка. Токены писались до словарей — жёсткий тест (98a §5.6) упадёт массово; после пилота, когда словари устоятся, — решение об ужесточении на гейте.

### 3.5. Пост-обработка

Вызов `tools/process_ship.py` (Python-подпроцесс, паттерн rembg; уже проверен, art_ships §2.4): вырез фона **по цвету** (BG_TOL 40), крупнейший связный компонент, сглаживание, кадрирование + паддинг 6 px, вписывание в **200×200** (ImageOps.pad, центрирование), нормализация ориентации (нос вправо). Выход — прозрачный PNG в пул.

### 4.1. `config/art/ships.json` — проекция `races/ships/*.md` (реестр 60)

```json
{
  "humans": {

    "blocked": ["tentacle", "organic", "crystal", "pyramid", "obelisk", "bioluminescent", "alien"]

```
