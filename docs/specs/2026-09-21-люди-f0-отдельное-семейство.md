## 1. Резюме

Доделать перенос людей в отдельное семейство **F0 «Люди»** во всей системе (сейчас F0 сделан только в арт-студии: `config/art/humans.json`, пути `race_f0_humans_*`). Правка — **метка классификации + данные + валидация + UI-списки + доки**; новых сущностей/таблиц/миграций нет, чисел баланса нет, рефакторинга нет.

**Что подтверждено безопасным (не трогаем):** `card_hash`/R-кривые (спец-случай humans — по `race_id`, не по family), смертность, `HumansSuitable`, выбор спавн-мира — **от family не зависят**; `validateRaceFamily` берёт family из лора → F0 заработает сам после правки `race_lore.json`; `config/art/families.json` F1 уже = расы 2–4 (без людей) — перенос **разрешает** старое расхождение лора и арта (вердикт @critic §2a).

**Канон:** было 9 биосемейств F1–F9 + «роботы»; становится **10 биосемейств F0–F9 + роботы**. Люди — раса №1 = единственная раса F0. F1 «Водные» становится **чисто водным** семейством (расы 2–4: Океаниды, Глубинники, Прибрежные). Это **переопределение прежнего ответа создателя 2026-09-16** («Результат — 9 семейств (F1–F9)», `22_races.md` §7) — на гейт (§9, S1).

**Роботы — не в объёме:** код `robotic`, UI «F10 Роботы». Не меняется; в списках сохраняется порядок и подписи.
