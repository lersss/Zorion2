## §A.1. Потребители легаси-блока (чек-лист подэтапа П4)

**Сервер:**
- `cmd/server/bootstrap.go` — корабль при регистрации (`RandomShipForRace`, §6.5).
- `internal/handlers/auth_handlers.go` — `/me` (`ResolveShipIcon` + `ship_options`),
  `PUT /me/ship-icon` (валидация), регистрация.
- `internal/handlers/admin_users.go` — создание игрока админом, `/admin/users`
  (отдаёт `ResolveShipIcon`).

  высадки.
- `internal/models/ship_sprites.go` — сам легаси-блок (`ShipSprites`, `LegacyShipIconMap`,
  `DefaultShipIcon`).
- `internal/repository/user_repository.go` — `userSelect` (`:388`, полный SELECT-список, из
  него же `GetByID` `:115`); **захардкоженный список колонок `users` живёт в

  (`:219`, под `GetByIDWithPosition`) правятся вместе с колонками** (+`race_id` — П1).

  короткий список `id, username, ship_icon, ship_color, current_world_id, role,
  current_position`).

`NOT NULL` + новый `DEFAULT` (иначе новые игроки получают легаси-имя).

## §A.2. Рёбра impact map (переносит @manager)

**Новые узлы (N9 — заводить; в реестре их нет, проверено 2026-09-23):**
`npc_agents.race_id` (table), `users.race_id` (table), `users.ship_icon` (table — миграция +
смена семантики), `ship_options` (mechanic/api — транспорт реестра), `npc_agents` (table —
узел таблицы), `race_ship_registry` (mechanic — расовый реестр + `spriteForAgent`),
`agent_origin` (mechanic — раса → родной мир). Узлы `users.ship_icon`, `ship_options`,
`npc_agents` в `docs/impact_map.json` **отсутствуют** — их не «обновить», а завести.

**Рёбра:**

- `npc_agents.race_id` → `internal/repository/npc_repository.go` (4 точки: SELECT-список
  `npcAgentColumns`, `scanNPCAgent`, `INSERT`, `pq.CopyIn` в `BulkInsert`),
  `internal/models/npc_agent.go`, `internal/npc/position_cache.go`,
  `internal/handlers/npc_positions.go`, `internal/handlers/admin_npc.go`.
- `users.race_id` → `internal/repository/user_repository.go` (`userSelect`/`scanUser`,
  `GetByIDWithPosition`/`scanUserWithPosition`),

- `users.ship_icon` → `internal/repository/user_repository.go` (`userSelect`, `GetByID`,
  `GetByIDWithPosition`/`scanUserWithPosition`, `PlayerPositions`), `internal/handlers/auth_handlers.go` (`/me`, `PUT /me/ship-icon`),
  `internal/handlers/players_positions.go`, `internal/handlers/surface_handlers.go`,
