**Что это значит.** Диапазоны **не пересекаются по смыслу**: «кто верхний»
решается случайными числами, а не ролью. Порядок закрытия (Esc / клик вне) не
знает о стеке: Esc с открытым меню поверх модалки закроет **модалку** (единственный
Esc-слушатель — у неё). Ловушки фокуса и блокировки прокрутки нет нигде. Это и
есть корень бага пояса (осн. §6.2): отказ сервера показывается **страницей**
(belt.html `#error`, UI §5.3), а не слоем над модалкой — контекст теряется.

**Что уже хорошо (не ломаем):** модалка системы умеет клик-вне и Esc; меню ПКМ
закрываются по `mousedown` вне; тосты и баннер пакмана самодостаточны; страничные
оверлеи belt/surface (`#error`/`#pause`/`#loading`) — правильный паттерн для
**своего** экрана (под ними нет другого контекста).

## 1. Модель слоёв: единый реестр полос

Один модуль-владелец `z-index` для попапов — **`web/static/js/ui/layers.js`**.
`z-index` больше **не пишется в разметке/файлах попапов**: его выдаёт реестр.

**Полосы (bands).** Понятная роль вместо числа. Внутри полосы порядок — по
порядку открытия (шаг 10), поэтому попапы одного типа корректно ложатся друг на
друга.

| Полоса | База | Роль | Кто в ней |
|---|---|---|---|
| `modal` | **1000** | диалоговый слой | модалка системы, диалоги/попапы форм, карточки-попапы (студии — позже) |
| `menu` | **1100** | транзиентные меню/подсказки | контекстные меню (карта, модалка, студия), тултипы (звезда, координаты, NPC), дропдаун поиска NPC |
| `banner` | **1200** | глобальные баннеры/пиллы | баннер пакмана, «Галактика пуста», offline-пилл (позже) |
| `alert` | **2000** | **ошибка/предупреждение/подтверждение поверх всего** | `openAlert`/`openConfirm` (новое) |
| `system` | **9000** | критические полноэкранные | вход в админку/студию, «сессия истекла» (позже) |
| `toast` | **10000** | уведомления | тосты (`ui/toast.js`) |

**Инварианты модели:**
- `alert` (2000) **выше любого легаси-попапа** (легаси ≤ 1300) — ошибка поверх
  модалки работает **даже до перевода** модалки/меню на реестр.
- `toast` (10000) остаётся **самым верхним** и **не участвует** в Esc/клик-вне/фокусе
  (уведомление, а не диалог) — поведение тостов не меняется.
- Хром страницы (`map.css` 10–60, шапки/зум/панели) — **не попап**: реестр его не
  трогает, значения остаются.
- Страничные оверлеи belt/surface (`#error`/`#pause`/`#loading`) — **не попапы**:
  это состояния **своей** страницы, под ними нет другого контекста. Остаются как
  есть; реестр их не касается.

**Кто верхний.** Реестр держит массив открытых слоёв (`stack`). Верхний — последний
открытый. `z` слоя = база его полосы + `10 · (число уже открытых слоёв этой полосы)`.
Упорядочивание между полосами задано таблицей, внутри полосы — открытием.

## 2. Контракт (API модуля `ui/layers.js`)

> Имена и сигнатуры — предложение @uidesigner; точная реализация — зона
> @developer. Смысл контракта обязателен.

```js
// Открыть слой. el — уже смонтированный в DOM корень попапа.
openLayer(el, {
  level,            // 'modal' | 'menu' | 'banner' | 'alert' | 'system' | 'toast'
  closeOnEsc = (level !== 'toast' && level !== 'banner'),
  closeOnOutside = (level === 'menu' || level === 'modal'),
  trapFocus = (level === 'modal' || level === 'alert' || level === 'system'),
  lockScroll = false,
  onClose,          // вызвать ОДИН раз при любом закрытии (чистка попапа)
}) -> handle        // { el, level, close(result), result }

handle.close(result)        // закрыть этот слой (результат доступен в onClose)
closeTop(reason)            // закрыть только верхний (Esc/клик вне)
closeToLayer(handle|level, {inclusive=false})  // «закрыть всё до уровня/слоя»
closeAll(level?)            // всё (или всю полосу) — навигация/разлогин
hasOpen() / topLayer()      // состояние стека

// Готовые диалоги поверх контекста (полоса alert):
openAlert({ title, text, actions = [{id:'ok', label:'Понятно', primary:true}] })
  -> Promise<actionId>      // возврат результата выбора
openConfirm({ title, text, confirmLabel='ОК', cancelLabel='Отмена' })
  -> Promise<boolean>
```

**Правила контракта:**
- **Владелец закрытия — реестр.** Попап **не вешает** собственный Esc/outside —
  иначе двойное закрытие (см. риск §8.1). Попап даёт реестру `onClose` со своей
  уборкой (снять DOM, остановить таймеры/rAF, вернуть колбэк).
- **Возврат результата** — через `handle.close(result)` и `onClose(result)`
  (диалоги `openAlert`/`openConfirm` возвращают Promise).
- **Отписка** — `close()` идемпотентен; `onClose` вызывается ровно один раз даже
  при `closeAll`.
- **Уровень выдаёт реестр**, попап его не считает (передаёт только `level`).

## 3. Поведение

### 3.1. Esc и клик вне — только верхний
- `Escape` → `closeTop('esc')`, **если** у верхнего `closeOnEsc`. Нижележащие не
  трогаются. Единый слушатель — в реестре (`keydown`, capture); при закрытии
  гасим событие, чтобы старые локальные слушатели не сработали повторно.
- Клик/`mousedown` вне корня верхнего слоя → `closeTop('outside')`, если
  `closeOnOutside`. Клик **внутри** верхнего слоя не закрывает ничего.
- Если `closeOnOutside=false` (алерт, тост, баннер) — клик вне **не** закрывает
  (алерт требует явного выбора).
- Открытие нового слоя **не** закрывает нижележащие (стек).

### 3.2. Фокус и доступность
- При открытии: сохраняем `document.activeElement`; фокус уходит в слой
  (`[autofocus]` → первый фокусируемый → сам корень с `tabindex="-1"`).
- **Ловушка фокуса** (`trapFocus`): `Tab`/`Shift+Tab` циклично внутри **верхнего**
  слоя; корень помечается `role="dialog"`, `aria-modal="true"` (меню —
  `role="menu"`), `aria-label` = заголовок/роль.
- При закрытии: фокус возвращается на элемент, открывший слой (или на
  нижележащий слой), если он ещё в DOM.

### 3.3. Блокировка прокрутки фона
- Пока открыт ≥1 слой с `lockScroll` — `document.documentElement.style.overflow='hidden'`
  (ref-count); при закрытии последнего — вернуть как было.
- Дефолт `lockScroll=false`: модалка системы прокрутку карты не блокирует
  (карта за ней и так фиксирована). Включаем адресно там, где фон прокручивается.

### 3.4. Навигация и разлогин
- Навигация в проекте — полная перезагрузка страницы: стек и DOM попапов
  умирают сами. **Дефект возможен только с `lockScroll`** — снимаем его на
  `pagehide` (и в `closeAll`) как страховку.
- Уход на `/login-page` (`handleUnauthorized` в `modal/index.js`, `belt_net.js`) —
  перед `location.href` вызвать `closeAll()` (косметика; страница всё равно
  перезагрузится).

### 3.5. Звук
- Не меняется: тосты звучат как раньше (`playToast`); закрытия молчат. Алерт
  ошибки — **предложение** играть `ui_error` и только на карте (`activateSound`)
  — вынесено в §10 О4.

## 4. Случай «ошибка поверх модалки» — фикс бага пояса

### 4.1. Как сейчас (диагноз)
Клик «⛏ Добывать» (`modal/events.js` `showBeltMenu`) делает
`window.location.href = '/belt.html?belt=<id>'`. Страница `belt.html` в `boot()`
шлёт `POST /api/belt/mine/enter`; сервер отказывает `400 «Трюм полон»`
(`belt_mining_handlers.go:424`, осн. §6.2); `belt_main.js` показывает
**полноэкранный** `#error` (UI §5.3). Итог: карта и модалка уехали вместе со
страницей — контекст потерян.

### 4.2. Как должно быть — «пред-проверка `enter` на карте» (рекомендую)

**Идея:** тот же запрос `enter` — но **не уходя со страницы**. Единственный
источник правды — сервер (механика/API **не меняются**), меняется только **где**
показывается ответ.

Поток по клику пункта «⛏ Добывать»(`showBeltMenu`):
1. Меню **не закрываем сразу**: пункт → «⏳ Заход в пояс…», `disabled`.
2. Шлём `POST /api/belt/mine/enter { belt_id }` (тот же `belt_net.enter`,
   идемпотентен — осн. §6.2/§12 п.4).
3. **200** → закрыть меню и перейти на `/belt.html?belt=<id>` (belt.html свой
   `enter` повторит идемпотентно — дубля сессии нет).
4. **4xx/сеть** → закрыть меню и показать **`openAlert` полосы `alert`** (2000,
   **выше модалки 1000 и меню 1100**). Модалка **остаётся открытой**, игрок —
   на карте.

**Матрица отказов (тексты — как у сервера, UI §5.3/§7):**

| Ответ `enter` | Заголовок/тело алерта | Кнопки |
|---|---|---|
| 400 `Трюм полон` | «Трюм полон» / «Нет свободного места в трюме — добывать некуда. Выгрузите груз и возвращайтесь.» | **«Открыть трюм»** (primary) / «Понятно» |
| 400 `Пояс выработан` | «Пояс выработан» / «Добывать здесь больше нечего.» | «Понятно» |
| 400 `Сначала долетите до пояса` | «Сначала долетите до пояса» / «Подлетите к поясу и попробуйте снова.» | «Понятно» |
| 400 `Пояс вне зоны видимости` | «Пояс вне зоны видимости» / «Подлетите ближе.» | «Понятно» |
| 400 нет данных / прочее | «Заход в пояс невозможен» / текст сервера | «Понятно» |
| сеть / 5xx | «Не удалось связаться с сервером.» / — | **«Повторить»** / «Понятно» |

**Поведение кнопок:**
- **«Понятно»** → закрывается **только алерт**; модалка и выбранная планета/
  вкладка на месте. Игрок может пойти выгрузиться сам.
- **«Открыть трюм»** → **осознанный** переход на дашборд, блок «Трюм» (страница
  `/`, вкладка «Корабль»). Карта при этом не сохраняется — но это **явное
  действие игрока**, а не автоматическая потеря контекста (что и было багом).
- **«Повторить»** → повтор `enter` из того же алерта (сеть вернулась → переходим).

### 4.3. Почему так (обоснование)
- **Не уходим со страницы без ответа** — контекст (модалка/камера/вкладка) не
  теряется никогда при отказе.
- **API/механика не меняются**: используется существующий `enter` (осн. §6.2);
  клиент лишь показывает отказ **правильным слоем**.
- **Один источник правды** — сервер; клиентский «пречек по трюму» не нужен
  (дублировал бы валидацию; поля трюма в модалке нет, UI §12 п.2).
- **Покрывает все отказы захода**, а не только «трюм полон»: выработанный пояс,
  «сначала долетите», сеть — тот же слой.
- **belt.html не меняется:** при **прямом** входе (закладка/F5) под ним нет
  модалки — полноэкранный `#error` остаётся правильным (UI §5.3).

**То же применимо к «Высадиться» → `/surface.html`** (та же навигация-отказ,
`surface_main.js`: ошибка → редирект на `/map`). В v1 **не трогаем** — отдельная
дельта (§10 О3).

## 5. План перевода существующих попапов (этапы)

> Перевод **инкрементальный**: реестр аддитивен и построен так, что `alert` (2000)
> выше любого легаси-попапа — фикс бага (§4) работает уже после этапа 1, даже
> если часть попапов ещё на старых числах.

### Этап 0 — инфраструктура (без видимых изменений)
Добавить `web/static/js/ui/layers.js` (реестр, контракт §2, глобальные
слушатели, `openAlert`/`openConfirm`). Никто его ещё не использует — поведение
страниц **не меняется**. Проверка: сборка/загрузка страниц без ошибок.

### Этап 1 — игра (фикс бага + единый стек)
| Что | Действие | Суть изменения |
|---|---|---|
| `ui/toast.js` | `z` из `LEVELS.toast` | только источник числа (поведение, таймеры, звук — как есть) |
| `modal/index.js` | модалка → `openLayer(level:'modal')`; убрать её `keydown`-Esc и клик по оверлею; `onClose → closeModal()` | Esc/клик вне — через реестр; **уборка `closeModal` не меняется** (rAF, таймеры, `setRedrawCallback`) |
| `modal/events.js` | `#star-context-menu`, `#star-tooltip` → `menu` | меню над модалкой (как по числам и было), Esc закрывает именно меню |

| `map/npc_agents.js` | `#npc-tooltip`, `#npc-search-results` → `menu` | поиск NPC ложится над тултипом того же уровня по открытию |

**Критерий этапа:** баг пояса воспроизводится только желаемым способом

## 7. Критерий проверки (как создатель увидит результат)

1. **Баг пояса — фикс.** Трюм полон, игрок на карте, открыта модалка системы →
   ПКМ по поясу → «⛏ Добывать»: игрок **остаётся на карте**, модалка открыта, а
   **поверх неё** — попап «Трюм полон»; «Понятно» закрывает только попап.
2. **Esc — только верхний.** Модалка + алерт: первый `Esc` закрывает **алерт**,
   модалка остаётся (та же планета/вкладка/камера); второй `Esc` — модалку.
3. **Клик вне — только верхний.** То же: клик по затемнению алерта (если он
   закрываем) / по пустому месту закрывает **верхний**, нижележащее цело.
4. **Вложенный попап не убивает нижний.** Открыть контекстное меню поверх
   модалки, затем ошибку поверх меню: закрытие по одному — по порядку
   (ошибка → меню → модалка), состояние модалки сохраняется всё время.
5. **Не сломано старое.** Меню карты/модалки, тултип координат, поиск NPC, тосты
   (верх-право, не гаснут по Esc), баннер пакмана и «Галактика пуста» — как
   раньше; прямой вход на `/belt.html` (F5) по-прежнему даёт полноэкранный
   экран ошибки.
6. **Фокус/прокрутка.** После закрытия попапа фокус возвращается туда, где был;
   `Tab` не уводит из открытого диалога; фон под ним не прокручивается (если
   `lockScroll` включён).

## 8. Риски регрессий и что НЕ трогаем

1. **Двойное закрытие (главный риск).** Пока у модалки/меню остаются свои Esc/
   outside-слушатели, реестр закроет **два** слоя за одно нажатие. Требование:
   при переводе попапа его локальные слушатели **удаляются** (ТЗ §6.2).
2. **Клик вне vs. drag/pan.** Модалка и карта перетаскиваются `mousedown`.
   Outside-закрытие обязано игнорировать события **внутри** корня верхнего слоя и
   не закрывать слой, открытый тем же жестом (проверять по `stack` после события).
3. **Уборка `closeModal`.** Если слой просто снять из DOM, не вызвов `onClose`,
   останутся `rAF`-цикл, `setInterval` опроса игроков, чужой `setRedrawCallback`.
   **Не менять** тело `closeModal()` (только вызывать его из `onClose`).
4. **Прокрутка.** Включать `lockScroll` точечно: блокировка на модалке системы
   ломала бы ожидание «карта под ней живёт». Дефолт — `false`.
5. **Пакман и агенты — семантика сохраняется.** У баннера/оверлея пакмана и
   тултипов NPC **не появляются** Esc/клик-вне/трейп: только смена источника
   `z-index`. То же — авто-закрытие тултипа координат (3 с).
6. **Страничные оверлеи belt/surface — не попапы.** `#error`/`#pause`/`#loading`
   (belt.css/surface.css) и `.overlay` студии не переводятся на реестр: это
   состояния своей страницы.
7. **Статика и стиль не трогаем.** `map.css` хром (10–60), `admin.css [data-tip]`
   (60), палитра/шрифты/ассеты. Температур в задаче нет.
8. **Админ/студии до этапов 2–3 — как есть.** Нативный `confirm()`, легаси-числа
   студии (4–40) и `#adminLoginOverlay` (9999) не меняются; фикс бага от них не
   зависит.
9. **Не трогаем роадмап** `99_roadmap.md` (владелец @manager).

## 10. Открытые вопросы (гейт создателя / уточнение у менеджера)

- **О1. «Открыть трюм» из алерта.** Рекомендую: переход на дашборд, блок «Трюм»
  (`/`, вкладка «Корабль») — **осознанный** уход, не баг. Альтернативы: только
  «Понятно» (игрок сам решает) либо (дороже, отдельная фича) **попап трюма поверх
  модалки** — тогда карта не теряется вовсе. Выбор за создателем.
- **О2. Пречек «трюм полон» на клиенте** (disable пункта «Добывать» через
  `GET /api/cargo`) — рекомендую **не** делать в v1: пред-проверка `enter` уже
  авторитетна и не дублирует валидацию (UI §12 п.2). Можно позже как оптимизация.
- **О3. «Высадиться» → `/surface.html`** имеет ту же навигацию-ошибку
  (`surface_main.js` → `/map`). Применить тот же пред-чек — отдельная дельта
  после v1?
- **О4. Звук алерта ошибки** — играть `ui_error` (как тост) или молча?
  Рекомендую играть на карте (там `activateSound`), в админке/студии — молча.
- **О5. Числа полос.** `alert=2000` (выше всех легаси ≤1300), `toast=10000`
  не двигаем, шаг 10 внутри полосы — техническая деталь @developer; подтвердить
  на этапе 0, что пересечений со статикой нет.
- **О6. Этапы 2–3** (админка/студии) — отдельными задачами, фикс бага не
  блокируют. Согласовать приоритет (студия — зона частой работы создателя).
