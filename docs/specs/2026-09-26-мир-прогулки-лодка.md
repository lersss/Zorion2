## 0. Одним абзацем

Лодка — **клиентское** состояние игрока (одна на игрока, не сущность БД): у зеркала по клавише «использовать» (`KeyE`) игрок садится в надувную лодку, плывёт по **тому же** `liquidLevel`, что и плавание (`y = liquidLevel(x) − BOAT_HULL`), быстрее плавания и ходьбы (×`BOAT_FACTOR = 1.6` от ходьбы), с инерцией/сносом, без ныряния; у берега — **мягкий стоп** (корпус не сходит на сушу и не входит в твёрдое). Повторное «использовать» — выход (лодка «складывается» в рюкзак). Лодка **не работает** на лаве и **не заходит на `underIce`** (в т.ч. в полыньи — решение создателя 2). Отрисовка — `drawBoat` (код-силуэт до спрайта @artist) между `drawShip`/`drawPlayer`. Ходьба и плавание (`Player.update`) **не меняются** — лодка их обходит своим циклом.

## 3. Модель

### 3.1. Габарит корпуса

Ориентиры — `PLAYER_H = 28 px`, `PLAYER_W = 12 px` (`surface_config.js`). Все числа — **гипотеза до гейта «офигеть»** (§4).

- **`BOAT_W = 34 px`** — ширина корпуса (горизонтальный габарит). ≈ 2.8·`PLAYER_W`, ≈ 1.2·`PLAYER_H`: одноместная надувная лодка, борта по обе стороны от игрока.
- **`BOAT_HULL = 20 px`** — высота **центра бокса игрока** над зеркалом в лодке (`y = liquidLevel(x) − BOAT_HULL`). Стопы бокса (`y + h/2`) — на `liquidLevel − 6 px` (планшир ~6 px над водой), голова — на `liquidLevel − 34 px`. Голова **выше** зеркала → подводный обзор (§5.3 воды) не включается.
- **`BOAT_DRAFT = 6 px`** — осадка (нижняя часть корпуса ниже зеркала) — **только отрисовка**, физику не трогает.
- **Продольный размер** не вводится: вид сбоку, `BOAT_W` и есть видимая длина корпуса.

**Координата игрока относительно корпуса:** центр бокса игрока совпадает по X с центром лодки; смещения бокса относительно корпуса нет.

### 3.2. Вход и выход

**Действие «использовать» — клавиша `KeyE`** (предложение; альт — `KeyF`/`Enter`, @uidesigner может добавить кнопку на HUD позже). Не конфликтует: `Space` — прыжок, `Shift` — спринт, `Arrow*`/`KeyA`/`KeyD` — движение, `ArrowDown`/`KeyS` — вниз, `Escape` — пауза. Событие **краевое** (срабатывает на `keydown`, не на удержании; `e.repeat` игнорируется; до `keyup` повторно не срабатывает).

**Посадка** (`use`, `boat.aboard === false`) выполняется, если все условия верны:
1. **Вода разрешена:** `world.liquid` есть; `world.liquid.medium !== 'лава'`; `world.liquid.level.mode !== 'underIce'` (решение создателя 2 — запрет и под коркой, и в полыньях);
2. **Зеркало рядом (с поиском смещения).** Посадка ведётся по **горизонтальному смещению** `dx` лодки от игрока, `|dx| ≤ BOARD_REACH`; берётся **ближайший** `dx` (перебор `0, ±1, ±2, …` до `BOARD_REACH`, шаг 1 px; детерминизм — без `Math.random`), при котором `liquidLevel(player.x + dx)` конечен и `≤ feet + BOARD_REACH`, где `feet = player.y + player.h/2`, `BOARD_REACH = 14 px` (полурост). При `dx = 0` — посадка **вплавь** (игрок уже над водой); при `dx ≠ 0` — посадка **с пологого берега**: лодка ложится на смежные мокрые колонки, а центральная колонка под игроком может быть **сухой**. С высокого обрыва (`feet ≫ liquidLevel` на всех `dx`) посадки нет — нужно спуститься;
3. **Корпус помещается:** `_canOccupy(player.x + dx)` — footprint лодки (шаг 4 px по `[x − BOAT_W/2, x + BOAT_W/2]`) целиком на мокрых колонках с `depth ≥ BOAT_MIN_DEPTH` и не в корке, **и полный силуэт** «лодка + игрок» свободен по `solidAt'` (§3.3 «Твёрдое»). Это же условие включает требование «полоса зеркала ≥ `BOAT_W`» (узкая лужа не годится). После посадки центр бокса игрока совмещается с `boat.x = player.x + dx`.

Иначе — посадки нет; режим отказа нефатальный (необязательное уведомление HUD, §8).

**Идемпотентность.** Лодка — **одна на игрока**, состояние — булев флаг `aboard`. Второе нажатие (и авто-повтор клавиши) не создаёт вторую лодку: краевое событие + флаг. Отдельного объекта в мире нет.

**Выход** (`use`, `boat.aboard === true`): разрешён **в любом месте воды** (умолчание — нет капкана: игрок всегда может выйти). `player` получает позицию и `vx` лодки, `vy = 0`; следующий кадр — обычный `Player.update` (плавучесть §6.1). Лодка **«складывается»** (возврат в снаряжение; в мире ничего не остаётся, персиста нет).

### 3.3. Физика

**Уровень.** `y = liquidLevel(x) − BOAT_HULL` — **прямо**, без сглаживания (в `basin` уровень ступенчатый по 2-px корзинам, разница мала). Это тот же `liquidLevel`, что у плавания/рендера — второго пути уровня нет (инвариант воды §9 п.3).

**Горизонталь** (гипотеза, §4):
```
const speed = WALK_SPEED * PPM * BOAT_FACTOR;      // 256 px/с (6.4 м/с)
let target = 0;
if (input.left)  target -= speed;
if (input.right) target += speed;
const a = (target !== 0) ? BOAT_ACCEL : BOAT_DRAG; // разгон быстрее, снос дольше
this.vx = approach(this.vx, target, a * dt);
const nx = this.x + this.vx * dt;
if (this._canOccupy(nx)) {
  player.distance += Math.abs(nx - this.x);        // HUD «путь» не замирает (§3.3)
  this.x = nx;
}
else { this.vx = 0; }                              // мягкий стоп у берега/стены
this.y = world.liquidLevel(this.x) - BOAT_HULL;
```
- **Спринт в лодке отключён** (как в плавании): лодка и так быстрее ходьбы; `Shift` не ускоряет.
- **Инерция/снос:** при вводе `BOAT_ACCEL`, без ввода — `BOAT_DRAG` (меньше) → лодка «катится» и плавно останавливается.

**Вертикаль.** Пока `aboard` — вертикали нет: `vy = 0`, `down` — no-op (**нырять нельзя**), `jump` в лодке — no-op (умолчание, §10 Q3), гравитация не применяется.

**Мягкий стоп.** Стоп — по **footprint**, а не по точке центра. Причина, почему зеркало «кончилось»: сухая колонка (`_liquidCol(x) === null`, в т.ч. `liquidLevel = Infinity`), глубина меньше `BOAT_MIN_DEPTH`, либо зеркало над коркой. Лодка не пересекает край: `x` не двигается, `vx = 0`; проникновения в сушу/твёрдое нет, отскока/демпфера нет (мягкий = без рывка и без урона).

**Твёрдое (проба — полный силуэт «лодка + игрок»).** `_canOccupy` проверяет не полосу корпуса, а **весь силуэт**: по X — `[x − BOAT_W/2, x + BOAT_W/2]` (шаг 4 px), по Y — от **макушки** (`liquidLevel − BOAT_HULL − h/2`; при `h = PLAYER_H = 28`, `BOAT_HULL = 20` → `liquidLevel − 34` — сходится с §3.1) до **низа осадки** (`liquidLevel + BOAT_DRAFT`). Каждая точка пробы свободна по `world.solidAt'` — **единой твёрдости**, что и у `Player` (`solidAt' = solidAt ∨ crust`, включая лёд `underIce`; §3.3 воды). Так лодка не входит ни корпусом, ни **игроком** в свисающий свод/скалу/`void`-стенку, стоящую в воде, и не «запирает» голову под коркой.

**Путь (HUD).** Лодка накапливает `player.distance` — при каждом фактическом сдвиге `player.distance += Math.abs(nx − x)` (как `Player`, `surface_player.js`), а HUD считает `distanceMeters = state.player.distance / PPM` (`surface_main.js`). Без этого в режиме лодки счётчик пути замирает. Отдельного счётчика у лодки нет.

**Плавучесть/режим «стоять на дну»** не взаимодействуют: в лодке `Player.update` **не вызывается** (§2.1 A). Вне лодки ЧК6.2 работает как был.

### 3.5. Отрисовка

- **`drawBoat(ctx, world, camera, vw, vh, player, boat, timeMs)`** — вызывается **до** `drawPlayer` (игрок садится поверх корпуса), после `drawShip`; порядок кадра: `drawShip → drawCreatures → drawBoat → drawPlayer` (§5.1 воды — новых покадровых проходов нет, лодка внутри существующего слоя «мир»).
- **Якорь:** `wx = boat.x`; `gy = liquidLevel(wx)`. Корпус: верх на `gy − BOAT_HULL + (~6)` (планшир), низ на `gy + BOAT_DRAFT`. Рисуется только при `aboard`; сложенная лодка невидима.
- **Код-силуэт (заглушка до спрайта):** две надувные «трубы»-борта (rounded rect по бокам `BOAT_W`), кормовая переборка, тёмный пол. Цвета — инвариантны к среде, читаются на любой воде: корпус `#c86432` (спасательный оранжевый), планшир `#f0d8c0`, тёмный контур `#5a3320`. Игрок (`drawPlayer`) остаётся как есть — визор/скафандр.
- **Покачивание/крен** — `sin(timeMs)`: `BOAT_BOB_AMP` по Y и `BOAT_ROCK_AMP` (наклон). **Pivot вращения — точка на линии воды** (`x = boat.x`, `y = liquidLevel(x)`), **не центр корпуса**: крен вокруг середины корпуса отрывал бы борта от зеркала «качелями». Только отрисовка; физику и ввод не трогает (как `SHIP_BOB_*` у корабля).
- **Силуэт и окклюзия (F1).** Игрок поверх борта рисуется **тем же** `drawPlayer` после `drawBoat` — второго прохода или второго файла слоя окклюзии **не нужно**: посадка «в лодку» читается силуэтом корпуса (провал аммидшипс — ложе), а не отдельным перекрывающим спрайтом.
- **Пульс-кольцо (F2).** `drawPlayer` рисует пульс-кольцо «я здесь» (радиус `h·0.8 ≈ 22–24 px`, `surface_render.js`) вокруг центра бокса — оно **перекроет** лодку 34×20. В режиме лодки кольцо **гасится**: `drawPlayer` получает признак `aboard` и при `aboard` кольцо не рисует. Альтернатива — рисовать кольцо **вокруг лодки** (`drawBoat`); умолчание — гашение.
- **Спрайт @artist (когда готов):** `web/static/sprites/surface/boat/boat.png` (одна картинка на все среды, §10 Q11). Файл — компактный бокс **204×120** (**6×** логического 34×20; экран апскейлит ×`ZOOM`×`dpr` — рисовать в 34 px нельзя, будет мыло; известный хвост), **линия воды внутри файла — y 84** (низ корпуса = `liquidLevel + BOAT_DRAFT`), пики борта (планшир, нос/корма) — y 0 (`lv − 14`, верх кадра; выше `y 0` ничего нет — кадр начинается с борта). `drawBoat` рисует спрайт в логическом боксе 34×20; нет/не загрузился — рисует код-силуэт (фолбэк не ломает кадр). Путь и имя — контракт для @artist (ТЗ §5). Ночной/второй версии **нет**, реколора **нет** (актёры ночью рисуются константой; реколор убил бы спасательный цвет).
- **Косметика (след/пена/вёсла/анимация гребка) — НЕ здесь**, идея `2026-09-26_вода-косметика-вида.md`.

### 3.6. Габарит и препятствия

- **Узкие места.** `level.polynya.w ∈ [14, 28]` — **дефолт схемы** (`LIQUID_DEFAULTS`), а **не жёсткий максимум**: валидация воды держит только `w_min ≥ PLAYER_W+2 = 14` и клампит `w_max ≤ gap`. Ширина полыньи **может** превысить `BOAT_W = 34`. Поэтому запрет лодки в полынье держится **режимом** (`underIce`), а **не шириной**: коллизия борта со **стенками корки как проход** не проектируется — вход на `underIce` запрещён целиком (§3.4). Это и есть решение создателя 2 — запрет вместо геометрии.
- **Узкая вода (`basin`).** Полоса зеркала уже `BOAT_W` → посадка невозможна (`_canOccupy` ложно); лодка не «застревает», т.к. и не появляется там.
- **Берег.** Мягкий стоп по footprint (§3.3) — лодка не сходит на сушу.
- **Обрывы/скалы/своды** (`solidAt'`). Проба **полного силуэта** (§3.3) — лодка и игрок не входят в твёрдое.

## 7. Инварианты и режимы отказа

1. **Лодка — клиентское состояние, не сущность БД.** Одна на игрока; состояния нет в пакете, нет персиста между прогулками.
2. **Идемпотентность.** Повторное/автоповторное нажатие не создаёт вторую лодку (краевое событие + флаг).
3. **Надводная.** `y = liquidLevel(x) − BOAT_HULL`; `down` не ныряет; голова выше зеркала → подводный обзор не включается.
4. **Единый уровень.** Лодка читает тот же `liquidLevel`, что плавание/рендер; второго пути уровня нет (инвариант воды §9 п.3).
5. **Не входит в твёрдое.** Проба **полного силуэта** «лодка + игрок» (X `[x − BOAT_W/2, x + BOAT_W/2]`, Y от макушки `liquidLevel − 34` до низа осадки `liquidLevel + BOAT_DRAFT`) по `solidAt'` — той же твёрдости, что у `Player` (включая лёд `underIce`).
6. **Запрет:** `underIce` (в т.ч. полыньи) и лава; узкая вода (`< BOAT_W`) — посадки нет.
7. **Не сходит на сушу.** Мягкий стоп по footprint; проникновения в сушу/твёрдое нет.
8. **Плавание/ходьба не меняются.** `Player.update` не вызывается в режиме лодки; вне лодки поведение ЧК6.2 прежнее.
9. **Детерминизм.** `Math.random` запрещён; покачивание — от `timeMs`.
10. **Урон не возвращаем** (2026-09-21).
11. **Косметика не входит** (вёсла/след/пена — идея вида воды).
12. **`surface_world.js` не растёт** (техдолг — отдельная задача).
13. **Путь (HUD).** Лодка накапливает `player.distance`; счётчик пути в режиме лодки не замирает.

**Режимы отказа:** посадка не удалась (нет воды рядом/лава/`underIce`/узко) → ничего не происходит (нефатально, опц. подсказка HUD); лодка у берега → стоп (не капкан, выход по `use`); выход в открытой воде → игрок плывёт (не тонет).

## 13. Критерии приёмки (для @tester/@balancetester)

1. **Посадка/выход.** У зеркала (`BOARD_REACH`) `use` (`KeyE`) сажает в лодку; второе `use` — выход, лодка складывается; повтор/автоповтор не создаёт вторую лодку.
2. **Уровень.** В лодке `y = liquidLevel(x) − BOAT_HULL`; голова выше зеркала — подводный обзор **не** включается; `down` не ныряет.
3. **Скорость/инерция.** Скорость ≈ `WALK·BOAT_FACTOR`; спринт не ускоряет; без ввода лодка «катится» и плавно тормозит (`BOAT_DRAG < BOAT_ACCEL`).
4. **Мягкий стоп.** У берега лодка останавливается, **не** сходит на сушу, **не** входит в твёрдое (`solidAt'`), без рывка/урона.
5. **Запреты.** На лаве и на `underIce` (включая полыни) посадки нет; в узкой воде (`span < BOAT_W`) — нет; вторая лодка не создаётся.
6. **Регресс.** Плавание (ЧК6.2) и ходьба не изменились: `surface-swim-check` 29/29, `surface-liquid-check` 34/34, e2e walk/swim/liquid-render зелёные; легаси-путей нет.
7. **Отрисовка.** `drawBoat` рисуется между `drawShip`/`drawPlayer`, игрок поверх; покачивание от `timeMs`; при отсутствии спрайта код-силуэт не ломает кадр; новых покадровых проходов нет.
8. **Детерминизм** (тот же seed/время → тот же кадр); **0 `pageerror`** в e2e-смоуке.
9. **Арт** (§5) от @gdesigner/@artist — силуэт/палитра/размер по ТЗ (приёмка — глазами создателя).
