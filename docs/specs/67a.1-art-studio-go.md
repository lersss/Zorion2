## 1. Цель и скоуп

Спроектировать **Go-продукт арт-студии генерации аватаров рас** — замену Python-прототипа
(`tools/race_studio.py`, `human_studio.py`, `race_gen.py`, `human_gen.py`, `race_forms.py`)
по арт-спеке `art_studio_spec.md`, но на стеке Go (решение создателя 2026-09-17: единый стек
с игрой, DoD `go build/vet/test`). Продукт — **локальный веб-инструмент художника**
(десктопная утилита, НЕ игровая фича), работает поверх ComfyUI и локальных скриптов
пост-обработки. Один процесс, один фиксированный порт, вкладки «Отбор»/«Эталон»/«Люди».

**В скоупе:** спека Go-инструмента (архитектура `cmd/art-studio/`, HTTP API, конфиги
`config/art/*.json`, пост-обработка, защита от дублей, прогресс/СТОП) + данные конфигов:
`forms.json` (словарь форм), `families.json` (F2–F9, 46 рас, заполнены из 99.2.21 §5),
`humans.json` (оси рандома людей, F1). Код — зона @developer по этой спеке.

**НЕ в скоупе (границы — §15):** код Go; анимация аватаров; интеграция с игровым UI;
голос/личности рас; аватары водных рас F1 (2 Океаниды, 3 Глубинники, 4 Прибрежные) —
студия людей генерирует только расу 1 «Люди» (как прототип `human_gen.py`).

## 3. Архитектура — `cmd/art-studio/`

Отдельный бинарь `zorion-art-studio.exe` (решение 67a п.2), НЕ трогает игровой сервер.
Сборка: `go build -o zorion-art-studio.exe ./cmd/art-studio` (пакет, не файл — в пакете
несколько файлов).

```
cmd/art-studio/
  main.go                 — точка входа: чтение конфигов (config/art/*.json), проверка
                            порта (защита от дублей §9.1), запуск HTTP-сервера
  config/
    load.go               — загрузка и валидация конфигов (forms/families/humans/studio)
    types.go              — Go-структуры конфигов (Race, Family, FormDict, HumanAxes)
  comfy/
    client.go             — интеграция с ComfyUI API: POST /prompt (txt2img/img2img),
                            polling /history/{pid}, скачивание /view
    workflow.go           — сборка workflow-JSON (перенос submit/submit_ref из race_gen.py)
  generator/
    prompt.go             — build_prompt / build_prompt_wide (перенос из race_gen.py),
                            формы из forms.json (phrase_template), рандом rng локальный
    worker.go             — фоновый джоб генерации: N картинок, 2 параллельных воркера
                            (решение art_studio_spec §4.6), проверка stop.flag перед
                            каждой картинкой, запись status.json
  postproc/
    rembg.go              — вызов Python-подпроцесса rembg (решение 67a п.1)
    rembg_cli.py          — скрипт вырезки: python rembg_cli.py <in> <out> (isnet-general-use)
    largest.go            — крупнейший связный компонент по альфа-маске (BFS, 4-связность)
    resize.go             — ресайз 200×200 (аналог ImageOps.pad, центр/низ), прижатие к низу
    composite.go          — композит прозрачного PNG на кабину (cockpit_1024.png)
    crop.go               — обрезка снизу (pct% высоты) + крупнейший компонент после среза
  handlers/
    http.go               — HTTP-хендлеры (§6), статика UI, no-cache заголовки
    state.go              — чтение/запись status.json, stop.flag, meta.json
  web/
    index.html            — UI (вкладки Отбор/Эталон/Люди; перенос HTML/JS прототипов
                            почти без изменений, решение 67a)
```

Правило AGENTS.md §4.9 (имена файлов в разных папках не совпадают): имена файлов выше
уникальны в пределах репозитория (проверено против `internal/`).

**Конкурентность (AGENTS.md §0):** общее состояние джоба (текущий прогресс, флаг стопа) —
под `sync.Mutex`; `*rand.Rand` — локальный `rand.New(...)` на вызов (не потокобезопасен);
проверка+действие атомарны (`TryStart` генерации, не `if running + Start`); запись
`status.json` — атомарная (tmp + rename).

## 4. Конфиги — `config/art/*.json`

Четыре файла. Три первых — данные (созданы этой спекой), четвёртый — параметры
инструмента (создаёт @developer при реализации по §4.4). Все — валидный JSON (UTF-8),
редактируемые без кода (спека §5.3). Имена рас — русские с номером («5 Аммиачники»,
формат прототипа), промпты — английские.

### 4.1. `config/art/forms.json` — словарь форм (перенос `race_forms.py`)

| Поле | Тип | Содержимое |
|---|---|---|
| `phrase_template` | string | `"a {struct} {character} {shape} of material, formed of {part}"` — формула сборки фразы (из `_build_all()`) |
| `shapes` | [{shape, categories}] | 28 базовых форм с категориями (crystal/cold/hot/gas/sulfur/energy/sphere/mech/organic/liquid) |
| `struct` | [string] | 25 модификаторов структуры |
| `character` | [string] | 20 характеров поверхности |
| `parts` | [string] | 25 деталей/элементов |
| `anthro_forms` | [string] | 43 антропоморфные формы (для галки «антропоморфный»; в арт-спеке §3.1 указано «18 шт» — устарело, в коде `race_forms.py` 43; перенесены все) |
| `category_keys` | {F2–F9: [string]} | категории форм по семействам (фильтр `forms_for(fam)`); F1 нет — люди отдельно |

Комбинаторный словарь: сборка в Go по `phrase_template` + фильтр по `category_keys[FAM]`
(если категорий нет — все формы), ровно как `race_forms.py: forms_for()`. Готовые фразы
в JSON НЕ хранятся (см. §2, вариант B).

### 4.2. `config/art/families.json` — семейства F2–F9 (46 рас)

Формат — эталон F2 из `race_gen.py` (дословно перенесён), F3–F9 заполнены из
`99.2.21-races-v1.md` §5 (основы рас). Структура:

```json
{
  "F2": {
    "name": "Крио-аммиачные",
    "races": [
      {
        "id": "5",
        "name": "5 Аммиачники",
        "basis": "жидкий NH3, моря",
        "forms": ["...", "..."],
        "materials": ["...", "..."],
        "glows": ["...", "..."]
      }
    ],
    "extra": ["no face, no eyes, no mouth", "..."],
    "anchor": ["anchored by a solid ice base extending to the bottom edge of the frame", "..."],
    "scene": "on flat dark grey background, on flat dark blue background",
    "neg": "text, watermark, blurry, ..."
  }
}
```

- `races[].id` — номер расы из 99.2.21 (строка); `name` — русское имя с номером
  (формат прототипа, используется в UI); `basis` — основа из 99.2.21 (справочно,
  в промпт НЕ попадает); `forms` 2–4 фразы, `materials` 2–3, `glows` 2–3.
- `extra` / `anchor` / `scene` / `neg` — общие шаблоны семейства (как F2).
- Состав: F2 (5,6,7,8,9,48), F3 (11,12,13,14), F4 (15,16,17,18,19,20,21,22,43),
  F5 (23,24,25,26,27,28,29,30,31,49), F6 (32,33,34,35,36,37), F7 (40,41,42),
  F8 (10,39,50), F9 (38,44,45,46,47). Итого 46 рас.
- **F1 в families.json не входит** (решение: люди — отдельная студия, §4.3). Водные
  расы 2–4 (Океаниды, Глубинники, Прибрежные) — аватары вне скоупа (§15).

**Как выводились формы F3–F9 (предположение дизайнера, проверяется на гейте):**
формы/материалы/свечения выведены из основы расы (99.2.21 §5: «Основа» + корм) в стиле
F2-эталона: материал = физическая среда основы, форма = её характерный объект
(гнездо/рои/кораллы/вихрь/кристалл), свечение = естественный свет среды. Негативы
адаптированы под семейство: убраны запреты, конфликтующие с сутью семейства
(у F4/F5 убран «red» — лава/сера; у F6 убраны кристалл-запреты — кремний = кристаллы;
у F7/F9 убраны «floating, no base» — парение норма; у F4 убраны «chimney, pipe,
structure, machine» — курильщики/гейзеры). Эталон создателя на формы F3–F9 **не задан**
(открытый вопрос, §13); источник стиля — проверенный F2-прототип.

### 4.3. `config/art/humans.json` — студия людей (F1, раса 1)

`{helmet}` (пусто или `"<значение> "`), `{scene}`. Правила подстановки — в коде

## 5. Генерация — ComfyUI

### 5.1. Workflow (перенос `race_gen.py` submit/submit_ref)

- **txt2img** (кандидаты эталона, пул): CheckpointLoaderSimple → 2×CLIPTextEncode
  (prompt/neg) → EmptyLatentImage 1024×1024 → KSampler (steps 28, cfg 7.0, dpmpp_2m/karras,
  denoise 1.0) → VAEDecode → SaveImage.
- **img2img** (вариации от эталона): LoadImage (эталон копируется в `C:\ComfyUI\input\`
  как `ref_<FAM>_r<race_id>.png`) → VAEEncode → KSampler (cfg 7.5, denoise = ползунок
  0.25–0.6, дефолт 0.35) → VAEDecode → SaveImage.
- Polling `/history/{pid}` каждые 2 с, таймаут 360 с; успех → скачивание `/view` в raw-файл.

### 5.2. Промпты (перенос `race_gen.py`)

- **`build_prompt`** (вариации расы, всегда от эталона — решение 67a):
  `"dramatic cinematic concept art of a non-organic alien creature, FRONT VIEW, made of
  {mat}, {form}, {glow}, {extra}, {anchor}, centered, {scene}, masterpiece, game avatar,
  no text, no watermark"` — `{form}` из `forms[]` расы, `{mat}`/`{glow}` — случайные из
  расы, `{extra}`/`{anchor}` — случайные из семейства, `{scene}` — случайная из
  `scene.split(", ")`.
- **`build_prompt_wide`** (кандидаты эталона, широкий поиск по всему семейству):
  неантропо — `"dramatic cinematic concept art of an ABSTRACT OBJECT, FRONT VIEW, made of
  {mat}, {form}, {glow}, no face, no eyes, no mouth, no human features, asymmetric,
  anchored by a solid base extending to the bottom edge of the frame, centered, {scene},
  masterpiece, game avatar, no text, no watermark"` — `{form}` из `forms_for(FAM)`
  (словарь форм, §4.1); антропо (галка) — `"realistic portrait of an alien humanoid race,
  FRONT VIEW, face looking directly at viewer, {form}, made of {mat}, {glow}, natural skin
  texture, head and shoulders, torso extending down below the frame, anchored, centered,
  {scene}, game avatar, no text, no watermark"` — `{form}` из `anthro_forms`.
- Раса кандидата выбирается случайно (материал/свечение от неё), метится в meta.json;
  раса эталона назначается при `/refset` (не при генерации) — решение 67a.

### 5.3. Параллельность

2 параллельных воркера (решение art_studio_spec §4.6: оптимум на RTX 4060 Ti; больше —
упрутся в VRAM). СТОП — мягкий: текущая пара догенерируется (~15 с), следующие не
стартуют (проверка `stop.flag` перед каждой картинкой). Без kill.

## 6. HTTP API

Один процесс, порт 8798 (фикс; `studio.json`). Все ответы — `Cache-Control:
no-store, no-cache, must-revalidate` (решение 67a: no-cache). JSON-ответы —
`Content-Type: application/json; charset=utf-8`. Пути — аналог Python-студий
(JS переносится почти без изменений).

### 6.1. Расовая студия (перенос `race_studio.py`)

| Метод/путь | Параметры | Ответ |

## 7. Пост-обработка (перенос `race_gen.py`/`race_studio.py`)

Цепочка на картинку: **raw (ComfyUI) → rembg → крупнейший компонент → в пул**
(прозрачный PNG); при принятии — **ресайз 200×200 (центр/низ) → final_accepted**.
Показ в UI — композит на кабину (не сохраняется).

1. **rembg** — Python-подпроцесс (решение 67a п.1): `exec.Command(python_cmd,
   rembg_cli, in, out)` — одна команда на файл, `isnet-general-use`. `rembg_cli.py`
   (поставляется в `cmd/art-studio/postproc/`): открывает RGB, `remove(...)`, сохраняет
   прозрачный PNG. Ошибка подпроцесса → картинка помечается FAIL (не валит джоб).
2. **Крупнейший связный компонент** — BFS по альфа-маске (порог альфа > 40, 4-связность),
   остальные компоненты обнуляются (убирает «мусор»/фон-хвосты; перенос
   `crop_bottom`/прототипа).
3. **Прижатие к низу** — при принятии: объект встаёт на нижний край кадра (см. 4).
4. **Ресайз 200×200** — аналог `ImageOps.pad(img, (200,200), centering=(0.5, 1.0))`:
   масштабирование с сохранением пропорций (вписывание), вставка в холст 200×200 с
   прозрачным фоном, центрирование по X, прижатие к низу по Y. Библиотека —
   `disintegration/imaging` (решение 67a: «disintegration/imaging»).
5. **Композит на кабину** — `cockpit_1024.png` в корне пула; прозрачный PNG
   накладывается на кабину (paste с альфой; кабина ресайзится под размер PNG).
   Используется в `/img`, `/refcand/*`, `/preview` — чтобы видеть чистоту вырезки
   (критерий приёмки 4).
6. **Обрезка снизу** (`/crop`) — оставить `pct%` высоты (мин 50), затем крупнейший
   компонент (перенос `crop_bottom`), сохранить поверх в пуле.

## 8. Память (файловая структура, перенос art_studio_spec §3.4)

Корень — `ai_drafts/` (вне git, существует). Пулы — `ai_drafts/races_pool/` и
`ai_drafts/humans_pool/` (как прототип; пути настраиваются в `studio.json`).

```
ai_drafts/
  races_pool/
    status.json            — прогресс генерации рас {running, done, total, current}
    stop.flag              — флаг мягкого стопа (создаётся /stop, удаляется по завершении)
    meta.json              — мета пула: [{file, seed, family, race, race_id, prompt, ref?}]
    r01.png ...            — пул отбора (прозрачные PNG после rembg)
    _raw_*.png             — временные raw от ComfyUI (удаляются после обработки)
    ref_cands/             — кандидаты эталона (c01.png... + meta.json: {file: {race_id, race, seed, prompt}})
    ref_<FAM>_r<id>.png    — эталоны рас (+ .json: {fam, race})
    cockpit_1024.png       — кабина для композита
  humans_pool/
    status.json, stop.flag, meta.json, hNN_m.png / hNN_f.png, _raw_*.png, cockpit_1024.png
  races_rejected/          — удалённые расы
  humans_rejected/         — удалённые люди
  final_accepted/
    <FAM>/r<race_id>/NN.png   — принятые аватары рас (200×200, прозрачные)
    race_f1_humans_NN.png     — принятые люди (200×200, прозрачные)
```

Правила переноса: `/genref` очищает `ref_cands/` перед стартом (кандидаты — разовая
пачка); `/genvar` очищает пул `r*.png` и `meta.json` перед стартом (приём во время
генерации не попадает в старую мету); `ref_*` и `ref_cands/` при этом не трогаются.
Автонумерация принятых — по существующим файлам (первый свободный номер).

## 9. Процессы и защита

### 9.1. Фикс-порт и защита от дублей (решение 67a; баг прототипа art_studio_spec §4.7)

При старте `main.go` первым делом делает `net.Listen("tcp", "127.0.0.1:8798")`; при
ошибке «порт занят» — вывод сообщения «Арт-студия уже запущена (порт 8798 занят)» и
`os.Exit(1)` (аналог `socket.bind` в прототипе). Один процесс на порт — два python-процесса
на один порт исключены по построению (Go-бинарь один).

### 9.2. Прогресс/СТОП

`status.json` пишется воркером после каждой картинки (`{running, done, total, current}`);
`/status` читает файл (переживает рестарт студии — прогресс не теряется). СТОП —
`stop.flag`: воркер проверяет перед каждой картинкой; текущая пара догенерируется,
следующие не стартуют; по завершении флаг удаляется, `status.json` = `{running: false,
current: "остановлено"}` (или «готово» при полном прогоне). Без kill.

### 9.3. Авто-обновление

UI опрашивает `/list`+`/ref`+`/status` каждые 3 с (`auto_refresh_ms`); дифф-рендер не
сбрасывает выбор (решение 67a: «карточки не сбрасываются»).
