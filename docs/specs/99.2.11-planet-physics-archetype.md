# Генератор планет: физика → архетип — спека блока 99.2.11

**Статус:** важно · проблема и цель зафиксированы
**Дата:** 2026-09-12 (обновлено 2026-09-13)
**Блок роадмапа:** `docs/gamedesign/99_roadmap.md` §99.2.11
**Связи:** `internal/generator/planet/`, `config/planet_archetypes.json`

---

**Проблема:** сейчас «хвост виляет собакой». Архетип выбирается первым
(`GenerateArchetype` по весам спектрального класса — рулетка по `Weight[class]`),
а физика выводится из него: масса, температура (клип `ArchetypeMin/Max`), вода,
жизнь (`GenerateProperties`, `properties.go`).

Цепочка сейчас: `класс звезды → рулетка → архетип → масса, T, вода, жизнь`.

**Цель:** перевернуть порядок. Сначала физика планеты из параметров звезды
(орбита, инсоляция → температура; масса по аккреции), потом классификация —
«эта температура и масса → архетип X».

**Затрагивает:** `internal/generator/planet/` (archetype.go, properties.go,
physics.go, core.go, composition_generator.go), конфиг `config/planet_archetypes.json`.
