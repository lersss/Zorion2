## 0. Признаки атмосферы (единый механизм — по составу, не ярлыки)

Гейты биомов по атмосфере работают на признаках, вычисляемых от
`atmosphere_data.composition` (как признак токсичности в §6.2 спеки). Каждый признак
достижим тем, что реально генерирует каскад 99.2.20 (формулы не трогаются; факты
сверены с `atmosphere.go`):

| Признак | Определение | Достижимость генератором |
|---|---|---|
| `no_toxic` | сумма токсичных газов (SO₂, H₂S, Cl₂, NH₃, CO, H₂SO₄-аэрозоль, CH₄) ≤ порога по каждому | да (жизненные/инертные составы) |
| `toxic` | любой токсичный газ выше порога | да: жаркие SO₂ (≤1%), холодные CH₄ (1–5%, внешняя зона); **умеренные токсичные (H₂S/SO₂/NH₃-обогащение) — только tuned-подкрутка 99.2.22** |
| `acidic` | SO₂ + H₂S + HCl + HF > 0.1% | да (жаркий режим: SO₂ ≤ 1%); **в сиде биомов не используется** (серные поля — гейт снят, Ио-тип) |
| `methane` | CH₄ > 1% | да, **только внешняя орбитальная зона (zoneOuter)**: холодный режим CH₄ до 5% (строго <5%, `rng*0.05`) |
| `nitrogen` | N₂ > 50% | да, **только умеренный режим без жизни (T 250–350)**; на сверххолодных (T<250) N₂ 3–8% (примесь) — **в сиде биомов не используется** (азотно-ледяная тундра гейтится по CO₂, см. §1) |
| `co2` | CO₂ > 50% | да (холодный 90–95%, горячий) |
| `oxygen_free` | O₂ < 1% | да (все не-жизненные режимы) |
| `dense` | P > 1 атм | да (плотные атмосферы) |

Пороги токсичности (числа — предположение, калибровка): SO₂ > 0.1%, H₂S > 0.1%,
Cl₂ > 0.1%, NH₃ > 1%, CO > 1%, CH₄ > 1%, H₂SO₄-аэрозоль > 0.1% — любой превышен → `toxic`.
**CH₄-порог 1% (не 5%)**: генерация даёт CH₄ строго <5%, порог «>5%» не срабатывал бы
никогда (находка @critic №3) — холодные метановые миры (CH₄ 1–5%, внешняя зона)
токсичны по этому порогу. Жаркие серные миры (SO₂ ≈ 1%) — токсичны. Умеренные
токсичные миры на фоне не возникают (см. `toxic`).

**Примечания к набору:**

- **Флаги, заполненные явно (находка @critic «рад/тид не заполнены»):**
  `requires_radiation = true` — радиационные_пустоши, радиационные_ковры; источник
  флага — среда поверхности: P_surf < 0.5 атм (тонкая атмосфера/магнитосфера → радиолиз),
  НЕ радиоактивность ядра (ядро вне скоупа). `requires_tidal_lock = true` —
  терминаторная_зона. `needs_light = false` — хемосинтетические_сады, светящиеся_чащи,
  радиационные_ковры (не-фотосинтетическая жизнь). Остальные биомы — флаги false/пусто.
- **Азотно-ледяная_тундра — честный гейт (находка @critic №1):** сверххолодный режим
  (T 35–60) даёт CO₂ 90–95%, N₂ 3–8% (примесь) — признак `nitrogen` (N₂>50%) недостижим.
  Гейт — `co2, oxygen_free` (CO₂-доминанта атмосферы); имя сохраняет образ Плутона/Тритона
  (льды N₂/CO/CH₄, азот — примесь).
- **Метановые биомы (метановые_моря, углеводородные_равнины, инеевые_рощи) — зависимость
  от внешней орбитальной зоны (находка @critic №9):** CH₄ до 5% даёт только холодный
  режим внешней зоны (zoneOuter); на внутренних/переходных орбитах признак `methane`
  (CH₄>1%) не сработает — биомы рождаются только во внешней зоне.
- **Аммиачные_крио-океаны — источник NH₃ (находка @critic №4):** каскад не выдаёт NH₃
  ни одним режимом; жидкий аммиак достижим только на tuned-мирах 99.2.22 (аммиачные
  расы, NH₃-обогащение). На фоне биом не рождается — осознанная зависимость от подкрутки
  (аммиачные миры — дом аммиачных рас, решение п.16).
- **co2_океаны — достижимость по механике не доказана на сиде (находка @critic №5):**
  комбинация (T 216–304 + P>5.1 + CO₂>50%) вероятна в холодной части (T 216–250, CO₂
  90–95%, толстая атмосфера P>5.1); контроль — §21 п.5 спеки; если в смоуке 0 — биом
  остаётся редким дефолтом (не ошибка, физика жидкого CO₂ требует P>5.1 бар — гейт учёного).
- **Гейты «что физически невозможно» учтены:** вода и метан/аммиак/CO₂ несовместимы
  на одной поверхности (жидкость-гейт, авто-матрица {вода, метан, аммиак, co2});
  метановые миры — бескислородные (`oxygen_free, methane`); H₂SO₄ на горячей
  поверхности не моделируется (венерианские плоскогорья — каменные); фотосинтез без
  света запрещён; высота «деревьев» на высоких g ниже.
- **Гейт биосферы:** все биосферные формы — `ж` (requires_life); земные — жидкая вода
  + `no_toxic` (решение п.19, закрывает @critic №2). Экстремофилы: кислотные_дебри — `toxic`
  (умеренные T — только tuned-миры 99.2.22, на фоне не рождаются); хемосады — геотерма;
  радиационные ковры — радиация. Химический_иней (`toxic`, T 150–300) достижим в
  холодной части (CH₄>1%, внешняя зона).
- **Минеральные «леса»** — НЕ биосфера (жизнь не требуется) — рождаются на стерильных мирах.
- **Отложено (вертикальная/аномальная модель):** облачные плавучие острова, сад нулевого
  тяготения (кандидат ГД-сущности), море «которое дышит» (объединено с термальными террасами).
- **Сверка с материалом учёного (§20 спеки):** стеклянные_поля — legacy-диапазон
  480–600 K (существующая форма «жарко плавит пески»); у учёного импактные тектиты
  200–400 K — расхождение осознанное (legacy сохраняется; импактные стеклянные поля —
  будущий контент). Серные_поля — диапазон расширен до 110–900 K (Ио-тип: средняя ~110 K,
  локально >1300 K), атмосферный гейт снят (Ио — разреженная SO₂, кислотность не обязательна).
- **Bands ↔ вилки сверены (находка @critic №11):** у каждого биома bands пересекаются
  с t_range (мёртвые полосы убраны: раковинная_пустыня/коралловые_рифы — только у;
  терминаторная_зона — ух; песчаные биомы расширены в жаркий пояс 350–500 K — пески
  пустыни 280–500, соляные/танцующие/грозовая 250–400 — жаркий пояс не обеднён
  песчаным контентом).
