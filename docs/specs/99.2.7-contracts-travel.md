Опирается на `11_contracts.md` §11.3 и `14_money.md` §14.5–14.6.

**Порядок работ:**

1. **Эскроу** (`14_money.md` §14.5.2) — контракт как пакет «условия + запертые
   средства». Списание с собственного счёта, без удалённой информации.

2. **Простейший тип — перелёт** (`11_contracts.md` §11.3.4, `14_money.md`
   §14.6.1). Проверка по прибытии, без частичного исполнения, без гонки.
   **Начинать с него.**

3. **Поставка сырья и товара** (`11_contracts.md` §11.3.1) — окно свойств,
   частичная поставка, несколько исполнителей. Гонка при сдаче — блокировка
   строки в БД (`AGENTS.md` §0).

4. **Истечение и возврат** (`14_money.md` §14.6) — без этого деньги утекают из
   оборота.

5. **Отмена только до взятия** (`11_contracts.md` §11.3.1).

6. **Бюджет с пополнением** (`14_money.md` §14.6.3) — для обслуживания роботов.
   Новая форма эскроу.

**Чем проверять.** Красный тест: заказчик публикует перелёт, исполнитель берёт,
летит, прибывает — эскроу раскрыт. Второй: не прибывает в срок — эскроу возвращён.
