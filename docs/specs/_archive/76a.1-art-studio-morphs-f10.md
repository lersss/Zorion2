## 3. Правила вывода морфов (как пересобирался материал)

Формат фраз — дословно как F4/F5 (эталон стиля, коммит `7467d0d`):

- **`beast_forms`**: `a creature with <голова/черта> and <деталь> on a <тело> body, made of <материал>` — 50 фраз на семейство. `<материал>` — из материалов/основ рас семейства (99.2.21 §5 + `basis` из `config/races.json`); `<тело>` — земной зоо-аналог, подобранный под среду семьи; `<голова>/<деталь>` — черты, характерные для среды (иней, кристаллы, туман, плазма, шестерни).

### 4.1. Правила вывода форм/материалов/свечений из слоя robotic

- **`power_source`** → свечение: солнце → тёплый/дневной свет (amber, dawn, solar); геотерма/тепло → раскалённый (white-hot, orange ember); реактор → индустриальный (furnace, warning, exhaust); термопары → слабый/холодный (lantern, dim, cryo); комбинации — смешанные.
- **`materials.categories`** (🪨⭐🔥) + **`axes`** (проводимость↑, твёрдость↑, энергоёмкость↑, плотность↓, токсичность↓, эластичность↑, хим.активность↓) → материал: 🪨⭐ → металл/сплав; 🔥 → топливо/раскалённое; твёрдость↑ → hardened/industrial; плотность↓ → lightweight; эластичность↑ → flexible membranes; проводимость↑ → alloy/mesh.
- **`heat`** → характер поверхности: радиаторы → гладкий металл с рёбрами; горячая_работа → расплав/раскалённый; лёд → крио-керамика/замороженный; среда → холодный металл.
- Конкретика «железо» допустима только для рас, где она в `basis` (51, 58 — «железо»); для остальных — общие «alloy/metal/steel» без бытовых названий.
