## Проблема

`OtherChangeRate` (холод, гравитация, радиоактивность) — последние λ-факторы:
линейная severity с капом на 1, жёсткие нули-обнуления (гравитация в жёстком
нуле → +Inf; холод — полюс B, T ≤ 100 K → +Inf). Это нарушает эталон
«порог-переключатель запрещён» и разрывает единую R-модель. Задача: перевести
все три в **рекурсивные R-компоненты** (доля за секунду, как жара):

```
R_total = R_ест + R_жара(T) + R_холод(T) + R_гравитация(g) + R_радиация(rad)
```

λ-механизм (`OtherChangeRate`, `exp(−λ·Δt)`) **удаляется**: `ChangeComponents`
возвращает только `r` за секунду (одну сумму).

## Разворот подходов — классы форм (правило 14d; для каждой компоненты)

Общий набор классов: **A** степенная от порога/границы комфорта; **B**
экспоненциальная от отклонения; **C** двухрежимная сшивка (как жара:
умеренная зона + критическая, сигмоида); **D** логистическая (насыщение к
R_max); **E** сумма односторонних (для двусторонних факторов). Ниже —
применимость и цена по компонентам.

### Холод R_холод(T), T в K

Целевое поведение: 0 при T ≥ 288 K (граница с жарой/естественной, как
R_жара с другой стороны); монотонный рост при охлаждении; вилки: −50 →
дни-недели, −100 → ~2 недели, −200 → часы-дни (эталон «минуты» для улицы),
−250 → часы.

- **A степенная от 288**: `R = c·(288−T)^n`. Проверено: точки −100/−200 дают
  n ≈ 9.3 — показатель слишком крутой; −50 тогда ~3.9 года, а вилка требует
  дни-недели. **Цена:** один показатель не держит «умеренный холод
  (дни-недели)» + «крио (минуты)» одновременно (наклоны немонотонны, как у
  жары 70→100). Отклоняется.
- **B экспонента от 288**: `R = R_0·exp(−k·(T−288))`. Проверено: k из
  −50/−200 даёт −100 в 5 раз выше вилки («плато» −50…−100 не воспроизводится).
  **Цена:** экспонента не даёт плато. Отклоняется.
- **C двухрежимная сшивка (рекомендация)**: умеренная зона (288…~150 K,
  степенная `R_ум = c_у·(288−T)^0.63`) + крио-зона (<150 K, степенная
  `R_кр = c_к·(150−T)^2.2 + R_ум(150)`), сшивка сигмоидой σ(T) с центром
  ~150 K. Держит все вилки (проверено численно, таблица ниже). **Цена:** две
  формулы + сшивка; коэффициенты калибруются по точкам (как жара).
- **D логистическая**: `R = R_max/(1+exp(−k(288−T)))` — насыщается к R_max,
  −250 и −200 неразличимы (вилка требует разницу 30 мин vs 10 мин).
  **Цена:** малый диапазон на крио-конце. Отклоняется.

### Гравитация R_гравитация(g), двусторонняя

Комфорт 0.8–1.2 g → 0. Вилки: 0.3 → годы (атрофия), 2 → дни-недели,
3 → дни, 5 → часы-дни, 10 → часы.

- **E сумма двух односторонних степенных (рекомендация)**: низкая ветка
  `R_н = c_н·(0.8−g)^3.3` при g < 0.8; высокая `R_в = c_в·(g−1.2)^1.54` при
  g > 1.2; сумма. Держит все вилки (проверено, таблица ниже). **Цена:** две
  ветки, асимметрия показателей (невесомость медленная — n 3.3, перегрузка
  быстрая — n 1.54).
- **A степенная от центра 1g**: `R = c·|g−1|^n` — комфорт 0.8–1.2 не центр,
  в зоне 0.8–1.2 даёт ненулевую смертность. **Цена:** несовместимо с
  комфортным диапазоном. Отклоняется.
- **B экспонента от границ**: две экспоненты — наклоны не монотонны
  (0.3→2 и 2→10 требуют разных k). Отклоняется.
- **C двухрежимная на каждой ветке** — избыточно для гравитации (степенная
  уже держит). Отклоняется.

### Радиация R_радиация(rad), шкала 0..100

Порог включения 20 (фоновый уровень; ниже — 0). Вилки в кратностях дозы:
×100 → годы-десятилетия, ×10000 → недели-месяцы, «за часы» → дни,
«за минуты» → часы. **Предположение (вопрос создателю):** шкала 0..100
логарифмическая — каждые +20 = ×100 дозы; порог 20 = фон. Тогда точки:
rad 40 (~×100) → ~30 лет; rad 60 (~×10⁴) → ~1 месяц; rad 80 (~×10⁶) → ~3 дня;
rad 100 (~×10⁸) → ~6 часов.

- **A степенная от порога 20 (рекомендация)**: `R = c·(rad−20)^n`, n ≈ 7.7.
  Проверено: держит все точки (таблица ниже). **Цена:** большой показатель —
  «порог + резкий рост» (физически: острая лучевая включается порогом);
  шкала логарифмическая — предположение.
- **B экспонента от rad**: `R = R_0·exp(k(rad−20))` — в середине (rad 60)
  даёт ~10 месяцев вместо ~1 месяца. Отклоняется.
- **C двухрежимная сшивка** — избыточно (степенная держит). Отклоняется.
- **D логистическая** — насыщение, rad 100 и 90 неразличимы. Отклоняется.

## Контрольные точки (критерий тестера, допуск «порядок»/±50%; не узлы)

### Холод (R_холод; t_вымир = ln(1e9)/|ln(1−R)|)

| T, °C (K) | Полное вымирание (вилка) | Полное (взято) | R_холод, 1/с |
|---|---|---|---|
| +15 (288) | комфорт (граница с жарой/ест.) | 0 | 0 |
| −50 (223) | ~дни–недели | ~10 дней | 2.44·10⁻⁵ |
| −100 (173) | ~2 недели | ~7 дней | 3.50·10⁻⁵ |
| −150 (123) | — | ~5.9 дней | 3.92·10⁻⁵ (сшивка, σ=0.5) |
| −200 (73) | ~часы–дни (эталон «минуты» для улицы) | ~30 мин | 0.0117 |
| −250 (23) | ~часы | ~10 мин | 0.0349 |

> **Проверка после фикса знака σ (2026-09-14, баланс-тестер):** при T > 150 K
> (умеренная зона) σ → 0 → R_холод = R_ум (степенная от 288, без NaN);
> при T < 150 K (крио) σ → 1 → R_холод = R_кр. Непрерывность в точке сшивки
> 150 K: R_ум(150) = 3.92·10⁻⁵ = R_кр(150) (оба дают одинаковое значение),
> σ(150) = 0.5 → R(150) = 3.92·10⁻⁵. Монотонность: 223 → 2.44·10⁻⁵,
> 173 → 3.50·10⁻⁵, 150 → 3.92·10⁻⁵, 73 → 0.0117, 23 → 0.0349 — возрастает
> при охлаждении ✓.

> наклоны ln t по ln dev немонотонны (40→60: −8.5, 60→80: −5.7, 80→100:
> −8.6) — одна степенная не попадает во все точки точно. Принят компромисс
> n ≈ 6.9, c ≈ 7.0·10⁻¹⁷: попадает в rad 60/80/100 (1 мес / 1.8 дня / 6 ч),
> rad 40 даёт ~10 лет (вилка «годы–десятилетия» ✓, плата за гладкость —
> в 3 раза быстрее целевых 30 лет).

## Рекомендация — итоговые формулы

```
R_холод(T):
  R_ум(T)  = c_у·(288−T)^0.63            при T < 288 K          (c_у ≈ 1.76·10⁻⁶)
  R_кр(T)  = c_к·(150−T)^2.2 + R_ум(150) при T < 150 K          (c_к ≈ 8.2·10⁻⁷)
  σ(T)     = 1/(1+exp(+k_х·(T−150)))     (k_х ≈ 1.0, сшивка ~150 K)
  R_холод  = R_ум·(1−σ) + R_кр·σ         при T < 288 K; 0 при T ≥ 288 K

R_гравитация(g):
  R_н(g) = c_н·(0.8−g)^3.3   при g < 0.8   (c_н ≈ 2.17·10⁻⁷)
  R_в(g) = c_в·(g−1.2)^1.54  при g > 1.2   (c_в ≈ 6.78·10⁻⁵)
  R_гравитация = R_н + R_в                 (0 в комфорте 0.8–1.2)
  гвард: r < 1 (степенная неограничена при экстремальных g; см. §Код)

R_радиация(rad):
  R_радиация = c_р·(rad−20)^6.9  при rad > 20   (c_р ≈ 7.0·10⁻¹⁷, калибровка по 4 точкам); 0 при rad ≤ 20
```

Коэффициенты — **калибруются численно по контрольным точкам** (как жара:
точки — критерий тестера, в коде их нет; предварительные значения выше).

## Согласованность с существующей моделью

- **Сумма:** `R_total = R_ест + R_жара(T) + R_холод(T) + R_гравитация(g) +
  R_радиация(rad)` — все рекурсивные (за секунду); `ChangeComponents`
  возвращает одно `r` (λ-механизм и `OtherChangeRate` удаляются).
- **Комфортные зоны (не пересекаются, ноль смертности):** температура
  288–303 K — только R_ест (холод 0 при T ≥ 288, жара 0 при T ≤ 303,
  естественная — рампа [15,30] °C); гравитация 0.8–1.2 g → 0; радиация
  ≤ 20 → 0. В комфорте по всем факторам R_total = R_ест (планета вымирает
  естественно, полное ≤ 120 лет).
- **Эталоны:** «−200 °C → минуты» ✓ (R_холод(73 K) ≈ 0.0117 → полное ~30 мин;
  для улицы быстрее — в модели «голая среда», поселение — ~30 мин, порядок
  «минуты»); «порог-переключатель запрещён» ✓ — все компоненты гладкие
  (степенные, сигмоиды), жёсткие нули-обнуления убраны (гравитация/холод
  больше не дают +Inf).
- **R_ест / R_жара не меняются** (99.2.12); контрольные точки жары — не
  трогаем.

## Что меняется в коде (код пишет разработчик по этой спеке)

1. **`change_components.go`**: `OtherChangeRate` (λ-механизм, за час) и
   `ColdChangeRate` (полюс B) **удаляются**; добавляются три рекурсивные
   компоненты: `ColdChangeRate` (переписывается — R_холод, за секунду),
   `GravityChangeRate(g)` (двусторонняя), `RadiationChangeRate(rad)`.
   `ChangeComponents(input)` возвращает **одно** `r` (сумму всех пяти,
   без `lambdaPerHour`); `RecursiveChangeRate` переименовывается/расширяется
   до полной суммы.
2. **`mortality.go`**: `TwoSidedSeverity`/`OneSidedSeverity` и полюса
   (`HardZero*`) для гравитации/радиоактивности **удаляются** из расчёта
   (используются только в тестах истории; для холода — полюс B убран);
   `hardZero`/`Uninhabitable` для этих факторов больше не дают +Inf.
3. **Сериализация/витрина**: `lambda_per_hour` = 0 (жара/холод/гравитация/
   радиация — всё в `r_per_sec`); `uninhabitable` — витринный порог
   «t_смерти(p₀) < 1 ч» по полному r (как 99.2.12); возрастной потолок
   120 лет — без изменений.
4. **`NDead`/«Вымерло»/момент смерти**: без изменений (порог p < 1,
   t_смерти = ln(p0)/|ln(1−r)|, дата = created_at + t).
5. **Гвард робастности `r < 1`** (замечание баланс-тестера 2026-09-14):
   гравитационная степенная `R_в(g) = c_в·(g−1.2)^1.54` неограничена сверху
   (при g ≳ 550, R_в > 1) → `pow(1−r, Δt)` с отрицательным основанием = NaN.
   В игре g ≤ ~3 (недостижимо), но защитный гвард обязателен для робастности:
   в `ChangeComponents` (или `Population`) при суммарном `r ≥ 1` возвращать
   «мгновенная гибель» (p = 0 при Δt > 0) либо клампить `r = min(r, 1−ε)`.
   Гвард применяется к сумме всех компонент (рост r < 0 разрешён — обрезка
   только сверху).

## Критерии готовности — тесты (допуск «порядок»/±50%)

`change_components_test.go`:

1. `TestColdRCurve` — R_холод по контрольным точкам: R_холод(288 K)=0;
   R_холод(223 K) ≈ 2.44·10⁻⁵; R_холод(173 K) ≈ 3.50·10⁻⁵; R_холод(150 K)
   ≈ 3.92·10⁻⁵ (сшивка); R_холод(73 K) ≈ 0.0117; R_холод(23 K) ≈ 0.0349
   (±50%).
2. `TestColdRMonotonic` — R_холод монотонно растёт при T → 0 (223→173→150→
   73→23 возрастает); R_холод(288)=0; **непрерывна в зоне сшивки ~150 K**
   (R_ум(150) = R_кр(150) = 3.92·10⁻⁵, σ(150)=0.5); **нет NaN в умеренной
   зоне** (T > 150 K: σ → 0, R = R_ум — знак σ фиксирован, см. §Рекомендация).
3. `TestGravityRCurve` — R_гравитация: 0.8–1.2 → 0; 0.3 → 2.19·10⁻⁸; 0.1 →
   6.6·10⁻⁸; 2 → 4.8·10⁻⁵; 3 → 1.2·10⁻⁴; 5 → 4.8·10⁻⁴; 10 → 1.92·10⁻³
   (±50%); симметрия: R_гравитация(0.8+δ) = R_н(δ) — только одна ветка
   активна вне комфорта.
4. `TestGravityRBothSides` — двусторонность: R(0.5) > 0 и R(1.5) > 0,
   R(1.0) = 0; R(0.5) ≪ R(5) (невесомость медленнее перегрузки).
5. `TestRadiationRCurve` — R_радиация: rad ≤ 20 → 0; 40 → 6.7·10⁻⁸;
   60 → 8·10⁻⁶; 80 → 1.3·10⁻⁴; 100 → 9.5·10⁻⁴ (±50%; n=6.9, калибровка
   по 4 точкам).
6. `TestNoHardZeroOther` — **заменяет старые hard-zero тесты для
   гравитации/холода/радиации**: TotalR(10 g) конечна (≈1.9·10⁻³, не +Inf);
   TotalR(73 K) конечна (≈0.0117); нет ни одной точки с λ = +Inf (порог-
   переключатель убран). Холодные тесты `TestHardZeroCold*` удаляются.
7. `TestTotalRSum` — модульность: R_total = R_ест + R_жара + R_холод +
   R_гравитация + R_радиация (декомпозиция: добавить каждый фактор по
   очереди — сумма растёт на соответствующую компоненту); комфорт по всем
   факторам: R_total = R_ест (288–303 K, 1g, rad 20).
8. `TestREtalonCold` — «−200 °C → минуты»: t_вымир(1e9) при 73 K ≈ 30 мин
   (допуск «порядок»); R_холод(73 K) ≈ 0.0117.
9. `TestRGuardCap` — гвард робастности: суммарный r ≥ 1 (экстремальная g)
   → p = 0 при Δt > 0 (или r клампится к 1−ε), без NaN
   (`pow(1−r, Δt)` с r ≥ 1 не вызывается); рост r < 0 разрешён (не
   клампится).
10. Существующие тесты: жара (R_total, стык, естественная), возрастной
    потолок 120 лет, uninhabitable — сохранить (поведение не менялось);
    `TestGravitySeverity*`/`TestRadioactivitySeverity*`/`TestHardZeroCold*` —
   удалить (механизм linear severity/полюс убран) или переписать на R-версии
   выше.

## Открытые вопросы

1. **Шкала радиации**: вилки в кратностях дозы (×100…×10⁸); отображение на
   игровую шкалу 0..100 — предположение «логарифм, каждые +20 = ×100 дозы»
   (порог 20 = фон). Альтернатива: шкала линейная, тогда точки другие —
   вопрос создателю.
2. **Точные коэффициенты** трёх кривых — калибруются численно по контрольным
   точкам (как жара); предварительные значения в §Рекомендация.
3. **«−200 → минуты»**: эталон задан для улицы; в модели «голая среда»
   (без укрытий) поселение вымирает за ~30 мин — порядок «минуты» соблюдён;
   если нужны строго минуты — поднять R_холод(73 K).
4. **Невесомость (g < 0.3)**: вилка «0.3 → годы»; экстремально низкая g
   (0.01) — физически деградация медленнее, но в модели продолжает расти
   (монотонность) — отдельная физика не нужна, порядок «годы» сохранён.
5. **Радиация — порог 20**: «фоновый уровень планеты» — константа профиля
   человека или свойство планеты? Сейчас — константа (как Threshold=20);
   если у планет разный фон — это расширение, отдельная задача.
6. **`faq_counter.md`**: новые контрольные точки — калибровочные, не FAQ;
   эталоны не менялись (счётчик 0).
