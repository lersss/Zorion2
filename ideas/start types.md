## Введение

Переменные звёзды — это **не отдельный спектральный класс**, а **модификатор**
к уже существующей звезде. Логично добавить поля `variable_type`,
`variable_period_days`, `variable_amplitude`, а не расширять `spectralWeights`.

Реализация разбита по приоритетам с точки зрения геймплея и реализуемости.

---

## 1. Высокий приоритет — стоит добавить

Эти типы либо визуально заметны, либо полезны для игровых механик
(навигация, события, ресурсы).

### 1.1. Цефеиды (классические, I типа)

- **Период:** 1–50 дней
- **Амплитуда:** 0.1–2ᵐ
- **Спектр:** F–K сверхгиганты
- **Особенность:** зависимость «период–светимость» → **стандартные свечи**
  для навигации
- **Геймплей:** определение расстояний, поиск пути

- [ ] Добавить тип `cepheid_classical`
- [ ] Задать диапазон периода и амплитуды
- [ ] Реализовать формулу «период–светимость» (опционально)

### 1.2. Цефеиды II типа (W Девы)

- **Период:** 10–30 дней
- **Спектр:** старые, малометалличные
- **Особенность:** слабее классических цефеид

- [ ] Добавить тип `cepheid_type2`
- [ ] Привязать к Population II

### 1.3. Мириды (долгопериодические)

- **Период:** 100–1000 дней
- **Амплитуда:** до 10ᵐ
- **Спектр:** M, C, S — красные гиганты
- **Визуально:** очень эффектны, «дышат» на карте

- [ ] Добавить тип `mira`
- [ ] Разрешить для классов M, C, S
- [ ] Добавить анимацию (если есть бюджет)

### 1.4. Затменные

- **Подтипы:** Алголь, β Лиры, W UMa
- **Период:** часы–дни
- **Амплитуда:** 0.1–3ᵐ
- **Требование:** **двойная система**

- [ ] Добавить типы `eclipsing_algol`, `eclipsing_beta_lyrae`, `eclipsing_w_uma`
- [ ] Проверять при генерации, что система двойная
- [ ] Визуализация мерцания

### 1.5. UV Кита (вспыхивающие красные карлики)

- **Период:** случайные вспышки
- **Амплитуда:** до 6ᵐ
- **Спектр:** M
- **Особенность:** **самый частый тип переменных**
- **Геймплей:** внезапные вспышки → события, помехи

- [ ] Добавить тип `uv_ceTi`
- [ ] Сделать массовым среди M-карликов
- [ ] Привязать к системе событий

## 2. Средний приоритет — добавить для разнообразия

### 2.1. Новые и карликовые новые (катаклизмические)

- **Состав:** белый карлик + компаньон
- **Период:** годы–тысячи лет между вспышками
- **Требование:** наличие белого карлика
- **Геймплей:** редкое событие, можно привязать к ресурсам / квестам

- [ ] Добавить типы `nova`, `dwarf_nova`
- [ ] Проверять наличие D-класса в системе
- [ ] Привязать к системе событий

### 2.2. T Tauri

- **Спектр:** F–M, молодые
- **Связаны с:** протозвёздами (уже есть тип системы)
- **Геймплей:** привязать к регионам активного звездообразования

- [ ] Добавить тип `t_tauri`
- [ ] Привязывать к регионам с протозвёздами

### 2.3. R Северной Короны (RCB)

- **Спектр:** F–G сверхгиганты, бедные водородом
- **Период:** годы
- **Амплитуда:** до 8ᵐ
- **Особенность:** редкие, пылевые

- [ ] Добавить тип `rcb`
- [ ] Низкая вероятность

### 2.4. Яркие голубые переменные (LBV)

- **Спектр:** O–B гипергиганты
- **Особенность:** очень редкие, мощные выбросы
- **Геймплей:** экзотика, «боссы» среди звёзд

- [ ] Добавить тип `lbv`
- [ ] Минимальная вероятность

### 2.5. Полурегулярные и неправильные

- **Спектр:** K–M гиганты и сверхгиганты
- **Период:** 20–2000 дней
- **Амплитуда:** 0.1–2ᵐ
- **Роль:** «заполнитель» для разнообразия

- [ ] Добавить типы `semiregular`, `irregular`
- [ ] Большая вероятность среди K–M гигантов

## 5. Взаимодействие с существующими типами

- **Сверхновые** — не переменные в обычном смысле, но эруптивные.
  Обсуждались отдельно (см. `02_worlds.md`).
- **Нейтронные звёзды** — пульсары и магнетары. Уже есть тип системы,
  но можно добавить как `variable_type = pulsar` / `magnetar`.
- **Чёрные дыры** — не переменные, но могут иметь переменное излучение
  аккреции (квазары, микроквазары).
- **Протозвёзды** — T Tauri логично привязать именно к ним.

---

## 6. Что НЕ стоит добавлять

- Всё, что не влияет на геймплей и не видно игроку
- Типы, требующие сложной физики (точные кривые блеска)
- Типы, которые дублируют уже существующие механики
  (например, сверхновые уже есть)

## 7. Итоговая рекомендация

### MVP (минимальный набор)

1. **Цефеиды** — навигация
2. **Мириды** — визуал
3. **Затменные** — визуал + двойные системы
4. **UV Кита** — массовость, события
5. **Новые / карликовые новые** — редкие события

### Второй этап

- T Tauri, RCB, LBV, полурегулярные

### Опционально

- Всё остальное — только если появится геймплейная механика
