Цена и память — по периоду; повторы — за всю сессию; срабатывания сторожа — из его журнала (.opencode/loop-guard.log); память — пиковый рабочий контекст агента. Кнопка «продлить» в карточке активной сессии даёт сторожу заявку на продление лимитов (на срок — истекает само). Кнопка «дать работать» в строке сессии — индульгенция: сторож перестаёт трогать эту вкладку (повторы, память, гашение) на срок; «снять» возвращает обычный режим. Сервис читает хранилище сессий opencode только на чтение, цифры обновляет раз в 20 секунд, таймер активности — каждую секунду. Масштаб страницы — кнопками A−/A+.
