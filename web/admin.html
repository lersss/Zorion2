🪐 Среднее количество планет по типу звезды

Mean-модель: n = floor(mean) + Бернулли(frac), потолок 8. Границы: 0 ≤ mean ≤ 8 — значение выше отклоняется сохранением (422). Экзотика: максимум генератора 1 («чаще 0»); протозвезда — 0.

⚖️ Масса звёзд (M☉)

Диапазон массы по типу: равномерно в [мин, макс] (29a §4м). Границы: мин > 0, макс ≥ мин, макс ≤ 100 — иначе отклоняется сохранением (422). Сохранение — кнопкой «Сохранить конфиг» выше.

⏱️ Автообновление карточки планеты

Отладочный режим: пока открыта карточка планеты, данные (в т.ч. пересчитанное население) подтягиваются заново каждые 3 секунды, чтобы вживую видеть динамику на «близнецах». Не влияет на обычных игроков, пока сами не включите здесь.

🔬 Проверка гипотез

Параметрический генератор строит планеты «снизу вверх» по плану осей, разрывая природные корреляции (например, «возраст → температура»). Каждая гипотеза — две группы («эксперимент» и «контроль») с одинаковыми осями, кроме одной варьируемой. Эксперимент перетирает текущую вселенную.

⚖️ Балансировка компонент изменения населения

Кривая R(X) каждой компоненты — сегментная (узлы + изгибы). Узлы — «ключевые изгибы» текущего поведения; ромбики ◆ на середине сегментов задают форму перехода (вверх — выпуклая, вниз — вогнутая). Крестики × — эталоны создателя (цели, не редактируются). Изменения применяются к расчёту населения сразу после «Сохранить» (in-memory, дефолты при рестарте).

Пресет — кривая одной компоненты под именем («Сохранить как» сразу применяет её к расчётам; «default» — заводской, удалить нельзя). Активные пресеты переживают рестарт сервера.

Колесо — зум по Y (точка под курсором не плывёт); зажим ЛКМ на пустом месте — пан по X и Y; drag узла — перемещение; вертикальный drag ромбика ◆ — изгиб сегмента; Shift+клик по кривой — добавить узел; ПКМ по узлу — удалить; клик по стрелочке ▲/▼ за краем — прыжок к объекту.

СПЖ и коэффициент рождаемости настраиваются в Настройках населения (вкладка «Основное») → открыть.
