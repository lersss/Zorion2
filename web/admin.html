🪐 Среднее количество планет по типу звезды

Mean-модель: n = floor(mean) + Бернулли(frac), потолок 8. Границы: 0 ≤ mean ≤ 8 — значение выше отклоняется сохранением (422). Экзотика: максимум генератора 1 («чаще 0»); протозвезда — 0.

⚖️ Масса звёзд (M☉)

Диапазон массы по типу: равномерно в [мин, макс] (29a §4м). Границы: мин > 0, макс ≥ мин, макс ≤ 100 — иначе отклоняется сохранением (422). Сохранение — кнопкой «Сохранить конфиг» внизу общего блока «Конфиг генерации».

⚖️ Балансировка компонент изменения населения

Кривая R(X) каждой компоненты — сегментная (узлы + изгибы). Узлы — «ключевые изгибы» текущего поведения; ромбики ◆ на середине сегментов задают форму перехода (вверх — выпуклая, вниз — вогнутая). Крестики × — эталоны создателя (цели, не редактируются). Изменения применяются к расчёту населения сразу после «Сохранить» (in-memory, дефолты при рестарте).

Пресет — кривая одной компоненты под именем («Сохранить как» сразу применяет её к расчётам; «default» — заводской, удалить нельзя). Активные пресеты переживают рестарт сервера.

Колесо — зум по Y (точка под курсором не плывёт); зажим ЛКМ на пустом месте — пан по X и Y; drag узла — перемещение; вертикальный drag ромбика ◆ — изгиб сегмента; Shift+клик по кривой — добавить узел; ПКМ по узлу — удалить; клик по стрелочке ▲/▼ за краем — прыжок к объекту.

СПЖ и коэффициент рождаемости настраиваются в Настройках населения (вкладка «Основное») → открыть.

❓ Как это устроено — механика за вкладкой

Хемотип — «направление питания» расы: вода, аммиак, метан, сера, градиенты… всего 13. У каждой расы в таблице питания (consumption) эти направления указаны с весами.

Вес — доля направления в диете расы, % (сумма по всем направлениям = 100). Ось с весом ≥ 10 обязательна к покрытию: если её не закрыть — раса голодает.

Окно — диапазон значений осей свойств, в котором ресурс «съедобен» для расы (её собственный диапазон пригодности: для аммиачников токсичное для людей — норма).

«Закрывает» / «кормит» — одно и то же (термин из дизайна): ресурс попадает в окно расы по оси, значит раса может его потреблять. «Ресурс кормит ось» = раса с этой осью в диете получает еду.

Ядерный ресурс — закрывает «свой» хемотип: вода-ресурс кормит водную ось, аммиак-ресурс — аммиачную. 13 ядерных = 13 направлений питания.

Мостовой ресурс — один ресурс закрывает вторичные доли нескольких осей/рас сразу (морская биомасса = вода + органика; органические аэрозоли — органика для углекислых без биосферы).

Посредственность — слой намеренно «средний»: ни один ресурс не закрывает требования товаров (§5.2.2) на приличном качестве. Расы сыты, а торговля жива — хорошие материалы ищут в полях, не в подножном слое.

T_melt / T_boil — температуры плавления/кипения в Кельвинах. Сублимирующий — жидкой фазы нет (лёд → сразу газ, кипение ≤ плавления). Сверхкритический — флюид вокруг критической точки (не жидкость и не газ).
