🏘️ Генерация поселений

Модель генерации: simple — обход всех планет без условий (только шанс + население); complex — правила по полям планеты (все выполняются вместе). Поля и их значения подгружаются с сервера.

🗑️ Очистка поселений

Удаляет только поселения. Планеты, заводы и партии товаров не трогаются — заводы создаются отдельно.

⏱️ Автообновление карточки планеты

Отладочный режим: пока открыта карточка планеты, данные (в т.ч. пересчитанное население) подтягиваются заново каждые 3 секунды, чтобы вживую видеть динамику на «близнецах». Не влияет на обычных игроков, пока сами не включите здесь.

🔬 Проверка гипотез

Параметрический генератор строит планеты «снизу вверх» по плану осей, разрывая природные корреляции (например, «возраст → температура»). Каждая гипотеза — две группы («эксперимент» и «контроль») с одинаковыми осями, кроме одной варьируемой. Эксперимент перетирает текущую вселенную.
